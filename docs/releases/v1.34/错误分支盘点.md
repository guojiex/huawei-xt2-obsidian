## 处理顺序

1. 先实现只接受固定白名单字段的本地诊断记录与设置页查看 / 复制，再用隐私测试约束所有调用方。
2. 按保存 / 草稿与切换、预览桥接、授权 / 文件、Git、分享、设置顺序补反馈和安全恢复。
3. 每项失败路径用可控注入验证；不在设备上强杀、制造崩溃或中断写入。

本表的“待整改”表示静态代码已发现差距，不代表已通过失败注入或设备验收。
