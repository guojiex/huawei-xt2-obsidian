# 设计稿需求对照与版本排期（2026-10-25）

## 1. 结论与计数口径

本次核对当前工作区 `docs/prototype/index.html`、样例生成清单、近期交互说明、需求池、版本需求/提示词，并静态核对原生 `Index.ets`、`AgentWorkspace.ets`、`SettingsView.ets`、`AgentMemoryStore.ets`。工作区包含未提交/未跟踪原生初稿；本轮没有构建或运行 App，不能把文件存在算成验收完成。

按“可以单独实现和验收的一组用户行为”计数，盘点本轮 **15 组** Agent/共用导航/窗口增量，不把重复修复、CSS 行数或同一功能的两个页面算成两项：

- **8 组漏项**：有原型行为或交互说明，但没有独立可验收的版本需求条款。
- **5 组需细化**：已出现在 7.1/7.2 等总项中，但未拆成可领取验收项，实施提示词也没有覆盖最新行为。
- **2 组冲突**：v0.7 已依赖分栏，v1.0 仍安排首次实现；旧的“所有 md 不拖动/每栏最小 18%”也与单屏横屏及 240vp 的最新规则冲突。

本轮已补齐为 **App v0.7 的 7.9–7.23**，没有新增版本号。8 个漏项中包含 **2 组原型演示资产**；它们不要求给 App 真实用户新增演示库或对话。其余 **13 组是产品交互对齐项**，原生仍须逐条实施或核验，不能从本表推断已经交付。

## 4. 已有需求，不重复计入漏项

- 原型中的文件树 CRUD/回收站、Markdown 编辑/图片查看、快切/最近打开分别已有 v0.2/v0.4 需求；共享样例、重置及版本记录已有 v0.5 需求。
- 确定性场景、Tools/Skills、配置快照与本地存储已有 v0.7 7.3–7.8 及独立 Agent v0.1 要求；仍须实施验收，但不是“没有列需求”。
- 图片/MD/ZIP/远端链接分享已有 v0.8；当前原型只覆盖单篇与仓库首页链接，文件夹/整库 ZIP 原型仍缺。这是“已有需求尚未实现”的反向缺口，不混入 8 个漏项。
- 正文搜索、双链/反链、相册/公式/Mermaid 已分配 v1.1–v1.3；假入口和语法示意不代表真实检索、索引、渲染或系统相册已实现。
