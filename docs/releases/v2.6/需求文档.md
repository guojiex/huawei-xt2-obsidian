# v2.6 需求文档 —— 图标整包迁移 HarmonyOS Symbol（SymbolGlyph）

> 状态：开发中（2026-11-23 立项并当日落码；构建 / 测试落码验收见 §6，XT2 逐图标目检待用户执行）
> 来源：[需求池 J 节「图标换 HarmonyOS Symbol」](../../requirements_backlog.md#j-视觉与设计系统design-token)；触发：v2.3 交付的自绘 pin / pinOff 图标被用户反馈「太丑」，追问官方样式参考后确认整包迁移条件已成熟。

## 1. 版本定位

把 `Icons.ets` 的 **45 个自绘路径图标整包迁到官方 `SymbolGlyph`（`sys.symbol.*`）**，图标风格从「自绘 24 viewBox 描边」统一为 HarmonyOS 官方 Symbol（系统应用同款）。调用面 `Icon(name, size, color)` 签名不变（约 112 处调用 / 21 个文件零改动或近零改动），只换实现。

前置阻塞已解除（2026-11-22，[api_notes J-2](../../harmonyos/api_notes.md)）：`sys.symbol.*` 全量名单位于 SDK `sysResource.js` symbol 段（4042 个），45 个图标名逐一核到官方 id（见 §3 映射表），无一缺失。

## 2. 完成判定

全仓 `Icon()` 调用点与内联图标全部渲染为官方 Symbol；映射表 45 个 id 全部编译通过；`arkts_check` 零错误；签名 HAP 构建通过；防线测试全绿零新增回归。XT2 真机逐图标目检由用户执行（见 2.6.6）。

### 2.6.2 `Icon()` 实现切换（签名不变）

- `Icons.ets` 的 `Icon(name, size, color, strokeWidth?)` 内部从 `Path` 换 `SymbolGlyph($r('sys.symbol.xxx'))`：`.fontSize(size)` 定尺寸、`.fontColor([color])` 上色（color 仍走 token，硬约束 17 不破）。
- `strokeWidth` 形参保留但仅对残余自绘兜底生效，官方 Symbol 无描边粗细概念。
- 自绘 `P_*` 常量与 `pathOf/scalePath` 保留（兜底 + Git 历史），不再被默认路径引用。

### 2.6.3 内联调用点迁移

- `FileTreeView` 树行内联 `iconCommands` + `Path`（L-7/Z2 首帧固化 workaround）改为内联 `SymbolGlyph` + `.fontColor([状态变量])`，仍直接绑状态、不走全局 @Builder 按值传参。
- 其余 `Icon()` 调用点因签名不变原则上零改动。

### 2.6.4 pin / pinOff（本版触发点）

- 置顶 / 取消置顶全部入口（树内左滑条、置顶区左滑条、行尾标记、长按菜单项）随整包迁移渲染为 `sys.symbol.pin` / `sys.symbol.pin_slash`，取代 v2.3 的自绘斜图钉。

### 2.6.7 更多菜单与顶栏按钮去重（需求池 P-05，2026-11-23 追加）

- 问题：双 / 三屏顶栏已常显「分享」「同步 Git」按钮（`Index.ets` 顶栏 `!isSingleScreenLayout()` 分支），更多菜单里「分享笔记」「同步到 Git」两项仍重复展示。
- 修复：菜单这两项仅在 `isSingleScreenLayout()` 时渲染——单屏顶栏无这两按钮，菜单保持唯一入口不变；双 / 三屏由顶栏按钮承载。其余菜单项（收藏 / 反链 / 预览 / 跟随 / 切换 / 编辑模式 / 统计 / 屏保 / 设置）不受影响。
- 原型无需改动：`mobileMore` 菜单本就只在单屏显示，双 / 三屏没有菜单入口，无重复问题。

## 4. 明确不做

- **原型 v2（HTML）图标不同步**：原型无法渲染 `sys.symbol` 字体，继续用内联 SVG（lucide）；硬约束 17 的设计真源覆盖 token（颜色 / 圆角 / 间距 / 字号），**图标字形以官方 Symbol 库为原生侧新真源**，原型与原生的图标字形差异登记为已知偏差，不回改原型。**唯一例外（2026-11-23 用户指定）**：`more` 换 `ellipsis_circle` 后，原型 3 处「⋯」触发器（单屏顶栏 mobileMoreTrigger、左右栏 leftMoreTrigger / rightMoreTrigger）同步改为圆圈内三点 SVG，与该 glyph 形态一致。
- Web 侧（编辑器 / 预览 / 分享捕获层）图标不动。
- 不引入 `Hds*` 组件（J-1 结论维持）。
- 不做 `symbolEffect` 动效与多色层 glyph（后续有需求再立项）。
- 不调 `strokeWidth` 视觉微调；不借机改图标尺寸 / 间距 token。

## 5. 技术约束与依赖

- [api_notes J-2](../../harmonyos/api_notes.md)（2026-11-22 更新）：名单位置、编译期 id 硬校验、⚠️ 真机渲染风险与逐图标目检要求。
- L-7 / Z2（全局 @Builder 按值实参首帧固化）：迁移后 color 走 `.fontColor([color])`，约束不变；已内联的调用点保持内联。
- AGENTS 硬约束 17（颜色只引用 token）、18（`sys.symbol.*` id 禁止凭记忆编造——本版 45 个 id 全部核自 SDK `sysResource.js`）。
- `SymbolGlyph` 为 ArkUI 全局组件（API 11+），无需 import。
