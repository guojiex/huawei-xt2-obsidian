# v2.11 需求文档 —— 标签浏览与过滤（v2.1 设计稿原生落码）

> 状态：开发中（2026-11-27 立项；同日两次改稿：标签分区药丸云 → 列表行 → **独立「标签」页签**，见 §1）
> 来源：需求池 B 节「标签 `#tag` 聚合」。设计真源：[v2.1](../v2.1/需求文档.md)（含 2026-11-22 走查追加的 §2.1.6 预览 chip 点击）+ [标签视图设计](../../prototype/v2/标签视图设计.md)（含 v2.11 修订注）。本版把设计稿落成原生 ArkTS：数据层与 v1.40 `search.db` 增量索引合流，侧栏独立「标签」页签 + 点击过滤文件列表 + 预览内标签 chip 点击进入过滤。

## 1. 版本定位

现状：`search.db`（[v1.40](../历史版本归档.md#v140-需求文档)）只索引标题与正文 FTS；标签只存在于预览的静态渲染（mdpreview frontmatter chips），无聚合、无浏览 / 过滤入口。

本版落原生：侧栏独立「标签」页签 → 点击标签把文件树切换为该标签的扁平过滤列表 → 预览内标签 chip 点击同样进入过滤（单屏展开侧栏）。

**形态改稿一（2026-11-27，开发中拍板）**：侧栏标签区从 v2.1 的「药丸云」改为 **Obsidian / Bear 式纵向列表行**（一行一个标签：`#` 引导符 + 标签名 + 行尾计数，选中整行高亮）。理由：侧栏是导航区，主流笔记应用侧栏一律用列表行；药丸是内容区语言，放导航区显得碎、行高不可控；列表行整行 48vp 触达更大、长中文标签省略号不挤乱布局。过滤条当前标签药丸与预览 chip **保持药丸**。

**形态改稿二（2026-11-27，开发中拍板）**：标签浏览入口从「文件页签内嵌分区」改为**独立「标签」页签**——侧栏页签变为**文件 / 标签 / 章节**，标签是整栏高度的独立面板（Obsidian tag pane 模式）。理由：内嵌分区挤占文件树高度（XT2 三栏单栏 200-248px，内嵌分区把文件树推出视口）；标签与「文件」是平级的浏览维度，不是文件列表的子分区；页签天然承担收起，`tags_open` 折叠记忆偏好删除。点标签行 → 设置过滤并**自动切回「文件」页签**（过滤条与结果列表在那里）。设计稿（`docs/prototype/v2/index.html` + 标签视图设计.md）已两次同步改稿。

**数据源拍板**（v2.1 遗留「排期时定」）：采用设计稿推荐项——**合流 `search.db` 增量索引**。新增 `search_tags` 表，随既有 pending → 消化 → hash 对账增量链路维护，免独立全量扫描，也免在 `Index.ets` 的每个变更点（保存 / 移动 / 重命名 / 删除 / 导入 / 回收站 / 备份恢复）另挂独立失效钩子；对账按 contentHash 跳过未变文件，标签天然保持新鲜。放弃「实时扫描 + 缓存」路线：其失效钩子面与本版要接的 mutation 点一一重叠，等于重复造 v1.40 的增量链路。

## 2. 完成判定

- 侧栏页签变为**文件 / 标签 / 章节**；「标签」是独立整栏面板（Obsidian tag pane 模式，v2.11 改稿二），面板标题「标签 · N 个」，标签行为列表行（`#` 引导符 + 标签名 + 行尾计数），按笔记数降序（同数按名称 `localeCompare('zh')`）；当前库无标签时面板显示空态文案；无折叠记忆（页签天然承担收起，`tags_open` 删除）。
- 点击标签行：进入该标签过滤并自动切回「文件」页签，文件树切换为该标签的扁平过滤列表 + 顶部过滤条；再点同一标签行（留在标签页签）或点「清除」恢复完整树；切换标签行直接切换目标；空结果显示空态文案。
- 过滤态：置顶 / 收藏分区暂时收起（数据与展开状态不变）；「全部笔记」分区标签与左滑提示行隐藏；标签已独立页签，不占文件页签高度，无单屏特例。
- 预览内 frontmatter chip 与正文行内 `#tag` chip 可点击：命中当前库标签 → 退出专注、侧栏切「文件」页签、单屏展开抽屉、进入该标签过滤；未命中静默忽略；当前打开笔记不变。
- 防御：切库清过滤；过滤中的标签被删光（改写 / 删除笔记后查询不到）自动退出过滤回完整树；RDB 不可用时标签分区隐藏，文件树 / 搜索既有行为不受影响。
- `tools/tests/test_note_tag_filter.mjs` 全过、受影响回归零新增失败；`arkts_check` 零错误 + 签名 HAP 构建通过。

## 3. 需求清单

来源：[需求池 B 节](../../requirements_backlog.md)「标签 `#tag` 聚合」；交互与聚合口径逐条对齐 [v2.1](../v2.1/需求文档.md) §2.1.2–§2.1.6 与 [标签视图设计](../../prototype/v2/标签视图设计.md)。

### 211.1 数据层：`search.db` 标签合流

- 新表 `search_tags`：`(vault_key, tag_key, tag, path)`——`tag_key` = 小写去重键，`tag` = 保留首个书写形式，`path` = 笔记库内相对路径；主键 `(vault_key, tag_key, path)`。
- `SearchStoreDevice` `SCHEMA_VERSION` `'1'` → `'2'`：升版触发既有「schema 不符 → 整库清空重建」官方口径（文件头注释 AC2），一次性、后台、幂等，代价与 tokenizer 配置变更同机制。
- 写入：`FullTextSearchService` upsert 文档（pending 消化、对账重扫、保存链路共用）时用 `NoteTagParser` 提取标签并整篇 replace 该 `path` 的 tag 行；删除文档（删除 / 移动 / 重命名 / 回收站）连带删除 tag 行。代次守卫沿用：旧代次 upsert 拒绝覆盖。
- 查询：`tagCounts(vaultKey)` → 标签 + 笔记数列表（排序在 UI 侧或查询侧统一）；`pathsForTag(vaultKey, tagKey)` → 命中路径列表。
- 降级：RDB / 建库失败时标签查询返回空集 → 标签分区隐藏（无标签口径），不阻塞文件树与搜索既有行为。

### 211.2 标签聚合口径（新增 `NoteTagParser.ets`，纯函数）

与原型 `docs/prototype/v2/index.html` 的 `frontmatterTags` / `inlineTags` / `validTag` / `noteTagList` 逐条对齐：

- frontmatter `tags:`：行内列表 `[a, b]` 与块列表、带引号 / 裸值均识别（与 mdpreview `renderer.mjs#frontmatterTags` 同源规则）。
- 行内 `#tag`：剥离 fenced code block、行内 code、`$$…$$`、`$…$` 后匹配 `(^|[\s(（])#([\p{L}\p{N}\p{M}\p{S}_/-]+)`；`validTag`：字符集合法且**不能纯数字**。
- 单笔记去重：frontmatter 优先于行内，按小写去重、保留首个书写形式。
- 不跨库：只聚合当前激活库。

### 211.3 侧栏「标签」页签（`VaultSidebar.ets` + `Index.ets`，v2.11 改稿二形态）

- 侧栏页签变为**文件 / 标签 / 章节**：`VaultSidebar` 新增第三个页签按钮与独立标签面板（`sidebarTab` 状态扩为三值），面板不在 `FileTreeView` 内嵌分区。
- 标签面板：面板标题「标签 · N 个」（无标签时仅「标签」）+ 整栏高度滚动列表；空态「还没有带标签的笔记」。无折叠态、无 `tags_open` 记忆（页签天然承担收起）。
- 标签行：列表行——`#` 引导符 + 标签名（超长省略号）+ 行尾小字笔记数；整行可点、触达 48vp；当前过滤项整行高亮（aria-pressed 口径）；标签行自带读屏名。
- 数据加载上提：`tagCounts` 由 `Index.ets` 统一查询后经 `VaultSidebar` 传入面板（与 `sidebarTab` 同一接线层），`FileTreeView` 不再持有标签分区数据。
- 无标签时页签仍可见（空态文案说明），不隐藏页签。

### 211.4 点击标签过滤文件列表（`FileTreeView.ets` + `Index.ets`）

- 点击标签行 → 设置过滤并**自动切回「文件」页签**（`Index` 侧 `setSidebarTab('files')` 既有链路）：文件树切换为扁平过滤列表：命中笔记行复用收藏行形态（首字色块 + 标题 + 行尾所在文件夹；当前笔记高亮），按文件夹路径 + 标题排序（`localeCompare('zh')`）；行点击在当前栏打开（`loadFile` / `loadRightFile` 既有链路）；过滤列表行无左滑操作。
- 过滤条出现在树区顶部：当前标签药丸 + 「清除」；过滤态隐藏「全部笔记」分区标签与左滑提示行（显示的是子集，不再读作「全部」）。
- 过滤态置顶 / 收藏分区暂时收起（只影响显示，数据与展开状态不变；清除后恢复）；标签已独立页签，无单屏特例。
- 再点同一标签行（留在标签页签）或点「清除」恢复完整树；切换标签行直接切换过滤目标；空结果空态文案「没有带「#标签」的笔记」。
- 防御：切库清过滤；过滤中的标签在刷新后查询不到（被删光 / 改写）自动退出过滤回完整树，不留在空过滤态。

### 211.5 预览 chip 点击进入过滤（v2.1 §2.1.6 原生落码，`web/mdpreview` + 桥接）

- mdpreview：frontmatter chip 与正文行内 `#tag` chip 从静态 span 改为 `<button>`（`data-note-tag`），读屏名「按标签筛选：#x」，Enter / 空格可触发；行内 `#tag` 在 text token 层渲染为 chip（fenced code / 行内 code / 数学 token 天然不经过该层，即原型剥离口径的等价实现）；`pointerdown` 阶段拦截 chip（先于 contenteditable 段落选中），简单模式捕获层放行 chip；点击经 `__arkts` 桥（base64 编码，`PreviewWebView` 既有代理通道）发送标签值。
- ArkTS（`Index.ets`）：收标签值 → 按小写匹配当前库标签集合的书写形式；命中：退出专注 → 侧栏切「文件」页签 → 单屏展开抽屉 → 进入该标签过滤（复用 211.4 同一状态与过滤条）；未命中静默忽略，不破坏已有过滤。当前打开的笔记不变。
- 编辑器源码 textarea 内的 `#tag` 仍是普通文本，不做点击。
- 改完 `web/mdpreview/src` 重新打包 rawfile 产物并一并提交（已知坑 3）。

### 211.6 防线测试

  - 行为级（esbuild + vm 装载 `NoteTagParser.ets`，仿 `test_full_text_search_index.mjs`）：frontmatter 各形态（行内 / 块列表 / 引号 / 裸）、行内 `#tag`（含代码块 / 行内代码 / 公式排除）、纯数字拒绝、小写去重保首书写形、frontmatter 优先。

## 4. 明确不做（本版）

- **多标签组合过滤**（AND / OR 多选）：单标签过滤；组合过滤回需求池（v2.1 §4 同款）。
- **标签层级**（`#父/子` 嵌套展开）、**标签重命名 / 合并 / 管理页**、**输入 `#` 自动补全**：均留池。
- **不跨库聚合**（沿用 v1.35 不跨库先例）。
- **过滤状态不持久化**：会话内存态，切库清、重启清；原型 URL `tag=` / `side=tags` 直达是原型专属，原生无对应入口。
- **编辑器源码内标签识别 / 点击**：仅预览 chip 可点（v2.1 §2.1.6 口径）。
- **原型与样例库不再改**：v2.1 已交付设计稿，本版是纯原生实现。

## 5. 红线

- **标签值是笔记内容，禁止进埋点与日志**（硬约束 16）：查询结果、过滤目标、chip 点击值一律不落 hilog；`SearchStoreDevice` 既有隐私口径（无 LIKE、错误日志不带值）沿用。
- **颜色 / 圆角 / 间距 / 字号只引用 token**（硬约束 17）：标签行 / 过滤条 / 分区样式对齐原型 `docs/prototype/v2/index.html` 的 token 用法，组件里禁止散写数值。
- **不新增权限**（硬约束 13）：`search.db` 仍是沙箱内 RDB，无新权限面。
- 分区标签 / 行形态复用 v1.54 / v1.62 / v1.97 已定设计语言，不另起炉灶。
- 笔记写入路径零变化：保存 / 删除仍走 `AtomicFile` 与既有链路，本版只读不改写。
- `build-profile.json5` 保持无签名配置（硬约束 19）。
