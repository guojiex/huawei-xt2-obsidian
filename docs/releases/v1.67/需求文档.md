# v1.67 需求文档 —— 侧栏顶部信息层级精简

> 状态：⚪ 规划中（2026-11-14）；v2 原型已调整，原生未开始，未发布。
> 需求来源：[需求池 Z-01–Z-04](../../requirements_backlog.md#z-侧栏顶部信息层级精简2026-11-14)。用户先要求修改设计稿，随后要求独立版本；同时纠正新增收起按钮与汉堡重复，撤除该入口。
> 设计真源：[v2 原型](../../prototype/v2/index.html)与[左上导航说明](../../prototype/v2/设计说明.md#左上导航精简2026-11-14)。本版为独立导航体验迭代，不新增 M 阶段，不改变现有实施优先级或 App 对外版本号。

## 1. 版本定位

减少进入文件树前的重复标题和说明，使当前知识库与搜索入口清晰可见。将本次已完成的原型调整迁入原生工作区，复用已有库管理、搜索、目录与导航能力。

## 2. 完成判定

单 / 双 / 三屏、简单 / 专业模式与深浅色下，侧栏顶部按「当前库 → 搜索 → 文件 / 章节及相关操作 → 内容列表」组织。数量不重复，库操作可达，页签与操作不挤压或溢出；长库名截断但可查看完整名称。汉堡作为唯一显式导航开关，单屏点正文遮罩仍可收起；专注内导航、焦点与返回行为正常。切库、切栏与旋转保留当前工作状态，不改笔记或丢失编辑内容。

原型、原生源码、自动回归、HAP 构建、模拟器、API24 / XT2 与发布证据分别记录，不能互相代替。

## 4. 明确不做

- 不实现本地 Agent View、不重做正文顶栏或文件树排序。
- 不修改搜索算法、库模型、保存链路、置顶 / 收藏数据与持久化格式。
- 不把 v1.59 今日笔记、v1.54 收藏或其他版本的功能并入本版。
- 不新增导航开关、权限、第三方 UI SDK 或未核实的系统组件。
- 本次仅立项与修正原型；原生实施待按实施总清单领取，不因立项宣称迁移完成。

## 5. 技术约束与依赖

- ArkTS、Stage、API ≤24；鸿蒙 API 结论以 [api_notes](../../harmonyos/api_notes.md) 为准。
- 视觉沿用 v2 token，并按既有映射同步原生资源；组件不散写颜色、字号、间距与圆角。
- 复用现有侧栏、库选择、搜索与导航状态，不新增业务服务或存储；目录栏宽与字号适配沿用 v1.39 的边界。
- 笔记标题、路径、数量等只用于本地 UI，不写入埋点。数据、授权与令牌策略沿用既有约束。
- 自动检查覆盖切库后数量刷新、搜索与库管理入口、页签操作显隐、导航开关、专注与单屏遮罩行为；对应原生变更需完成受影响回归与 HAP 构建。
- 模拟器回归执行前读取仓库模拟器 Skill；API24 / XT2 验收由用户执行。
