# v1.45 需求文档 —— 首发期间可配置小艺对话入口

> 状态：实现中。2026-11-14 用户将原构建期开关调整为应用内设置：默认隐藏主页面小艺入口，用户可在「设置与关于 → 通用 → 小艺入口」随时显示或隐藏。此前 `.local/local-agent-ui.json` 方案由本需求取代。

## 1. 目标与范围

App 首发准备期间，主页面的小艺托管对话入口默认关闭；用户可从设置页自行决定是否显示。设置全局生效并跨重启保存，切换后立即更新主页面入口。该选项只控制入口显示，不启动或关闭其他小艺服务，也不改变 Agent 工作区、端插件工具或笔记数据。

此功能不代表小艺对话或端插件已完成平台发布与验收。系统组件仅在支持该能力的设备上可用。

## 2. 需求与完成判定

| 编号 | 需求 | 完成判定 |
| --- | --- | --- |
| 45.1 | 在「设置与关于 → 通用」提供“显示小艺入口”开关。 | 单屏、双屏和三屏均可找到并操作；开关使用全局应用偏好。 |
| 45.2 | 全新安装默认关闭；用户开启后，笔记主页面显示系统 `FunctionComponent`「Agent 对话」，关闭后隐藏。 | 偏好持久保存；切换即时生效；进程重启后恢复上次选择。首次关闭时不动态加载组件；启用后才加载。关闭时不再渲染入口，进程已加载的模块可留到进程退出。 |
| 45.3 | 保留小艺组件、本地 Agent 工作区与端插件能力，不触碰笔记数据。 | 改动局限于入口偏好、设置行及其调用接线；对照差异确认无其他 Agent 行为变更。 |

设置缺失、损坏或读取失败时一律回退为关闭。写入失败时保留当前运行状态并告知用户；不得因偏好故障阻断笔记功能。应用数据重置清除该偏好后，入口恢复默认关闭。

## 3. 明确不做

- 不提供自动启动小艺、后台运行或通知开关；本项仅控制主页面入口显隐。
- 不删除或改造 AgentKit / FunctionComponent、本地 Agent 工作区、端插件工具或平台配置。
- 不自动开启入口，也不以本地代码或构建结果声称 AppGallery 已上架、Agent 已发布或平台调用已验收。
