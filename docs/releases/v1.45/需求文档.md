# v1.45 需求文档 —— 首发期间暂隐小艺托管对话入口

> 状态：开发中，2026-11-08 用户提出。来源：[需求池](../../requirements_backlog.md)。

## 1. 目标与范围

曜石笔记 App 首次上架前，暂时隐藏主页面顶栏的系统 `FunctionComponent`「Agent 对话」，先完成 App 首发上架。App 上架后再安排 Agent 的后续开发 / 上架；入口恢复时机由后续明确决定，不随 App 上架自动恢复。

仅隐藏主页面托管对话入口，不删除 `AgentKitSlot` 实现，不更改端插件工具、平台配置、本地 Agent 初稿、设置内容或笔记功能。此调整不代表小艺对话或端插件已完成平台发布与验收。

## 2. 需求与完成判定

| 编号 | 需求 | 完成判定 |
| --- | --- | --- |
| 45.1 | App 首发上架期间，笔记主页面所有窗口形态都不显示「Agent 对话」系统组件入口。 | 构建参数 `showXiaoyiDialogEntry=false`，顶栏不构建该入口。 |
| 45.2 | 入口隐藏期间，不加载托管对话组件；保留组件实现供 App 首发后继续 Agent 工作。 | 初始化不触发 AgentKit 动态加载；组件文件与插件实现保留。 |
| 45.3 | 不改变本地 Agent 工作区草稿、设置、端插件工具和其它笔记主页面功能。 | 改动局限于入口开关、加载与渲染条件；差异检查确认无其它 Agent 行为变更。 |

构建开关保存在 gitignore 的 `.local/local-agent-ui.json`，由 Hvigor 同时提供给 IDE 和命令行构建。缺少文件、字段缺失或格式无效时默认隐藏。显示入口时设置：

```json
{
  "showXiaoyiDialogEntry": true
}
```

隐藏时将其设为 `false`；修改后重新构建即可生效。

## 3. 明确不做

- 不删除 AgentKit / FunctionComponent 组件、端插件工具或相关平台配置。
- 不修改本地 Agent Workspace、其数据或设置页。
- 不在 App 首次上架后自动重新显示入口；Agent 后续开发和入口恢复另行明确。
- 不以本地代码或构建结果声称 AppGallery 已上架、Agent 已发布或平台调用已验收。
