# v1.46 需求文档 —— 焦点与崩溃兜底加固

> 状态：开发中，2026-11-08 立项。来源：[需求池 T 组](../../requirements_backlog.md#t-焦点与崩溃兜底加固2026-11-08)；46.7 / 46.9 分别来自 [U 组](../../requirements_backlog.md#u-弹窗按钮状态刷新回归2026-11-08已分配-v146) / [V 组](../../requirements_backlog.md#v-失败信息携带底层错误2026-11-08已分配-v146)。

## 1. 目标与范围

按 2026-11-08 官方答复（[qa 归档](../../harmonyos/qa/2026-11-08_焦点requestFocus错误码与全局兜底答复_API24.md)，结论见 [api_notes L-19 / L-20](../../harmonyos/api_notes.md)）加固两次 DFX JSCrash 暴露的系统性薄弱面：

1. `FocusRequest.safely` 兜底日志区分焦点错误码（T-01）；
2. `EntryAbility` 安装 `errorManager.setDefaultErrorHandler` 全局 JS_CRASH 兜底（T-02）；
3. 修复简单模式纯文本段落宿主的引擎焦点黑框（T-03，v1.18 18.4 遗留场景回流）；
4. `focusEmptyPane` 撤除 `setTimeout(0)` 时序猜测，按 L-20 官方推荐改事件驱动（T-04，2026-11-08 用户追加）。

不改变任何焦点目标选择与产品交互；22 处调用点继续全部经由 `common/FocusRequest.ets` 收口。T-03 仅抑制 ArkWeb 给聚焦 contenteditable 宿主画的默认焦点描边（CSS `outline: none`），光标、格式栏与编辑行为不变。T-04 仅改 `focusEmptyPane` 的请求时机（定时器猜测 → 预查询 + onAppear 事件），目标选择逻辑（`emptyPaneFocusId`）原样保留。

## 3. 明确不做

- 不在 `focusEmptyPane` 之外的 21 处调用点接入预查询 / onAppear 改造：预查询挡不住 150001/150002 与「查询后、请求前销毁」窗口，就地 try-catch 已足够（焦点是尽力而为的 UX 增强）；仅 `focusEmptyPane` 因定时器时序猜测被 2026-11-06 DFX JSCrash 实证过不可靠而改造为 46.5。
- 不把兜底日志接进 `hiAppEvent`、第三方上报或任何埋点通道。
- 不移除、不绕过调用侧 try-catch：全局兜底是崩溃后的观测与可控退出，不替代就地捕获（官方定位）。

### 2026-11-08 追加 46.5（T-04，用户指定：撤除 focusEmptyPane 的定时器时序猜测）

### 2026-11-10 追加 46.12（表格浮条从未弹出：`visualBlockRect` 修复 display:contents 块盒为 0）

- **根因**：`.preview-source-block` 自 v0.9 起 `display:contents`（保证块间排版与无包裹层一致），自身无盒模型 →
  `getBoundingClientRect()` 宽高全 0 → `lockedBlockAnchor` 的 rect 校验（`width <= 0` 等）永远失败 → anchor 从不发布 →
  表格浮条（EM-C4）从未弹出，v1.14 验收未覆盖此项（EM-C4 当时未执行表格浮条断言）。
- **改动**（`web/mdpreview/src/index.ts`）：新增 `visualBlockRect(block)`——块盒宽高均 0 时，取内容子元素盒子并集（
  `DOMRect.fromRect`）；全空或退化（right≤left / bottom≤top）返回 null；块有盒时行为不变。`publishLockedBlockAnchor` 由
  `block?.getBoundingClientRect()` 改用之。rawfile 产物重打包入库。
- **验证**（x86_64 模拟器，简单模式）：双击结构可编辑表格单元格（快速上手「三种形态」表）→ anchor 发布链全通：hilog

  `hasToolbar=true` → 浮条布局（placement=Top）；浮条渲染可见（白色圆角卡片：加号 / 垃圾桶 / 三点图标，截图 `tbl10_crop.jpeg`
  ）。诊断用 DBG 日志（Index / PreviewWebView / blockSelection / WEBCONSOLE 转发共 10 处）验证后已全部剔除，产物同步重打包。

  true），双击产生选区后浮条出现并驻留——与文本块浮条既有交互一致，不在本轮改动范围。
