# v1.50 需求文档 —— Pin 置顶（文件列表）与表格浮条跟随单元格

> 状态：50.1–50.4（Pin 置顶）本地实现完成（2026-11-10），待模拟器 / XT2 目视验收。来源：[需求池 · Pin 置顶（文件列表 / 卡片 / 双栏）](../../requirements_backlog.md)（用户授权「全都做，按顺序」，本版承接该条）。
> 50.5（表格浮条跟随单元格）2026-11-10 追加。来源：[需求池 · X 节 X-01](../../requirements_backlog.md)（用户反馈表格浮条永远在表格正中央，不跟手也不跟被点 cell）。

## 1. 背景

需求池 2026-10-31 条目：笔记可置顶，覆盖列表页、卡片与双栏视图；**置顶是显式排序权重**，与「最近打开 / 收藏 / 星标」互补而非独立容器。

范围裁定：**卡片视图与双栏视图当前不存在**（卡片视图、双栏拆分仍在需求池未实现），本版只做**侧栏文件树（文件列表）**的置顶；待那两类视图落地时在本条目下各自接入。需求池条目按「文件列表」部分交付。

## 2. 需求

### 50.1 置顶语义（显式排序权重）

- **仅笔记文件行可置顶**；目录不参与——树内目录置顶会整体挪动子树、与展开态纠缠，视觉成本高且收益小。
- 置顶笔记在**同一父层内排最前**（高于目录行）；置顶组内按当前排序模式排（name = 字典序升序 / mtime = 降序）。
- 其余行维持 v1.49 规则：目录在前、文件在后，同组按模式排，父先于子 DFS 不变式不破。
- 与排序模式（v1.49）正交：两种模式下置顶权重都生效。

### 50.2 置顶入口

- 文件行**左滑操作条最前**新增置顶按钮：未置顶显示「置顶」，已置顶显示「已置顶」；点击切换，操作条收回。
- 键盘 PathActionsMenu（MENU / Shift+F10）文件行同步增加置顶 / 取消置顶项。
- referenceOnly（Agent 引用侧栏）沿用置顶排序但不显示操作入口（与 v1.49 口径一致）。

### 50.3 持久化

- **按库持久化**（置顶是库内容组织，跟库走，与 ExpandStore 同库不同键）：`file_tree_state` preferences 新增 `pinned_<vaultId>` 键，JSON 字符串数组；坏值回退空数组。
- 置顶行名字尾部显示小 pin 图标（tertiary 色）作状态标记。

### 50.4 陈旧条目边界

- 改名 / 移动 / 删除后旧置顶路径失效（不自动跟随），条目留存于偏好但不再匹配任何行、无副作用；用户对新路径重新置顶即可。不做自动清理（S 体量，收益小）。

## 3. 验收标准

1. 置顶文件在其父层内排最前（高于目录），两种排序模式下均生效。
2. 置顶 / 取消置顶即时重排；偏好按库持久化，重启后保持。
3. LazyForEach 行键含置顶态，切换置顶后行内 pin 标记与顺序正确刷新（faqs-arkui-219 同坑）。
4. 防线：`Icon(` 实参不含 `this.`；目录行不出现置顶入口；referenceOnly 无操作入口。

## 5. 追加 50.5：表格浮条跟随活动单元格（2026-11-10）

### 50.5 背景

- v1.14 14.2 落地表格浮条，v1.46 46.12 修复其「从未弹出」；锚定几何自始至终是**整块** `.preview-source-block` 的矩形——表格即整表，浮条经 `calculateAnchoredPopupLayout`（Index.ets:6160 `centerX = anchorX + anchorWidth / 2`）按 anchor 中心对齐，故永远出现在表格水平正中央，不跟手也不跟被点 cell。
- 2026-11-10 调研：鸿蒙官方菜单 / 选择浮层（`bindSelectionMenu` / `bindContextMenu`，FAQ faqs-arkui-1509「菜单随点击位置弹出」）一律跟随触发点；Obsidian Advanced Tables 用固定侧栏工具、Notion 行列柄贴操作对象——无产品在表格正中央放操作栏。

### 50.6 需求

`publishLockedBlockAnchor`（web/mdpreview/src/index.ts）对结构可编辑表格（`sourceType === 'table' && tableStructureEditable === 'true'`）：

1. 沿现有逻辑先用当前选区 / 保存选区解析活动 cell，更新 `tableActiveRow/Column`（不变）。
2. **新增** `activeTableCellRect`（blockSelection.mjs）：按 `tableActiveRow/Column` 从块内 `table.rows[row].cells[column]` 取活动 cell 的 `getBoundingClientRect()` 作为 anchor rect 上报——浮条出现在被点 cell 的上缘或下缘（沿用既有 `showAbove` 判定与 pane 内 clamp，不新增越界路径）。
3. **回退链**（行为不劣于 46.12 现状）：
   - 非结构可编辑表格 / cell 索引无效 / 表不存在 / cell rect 宽高为 0 → 回退整块 `visualBlockRect`；
   - cell rect 完全在视口外导致 `lockedBlockAnchor` 校验失败 → 回退整块 rect 重试；
   - 整块 rect 也失败 → payload 为空，浮条关闭（现状）。

### 50.7 不做

- Notion 式行列柄、拖拽排序；浮条箭头 / 吸附动画；属性面板（更多 → sheet）的锚定变化。

### 50.8 完成判定

- `web/mdpreview/test/block_selection.test.mjs`：活动 cell rect 优先、回退链三档、非表格块不受影响的断言全绿；`web/mdpreview` 全量测试全绿。
- 受影响防线测试（`test_preview_block_selection.mjs` / `test_preview_follow.mjs`）不新增失败。
- rawfile 重打包产物入库；签名 HAP 构建成功。
- 模拟器 / XT2 目视：点不同 cell 浮条跟随；cell 滚出视口回退表格锚；浮条不越栏。
