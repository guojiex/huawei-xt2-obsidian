# v2.1 需求文档 —— 标签浏览与过滤（设计稿：侧栏标签分区 + 点击标签过滤笔记列表）

> 状态：开发中（2026-11-21 立项；2026-11-22 吸收用户走查反馈，补「笔记预览内标签 chip 点击 → 左侧进入该标签过滤」）
> 版本号说明：初立 v1.100（三位制）；2026-11-21 用户拍板统一采用 R1 两位制顺延口径（同 [v2.0](../v2.0/需求文档.md) 条目），改号 **v2.1**。仅内部迭代编号，非破坏性变更、非对外 2.1（对外版本真源仍是 `changelog.json`）。
> 来源：需求池 B 节「标签 `#tag` 聚合」（`docs/requirements_backlog.md`）。用户提出「增加个版本，设计稿那里设计一下，按照标签展示笔记——按标签过滤笔记」。本版只做**设计稿**：v2 原型 + 样例库标签数据 + 规格文档；**不落任何 ArkTS / 端侧代码**（原生实现留待后续版本，数据源可复用 [v1.40](../历史版本归档.md#v140-需求文档) `search.db` 索引或实时扫描，排期时定）。

## 1. 版本定位

按标签找到并过滤笔记 = 侧栏「标签」分区列出当前库全部标签（按笔记数排序），点标签把「全部笔记」树切换为该标签下的笔记列表（过滤态），可一键清除回到树。本版交付原型设计稿与标签聚合口径定义。

## 2. 完成判定

在 v2 原型（`?ui=2`）中：侧栏出现「标签」分区且按笔记数降序展示标签药丸；点击任一标签，文件树切换为该标签的笔记列表并显示过滤条；点过滤条「清除」或再点同一标签恢复完整树；点笔记预览内的标签 chip，左侧同样切到该标签列表（单屏自动展开侧栏）；URL `tag=` / `tagsOpen` 参数可直达与恢复；防线测试全绿且既有原型测试零回归。

## 3. 需求清单

### 2.1.1 样例库标签数据（真源 `sample_vault/`）

- 给样例笔记补 frontmatter `tags:`（选择形成交叉：部分标签多篇、部分单篇），至少一篇正文含行内 `#标签` 演示行内标签计入聚合。
- 重跑 `python3 tools/generators/build_sample_vault.py` 同步原型内嵌块（该生成器自 v1.82 起只产出原型，App 侧不预置样例库）。

### 2.1.2 侧栏「标签」分区（原型）

- 位置：filesPanel 内，收藏区之后、「全部笔记」分区标签之前（侧栏顺序：置顶 → 收藏 → 标签 → 全部笔记 → 树 → 回收站）。
- 结构复用置顶 / 收藏设计语言（[v1.62](../历史版本归档.md#v162-需求文档)「共用分区标签与行组件」承诺的延续）：`<details class="favorites-folder">` + `.fav-head` 区头「标签」+ 标签总数 + 右端折叠箭头；点区头展开 / 收起。
- 内容：标签药丸流（`#标签` + 笔记数），排序 = 笔记数降序、同数按名称 `localeCompare('zh')`。
- 当前库无任何标签时整个分区隐藏；折叠状态按库记忆；URL 参数 `tagsOpen`。

### 2.1.3 点击标签过滤笔记列表（原型）

- 点击药丸 → 「全部笔记」树切换为**扁平过滤列表**：符合条件的笔记行（复用收藏 / 置顶行形态：首字色块 + 标题 + 行尾所在文件夹；当前笔记高亮），按文件夹路径 + 标题排序；行点击在当前栏打开（与收藏区一致）。
- 过滤条出现在树区顶部：当前标签药丸 +「清除」按钮；过滤态隐藏「全部笔记」分区标签（显示的是子集，不再读作「全部」）。
- 再点同一标签药丸或点「清除」→ 恢复完整树；切换标签直接切换过滤目标。
- 过滤结果为空时显示空态文案；回收站、置顶区、收藏区不受过滤影响。
- 过滤态下置顶 / 收藏分区暂时收起，把侧栏高度让给结果列表（只影响显示，数据与展开状态不变；清除筛选后恢复）；双屏 / 宽屏保留标签分区，方便直接切换过滤目标；单屏抽屉高度有限，过滤态连标签分区一起收起，优先露出结果列表。
- URL 参数 `tag=<encoded>` 记录过滤态，`restoreUrl` 校验标签存在于当前库标签集合，否则丢弃。

### 2.1.4 标签聚合口径（定义，供实现版沿用）

- 聚合范围 = frontmatter `tags:`（复用原型 `frontmatterTags` 解析）+ 正文行内 `#tag`（排除代码块与行内代码）；两者按小写去重，保留首个书写形式。
- 不跨库：只聚合当前激活库；派生库（reading / projects）各自独立聚合。

### 2.1.5 防线测试

- 新增 `tools/tests/test_prototype_tags.mjs`：结构断言（分区 / 药丸 / 过滤条 / 空态）+ 行为断言（聚合、排序、过滤切换、URL 参数）+ token 红线（新增 CSS 无散写颜色）。

### 2.1.6 笔记内标签 chip 点击进入过滤（2026-11-22 用户走查反馈吸收）

- 笔记预览里的标签 chip（frontmatter 属性行的 tag 药丸 + 正文行内 `#tag`）从静态 span 改为 `<button>`（`data-note-tag`），读屏名 `按标签筛选：#x`，Enter / 空格可触发。
- 点击 chip → 侧栏切到「文件」tab 并进入该标签过滤（复用点侧栏药丸的同一状态与过滤条）；单屏展开侧栏抽屉，双屏 / 宽屏确保目录栏可见；专注模式先退出专注；当前打开的笔记不变。
- 标签名按小写匹配当前库标签集合的书写形式；当前库不存在的标签静默忽略，不破坏已有过滤。
- 预览层在 `pointerdown` 阶段拦截 chip（先于 contenteditable 的段落选中），简单模式捕获层也放行 chip，避免点击 / 回车被当作普通段落打开块编辑器；编辑器源码 textarea 内的 `#tag` 仍是普通文本，不做点击。

## 4. 明确不做（本版）

- **不落端侧代码**：`TagService` / search.db 标签表 / ArkTS 组件——全部留给实现版。
- 不做多标签组合过滤（AND / OR 多选）——单标签过滤；组合过滤回需求池。
- 不做标签层级（`#父/子` 嵌套展开）、标签重命名 / 合并、标签管理页、输入 `#` 自动补全——均留池。
- 不做跨库标签聚合（沿用 [v1.35](../历史版本归档.md#v135-需求文档) 不跨库先例）。
- 不做编辑器源码 textarea 内的标签识别 / 点击（仅预览 chip 可点，见 2.1.6）。

## 5. 红线

- 颜色 / 圆角 / 间距 / 字号只引用 token，组件里禁止散写数值（硬约束 17）。
- 分区标签 / 行形态复用 v1.54 / v1.62 已定设计语言，不另起炉灶。
- 标签值是笔记内容，**禁止进埋点**（硬约束 16）；本版纯原型无埋点面，实现版沿用红线。

## 6. 技术约束与依赖

- 唯一改动面：`sample_vault/notes/*.md`（加 tags 真源）、`docs/prototype/v2/index.html`（生成块 + UI 代码）、新增 `docs/prototype/v2/标签视图设计.md`、新增 `tools/tests/test_prototype_tags.mjs`、本需求文档、需求池分配记录、实施总清单立项条目（README 版本索引表按 v1.90+ 惯例不逐行登记）。
- 2.1.6 追加改动面：同一原型的 `tagChip` / `openTagFilter` / 预览 click 委托 / 简单模式捕获层 / chip 样式，规格文档与防线测试同步；无新增文件、无端侧改动。
- 既有原型测试（`test_prototype_v2_url.mjs` 等）必须保持零新增失败。
- 实现版前置：标签提取性能口径（增量 vs 全量扫描）排期时定，可与 v1.40 search.db 增量链路合流。
