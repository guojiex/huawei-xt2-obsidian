## 1. 版本定位

官方 UX 标准要求可滚动内容显示在底部导航条（小白条）下方，仅固定交互控件避让。本仓次级页面（设置等）的滚动内容目前止步于安全区下沿，底部 80px 手势条区只显示根容器底色，与标准不符、用户观感是「一条没用上的灰带」。本版让次级页面的可滚动内容延伸到屏幕物理下沿，滚动时内容从小白条下方穿过；固定控件仍避让。

## 2. 完成判定

API26 模拟器上打开设置页，滚动到底：内容延伸至屏幕物理下沿（dump 边界到窗口底），小白条区域可见滚动内容；最后一条设置项可完整滚动到小白条上方不被遮挡；UndoBar 等浮层控件位置不变（仍在安全区内）。其他次级页面（统计/库管理/Agent/版本记录/隐私政策）同口径抽查。XT2 / API24 由用户手动验收。

## 4. 明确不做

- **不改工作区（三栏笔记视图）**：底部是全宽固定状态条（hint/Statusbar），滚动容器本就无法触达物理下沿；现状底部 80px 由根容器铺 bg_page 作为小白条的沉浸背景，已满足官方标准中「为导航条提供沉浸的背景效果」一项。
- **不改 Agent 页**（验收时确认）：页面底部是固定输入区（正确避让小白条），聊天滚动容器底部被输入区隔开、不与安全区边界重合，无可延伸对象。
- **不改隐私政策页**（验收时确认）：整页 WebView，滚动在 Web 内部，`expandSafeArea` 对 Web 组件行为未验证；如后续需要再立项。
- 不做 `setWindowLayoutFullScreen`、不改 `navigationBarContentColor` / `navigationBarColor`（见 57.3 理由）。
- 不重排次级页面信息架构；只动底部安全区延伸。
- 不改并行版本 v1.56（分享接收）涉及的 EntryAbility 分享处理与 Index.ets 分享入口区域；编辑共用文件用内容寻址。

## 5. 技术约束与依赖

- 环境事实：HarmonyOS API 24 / ArkTS；API26 模拟器仅用于 UI 验收，证据不外推 API24 / XT2 真机（AGENTS.md ABI 节）。
- expandSafeArea 现有 5 处不动（根 Stack / NoteWorkspaceShell Stack 已生效；nav Column 等 2 处失效但属工作区范围，本版不修）。
- 颜色 / 间距只引用 token（硬约束 17）；导航条避让高度走 `avoidAreaChange` 动态值（官方答复，禁止硬编码）。
- EntryAbility 已有 `avoidAreaChange` 监听模式（keyboardInsetPx 先例），扩展 TYPE_NAVIGATION_INDICATOR 分支复用同一监听。
- Index.ets 正被并行工作流编辑（v1.56 分享接收，行号漂移 +50），所有编辑内容寻址（字符串匹配），不按行号。

## 6. 验收记录

### 6.1 原生实现（2026-11-13）

- `entryability/EntryAbility.ets`：`avoidAreaChange` 监听器加 `TYPE_NAVIGATION_INDICATOR` 分支 + 启动时 `getWindowAvoidArea` 补发初始值 → AppStorage `navIndicatorHeightPx`（px）。
- `components/SettingsView.ets`：三处滚动容器（单屏分类列表 / 多屏侧栏 / 内容区）加 `expandSafeArea([SafeAreaType.SYSTEM], [SafeAreaEdge.BOTTOM])`；内容底部 padding 加动态避让。
- `components/ReleaseHistoryView.ets` / `VaultManagerView.ets` / `VaultStatsView.ets`：滚动容器加 expandSafeArea + 内容底部动态避让（四视图均 `@StorageProp('navIndicatorHeightPx')` + 页面侧 `px2vp`）。
- 防线测试 `tools/tests/test_nav_indicator_immersion.mjs`（3 用例：expandSafeArea 存在性 / EntryAbility 发布链路 / 消费视图 StorageProp + px2vp + 禁硬编码），3/3 通过。
- 实验结论回填 [api_notes AE3](../../harmonyos/api_notes.md)：固定宽度不阻碍 bottom 方向扩展（与官方 FAQ 字面表述冲突，实测为准）；expandSafeArea 加在 Scroll 上即内容穿小白条；nav Column 失效真实原因未定。
