# v1.76 需求文档 —— Git 同步：全屏页面 + 左右分栏逐行差异

> 状态：文档立项（2026-11-16）；原型已完成，原生实现进行中。
> 设计真源：[Git 同步页设计](../../prototype/v2/Git同步页设计.md)（§2 结构、§2A 逐行差异）；原型入口 `?ui=2&view=sync`，底部演示脚注「内容差异」直接展开一例。需求来源：用户 2026-11-16 提出「浮窗太丑，改成全面窗口，就像点了配置按钮之后展示的新页面那样」，同日拍板「整个同步改全屏页 + 设计稿和原生一起改」。

## 1. 版本定位

v1.75 已实现推送前逐行差异，但同步入口仍是 `CustomDialog` 浮窗 / 半模态，差异在改动清单里就地展开——空间局促、视觉与「设置与关于」等独立页面不一致。本版把**整个同步界面**从浮窗改为**占满内容区的独立全屏页面**（与「设置与关于」同范式：顶部返回栏、主体分栏、底部操作栏），逐行差异改到右栏独立展示，长文档能看得更完整。

不改变 v1.75 的 diff 数据口径（HEAD ↔ 工作区未提交改动）、native `getFileDiffs` 能力、push-only 与 v1.73 fast-forward pull 安全边界——本版是**呈现形态**改造，数据链与业务语义完全复用 v1.75。

需求池：Git 同步相关条目在 [§C 同步与数据](../../requirements_backlog.md#c-同步与数据)。

## 2. 完成判定

在 Git 知识库打开同步入口 → 进入**占满内容区的全屏页**（顶栏「‹ 同步到 Git + 库名 · 推送到分支」，工作区 / 侧栏隐藏），不再是浮窗 / 半模态 → 左栏为仓库状态卡 + 本地改动清单 + 提交说明，右栏为逐行差异：未选文件时显示占位引导，点某文件右栏显示该文件红绿逐行差异，再点收起、手风琴单开 → 返回 / Esc / 系统返回键退出全屏页回到笔记，焦点回到同步入口；推送 / 拉取各状态与 v1.75 一致。单屏布局下清单在上、差异在下。深色模式可读；笔记正文只在该 UI 内展示，不进日志 / 埋点。

## 4. 明确不做

- 不改变 push-only / 仅快进 pull 的安全边界，不做合并 / 冲突解决 UI。
- 不改变 diff 数据口径与 native `getFileDiffs`（不新增 native 接口、不动类型声明）。
- 不把同步页改成独立 `@Entry` 页面 / router 路由（沿用 Index 内 `topView` 切换范式，与设置页一致）。
- 不新增权限；笔记正文（路径 / 内容）不进 `hilog` / 埋点（硬约束 16）。

## 5. 技术约束与依赖

- **原生外壳**：全屏页挂在 Index `build()` 的次级视图分支（`if (this.topView !== 'note')`），与 `SettingsPane` / `ManagerView` 同级；工作区 `Column` 在 `topView === 'note'` 时才 `Visibility.Visible`，其余隐藏但保持 Web 编辑器挂载。
- **状态与返回**：新增 `gitsyncReturnView: string = 'note'`；`openGitSyncDialog` 前仍需 `flushWorkspaceSaves` 且当前库为 git；`leaveSecondaryView` 加 `gitsync` 分支回 `gitsyncReturnView`；`onBackPress` 对 `topView !== 'note'` 已统一走 `leaveSecondaryView`，无需单独改。
- **组件改造**：去掉 `@CustomDialog`、`controller`、`UtilityDialogShell`；`dismiss()` 不再 `controller.close()`，改为 `onDismiss()` 回调通知 Index 切回 note；保留内部全部 `@Builder`（状态卡 / 分支编辑 / 凭据 / 逐行差异 / 结果 / 页脚）与状态逻辑。
- **右栏布局**：单屏 `singleScreen` 用 `Column`（清单上、差异下，清单限高）；宽屏用 `Row`（左栏固定宽 / 右栏 `layoutWeight(1)`）。颜色 / 圆角 / 间距 / 字号只引用 `app.color.*` / `app.float.*` 或 `Tokens` 常量，不散写数值。
- 真机验收（API24 / XT2）由用户执行后回填 §6.2。
