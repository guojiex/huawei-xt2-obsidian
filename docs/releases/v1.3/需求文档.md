# v1.3 需求文档 —— 丰富 Markdown 内容

> **状态**：🟡 代码、静态检查与 HAP 构建完成；API26 已目视验证有效及无效公式/Mermaid、错误块后的正文；图片导入仍待验证，API24/XT2 与 Git 图片同步待验，不代表版本全部交付或发布
> **对应里程碑**：M8

## 1. 版本定位

补齐在手机上写结构化笔记时常用的内容输入与预览能力。

## 2. 完成判定

可从相册插入图片到当前库并在预览中显示；公式和 Mermaid 图可渲染，折叠切换后内容与附件引用仍正确。

## 3. 需求清单

| # | 需求 | 来源 | 验收点 |
| --- | --- | --- | --- |
| 1 | 图片插入 | 需求池 A「图片插入（相册选择/拍照/粘贴）」 | 本版先完成相册选择，图片保存到当前库并插入相对路径；原图与 Markdown 可一起同步或迁移 |
| 2 | 数学公式渲染 | 需求池 A「数学公式（KaTeX）」 | 行内和块级公式在预览中正确显示；源码仍是普通 Markdown 文本 |
| 3 | Mermaid 图渲染 | 需求池 A「Mermaid 图」 | fenced code block 的 Mermaid 图可预览；非法语法显示错误提示且不影响其他内容 |

## 4. 明确不做

- 拍照、粘贴图片、任意附件、所见即所得编辑：分别保留在需求池，待本版相册路径稳定后再排。
- 图谱：笔记关系可视化是独立需求，不与 Mermaid 混同。

## 5. 技术约束与依赖

图片必须留在当前库可迁移的目录中；路径走统一解析器。相册接口和权限在落码前核对 [`api_notes.md`](../../harmonyos/api_notes.md)，不凭通用移动端经验推断。
