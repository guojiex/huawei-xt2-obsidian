# v1.84 滚动容器边界反馈动效

> 来源：[需求池 AD 节](../../requirements_backlog.md)，2026-11-19 用户对照 AGC《通用应用 UX 体验标准》2.1.5.3.3「滑动过界反馈动效一致性」提出。
> 标准原文：界面滑动到边界位置时（上下滑动到顶部或底部，左右滑动到左边界或右边界），应该有反馈动效；等级「强烈推荐」；系统能力指向 `Scroll` 的 `edgeEffect`。
> 状态：🟡 本地实现完成（自动回归与签名构建通过，设备动效手感由用户执行）。

## 1. 背景与根因

用户提出应用滑动到边界没有反馈动效。核实结论（SDK `common.d.ts`，`edgeEffect` JSDoc）：

- **`Scroll` / `Grid` / `WaterFlow` 默认 `EdgeEffect.None`** —— 无边界反馈。应用内 30 处 `Scroll()` 中 29 处未显式设置 edgeEffect（仅 `EditorMismatchDialog` 一处已显式 Spring），这是缺口的根因。
- **`List` 默认 `EdgeEffect.Spring`** —— 文件树、目录列表、快速切换等 `List` 已有回弹，不动。
- 应用无 `Grid` / `WaterFlow` / `Swiper` 滚动容器。

## 3. 明确不做

- 不给 `List` 补 edgeEffect（默认已是 Spring，显式重复设置无收益）。
- 不动 Web 组件 HTML 滚动、CodeMirror / mdpreview 内部滚动（84.3）。
- 不改 `alwaysEnabled`（沿用默认 true：内容不足一屏仍可拖出回弹，与系统一致）。
- 不新增 changelog 对外版本条目（交互反馈补齐，`versionName` 不动）。
