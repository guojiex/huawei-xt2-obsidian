## 隐私问卷本地事实（源码核对，不是公开政策）

2026-11-02 已打开用户提供的政策，发布前需核对其中关于信息传至中国境内服务器、外部授权目录、Git 同步以及日志可能包含文件名 / 路径 / 字数的表述与最终发布包实际行为是否一致；不凭静态查阅认定正文已合规。

- 沙箱库的笔记和附件位于应用私有空间；v1.5 外部库授权关联原目录、直接读写外部笔记和附件，不能再统一描述为全部只在沙箱。回收站 / 草稿的私有隔离、解除关联边界按 v1.5 验收核对。工作区会话与编辑器偏好使用应用 Preferences。对应 `VaultPathResolver.ets`、`NoteDraftService.ets`、`WorkspaceSessionStore.ets` 和 `EditorPreferenceStore.ets`。
- 用户在同步页导入或操作 Git 库时，应用按该库配置连接远端；仓库地址、分支和非敏感用户名保存在注册表，令牌单独放入 `AssetStoreKit` 的 `SECRET`。对应 `SyncPage.ets`、`VaultRegistry.ets` 和 `GitCredentialStore.ets`。
- 用户主动分享笔记、图片或文件时，应用通过系统 Share Kit 打开分享面板；文本分享会先预览再交接。接收应用及接收结果由用户选择，当前没有备忘录接收可编辑性的证据。对应 `Index.ets` 和 `NoteTextShareService.ets`。
- 反馈页用 `mailto:` 打开邮件应用并填入用户填写的反馈字段；发送动作由邮件应用完成。对应 `SettingsView.ets`。
- 当前模块清单声明 `ohos.permission.INTERNET` 和 `ohos.permission.FILE_ACCESS_PERSIST`。发布前仍须以待提交 HAP 的权限扫描、三方依赖清单和应用市场问卷为准。
- `web/gitbridge/package.json`、`web/mdeditor/package.json` 和 `web/mdpreview/package.json` 中的直接 Web 依赖包括 isomorphic-git、CodeMirror、marked、KaTeX、Mermaid 和 buffer；这是直接依赖记录，不含传递依赖，也不替代最终 HAP 的三方 SDK / 权限扫描。
