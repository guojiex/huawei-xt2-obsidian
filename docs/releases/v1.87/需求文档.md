# v1.87 需求文档 —— Git 同步页设计稿对齐（单屏 / 双屏 / 三屏）

> 状态：已实现（2026-11-19）。设计真源：[Git 同步页设计](../../prototype/v2/Git同步页设计.md)（§2 结构图、§5 组件表）；原型入口 `?ui=2&view=sync`。需求来源：用户 2026-11-19 反馈「同步到git页面，单屏双屏三屏的ui都没有按照设计稿实现」——v1.77–v1.79 落地时原生完成了结构与分组，但未逐项对齐原型 CSS：页面画布仍用 `bg_page`（#E9EDF2，原型 `.sync-page` 是 `--nav` #F5F6F8）、左右内容区零内边距贴屏幕边缘、两张卡无描边无卡头分隔线、宽屏左栏是 40% 弹性宽度（原型 396 固定 + 右侧分隔线）、右栏 diff 非白底、页脚灰底无顶部分隔线。本版只做视觉对齐，不改 Git 语义、diff 数据链与任何交互。

## 1. 版本定位

v1.76–v1.79 定义了同步页的形态与语义（全屏页、左清单右差异、单屏简化），但原生实现与原型 CSS 之间有一批视觉偏差，三种形态都受影响：最刺眼的是内容贴边（原型 `.sync-side` 有 `--s4` 四周内边距，原生宽屏左栏只有 `padding({right:s2})`、单屏滚动流完全没有内边距），其次是画布色、卡片描边 / 卡头分隔线、左栏定宽、右栏白底与页脚样式。本版把原生 `GitSyncDialog` 逐项对齐原型 token：画布 `--nav`、内容内边距 `--s4`、卡片 1px `--line` 描边 + 卡头 `min-height --s12` + 分隔线 + 标题 `--small`/600、状态行包进 `--nav` 底内卡、左栏 `calc(--nav-width * 1.65)` = 396 定宽 + 右侧分隔线、右栏 `--paper` 白底、diff 卡头分隔线、页脚 `--paper` 白底 + 顶部分隔线、文件行选中态左轨。原型本身已是真源，不改。

## 2. 完成判定

打开 Git 库同步页 → **三种形态**内容区四周都有 16vp 内边距、卡片不贴屏幕边缘 → 画布为 `--nav` 底（浅色 #F5F6F8、深色跟随资源）→ 「推送概览 / 本地改动」两张卡有 1px 描边、卡头高 48 且带底部分隔线、标题 14/600 → 状态三行落在 `--nav` 底、10 圆角的内卡里，行 14/600、行高下限 52、标签列宽 64 → 宽屏左栏固定 396 宽并带右侧分隔线，右栏白底铺满、diff 卡头带底部分隔线、行号列带右侧分隔线 → 页脚白底、带顶部分隔线 → 宽屏文件行选中态有 4vp 品牌左轨、文件名 600、统计品牌色 → 深色模式全部跟随资源可读。Git 流程、diff 数据、单屏 v1.79 语义全部不变。

## 4. 明确不做

- 不改任何 Git 语义与数据链：native `getFileDiffs` / `pull_target_branch` / push-only 边界、`GitNativeService`、两份 `Index.d.ts` 零改动。
- 不改原型 `index.html` 与设计文档（原型即真源，本版是原生向原型对齐，方向单向）。
- 不改 Appbar / `Index.ets` 布局链路、`GitSyncPane()` 路由、返回与忙碌保护。
- 单屏 v1.79 语义不变：无右栏 diff、文件行纯信息行、整页单一滚动流。
- 提交字段输入框（`bg_secondary` + `Radius.control`）、「· 必填」标签、拉取链接 `body3`、行号列宽 `Space.s8`（= `calc(--s6 + --s2)`）为已核实的合规映射，不动。
- 不做模拟器 / 真机验收（用户自行验收，实测结果照实回填）。

## 5. 技术约束与依赖

- 颜色只引用 `$r('app.color.*')`（深色自动跟随），数值只引用 `Tokens`（`Space` / `Radius` / `FontSize` / `Size` / `Weight`），组件里不散写数值；396 定宽入 `Size.syncSideW`，600 字重用 `Weight.semibold`（既有 token）。
- `bg_navigation` 浅色 #F5F6F8 / 深色 #171D25，与画布、状态内卡共用同一 token；`bg_card` 浅色 #FFFFFF（`--paper`）/ 深色 #1D232B，与右栏、页脚共用。
- 既有契约断言不得破坏：`ChangeRow` 选中底色分支（`brand_bg` 三元）、`DiffLineRow` 内 `bg_secondary` 恰 2 处、单屏分支不含 `DiffPane()`、宽屏分支含 `DiffPane()`、`v1.84` 全部 `Scroll` 带 `edgeEffect`（本版不新增 / 不删除 `Scroll`）。
- 左轨用 `border({width:{left:Space.s1}})` 近似原型 `border-left` + `inset box-shadow`：机制同源（原型 `.sync-file-toggle` 本身就是透明左轨 + 选中换色）。
- 命令行构建走 `tools/build.ps1`（签名注入见 AGENTS.md 硬约束 19）。
