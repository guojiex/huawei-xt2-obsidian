# v0.11 需求文档 —— 编辑器行号

> 状态：原生实现完成；v2 原型真实浏览器确认开关默认关闭；行号渲染交互与设备验收待补。用户于 2026-10-30 调整顺序，要求先实现本版。
> 来源：[需求池 O-01–O-02](../../requirements_backlog.md#o-编辑器行号2026-10-30已分配-v011)。
> 对应里程碑：M4.12，完整归本版；本轮先于 v0.10 实施，本地版本验收收口前，无日历工期承诺。

## 1. 版本定位

在设置中让用户选择是否在 Markdown 编辑器显示行号，帮助定位源码。

## 2. 完成判定

设置可即时控制左右编辑栏行号，偏好在重新打开后保留，行号与实际源码行对齐；预览和笔记内容不受影响。原型、原生与设备分别验证。

## 3. 需求与验收点

| 编号 | 来源 | 交付与验收 |
| --- | --- | --- |
| 11.1 | O-01 | 设置 → 通用 → 编辑器提供“显示行号”开关，默认关闭；切换即时生效，并持久化到本地应用偏好。重置所有数据时恢复默认 |
| 11.2 | O-01 | 所有知识库共用同一偏好；左右栏各自在编辑模式展示，预览模式不展示，切换模式与笔记不丢失偏好 |
| 11.3 | O-01 | 行号不写入 Markdown，不影响保存、光标、选区、输入法、撤销及编辑/预览跟随 |
| 11.4 | O-02 | 从 1 开始按源码实际行编号，包括空行及末尾空行；软换行不新增行号，滚动、输入、宽度变化后与正文对齐 |
| 11.5 | O-02 | 覆盖单/双/三屏、横竖屏、浅深色、长行、空行和多位行号；开关可访问，行号不拦截编辑操作 |

## 4. 明确不做

- 不增加行号跳转、行选择、其他编辑器设置或预览行号。
- 不修改包版本或发布状态；原型、原生、模拟器与真机证据分别记录。
