# v0.11 需求文档 —— 编辑器行号与首装教程库

> 状态：功能与代码已落地；v2 原型、打包页和 API26 ArkWeb 模拟器均有验收记录。API26 模拟器已覆盖单 / 双 / 三屏行号、双栏共用偏好及重启恢复；方向、主题和更长文档矩阵仍待验。API24 / XT2、应用内重置及既有安装升级检查按本轮目标 skip，不算通过证据。
> 来源：[需求池 O-01–O-02](../../requirements_backlog.md#o-编辑器行号2026-10-30已分配-v011)；首次安装教程库分离见 [K 节](../../requirements_backlog.md#k-共享样例库与渲染基线2026-10-25)。
> 对应里程碑：M4.12；按当前目标顺序，在 v0.9 收口和 v0.10 验收之后继续；无日历工期承诺。

## 1. 版本定位

在设置中让用户选择是否在 Markdown 编辑器显示行号，帮助定位源码；全新安装时分开个人知识库与预置教程库。

## 2. 完成判定

设置可即时控制左右编辑栏行号，偏好在重新打开后保留，行号与实际源码行对齐；预览和笔记内容不受影响。全新安装默认进入教程库并打开《快速上手》，个人库为空；后续启动恢复用户上次选择和工作区状态。

## 3. 需求与验收点

| 编号 | 来源 | 交付与验收 |
| --- | --- | --- |
| 11.1 | O-01 | 设置 → 通用 → 编辑器提供“显示行号”开关，默认关闭；切换即时生效，并持久化到本地应用偏好。重置所有数据时恢复默认 |
| 11.2 | O-01 | 所有知识库共用同一偏好；左右栏各自在编辑模式展示，预览模式不展示，切换模式与笔记不丢失偏好 |
| 11.3 | O-01 | 行号不写入 Markdown，不影响保存、光标、选区、输入法、撤销及编辑/预览跟随 |
| 11.4 | O-02 | 从 1 开始按源码实际行编号，包括空行及末尾空行；软换行不新增行号，滚动、输入、宽度变化后与正文对齐 |
| 11.5 | O-02 | 覆盖单/双/三屏、横竖屏、浅深色、长行、空行和多位行号；开关可访问，行号不拦截编辑操作 |
| 11.6 | 启动缺陷修复 | 首页不静态加载 AgentFrameworkKit；API26 模拟器跳过 AgentKit 动态模块后可正常进入应用；支持设备仍在原顶栏位置加载并显示系统 `FunctionComponent`，不改交互入口 |
| 11.7 | K 节首装知识库分离 | 按 [首次安装知识库决策](../../open_questions.md) 创建空白“我的笔记”和预置样例的“曜石笔记教程”；首次启动进入教程库并打开《快速上手》，后续恢复上次选择和工作区状态；既有安装不迁移或覆盖 |

## 4. 明确不做

- 不增加行号跳转、行选择、其他编辑器设置或预览行号。
- 不修改包版本或发布状态；原型、原生、模拟器与真机证据分别记录。

## 5. 技术约束与依赖

遵循 [仓库开发手册](../../../AGENTS.md)、[v2 设计稿](../../prototype/v2/index.html) 和 [API 真源](../../harmonyos/api_notes.md)；实施时复用现有编辑器及设置持久化机制，API 不得超过 24。不得重建编辑器或改变现有文件与保存语义。
