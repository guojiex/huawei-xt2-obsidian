# v0.11 需求文档 —— 编辑器行号与首装教程库

> 状态：原生设置、应用级偏好与左右栏接线完成；v2 原型及实际打包的 CodeMirror 页面已在浏览器检查开关和行号渲染；ArkWeb + ArkTS 应用内运行、真实 Preferences 恢复与设备验收待补。首装双库拆分与教程库默认选择已实现并通过 HAP 构建，首次安装设备验证待补。
> 来源：[需求池 O-01–O-02](../../requirements_backlog.md#o-编辑器行号2026-10-30已分配-v011)；首次安装教程库分离见 [K 节](../../requirements_backlog.md#k-共享样例库与渲染基线2026-10-25)。
> 对应里程碑：M4.12；按当前目标顺序，在 v0.9 收口和 v0.10 验收之后继续；无日历工期承诺。

## 1. 版本定位

在设置中让用户选择是否在 Markdown 编辑器显示行号，帮助定位源码；全新安装时分开个人知识库与预置教程库。

## 2. 完成判定

设置可即时控制左右编辑栏行号，偏好在重新打开后保留，行号与实际源码行对齐；预览和笔记内容不受影响。全新安装默认进入教程库并打开《快速上手》，个人库为空；后续启动恢复用户上次选择和工作区状态。
