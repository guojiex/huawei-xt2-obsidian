## 1. 版本定位

每个正文栏都能关闭当前笔记，关闭后该栏回到重新设计的空态；**在哪一栏关闭就只清空哪一栏，不收起栏、不改变布局**。

## 2. 完成判定

单屏、双屏、三屏下，左栏与右栏都能从笔记路径行的「×」关闭笔记；关闭后只有该栏变为空态，另一栏、导航、双栏开关和栏宽均不变；空态提供重新打开、新建、搜索与最近打开；空栏状态在工作区会话与复现链接中保留。原生与设备分别验收。

## 3. 需求清单

| # | 需求 | 验收点 |
| --- | --- | --- |
| 28.1 | **关闭入口。** 每个正文栏的笔记路径行（如「00_开始 / 快速上手.md」）右端放 40vp 圆形「×」，读屏名称「关闭笔记：<标题>」。简单 / 专业模式、单 / 双 / 三屏都在同一位置；栏内没有笔记时整行隐藏。 | 路径行在简单模式与单屏同样可见，不依赖被隐藏的栏头 |
| 28.2 | **只关闭所在栏。** 点击后先完成该栏的正常保存，**保存失败则不关闭**并提示原因；成功后只把该栏的笔记置空。不收起右栏、不切换双栏 / 专注状态、不改栏宽、不改另一栏；两栏开同一篇时只关闭点击的那一栏。笔记文件本身不受影响。 | 关闭右栏后右栏仍展开且为空态；关闭左栏后右栏照旧 |
| 28.3 | **单屏停在空态。** 单屏关闭后停留在该栏空态页，不自动打开文件列表或其他笔记。 | 单屏关闭后显示空态，导航保持收起 |
| 28.4 | **空态重做（两栏共用）。** 居中排布：小字品牌名「曜石笔记」（`--caption`、字距 .12em、`--muted`）、品牌标语作标题「把空间，留给思考。」（宽屏 28px、单屏 24px、右栏 20px，600）、说明（宽屏「从文件列表选一篇，或拖到这一栏打开。」；单屏「从文件列表选一篇笔记，或新建一篇。」）；刚关闭过笔记时显示「↶ 重新打开「<标题>」」；操作「新建笔记」（主）+「搜索笔记」，单屏另有「文件列表」；下方「最近打开」最多 4 篇（标题 + 所在文件夹，另一栏已打开的标注「另一栏已打开」，不含刚关闭的那篇）。库里没有笔记时标题改为「空白，是最好的开始。」、说明「这个库还没有笔记。新建第一篇，开始写作。」，只有「新建笔记」。空栏不显示编辑 / 预览栏头。栏状态由区域读屏名称表达（如「左栏未打开笔记」），标题只承担气质，不承担状态（2026-11-05 用户要求：空态放标语文字，取代图标与「未打开笔记」）。 | 新建 / 搜索 / 最近打开 / 重新打开都作用于**该空栏**；左右空态垂直对齐 |
| 28.5 | **焦点。** 关闭后焦点移到该栏的「重新打开」（没有时为「新建笔记」）；从空态打开笔记后焦点回到该栏正文。 | 键盘可完成关闭 → 重新打开的往返 |
| 28.6 | **会话与链接。** 空栏写入工作区会话（v0.9 工作区恢复），重开 App 仍为空栏；原型复现链接用 `left=` / `right=`（空值）表示空栏，不回退为默认笔记。 | 刷新 / 打开 `…&right=` 后右栏仍为空态 |
| 28.7 | **相关入口降级。** 栏为空时，该栏的分享、反链、在另一栏预览、格式栏与缩放控件不可用或隐藏（沿用 v0.9「未选择笔记」规则）；双栏仅一栏有笔记时，专注入口不显示、分栏入口保持。 | 不出现作用于空栏的可点操作 |
| 28.8 | **原型同步。** v2 原型实现 28.1–28.7；保留 `emptyNewNote` / `emptySearch` 元素 ID（左栏空态内）；演示开关「未选笔记」继续可用。 | 原型不作为原生或设备验收 |

## 4. 明确不做

- 不做多标签页、「关闭其他 / 关闭全部」或关闭历史列表；重新打开只记最近一次关闭（按栏、按库）。
- 不因关闭而删除、移动或改名笔记；不改回收站语义。
- 不做关闭确认弹窗（关闭前已自动保存；保存失败直接阻止关闭并提示）。
- 不改变双栏 / 专注 / 栏宽规则（v0.7、v1.8、v1.22）。

## 5. 技术约束与依赖

- 环境事实：HarmonyOS API 24 / ArkTS；包名 `com.jxg.huaweiobsidian`；目标设备 XT2。**禁止凭记忆编造 HarmonyOS API**（`AGENTS.md` 硬约束 18）。
- 关闭前保存复用现有保存 / 草稿链路与 v1.7 工作区目标保护；不新增保存路径，已有文件更新仍走 AtomicFile。
- 空栏状态复用 v0.9 工作区会话恢复的存储键；「最近打开」复用 v0.4 最近打开服务，不另存第二份。
- 视觉 token 以 v2 原型 `:root` / `[data-theme="dark"]` 为准。
