## §2 🔴 中文输入法（**M0.5 spike 的真机部分**）

背景：早期 API 24 x86 模拟器存在输入限制，API 26 arm64 已有基本拼音输入证据；当前仍需完成系统性对照和 XT2 复验。具体边界见 [api_notes B6/L-8](../../harmonyos/api_notes.md)。

**本版本（9344790）起编辑器已接入**：点文件树里的 `.md` 文件，内容会经桥接下发到
CodeMirror 6 编辑器（模拟器已验证桥接双向打通、ready 事件过桥）。
所以输入法要测**两处**：新建笔记对话框（ArkUI 原生，2.1–2.5）+
**编辑器（ArkWeb + CodeMirror，M0.5 spike 的核心决策点，2.6–2.11）**。

| # | 操作 | 预期 | ❌ 什么算失败 |
| --- | --- | --- | --- |
| 2.1 | 点**目录树头部「＋」**，选择笔记类型 | 弹对话框，输入框拿到焦点、键盘弹出 | 对话框不弹 / 键盘不弹 |
| 2.2 | 用**中文输入法**输入 `测试笔记`，点 **创建** | 建成功，**文件树里出现这一篇**（自动展开父目录并选中，状态栏库名后出现文件名） | 中文变乱码 / 空文件 / 树上不出现 |
| 2.3 | 再建一篇**带目录的**：输入 `工程/流式系统/第一篇` | 自动建出两级目录，树上正确嵌套 | 只建了文件没建目录 / 路径错 |
| 2.4 | 输入**非法名字**（如 `../逃逸`、`a/b/c/../../d`）后创建 | 被拒绝并 toast，**树上不出现、不崩** | 逃逸到库外 / 崩溃 |
| 2.5 | 同一名字**建两次** | 第二次自动加后缀（如 `测试笔记 1.md`），不覆盖 | 覆盖旧文件 / 报错 |

### 2B 🔴 编辑器中文输入（CodeMirror 6 in ArkWeb，**M0.5 的决胜项**）

> 这条决定 M2 用 CodeMirror 6 还是降级 TextArea。**重点看「上屏」一瞬间**：拼音组词时正文里出现的
> 应该是带下划线的拼音预览（composition），选词后整词替换——而不是乱码、重复、或光标乱跑。

| # | 操作 | 预期 | ❌ 什么算失败 |
| --- | --- | --- | --- |
| 2.6 | 点文件树里的 **README.md** | 编辑区标题变成 README.md，**正文显示文件内容**（不是空白、不是「源模式」占位） | 空白 / 标题不变 / 内容缺失 |
| 2.7 | 在正文里**点一下**，用中文输入法打 `你好世界` | 组词过程正常（拼音预览 inline 显示），选词后正确上屏 | 拼音直接进正文 / 上屏乱码 / 候选框位置错 |
| 2.8 | 紧接 2.7 **继续打一段长句**（10 字以上，带标点 `，。`） | 整段正确，全角标点正常 | 丢字 / 重复字 / 标点变半角或乱码 |
| 2.9 | 上屏后**按退格** | 一次删一个已上屏的汉字（不是把整个拼音组词吞了、也不是一次删一段） | 一次删多个 / 删不掉 / 删出乱码 |
| 2.10 | 打几个字后**切走再回来**（切库或选另一个文件再选回） | 内容还在（已有自动保存，切文件/切库前应先 flush；重新打开从磁盘读回） | 内容丢失 / 串文件 / 白屏 / 崩溃 |
| 2.11 | 长文档（如 100 行以上）**滚动 + 点中间行输入** | 滚动流畅，点哪光标在哪，键盘弹出不遮挡输入行 | 光标漂移 / 键盘挡住输入行 / 卡顿 |
| 2.12 | 点**目录行尾的 + 按钮**（如 `工程` 行） | 弹对话框，**目录行显示 `工程`**，只打名字 → 建在该目录下，树上出现（模拟器已验点击与预填） | 目录行显示根目录 / 建到根下去了 / 点 + 把目录折叠了 |
| 2.13 | 对话框里**点一下目录行** | 列表展开：第一项「根目录」+ 全部目录（含嵌套，如 `工程/流式系统`）；点一项 → 目录行更新为该目录 | 列表不展开 / 选了没反应 / 没有根目录项 |
| 2.14 | 先点树里一个文件，再点**目录树头部「＋」** | 目录行恒为**根目录**，不继承上次目录 | 继承旧目录 / 建到错误位置 |
| 2.15 | 在某目录下建完一篇，分别点**头部「＋」**与**目录行尾「＋」** | 头部入口预填根目录；行尾入口预填该目录，互不串用 | 预填错误 / 仍按 lastdir 记忆 |

**结论口径**（跑完填一个）：

| 现象 | 结论 |
| --- | --- |
| 2.6–2.11 全过 | **CodeMirror 6 路线成立**，M2 按原计划推进 |
| 仅 2.9/2.11 小瑕疵 | 成立，瑕疵记 api_notes，M2 内修 |
| 2.7/2.8 上屏乱码或丢字（composition 坏了） | **降级 TextArea**，M2 排期调整（预案早已写好） |
| 2.6 内容就不显示 | 不是输入法问题，是内容下发链路问题——**马上告诉我**，我查桥接 |
