## 目标行为

| 场景 | 全局顶栏 | 编辑/预览栏头 |
| --- | --- | --- |
| lg 三屏，目录显示或收起 | 当前库名 | 编辑栏显示当前文件名（含 `.md`，只取路径末段）；预览栏显示“预览” |
| md 双屏，目录显示或收起 | 当前库名 | 编辑栏显示当前文件名（同上）；预览可见时显示“预览” |
| sm 单屏编辑 | 当前笔记名（只取文件名，去掉末尾 `.md`） | 不重复显示文件名，保留现有编辑/预览切换 |
| sm 单屏预览 | 同一篇当前笔记名 | 不再额外显示“预览”标题，保留切换控件 |
| 未选择笔记 | sm 显示“曜石笔记”；md/lg 仍显示当前库名 | md/lg 编辑栏显示“尚未选择笔记” |
| 设置、库管理、回收站、版本记录等次级页面 | 保留各自页面标题 | 保持现状 |

文件树的文件名和选中态照常保留。预览正文中的 `# 标题` 是用户内容，不要自动隐藏、删除、改写或与文件名强制同步。

## 当前实现定位（执行前重新核对）

主要文件：`entry/src/main/ets/pages/Index.ets`。

- `Appbar()`：笔记视图当前统一调用 `currentVaultName()`，所以 md/lg 已符合目标，主要补 sm 分支；保留次级页面标题分支和按钮行为。
- `EditorPane()`：当前把完整 `currentFilePath` 或“源模式”传给 `PaneHead`，需要调整为文件名或空态文案。
- `PreviewPane()`：向 `PaneHead` 传“预览”。
- `PaneHead($$: PaneHeadParam)`：现在统一渲染标题，sm 另有 `SegToggle()`。按形态隐藏标题，但保留栏头和切换控件，核对切换控件仍位于右侧，不因删掉带 `layoutWeight(1)` 的标题而跑到左侧。
- 保持 `@Builder` 的 `$$` 按引用传参模式。标题刷新曾因按值传参失效，见 `docs/harmonyos/api_notes.md` I 组相关记录，不要重复引入该问题。
- 当前 App 与原型的其他差异（例如双屏编辑/预览切换）属于其他任务。此次不新增控件、不调整布局分配，不挂载或卸载 WebView 来解决标题问题。

优先用现有状态派生显示文本，不新增第二份保存的文件名/标题状态，不引入服务或通用标题框架。若已有合适的文件名处理方法则复用；只处理显示文本，禁止改变实际路径。长标题沿用单行省略及现有字号、颜色、间距 token。

## 验证

1. 用含中文、嵌套目录的笔记检查：如 `10_写作/基础排版.md`，宽屏编辑栏头应为“基础排版.md”，单屏顶栏应为“基础排版”。
2. 验证 sm 编辑与预览切换：文件名不重复，切换入口仍可见且位置正确，Markdown 正文标题保留。
3. 切换 sm → md → lg → sm，以及 md/lg 收起与展开目录：库名/笔记名随形态正确变化，当前笔记内容保持。
4. 切换笔记、切库、重命名当前笔记、重命名当前库后核对标题及时刷新；空库/无选中笔记显示上表空态，不残留上一篇名称。
5. 进入已有次级页面、切换形态再返回：页面标题及返回后的笔记标题正确。长中文文件名不挤压按钮、不换行溢出。
6. 执行当前环境可用的项目构建；Windows 可用 `tools/build.ps1`，其他环境沿用已配置的构建方式，不擅自修改 SDK、签名或构建配置。`build-profile.json5` 的 `signingConfigs` 必须保持 `[]`。

这是显示逻辑修复，优先构建与正常 UI 验证，不为它新建复杂测试框架。不在模拟器主动制造崩溃、强杀或写入中断。无法运行的设备/模拟器检查明确标为待验；编译通过不等于设备验证通过。
