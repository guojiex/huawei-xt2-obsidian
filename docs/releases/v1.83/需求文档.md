# v1.83 简单模式空笔记占位文案统一

> 来源：[需求池 A 节「简单模式空笔记占位文案统一」](../../requirements_backlog.md)，2026-11-18 用户截图反馈并拍板。
> 状态：🟡 本地实现完成（自动回归与签名构建通过，XT2 真机核对由用户执行）。

## 1. 背景与现象

用户在 XT2 上把同一篇空笔记 `1.md` 同时开在正文栏与参考栏（简单模式），两栏显示不同文案：

- 活动栏（可编辑）：占位显示「在此输入正文」（`web/mdpreview/src/index.ts` 简单模式可编辑空态分支）。
- 非活动栏（只读镜像）：占位显示「空笔记」（`setContent` 空笔记分支）。

这是 v1.7「两栏开同一篇只保留一个可编辑光标」防冲突规则（`Index.ets` 的 `simplePreviewEditable` / `refreshSharedEditability`）叠加两种空态占位文案后的观感结果：内容一致、可编辑性不同、占位文案不同，用户误以为两栏显示不一样（截图存证：`.local/Screenshot_2026-11-18T082558.png`，不入库）。
