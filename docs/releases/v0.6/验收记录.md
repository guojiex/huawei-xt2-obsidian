### 已知基线

- 用户此前在 XT2 验证过部分小艺能力可用；说“读取‘小艺测试’里的《今天的笔记》”时，小艺回复“应用不支持”。这条用户实测保留为未解决问题，本次不以本地模拟回复覆盖。
- 使用 Codex 内置浏览器只读核对平台：Agent“曜石笔记助手”仍为草稿；`ReadNote` / `0.1.0` 和其余工具行可见；应用关联已开启，测试白名单没有用户组。没有修改平台配置或提交审核。真实绑定/权限可用性、调用资格和已上架版本是否包含新增工具仍待确认。

### App 实现

- 笔记工作区顶栏直接使用系统 `FunctionComponent`，不以 HTML 标记或自绘按钮代替。单屏、双屏和三屏布局共用顶栏入口；系统组件的实际外观及 XT2 排布待设备验证。
- 本地意图配置声明 `QueryNotes`、`ReadNote`、`CreateNote`、`AppendNote`、`EditNote`、`UndoLastEdit`，执行器将这六项路由到 `InsightIntentNoteService`；`ListVaults` 和 `CreateVault` 仍由原执行器处理。
- 六项笔记工具的 `vaultId` 可选（2026-10-30 用户决策，见[需求 §3.4](需求文档.md#34-笔记工具-vaultid-缺省当前库2026-10-30)）：显式传入优先，缺省定位用户当前选择的知识库，未选择时返回 `NO_CURRENT_VAULT` 拒绝；显式传入仍校验注册库、库内相对路径与目标文件。未保存编辑会拒绝后台读取/写入；写入复用 `NoteService` 的保存队列和 `AtomicFile`，内容版本冲突会拒绝覆盖。撤销只处理本次本地操作且目标仍与操作结果一致的情况。
- 小艺面板关闭后只刷新当前仍打开且无未保存编辑的文件；不覆盖编辑器中的未保存内容。
