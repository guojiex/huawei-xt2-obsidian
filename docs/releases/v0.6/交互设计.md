# 小艺：库内 Agent 对话工作区

> 2026-10-25 用户确认：App 内类似 ChatGPT 的对话页，左侧有对话列表，可把笔记拖进输入框；首期单知识库内对话，未来再讨论联合多个本地库。写入直接执行并展示结果，每次可撤销。当前仅产品设计与离线原型，真实小艺接入仍在末尾外部依赖队列。

## 1. 核心场景：读书笔记的来回讨论

只读参考用户库中的阅读日记、书籍索引和“问题导读掌握循环”的组织方式：读前设问 → 阅读后的个人回答 → 诊断与追问 → 下一轮讨论 → 沉淀概念或行动笔记。不复制私人正文、对话、个人经历或文件名到公开样例。

公开演示使用原创 `sample_vault/notes/40_阅读/读书对话练习.md`，不是实际书籍摘录。界面保留多轮消息与引用来源；本轮不把提问、诊断做成固定向导，用户可以自由对话。

## 2. 信息架构与三形态

入口：在原型版本标注选择 v0.6 → 查看该版 UI，进入独立“小艺对话”页。笔记页顶栏也有同版“小艺”入口；返回回到笔记页，再进入可继续当前对话。

| 形态 | 导航 | 聊天与引用 |
| --- | --- | --- |
| lg 三屏 | 左侧一屏，上半区对话列表、下半区文件列表，同时可见 | 右侧两屏为聊天区；从文件列表拖入输入框添加引用，避免把聊天挤成窄列；分界沿现有三等分边界 |
| md 双屏 | 左侧一屏，“对话 / 笔记”切换共用列表槽 | 右侧一屏持续显示聊天，切到笔记后拖入；也可点击引用 |
| sm 单屏 | 默认全屏聊天；“对话 / 笔记”和“＋ 引用笔记”打开应用画布内导航抽屉 | 选笔记后自动回聊天；点击引用是完整替代路径，触屏无需成功拖拽 |

不是把弹窗画在手机下面，也不同时新增第四栏。面板内容独立滚动，输入框在聊天区底部；窄屏操作允许换行、长路径折行，不用裁切文本。

## 3. 对话、知识库与引用

- 每段对话固定属于一个知识库。顶栏切库后切换到该库自己的对话列表、草稿与引用，不把原对话迁移到另一个库。
- 新对话初始不附带笔记；拖入/点击后形成可移除的引用卡片，显示文件名。文件列表与消息引用展示完整相对路径以区分同名笔记。
- 发送时读取明确引用的笔记内容，消息保留本轮引用的内容快照；后续追问可以沿用本段对话的引用。原型保留这些快照，但不调用模型。真实平台传递方式与范围告知须待能力核实，不能承诺全部内容只在端侧处理。
- 拖入只添加引用，不移动文件；拒绝跨库或外部文件拖入。引用失效不猜目标，要求重新选择；多个引用先逐个显示，写入目标必须明确。
- 第一版不支持跨库联合检索/对话；该意愿留在需求池，不提前做跨库权限与索引。
- 原型对话历史、草稿和写入仅在浏览器内存，刷新恢复；真实对话存储、平台上下文与持久化契约仍待接入阶段确定，不假装原型已持久化。

## 4. 写入直接执行，结果内撤销

对话本身不默认改笔记。用户明确要求创建/追加/替换，或点击“追加到引用笔记 / 存为新笔记”后直接执行，不再弹修改预览确认框。多篇同名或目标含糊时先澄清对象，澄清不是重复确认已明确的写入指令。

消息内显示：操作结果、完整目标路径、修改前后内容、“查看笔记”“撤销这次操作”。新建重名沿用不覆盖策略并显示实际名称。撤销只覆盖最近一次操作；文件有后续编辑、其他写入或目标变化时拒绝覆盖。失败保留原文、对话和输入，不返回假成功。

原型可点击体验追加、新建及一次撤销；每张写入结果独立显示，只有最近一次可实际撤销。锚点替换的真实工具仍按需求 §3 约束实施，本次不提供假模型自动定位效果。未保存编辑或引用后内容变化均拒绝过期写入，提示重新引用；连续操作先核对最新原文。

## 5. 状态与平台边界

- 顶部始终标注“小艺尚未开通、预设演示回复、仅影响本页”，自由输入会出现明确标注的预设追问，不假装真实推理。
- 支持空问题、空候选、移除引用、切换对话/库、引用变化、重复写入、撤销冲突等状态。
- 中文输入法 composition 期间 Enter 不发送，Shift+Enter 换行；无拖拽也可完成引用。
- 真实流式生成、停止、失败重试、授权、冷启动和小艺平台能否承载/回传这种 App 内聊天，必须核实 API 24 与平台契约。此页是我们自己的产品工作区，不声称是可直接嵌入的平台原生聊天控件。
- 不新增系统小艺入口作为首期产品承诺；不做批量改写、整篇/整库删除、自动 commit。历史平台调查保留。

## 6. 设计验收

必须检查：进入/返回、两段对话切换与新建、多轮输入、引用/移除、拖入与点击替代、库隔离、追加/新建、结果查看与撤销，以及后续编辑时拒绝撤销。sm/md/lg、长路径、中文输入、浅深色、列表和聊天区滚动需视觉与交互验收。

自动化逻辑与静态检查和真实视觉验收分别记录；当前平台、API 24 与 XT2 均未接入。设计完成不改变外部依赖排期。
