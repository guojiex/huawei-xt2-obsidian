# 小艺：笔记页入口与托管对话面板

> 2026-10-26 用户确认：在我们的笔记界面点击按钮拉起小艺智能体，在小艺面板里聊天，通过端插件操作本地笔记。此设计替代本版原先依赖 App 自有聊天页的方案。仅调整设计、需求与离线原型；真实接入仍等待开通和重新排期。

> **2026-10-27 入口修订**：按客服建议与官方指南，入口由 `FunctionComponent` 本身提供，设置标题“Agent 对话”以呈现按钮样式并放在原入口位置。普通 ArkUI Button 没有公开的启动面板 API；不覆盖组件外观、不叠放自绘按钮。平台组件的视觉细节由系统控制，原图标不能保证保留。路线明确不自动恢复 v0.6 排期。

## 1. 职责与范围

App 提供“Agent 对话”入口、本地笔记工具、编辑保护和一次撤销；小艺承载聊天、模型调度与平台会话。接口依据只引用 [api_notes F1 / F12–F13](../../harmonyos/api_notes.md)，不把小艺当成自有聊天页的模型 Provider。

[v0.7 本地工作区](../v0.7/交互设计.md) 保留为独立 mock 与本地 Agent 工程，其对话列表、拖入引用、系统提示词设置不再是小艺接入前置，不删除已有原生工作。

## 2. 主流程

1. 用户打开笔记，在顶栏点击 `FunctionComponent` 入口。设置标题“Agent 对话”，放在原入口位置；由用户直接点击该系统组件拉起小艺托管面板，不用普通自绘 Button 调用，也不采用 Stack 覆盖。单屏也保留入口可见，不藏进更多菜单；实际宽度、图标和平台组件留白按系统渲染验收。
2. App 先完成当前编辑的正常保存，失败则留在笔记页，显示原因并允许重试。空库或未选笔记时提示先打开笔记，不默默读取其他笔记。
3. 成功后拉起指定笔记智能体。初始问题只用于引导阅读/整理；不会在点击时自动把整篇笔记拼入问题。当前库/笔记范围由 App 本地记录，定位参数如何可靠传给平台仍需联调。
4. 用户在小艺面板里输入问题或明确写入指令。需要读取、创建、追加、锚点编辑或撤销时，由端插件调用本地受控工具。工具成功后小艺根据真实结果回答，不把请求发出视为完成。
5. 用户关闭平台面板回到笔记，App 按实际文件结果刷新。保留原笔记、编辑/预览状态与导航布局；光标和滚动尽量恢复，具体行为须真机验证。

## 3. 面板与三形态

小艺面板属于平台交互，不在 App 内新建聊天列表、消息气泡、流式接收器或会话持久化。会话创建/历史/关闭行为以平台为准；不承诺每次都新建会话或能直接删除平台会话。

sm/md/lg 均从同一顶栏入口拉起，不增加第四栏，也不把 v0.7 聊天区嵌入笔记分栏。原型以窄屏底部、宽屏右侧卡片表达交接过程，**尺寸、位置、遮罩和外观不是系统组件契约**；正式 App 以实际组件呈现与三形态验收为准。

## 4. 工具范围、结果与撤销

端插件名称、六项工具名称及模型可见描述见 [端插件设计](端插件设计.md)。

本地授权范围固定为发起时的库和目标笔记，不能仅依赖大模型记住范围，也不能直接使用工具执行时的全局 currentVault。切库、目标失效、权限撤回或缺少有效上下文时拒绝操作，提示用户返回目标笔记重新发起。创建笔记的目标目录也限制在已授权库中。

明确修改指令直接执行，不增加重复的修改确认弹窗；目标含糊先澄清。先读后改、唯一锚点、版本冲突检查、AtomicFile 与一次前像继续复用本地服务。工具返回实际路径、成功/失败及可供解释的结果；小艺如何呈现查看/撤销入口须按端插件支持能力核实，不假定能够注入任意原生按钮。

关闭面板不自动撤销已完成写入，也不意味着平台请求已取消。后续调用必须继续检查本地授权上下文。回到 App 后展示实际变更与可用的一次撤销；有后续编辑则拒绝覆盖。

## 5. 不可用与设置

小艺不支持、智能体不可用、网络异常或拉起失败时留在笔记页，用简短提示说明，可重试，不自动切入本地 mock，不弹空白聊天页。账号登录、协议与权限交互由正式平台流程承载，不在原型伪造授权成功。

小艺的角色指令、插件编排、模型和会话由平台配置；App 的本地 Agent 提示词/Skill 设置不宣称能修改小艺。首期不新增自定义 agentId、模型或 API Key 设置。必要的用户范围告知与正文处理边界待平台联调确认，不承诺读出的笔记正文只在端侧。

需检查：sm/md/lg、浅深色、窄横屏下 FunctionComponent 入口与关闭可达；键盘焦点只在示意面板内，Escape 返回；追加后回到笔记可见真实演示内容，撤销恢复；本地 v0.7 mock 仍可独立打开。原型按钮只是交互示意，不复刻系统组件外观。
