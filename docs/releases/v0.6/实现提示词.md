## 用户确认的产品交互（2026-10-26，替代旧自有聊天页假设）

以本版交互设计为准：笔记顶栏“Agent 对话”拉起指定平台智能体，用户在小艺托管面板聊天，单 Agent 通过端插件调用本地笔记工具。App 负责保存协调、发起范围、写入安全、返回刷新与撤销，不实现小艺消息列表或将其接到 v0.7 MockProvider。

平台会话管理与模型/提示词配置归平台；App 不承诺强制新会话、会话迁移、消息流回调或任意平台消息按钮。入口采用何种 UI 需先按 [api_notes F1](../../harmonyos/api_notes.md) 解决与原按钮设计的冲突，再验证 agentId、queryText、支持查询和面板开关事件及端插件的目标上下文绑定与结果展示。未核实上下文时不得以全局当前库代替授权。打开失败不进入 mock，关闭不冒称请求已取消。

工程当前 SDK/target 为 API 26，兼容下限仍为 API 24；按已核实的接口版本实施，不擅自修改兼容策略。真实接入暂缓不因本次设计修改自动解除；只领取已重新排期的任务。v0.7 本地工作区独立保留，不是小艺 UI 或会话存储。
