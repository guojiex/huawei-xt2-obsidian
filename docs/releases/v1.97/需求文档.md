# v1.97 需求文档 —— 收藏列表原生落码（侧栏收藏区 + 文件行星标 + 菜单入口）

> 状态：开发中（2026-11-21 立项落码）
> 来源：[需求池 · 最近打开 / 收藏 / 星标](../requirements_backlog.md)——「收藏」部分；设计稿与规格由 [v1.54](../历史版本归档.md#v154-需求文档) 交付（第三稿，经用户走查），本版为其**原生落码**；「星标」仍留池。

## 1. 版本定位

把 v1.54 已设计的「收藏」独立容器原生落地：侧栏「置顶 → 收藏 → 全部笔记 → 树」四段布局、文件树笔记行行尾星标切换、笔记级「⋯」菜单收藏入口，以及收藏数据的全生命周期接线（永久删除清理、改名 / 移动 retarget）。

## 2. 完成判定

任意笔记（含折叠文件夹内）收藏后，侧栏「收藏」分区**立即出现该行**并可点击打开；取消收藏后行消失；文件行星标、「⋯」菜单项与收藏区三处状态即时同步；重启保持；既有数据零迁移（本版为新增键，无旧数据）。

## 3. 需求清单

### 97.1 收藏区（54.1 原生落码）

- 位置与显隐：置顶区之下、目录树之上；仅当前库至少有一篇收藏且非 referenceOnly（Agent 引用侧栏）时显示；按库隔离；「全部笔记」分区标签在置顶 / 收藏任一区可见时显示（v1.67 67.5 口径）。
- 区头 = 分区标签（与置顶区共用形态）：「收藏」+ 篇数，caption 字号、字重 500、字距 0.08em、muted 色；折叠箭头区头右端常显（原生不做指针类型判断，v1.62 先例）；点区头任意处展开 / 收起，折叠状态按库记忆、默认展开。
- 行形态与置顶区行**共用同一行组件**（v1.62 承诺「收藏落地时共用分区标签与行组件，不写两套」）：首字色块（callout 色板按所在文件夹哈希，同文件夹同色）+ 标题 + 行尾所在文件夹（只显示最近一级，根目录显示「根目录」，最多占行宽 40%）；当前笔记仅标题变品牌色，不加底色；区内滚动上限约 5.5 行；收藏时间倒序（最新在前）。
- 移出收藏：
  - 触屏左滑：「改名 / 移出收藏」两按钮，**滑到底松手 = 移出收藏**（提示「· 松手移出」，非删除语义，54.1 第三稿）。
  - 指针设备：行悬停 / 键盘焦点时行尾文件夹名原位换成「移出收藏」图标按钮（实心星，muted）。
  - 均给 toast「已取消收藏：X」。

### 97.2 收藏入口（54.2 原生落码，含一处原生口径修订）

- 文件树每个**笔记行**行尾、跨栏图标之前，增加星标切换按钮：未收藏 = 描边星（muted）、已收藏 = 实心星（muted，16vp）——收藏状态已由顶部收藏区表达，树内不抢视觉；目录行不加。
- **原生口径修订（54.2「指针设备悬停降噪」原生不做）**：v1.54 设计了「指针设备未收藏星标默认隐藏，悬停 / 当前行 / 焦点时出现」；原生无法区分触屏与指针设备，XT2 触屏优先，未收藏描边星**常显**（muted 已降噪）。沿用 v1.62「原生不做指针类型判断」先例；原型 hover 降噪保持不动，两侧按需求有意不同步。
- 「⋯」菜单「当前笔记」组新增收藏切换项（「分享笔记」之后）：label「收藏此笔记 / 取消收藏此笔记」动态反映状态，作用于激活栏笔记（`activeFilePath()`），无笔记时禁用；与星标入口即时同步。
- 点击切换 toast「已收藏：X」/「已取消收藏：X」；树行星标与收藏区即时同步刷新（LazyForEach 行键含收藏态，faqs-arkui-219 同坑）。

### 97.3 数据与生命周期（54.3 原生落码）

- 新增 `FavoriteStore`（`model/FileTree.ets`，与 PinStore 同库同款）：`file_tree_state` preferences 的 `favorites_<vaultId>` 键（JSON 字符串数组；数组顺序即收藏先后，渲染逆序 = 最新在前，与 Pin 同构）；折叠键 `favSectionOpen_<vaultId>`（布尔，默认展开，坏值回退展开）。
- 收藏行解析复用 `FileTree.pinnedNotes`（标题 / 文件夹 / 首字 / 色板与置顶区同一纯函数，不写两套）；删除进回收站 = 快照交集自然隐藏、关系保留、恢复自动回显；陈旧条目无副作用不自动清理。
- **永久删除**：从收藏列表移除——单条永久删除（`doPurgeFromTrash`）与清空回收站的成功条目（`doEmptyTrash` · `outcome.succeeded`）调 `FavoriteStore.removePaths`；补齐 [v1.55 55.3](../历史版本归档.md#v155-需求文档) 登记的「收藏清理原生空操作」遗留。
- **重命名 / 移动**：`FavoriteStore.retarget`（54.3「收藏区标题与文件夹标注跟随树数据，收藏关系不丢」）——与 Pin 陈旧口径（50.4 不 retarget）**有意不同**，按 v1.54 §54.3 执行。

### 97.4 红线

- 收藏的标题 / 路径 / 篇数禁止进埋点（H 节红线延伸）；toast 与读屏文案是本地 UI，不是埋点。
- 零新增权限；颜色 / 圆角 / 间距 / 字号只引用 token（硬约束 17）；图标全自绘（Icons.ets 直线命令路径），不引 SymbolGlyph。

## 4. 明确不做（本版）

- 星标（`#tag` 式标签聚合）——仍留需求池（v1.54 §3 沿用）。
- 收藏手动拖动排序、按文件夹分组、跨库收藏聚合、收藏内搜索——回需求池。
- 指针设备悬停降噪（54.2）——原生口径修订见 97.2；原型不动。
- 卡片与双栏视图接入——两类视图尚不存在，落地时各自接入（与 v1.50 Pin 同口径）。
- 收藏行左滑「改名」之外的编辑类操作；「章节」页签、referenceOnly 侧栏不加收藏区。

## 5. 技术约束与依赖

- 涉及文件：`common/Icons.ets`（star / starFilled 图标 + FILLED_ICONS）、`model/FileTree.ets`（FavoriteStore）、`components/FileTreeView.ets`（收藏区渲染 + 树行星标 + 行键）、`pages/Index.ets`（菜单入口 + purge 清理 + 改名 / 移动 retarget）、`tools/tests/test_file_favorites.mjs`（新增契约）、`tools/tests/test_file_pin.mjs`（行组件共用化适配）。
- 全局 `@Builder` 按值实参首帧固化（api_notes L-7 / Z2）：树行星标 Icon 名必须拆字面量 if/else 分支（`'star'` / `'starFilled'`）。
- LazyForEach 行键：树行键追加收藏态（`|fav`）；收藏区行键独立空间 `fav-<relPath>`（与置顶区 `pin-` 同理）。
- 回收站 trash relPath 与原库路径相同（镜像结构），purge / purgeAll 传入的 relPath 即收藏列表里的原路径，可直接用于 `removePaths`。
- 需求池注记与总清单立项条目随本版提交。

**待验（模拟器 / 真机走查项）**
