# v1.41 需求文档 —— 启动页品牌遮罩

> 状态：开发中，2026-11-07 立项。
> 需求来源：[需求池 D / 启动页品牌遮罩](../../requirements_backlog.md#d-鸿蒙系统能力与设备特性)
> ；设计真源 [启动页设计](../../prototype/v2/启动页设计.md)。

## 1. 版本定位

把冷启动期间的纯色遮罩（`workspaceInitialRenderReady=false`）升级为品牌层：应用图标 + 品牌名 +
一句随机名言。底色、原子首帧语义、恢复逻辑全部不变；系统开屏维持现状（简易启动页，`module.json5` 零改动）。
