# v0.4 需求文档 —— 快速找到笔记

> **状态**：🟡 本地库功能实现与 API 26 模拟器验证完成；搜索框聚焦时单次 Back 关闭待验；XT2 真机和 Git 库联调待验；未发布（2026-10-23）
> **对应里程碑**：M4.5

## 1. 版本定位

补齐日常找笔记的入口。保留现有文件树和多库模型，不引入全库正文索引。

## 2. 完成判定

在当前库能按文件名快速打开笔记、查看最近打开；切库不串数据。

## 3. 需求清单

| # | 需求 | 来源 | 验收点 |
| --- | --- | --- | --- |
| 1 | 快速切换与文件名模糊搜索 | 需求池 B「快速切换」「文件名模糊搜索」 | 当前库输入部分文件名能列出匹配项；选中后打开正确文件，重名文件展示相对路径 |
| 2 | 最近打开 | 需求池 B「最近打开 / 收藏 / 星标」 | 每库分别记录最近打开项；删除或移动后不留下不可打开的入口。收藏与星标本版不做 |

## 4. 明确不做

- 正文搜索、双链和反链：留给 v1.1 / v1.2 的索引层。
- 左滑交互与删除兜底：仍属 v0.2 §3.2 的需求，本版不重复分配。
- v0.2 / v0.3 未通过的真机验收项：仍由原版本负责，不因本版规划而视为完成。

## 5. 技术约束与依赖

> 2026-10-25 顶栏评估：现有 sm 使用紧凑单行标题与放大镜入口，不新增常驻搜索框或缩小标题字号；保持 48vp 触控热区与长标题省略。材料只是通用设计参考，后续 v1.1 复用本入口，不视为新增功能。

- 本版不依赖 clone 成功或 v0.3 完整验收；复用现有本地库、文件树与打开/保存流程即可推进。先完成本地库的模拟器验证；Git 库联调和 XT2 验收待条件具备后补，不据此宣称旧版完成。

- 目录与文件操作复用现有 `NoteService`、`FileTree` 和库内路径解析器；已定决策见 [`open_questions.md`](../../open_questions.md)。
- 涉及 HarmonyOS 文件能力时先核对 [`api_notes.md`](../../harmonyos/api_notes.md) 对应条目；不可凭记忆写接口。

## 6. 验收记录

### 需求 1：快速切换与文件名模糊搜索

- **实现**：`FileTree.allMarkdownFiles()` 递归扫描当前库，不依赖目录展开状态；候选沿用文件树规则（跳过隐藏项，仅 `.md`/`.markdown`，深度最多 8、节点最多 1000）。`QuickSwitcher` 支持部分文件名/路径匹配、中文名称、空结果状态，并为同名文件展示库内相对路径。选择后复用现有笔记打开与保存流程。
- **模拟器验证**：API 26 arm64 Huawei TripleFold 7.0.0 模拟器覆盖 sm/md/lg 打开、选择和关闭；验证多级折叠目录、同名文件路径、中文部分匹配、空结果和 `.markdown` 文件。输入框无焦点时，返回键关闭快切并停留在笔记页。
- **最新设计稿复核（2026-10-23）**：快切为原笔记页上方的遮罩弹层，卡片顶部居中；sm 保留两侧边距，md/lg 卡片宽度不超过 560vp。API 26 模拟器复测 sm、md、lg 均显示在原页面上方；卡片左右外部点击均关闭，md/lg 还点测了卡片与屏幕边缘之间的空白；卡片内点输入框后仍保持打开并可聚焦。无输入框焦点时 Back 关闭弹层；输入框有焦点时第一次 Back 只清焦点、第二次关闭，单次关闭待进一步核实。模拟器控件树确认关闭后快切输入框节点消失。
- **编辑保护**：在 `archive.markdown` 输入 `PreserveMe` 后切换笔记，再从最近打开重新打开该文件；编辑器仍显示 `PreserveMe`，确认切换前内容已保存。

### 需求 2：按库隔离的最近打开

- **实现**：只在读取成功并载入编辑器后记录最近项；Preferences key 按库 id 隔离。打开面板时按当前库候选清除失效路径；文件/目录改名或移动时同步迁移历史路径。
- **模拟器验证**：`v04accept1023` 库有 6 条最近项；切到 `local` 搜索 `RootNote` 返回 0 条且最近列表为空；切回测试库仍保留自己的最近项。删除 `archive.markdown` 并重开面板后，最近项从 6 条降为 5 条且该路径消失。将 `folder` 改名为 `foldermoved`，再将其移动到 `left` 后，最近项数量保持 5；搜索 `left/foldermoved` 能命中并打开 `left/foldermoved/inner/FoldedNeedle.md`。
- **重名与目录状态**：两条 `Shared.md` 分别显示 `left/Shared.md` 与 `right/Shared.md`；折叠状态下仍可搜索和打开多级目录中的 `FoldedNeedle.md`。

### 构建、API 与待验

- **构建**：2026-10-23 使用 DevEco 自带 Hvigor 执行 `assembleHap`，`BUILD SUCCESSFUL`（33 tasks）；快切弹层修正后再次构建并安装到 API 26 模拟器。本机无 `.local/local-signing.json`，产物为 `entry-default-unsigned.hap`；未改版本号、未发布。
