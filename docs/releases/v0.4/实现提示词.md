## 项目和边界

你在“曜石笔记”仓库工作：华为 XT2 三折叠、本地 Markdown、多库，ArkTS + Stage 模型，HarmonyOS API ≤24。先读仓库 `AGENTS.md`，再读 `docs/releases/v0.4/需求文档.md`、`docs/releases/实施总清单.md`、`docs/mvp_design.md`、`docs/open_questions.md` 和 `docs/harmonyos/api_notes.md`。v0.2、v0.3 的真机验收是本版前置条件；若未完成，报告阻塞，不将旧版功能算成本版交付。

不得凭记忆编 HarmonyOS API、`Hds*` 组件或 `sys.symbol.*`。查不到 API 24 SDK 签名或知识库结论时，列出待核实点。布局仍用现有 sm/md/lg 自绘结构，组件颜色/间距/字号只用 token。改动只限本版需求。
