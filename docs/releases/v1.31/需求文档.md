## 1. 版本定位

单屏顶栏「…」菜单原为纯文字列表：笔记级操作与应用级入口混排、设置夹在中间、反链在末尾；「编辑模式」占三行；Git 待推送数为蓝色小字像链接。本版只整理视觉与分组，不增删功能。

## 2. 完成判定

单屏更多菜单按「当前笔记 / 编辑模式 / 应用」三组呈现，每项有图标、统一行高；编辑模式为一行分段切换；待推送为计数徽标；无笔记时笔记组灰显；深浅色均清晰。原生与设备分别验收。

## 3. 需求清单

## 4. 明确不做

- 不增删菜单项、不改各项行为；不改宽屏栏内「…」菜单（`leftMore` / `rightMore`）。
- 不把菜单改成底部半模态（菜单项少，就地弹出更快）。

## 5. 技术约束与依赖

- 环境事实：HarmonyOS API 24 / ArkTS；包名 `com.jxg.huaweiobsidian`；目标设备 XT2。**禁止凭记忆编造 HarmonyOS API**（`AGENTS.md` 硬约束 18）。原生菜单组件、分组与图标资源以 API 24 SDK 核实为准。
- 视觉 token 以 v2 原型 `:root` / `[data-theme="dark"]` 为准；图标复用现有原生图标资源，缺失的按同一线稿规格补充。

### 6.2 原生与设备

**原生实现（2026-11-06，本地完成待验）**：31.1–31.6 全部落码于 `entry/src/main/ets/pages/Index.ets`。

- **31.1 三组顺序**：`MoreMenu()` 改为 `MobileMoreMenuNoteGroup()`（分享笔记 → 查看/隐藏反链 → 切换笔记）→ `MobileMoreMenuExperienceGroup()`（编辑模式一行）→ `MobileMoreMenuAppGroup()`（同步到 Git（仅 `GIT_ENTRY_UI_ENABLED && currentVaultIsGit()`）→ 设置与关于）；组间 `--line` 细分隔线（后两组 `.border({ width: { top: 1 }, color: app.color.line })`）。切换笔记仅专业模式且两栏为不同笔记时出现，文案改「切换到笔记：标题」（新增 `paneNoteTitle()` 去 `.md`，对齐原型 JS 的 title 改写）。设置始终在末尾。
- **31.2 图标行**：新增 `MobileMoreMenuItem` builder——`Icon(icon, Space.s5=20, text_secondary)` + `FontSize.body1` 文本 + `Size.touch=48` 行高 + `Space.s3` 左右内边距 + `Radius.control=10` 圆角 + hover `bg_secondary` 底（`mobileMoreHoveredAction` 独立悬停态）+ `maxLines(1)` 省略。六个图标全部复用既有 `Icons.ets` 映射：share（P_SHARE 分享箭头）、link（P_LINK）、swap（P_SWAP）、rename（P_RENAME 笔）、sync（P_SYNC）、settings（P_SETTINGS），无新增图标。
- **31.3 编辑模式一行**：`MobileMoreMenuExperienceGroup`——Row `FlexAlign.SpaceBetween`：左「笔线稿 + 编辑模式」、右 `MobileMoreSegButton('simple','简单')` / `('professional','专业')` 分段（容器 `bg_secondary` 底 + `Space.s1` 内边距 + `Radius.full`）；选中段 `brand_bg`（--blue-soft）底 + `brand` 字 + 600 字重，未选中透明；选择后 `moreMenuOpen = false` 并 `selectEditorExperience()`（沿用 v1.7 行为）。原两行 `ExperienceMenuItem`（简单模式/专业模式 + ✓）删除。
- **31.4 待推送徽标**：`MobileMoreGitSyncItem`——`gitAheadBadgeLabel()` 计数改 `brand` 底 + `on_brand` 字 + `Radius.full` 圆形徽标（`lineHeight(Space.s5)` + `constraintSize({ minWidth: Space.s5 })`，与顶栏 `GitAheadBadge` 角标同源）；行级 `accessibilityTextHint` 与徽标 `accessibilityText` 均读「N 个提交待推送」；无待推送不显示。原「N 个待推送」蓝色小字删除。
