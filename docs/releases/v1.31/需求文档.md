# v1.31 需求文档 —— 单屏更多菜单视觉整理

> 状态：⚪ 规划中；v2 原型已实现，headless Chrome 功能与截图核对通过；原生未实现、未验收。
> 对应里程碑：独立优化。领取顺序以 [实施总清单](../实施总清单.md) 为准。
> 需求来源：[需求池 P-03](../../requirements_backlog.md#p-单屏工作区体验优化2026-11-01)（2026-11-04 用户反馈单屏更多菜单「太丑」）。

## 1. 版本定位

单屏顶栏「…」菜单原为纯文字列表：笔记级操作与应用级入口混排、设置夹在中间、反链在末尾；「编辑模式」占三行；Git 待推送数为蓝色小字像链接。本版只整理视觉与分组，不增删功能。

## 2. 完成判定

单屏更多菜单按「当前笔记 / 编辑模式 / 应用」三组呈现，每项有图标、统一行高；编辑模式为一行分段切换；待推送为计数徽标；无笔记时笔记组灰显；深浅色均清晰。原生与设备分别验收。

## 3. 需求清单

| # | 需求 | 验收点 |
| --- | --- | --- |
| 31.1 | **三组顺序。** ① 当前笔记：分享笔记、查看 / 隐藏反链、切换笔记（仅两栏为不同笔记时）；② 编辑模式；③ 应用：同步到 Git（仅 Git 库）、设置与关于。组间 `--line` 细分隔线；组内无可见项时整组隐藏（编辑模式组除外）。 | 设置始终在末尾；笔记操作集中在顶部 |
| 31.2 | **图标行。** 每项左侧 20vp 线性图标（`--muted`）+ 文本（`--body`），行高 `--touch`，左右内边距 `--s3`，圆角 `--small-r`，悬停 `--nav` 底；文本过长省略。图标与顶栏 / 格式行所用同一套线稿（分享箭头、链接、交换、同步、齿轮、笔）。 | 图标与文字左对齐成两列 |
| 31.3 | **编辑模式一行。** 「✎ 编辑模式」与右侧「简单 / 专业」分段同行；选中项 `--blue-soft` 底 + `--blue` 字 + 600 字重，未选中透明底；文案不换行。选择后立即生效并关闭菜单（沿用 v1.7 行为）。 | 深色下选中项清晰可辨 |
| 31.4 | **待推送徽标。** 「同步到 Git」右侧为 `--blue` 底、`--paper` 字的圆形计数徽标（与顶栏同步按钮角标一致），读屏「N 个提交待推送」；无待推送时不显示徽标。 | 不再呈现为蓝色链接样式 |
| 31.5 | **禁用态。** 未打开笔记时，分享笔记、查看反链以 40% 不透明度显示且不可点；编辑模式与应用组照常可用。 | 空态下菜单仍可进入设置与切换模式 |
| 31.6 | **外形。** 菜单最小宽 `--s16 × 4.25`，圆角 `--r`，阴影 `--float-shadow`，上下内边距 `--s1`；仍从「…」按钮右下方展开，Escape / 点外部关闭并把焦点还给「…」。 | 380vp 单屏内不溢出 |
| 31.7 | **原型同步。** 保留 `mobileShare`、`mobileBacklinks`、`switchPane`、`quickSimple`、`quickProfessional`、`mobileGitSync`、`mobileSettings` 等元素 ID；动态文案改写 `.menu-label`，不覆盖图标。 | 原型不作为原生或设备验收 |

## 4. 明确不做

- 不增删菜单项、不改各项行为；不改宽屏栏内「…」菜单（`leftMore` / `rightMore`）。
- 不把菜单改成底部半模态（菜单项少，就地弹出更快）。

## 5. 技术约束与依赖

- 环境事实：HarmonyOS API 24 / ArkTS；包名 `com.jxg.huaweiobsidian`；目标设备 XT2。**禁止凭记忆编造 HarmonyOS API**（`AGENTS.md` 硬约束 18）。原生菜单组件、分组与图标资源以 API 24 SDK 核实为准。
- 视觉 token 以 v2 原型 `:root` / `[data-theme="dark"]` 为准；图标复用现有原生图标资源，缺失的按同一线稿规格补充。
