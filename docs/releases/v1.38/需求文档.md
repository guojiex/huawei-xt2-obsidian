> 状态：🟡 原型与原生本地实现完成（2026-11-08）；定向测试、全仓回归、签名构建与 API26 模拟器控件树验证通过；浏览器截图与 API24 / XT2 待用户验收。
> 对应里程碑：独立优化。领取顺序以 [实施总清单](../实施总清单.md) 为准；依赖 [v1.22 分栏调节条增强](../v1.22/需求文档.md)。
> 需求来源：[需求池 Q-02](../../requirements_backlog.md#q-分栏调节条交互增强2026-11-03)（2026-11-07 原型走查，用户确认「右边的中间也是可以拉的」）；设计基线：[分栏调节条设计 §4](../../prototype/v2/分栏调节条设计.md#4-显示范围与比例)。

## 1. 版本定位

三栏布局（目录 + 正文 + 参考）下，目录 | 正文之间有抓握把手可拖，但正文 | 参考之间只有一条分隔线、两栏固定均分；只有收起目录变成双栏后才能调。两处分隔视觉不一致，用户也会以为把手漏画了。本版让三栏时正文 | 参考之间同样显示把手并可拖动，与目录调节条行为一致。

本版只扩大正文 / 参考调节条的**显示范围**，调节条本身的外观、吸附、键盘、读屏规则沿用 v1.22，不重做。

## 2. 完成判定

三栏时正文 / 参考之间显示可拖动的调节条；拖动、键盘、恢复默认与读屏行为与双栏时一致；拖动目录时右侧两栏按比例缩放；展开 / 收起目录后正文 / 参考比例保持；任一栏不小于 240vp。原型、原生与设备分别验收。

## 3. 需求清单

| 编号 | 需求 | 验收点 |
| --- | --- | --- |
| 38.1 | **三栏显示正文 / 参考调节条。** 显示条件由「目录收起且双栏均可见」改为「正文与参考双栏均可见」，不论目录是否展开。三栏时出现两处调节条（目录 \| 正文、正文 \| 参考），把手、轨线、悬停 / 聚焦 / 拖动状态与 v1.22 一致。单屏、专注模式、设置页继续不显示；双屏预设下目录展开时参考栏本就不显示，不出现该调节条。 | 三屏预设 + 目录展开 + 参考开启时两处把手同时可见且均可拖；关参考 / 单屏 / 专注时隐藏 |
| 38.2 | **比例基准与持久化。** 正文 / 参考比例以「目录右侧可用区域」为基准（目录收起时即整个窗口），三栏与双栏共用同一比例值和既有栏宽存储键，不新增存储项。 | 三栏调到 40 / 60 后收起目录，双栏仍为 40 / 60；反之亦然；重开应用后保持 |
| 38.3 | **两处联动与边界。** 拖动目录调节条时，右侧两栏按当前比例同步缩放，正文 / 参考比例不变。目录最大宽度按当前比例限制，保证右侧每栏均不少于 240vp；正文 / 参考可调范围为 [240vp，可用区域 − 240vp]。可用区域不足 480vp 时正文 / 参考调节条隐藏（沿用 v1.22 窄窗口规则）。同一时刻只响应一处拖动，拖动中另一处轨线弱化。 | 把目录拖到最大时正文、参考均不小于 240vp；拖动目录前后正文 / 参考百分比不变；旋转或窗口变化后各栏仍不小于 240vp |
| 38.4 | **恢复、吸附、键盘与读屏沿用 v1.22。** 吸附点为可用区域的 1/2；Esc 取消、双击 / 两次轻触 / Enter / 设置「恢复默认栏宽」恢复默认（同时恢复目录 1/3 与正文 / 参考 1/2）；方向键 16vp / Shift 64vp、Home / End 到边界。读屏文本按可用区域报百分比（「左栏 x% · 右栏 y%」），数值范围随目录宽度更新。不弹任何视觉读数浮层（v1.22 22.2 已撤销）。 | 三栏时键盘步进、Home / End、Enter、Esc 与双栏表现一致；读屏百分比两侧相加为 100% |
| 38.5 | **v2 原型同步。** 原型三栏时显示并可拖动正文 / 参考调节条，规则同 38.1–38.4；补充截图到 `docs/prototype/v2/截图/` 并更新 [分栏调节条设计](../../prototype/v2/分栏调节条设计.md) 状态。扩展 `tools/tests/test_split_handle.mjs`（或同类定向测试）覆盖三栏显示条件、比例基准、目录联动缩放与边界。 | 定向测试通过；截图含三栏两处把手；浏览器原型不作为原生或设备证据 |
| 38.6 | **原生实现。** 笔记工作区三栏布局复用 v1.22 的 `SplitHandle` 与既有栏宽状态，不复制第二套拖动控件；三栏正文宽度改为按 38.2 比例计算，不再固定均分。 | 签名 HAP 构建通过；API26 模拟器三屏目视；API24 / XT2 由用户手动验收 |

> 2026-11-07 补充：本版中的「240vp」「2 × 240vp」「480vp」为当前统一下限；[v1.39](../v1.39/需求文档.md) 落地后改按各栏角色与系统字号计算的下限，本版验收以当时生效的下限为准。

## 4. 明确不做

- 不改调节条外观、热区、吸附距离、键盘步长与读屏规则（v1.22）；不恢复视觉读数浮层。
- 不改默认比例（目录 1/3、正文 / 参考 1/2）、每栏最小 240vp、栏数量与折痕规则；原生 MD 布局目录默认 0.38 的待决项（需求池 Q 节）不在本版处理。
- 不新增栏宽存储键或设置项；不做三栏、双栏各自独立记忆正文 / 参考比例。
- 不做 Agent 页分栏（v0.7 Agent 专属部分已延期）。
- 不做拖动惯性、多段吸附、拖动预览缩略图或振动依赖。

## 5. 技术约束与依赖

- 环境事实：HarmonyOS API 24 / ArkTS；包名 `com.jxg.huaweiobsidian`；目标设备 XT2。**禁止凭记忆编造 HarmonyOS API**（`AGENTS.md` 硬约束 18），手势、读屏与布局接口以 [API 笔记 L-11](../../harmonyos/api_notes.md#l-11-v07-分栏手势与单屏横向窗口识别api-24-sdk-声明) 已核实内容为准。
- 栏宽模型与持久化来自 [v0.7 §7.22–7.23](../v0.7/需求文档.md)：本版只把正文 / 参考比例的基准明确为「目录右侧可用区域」，与 7.22「收起目录后编辑 / 预览拖动保留独立状态」一致（该比例独立于目录宽度），不改变既有存储键。
- 调节条控件、状态与读屏来自 [v1.22](../v1.22/需求文档.md)；本版不回填 v1.22 需求。
- 设计以 [分栏调节条设计 §4](../../prototype/v2/分栏调节条设计.md#4-显示范围与比例) 为准；视觉 token 以 v2 原型 `:root` / `[data-theme="dark"]` 为准。
- 原型现状（2026-11-07 核对）：`splitActive` 对正文 / 参考要求 `m.referenceVisible && !m.side`，`applySplits` 在目录可见时把正文宽度固定为可用区域的一半；38.5 需改这两处及以窗口宽度换算像素的相关函数（范围、吸附点、读屏文本、拖动与键盘起点）。
