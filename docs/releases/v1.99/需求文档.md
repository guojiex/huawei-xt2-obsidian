# v1.99 需求文档 —— 华为云空间同步设计稿（状态页 + 新建库存储位置）

> 状态：设计稿完成（2026-11-21 立项，当日完成规格文档 + 原型 + 防线测试）
> 来源：需求池 C 节「华为云空间同步」。技术可行性已于 2026-11-21 完成官方核实与本机 SDK 复核（结论真源：[`docs/harmonyos/api_notes.md`](../../harmonyos/api_notes.md) AN1–AN5 组；问答存档 [`2026-11-21_云空间端云文件协同_API24.md`](../../harmonyos/qa/2026-11-21_云空间端云文件协同_API24.md)）。用户拍板开新版本先出设计稿。

## 1. 版本定位

华为云空间同步 = 把笔记库放进系统云空间目录（`context.cloudFileDir`），由系统在登录同一华为账号的设备间双向同步（Core File Kit 端云文件协同，非 Drive Kit）。本版只做**设计稿**：在 v2 原型上落地「云空间同步状态页」与「新建库存储位置选择」两块 UI 设计，产出设计规格文档；**不落任何 ArkTS / 端侧代码**。

## 2. 需求清单

### 99.1 云空间同步状态页（原型）

- 库管理页新增「华为云空间」状态入口卡（未开启 / 已连接 / 同步中 / 同步失败四态摘要），点击进入全屏状态页。
- 全屏状态页（与 Git 同步页同范式：返回栏 + 单列滚动 + 演示脚注）：
  - **未开启态**：三步开启引导（登录华为账号 → 系统设置·云空间开「曜石笔记」开关 → 回来新建云空间库）+「我已开启，重新检测」。
  - **已开启态**：连接状态 + 上次同步时间 + 云空间库数量 +「立即同步」；同步中 / 失败（网络不可用、云端未就绪）状态演示。
  - **云空间库列表卡**：列出 `type==='cloud'` 的库；空态给「新建云空间库」入口（预选存储位置）。
  - **使用注意卡**：多端勿同时编辑同一篇（冲突策略平台未定义）、云空间库不参与 Git 同步、省电 / 无网时系统会延迟同步、异端新文件首次打开需联网取回。
- URL 直达：`?ui=2&view=cloud`（沿用 Git 同步页 `__initialViewSync` 跨 script 块模式）。
- 规格文档：[`docs/prototype/v2/云空间同步设计.md`](../prototype/v2/云空间同步设计.md)。

### 99.2 新建库存储位置（原型）

- 新建库对话框加「存储位置」切换：本机（默认）/ 华为云空间；选择云空间时标题、说明、目录提示（`cloud/<id>`）联动。
- 云空间未开启时「华为云空间」选项禁用并提示先开启；创建的库标记 `type: 'cloud'`，库卡片类型标签显示「华为云空间」。

### 99.3 防线测试

- 新增 `tools/tests/test_prototype_cloud_sync.mjs`：页面结构、四态渲染、入口卡联动、存储位置联动、URL 直达捕获、禁止散写颜色值（token 红线）。

## 3. 明确不做（本版）

- **不落端侧代码**：`app.json5` 的 `cloudFileSyncEnabled`、`cloudFileDir`、`@ohos.file.cloudSync` 调用、`VaultAccess` 云根实现——全部留给后续实现版本。
- 不迁移现有库到云空间；不做「云空间库 → 本地」搬移。
- 不做同步冲突解决 UI（平台冲突策略未记载，设计稿只做提示文案；双机冲突实测排期前完成）。
- 不做 AGC / 云空间开通引导的实名流程细节（AGC 前置开放性问题未核实，见 AN 组 ❓）。
- 不动 Git 同步页、导入库弹窗、设置页四分类结构。

## 4. 红线

- 颜色 / 圆角 / 间距 / 字号只引用 token，组件里禁止散写数值（硬约束 17）。
- 原型演示不得模拟真实云连接或读写文件；演示脚注明示「不连接华为云空间」。
- 涉及云空间的技术结论一律链接 `api_notes.md` AN 组，不复制进设计文档。
- 零新增权限（本版纯原型，端侧无改动；将来实现版也零新增权限，见 AN2）。
