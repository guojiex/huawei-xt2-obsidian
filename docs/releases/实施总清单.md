- [ ] 只领取**一个版本或其中一个可独立验收的任务**；该版本需求文档与实现提示词必须先读。
- [ ] 涉及 HarmonyOS API 时，在 `api_notes.md` 或 API 24 SDK 类型定义中核实名称和签名；⚠️/❓ 结论不能直接当作真机已验证。
