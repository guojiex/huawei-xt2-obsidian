# 二、任务 1（P0）：顶栏汉堡在 md/lg 改成「收起/唤回」切换

**文件**：`entry/src/main/ets/pages/Index.ets`

**现状代码**（约 109–116 行）：

```typescript
  /** 顶栏汉堡：sm = 抽屉开关；md/lg = 唤回收起的侧栏（spec 非功能约束） */
  private onHamburger(): void {
    if (this.breakpoint === Breakpoint.SM) {
      this.drawerOpen = !this.drawerOpen;
    } else {
      this.sidebarCollapsed = false;
    }
  }
```

**问题**：md/lg 分支把 `sidebarCollapsed` 赋成 `false` 是**单向「唤回」**。
侧栏默认展开（`sidebarCollapsed` 初值 `false`），再赋 `false` 无任何状态变化，
所以用户在三屏态点汉堡**完全没反应**，无法收起文件树。
用户只能靠侧栏组件内部的收起按钮（`VaultSidebar` 的 `onCollapse`）——但顶栏那个图标点了就该有反应。

**要求**：

- `else` 分支改为 **toggle**：`this.sidebarCollapsed = !this.sidebarCollapsed;`
- 同步把上方那行注释改成准确描述：`sm = 抽屉开关；md/lg = 收起/唤回切换（toggle）`
- **不要改** `this.drawerOpen` 那条分支（sm 抽屉语义已验证正确）
- **不要改** `onBreakpointChanged()`（切到 md/lg 强制收抽屉是刻意的，别动）
- **不要改** `WideContent()` 里的任何布局（`layoutWeight` 的 1 / 2 分配保持原样）
