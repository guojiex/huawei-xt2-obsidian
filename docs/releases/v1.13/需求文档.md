# v1.13 需求文档 —— 设置页分组列表整理

> 状态：🟡 原生同步、定向回归与签名 HAP 构建已完成；API26 模拟器目视及 API24 / XT2 验收待补，不代表整版已验收。优先级见 [实施总清单](../实施总清单.md)。

## 1. 需求来源与范围

承接 [需求池设置页分组列表整理](../../requirements_backlog.md)。候选将“设置与关于”的通用、数据、问题与建议、关于四类内容统一为分组标题和列表行，减少卡片、下拉、单选、开关等视觉样式不一致。以已合并的 [v2 设计稿](../../prototype/v2/index.html) 和设计说明为视觉依据；保留隐私政策入口、缩放焦点恢复及其他现有行为。

| 分类 | 候选变化与边界 |
| --- | --- |
| 分类导航 | 宽屏左右分栏、窄屏先选分类；清理多余箭头和单屏错误选中态，保留现有逐级返回与焦点恢复。 |
| 通用 | 编辑模式改成分组单选行；保留外观、行号、布局与恢复默认栏宽；诊断信息采用可展开行，评估栏宽数值调整位置。 |
| 数据 | 重置入口采用危险行，确认操作在组内展开；保留既有确认、防误触、成功 / 失败和数据影响说明，不改变重置语义。 |
| 问题与建议 | 精简重复标题，保留反馈字段、预览、邮箱及用户主动打开邮件应用的路径；不自动发送、不附加笔记或日志。 |
| 关于 | 居中展示应用标识与版本；保留反馈邮箱、隐私政策、许可、更新日志和完整版本记录。政策查看与返回沿用 [v1.11](../v1.11/需求文档.md)，不得回退。 |

尺寸、间距、颜色、圆角和字体沿用现有 token；候选中硬编码的像素值仅为视觉参考，不能直接照搬。各行文案在实施时核对既有产品含义，不能因精简遗漏隐私、重置影响或操作反馈。

## 2. 验收

- 原型和原生分别核对通用 / 数据 / 问题与建议 / 关于的内容、交互和现有入口无遗漏；特别检查隐私政策、反馈邮箱、重置确认、版本记录、主题、编辑模式和行号。
- 单屏、双屏、三屏及窄横屏检查分类与详情、返回、滚动、键盘焦点、浅 / 深色；动作可见、文字不遮挡，重置取消不产生副作用。
- 独立确认恢复栏宽与工作区状态、栏宽诊断、返回后编辑状态；不改变笔记数据及保存逻辑。
- 按实际记录原型、自动测试、构建、模拟器和 API24 / XT2 证据；用户手动执行真机验收，候选包自述不作为本仓库验收通过。

## 3. 明确不做

不新增设置项、网络服务、隐私采集或版本号来源；不改政策正文、首次启动授权、反馈发送及数据重置的业务语义。预览缩放按 [v1.12](../v1.12/需求文档.md) 跟踪；基础无障碍矩阵按 [v1.10](../v1.10/需求文档.md) 跟踪。
