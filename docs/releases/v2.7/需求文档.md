## 1. 版本定位

把 frontmatter（文档属性）编辑面板从「逐行保存按钮 + 复选框 + 选择日期按钮」的临时表单，改成设计稿 `docs/prototype/v2/index.html` 的 `#blockSheet` props 规格（index.html:2826-2839）：设置式**分组列表**、字段小字标签、Enter / 失焦即写回（不再有逐行「保存」）、布尔用开关、日期用可点字段调起系统日期选择、复杂值只读「保留原值」、独立「添加属性」组与底部说明，弹窗标题带「N 项」副标题。

2026-11-24 按用户反馈二次重做（m00584）：设计稿与端侧一起改成「nav 底色 + 白色圆角卡片 + 设置行」的属性面板；添加属性折叠；顶部把手支持上拉 92% / 全屏档；修复半屏下内容滚不到底。只改属性面板的视觉与交互外壳；frontmatter 解析、只重写改动键的 YAML 回写、未知结构 / 注释逐字保留、串行保存、非 YAML 只读 + 源码抽屉等数据安全边界零变化。其他复杂块（链接 / 双链 / 图片 / 公式 / 提示块 / 表格 / 脚注 / 块 ID）面板不在本版范围。

## 2. 完成判定

点按预览里的「属性 · N 项」打开面板：标题下方显示「N 项」；内容区为 nav 底色，属性收在白色圆角卡片里，卡片内每行是「key + 类型小字」、右侧值控件、行尾垃圾桶，行间 1px 分隔；文本 / 列表输入透明右对齐、无逐行「保存」，Enter 或失焦写回；布尔是开关；日期是日期文本 + 右箭头，点按调起系统日期选择，确认后写回；复杂值只显示「保留原值」，不提供删除。卡片底部是折叠的「＋ 添加属性」，展开为名称 / 值输入 + 取消 / 添加 + hint；空态显示「还没有属性 / 从下面添加第一个属性」。

半屏 sheet 顶部有拖拽把手，上拉到 LARGE 档接近全屏，下拉回 MEDIUM；内容能滚动到最后一个属性、添加行与底部说明，不再被裁切。只改一个键时其他行（嵌套结构、注释、未知类型）逐字保留；串行保存、区间校验、非 YAML 只读与源码抽屉等既有行为不回归。

## 4. 明确不做

- 不改链接 / 双链 / 图片 / 公式 / 提示块 / 表格 / 脚注 / 块 ID 面板的排版：设计稿同批的行式语言本版只落在属性面板。
- 不改属性入口 chip（「属性 · N 项」）与预览渲染；不改宽屏 POPUP 的形态、宽度、关闭方式。
- 不改 frontmatter 解析、YAML 写回、未知键 / 注释保留策略与撤销链路。
- 不新增权限、不引入第三方组件；日期选择用系统 `DatePickerDialog`。
- 原型只改 `#blockSheet` 的 props 形态与拖拽演示，不动其他块面板与页面其他区域；原型拖拽不代替原生 `detents` 的真机验收。

## 5. 技术约束

- 设计真源 `docs/prototype/v2/index.html`（`:root` token；`.hs-group` / `.hs-row` / `.cb-field` / `.cb-label` / `.cb-hint` / `.cb-input` / `.cb-remove` / `.cb-keep` / `.cb-add` / `.cb-info`，index.html:469-472、613-644）；端侧只引用 `common/Tokens.ets` 与 `app.color.*`，不散写数值（AGENTS.md 硬约束 17）。
- `SheetTitleOptions.subtitle` 已核实：本机 SDK `component/common.d.ts:11446-11467`，`subtitle?: ResourceStr` since API 11，满足 API ≤24。
- 日期选择用 `UIContext#showDatePickerDialog`（`api/@ohos.arkui.UIContext.d.ts:4737` `showDatePickerDialog(options: DatePickerDialogOptions): void`，API 10+；选项类型见 `component/date_picker.d.ts:521`、`onDateAccept?: Callback<Date>` 见 `:805`）。`DatePickerDialog.show` 自 API 18 起废弃，构建会告警，故走 UIContext；仅 frontmatter 日期字段调用。
- 保存仍走 `saveBlockPanelFrontmatterProperty(action, key, value)` 串行队列；输入失焦 / 提交只传当前 key / value，不引入批量写。
- 多档 sheet 用 `SheetOptions.detents`（本机 SDK `component/common.d.ts:11795`，since API 11）；设置 detents 后 `height` 失效，故 frontmatter 分支不再传 `height`。`backgroundColor` 来自 `BindOptions`（`SheetOptions extends BindOptions`）。
- 满高布局依赖 `blockPanelFillSheet`：单屏由 `Index.ets` 传 `true`，面板根 `height('100%')`、`Scroll.layoutWeight(1)`；宽屏为 `false`，保持 `constraintSize` 原行为。该组合需在 XT2 上确认 100% 高度不会被系统 sheet 二次裁切。
- 回归切片约束：`tools/tests/test_block_property_panel.mjs` 以 `loadBlockPanelFrontmatter()` 到 `blockPanelCalloutTypeOptions()` 的源码切片做真实编译，新增 frontmatter 方法必须留在这段之间；`makeApp` 需提供 `blockPanelSubtitle` / `onSubtitleChange` / 可空的 `blockPanelAnchor`。
