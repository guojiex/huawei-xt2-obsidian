## 当前能力与目标

| 类别 | 当前 App 源码能力 | 设计参考与实施安排 |
| --- | --- | --- |
| 标题、段落、强调、删除线、列表、引用、表格、任务列表、标准链接 | marked/GFM 已有解析路径；不代表本样例已逐项设备验收 | v0.5 用共享样例正常回归，基础排版是首批验收对象 |
| fenced code | 普通代码块；未接语法着色库 | 按参考库常见语言验收显示与横向滚动，着色另评估 |
| 标准 Markdown 本地图片 | PreviewWebView → readAssetDataUri 已有路径；SVG 在 MIME 白名单 | 共享原创 SVG，原型显示内嵌同一资源；待设备验收 |
| frontmatter、callout、高亮、标签、Obsidian 注释 | 无对应完整语义处理 | 高优先级渲染补齐候选，原始样例先保存；本版不伪称支持 |
| 双链、标题链接、反链 | App 尚未完整支持；原型部分点击仅为示意 | v1.2 负责真实解析与跳转；样例路径、别名与标题不可丢 |
| 行内/块级公式、Mermaid | App 未接 KaTeX / Mermaid | v1.3 的渲染目标，原型仍是明确标注的源码示意 |
| Obsidian 图片/笔记嵌入 | 标准图片路径不等于 `![[...]]` 支持 | 后续语法与路径解析，不执行远端嵌入脚本 |
| Dataview、任意 HTML 执行 | 无插件运行时 | 不承诺支持，源码作为普通文本或代码展示 |

样例同时是回归输入和目标清单。不能为了展示效果先把正文改写成 HTML，也不能把设计稿的假图/占位符当作 App 渲染通过。

## 数据路径与维护

`sample_vault/notes/` → `tools/build_sample_vault.py` → 原型生成区 + `SampleVaultData.ets` → 首次安装 `SampleVaultInstaller` → 默认本地库。

运行 `python3 tools/build_sample_vault.py --check` 可检查漂移。样例文件稳定 id 与展示路径写在 manifest；用户安装后得到自己的可编辑副本，升级不覆盖、启动不补回删除；其他新建本地库为空。小艺用“可编辑练习”验收，仍需真实平台接入。
