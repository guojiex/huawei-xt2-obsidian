## 设置内重置（2026-10-25）

用已核实的 ApplicationContext.clearUpApplicationData（API 11）恢复应用数据，不手工拼路径删除。设置中独立危险操作区，确认框列明本地数据不可恢复、远端不变、App 会关闭；输入“重置”才启用确认。先清理应用 Git 资产；失败应显示错误且允许重试。系统成功会关闭进程，不依赖成功回调重建 UI；下次打开由样例安装链路恢复。相关 API 见 api_notes M 组。只用 mock 单测验证调用与失败顺序，本轮不要实际清空现有 App 数据。
