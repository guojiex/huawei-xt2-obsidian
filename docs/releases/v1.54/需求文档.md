# v1.54 需求文档 —— 收藏列表（设计稿）

> 状态：设计稿交付（2026-11-10），原生实现留待后续版本。来源：[需求池 · 最近打开 / 收藏 / 星标](../../requirements_backlog.md)
> （「最近打开」已由 [v0.4](../v0.4/需求文档.md) 交付，本版承接「收藏」部分；「星标」仍留池）。

## 1. 背景

需求池条目「最近打开 / 收藏 / 星标」：最近打开已在 v0.4 交付。本版把「收藏」做成**独立容器**——用户把常用笔记加入收藏，
侧栏顶部随时可达，不用每次在目录树里翻找。

与既有两列能力的边界（不混淆）：

- 与 **Pin 置顶（v1.50）** 正交：Pin 是文件列表内的**排序权重**，收藏是**独立列表**；两者可叠加。
- 与 **最近打开（v0.4）** 不同：最近打开是被动记录、有上限，收藏是用户显式标记、无上限。

## 2. 设计规格（原生实现按此执行）

### 54.1 收藏区（侧栏文件视图顶部；2026-11-11 第三稿重做）

设计目标：前两稿的收藏行与目录树行几乎一样（同样的文件夹式区头、同样的笔记图标、满屏蓝色实心星），同一篇笔记上下各出现一次、长得一样，用户分不清哪块是收藏、哪块是树。第三稿让收藏区**一眼可辨、但不抢目录树的戏**。

- 位置与显隐：侧栏「文件」页签内、计数头之下、目录树之上；仅当前库至少有一篇收藏时显示；按库隔离；折叠状态按库记忆（`favoritesFolderState`，`favOpen` 进 URL）。
- **区头 = 分区标签**，不再是文件夹行：「收藏」+ 篇数，`--caption`、字重 500、字距 0.08em、`muted`；无图标。折叠箭头放在区头**右端**，指针设备仅悬停 / 键盘焦点 / 已收起时显示，触屏常显；点区头任意处展开 / 收起。
- **目录树上方加同款分区标签「全部笔记」**（仅收藏区可见时出现），让侧栏读作「收藏 / 全部笔记」两个分区；取代前稿的分隔线。
- **行 = 首字色块 + 标题 + 所在文件夹**：
  - 首字色块：24vp 圆角方块，内为标题首字（拉丁字母大写），文字色与 14% 底色取自 callout 色板（`--cb-note / tip / warn / purple / gray`），**按所在文件夹哈希取色**——同一文件夹的收藏同色，形成视觉分组；不用星标、不用笔记图标，与树行明确区分。
  - 标题：`--small`、`ink`、超长 ellipsis。
  - 所在文件夹：行尾 `--caption` `muted`，只显示最近一级（根目录显示「根目录」），最多占行宽 40%；完整路径进悬停提示与读屏（「打开收藏的笔记：X，位于 Y」）。
  - 行高 40vp（`--s10`），粗指针 48vp（`--touch`）；行间距 2vp。
- **当前笔记**：只把标题变 `--blue` + 字重 500，**不加底色**——底色高亮留给目录树，避免同一篇笔记两处同时高亮。
- **移出收藏**：
  - 指针设备：悬停 / 键盘焦点时，行尾文件夹名原位换成「移出收藏」图标按钮（实心星，`muted`，悬停 `ink`），点击即移出、无确认、不删笔记。
  - 触屏：行左滑展开「改名 / 移出收藏」，**滑到底松手 = 移出收藏**（提示文案「· 松手移出」，操作底色 `ink`）。**不再沿用文件树的「滑到底删除」**——在收藏列表里滑一下就把笔记删进回收站，与用户预期不符。
  - 两种方式都给 toast「已取消收藏：X」。
- 列表超高：区内滚动，上限约 5.5 行，细滚动条，不推挤目录树。
- 排序：收藏时间倒序，最新在前。

### 54.2 收藏入口（文件行行尾星标）

- 文件树每个**笔记行**行尾、跨栏图标之前，增加星标切换按钮：未收藏 = 描边星（muted），已收藏 = 实心星（`muted`，悬停 `ink`；2026-11-11 第三稿由 `--blue` 改为 `muted`，图标 16vp——树里满屏蓝星太吵，收藏状态已由顶部收藏区表达）；
  `aria-pressed` 反映状态。
- **指针设备降噪**：未收藏星标默认隐藏，行悬停 / 当前行 / 键盘焦点时才出现；已收藏实心星常显（状态可见性优先）；
  触屏设备（无 hover）常显。
- **菜单入口**：三个笔记级「⋯」菜单各提供收藏切换——移动端顶栏「⋯」的「当前笔记」组、桌面左 / 右栏「⋯」菜单
  （跟随各自栏内笔记，移动端跟随激活栏笔记）；标签「收藏此笔记 / 取消收藏此笔记」，`aria-pressed` 反映状态，
  无笔记时禁用；与星标入口即时同步（降噪后保住的显式可达路径）。
- 点击切换收藏 / 取消收藏，toast 反馈「已收藏：X」/「已取消收藏：X」；树行星标与收藏区即时同步刷新。
- 文件夹行不加星标；「章节」页签不加收藏区。

### 54.3 数据与生命周期

- 收藏 = **轻量持久化的按库笔记列表**。原生建议 `favorites_<vaultId>` preferences 通道（与 v1.50 `pinned_<vaultId>`
  同款），**不建第二份业务索引**——展示时标题 / 文件夹经现有文件树数据解析，与快切 / 回收站同口径。
- 删除（进回收站）：收藏区**隐藏**该行，收藏关系保留；恢复后自动回到收藏区。
- 永久删除：从收藏列表移除。
- 重命名 / 移动：收藏区标题与文件夹标注跟随现有树数据，收藏关系不丢。
- 陈旧条目（路径已不存在）无副作用、不自动清理（与 v1.50 Pin 口径一致）。

### 54.4 红线

- 收藏列表不进埋点：收藏的标题 / 路径禁止上报（H 节「笔记内容禁止进埋点」红线延伸）。
- 零新增权限；样式只用既有 token，不散写颜色 / 间距数值（硬约束 17）。

## 3. 明确不做（本版）

- 星标（`#tag` 式标签聚合）——仍留需求池，本版不合并进收藏。
- 收藏手动拖动排序：第三稿评估后仍不做，回需求池（收藏超过约 10 条后有价值，届时与「按文件夹分组」一起考虑）。
- 跨库收藏聚合、收藏手动排序、收藏内搜索。
- 卡片与双栏视图接入：两类视图尚不存在，落地时各自接入（与 v1.50 Pin 同口径）。
- 原生 ArkTS 落码（本版仅设计稿 + 规格，后续版本承接）。

## 4. 验收标准（设计稿）

1. 原型侧栏出现「收藏」折叠区（默认打开的 `reading` 库预置 2 条演示收藏，开箱即见；`local` 库另有 2 条，刷新恢复样例）；展开显示单行行（图标 + 标题，悬停可见所在文件夹），点击在激活栏打开。
2. 文件行行尾星标可切换收藏；已收藏行显示实心常显星标，未收藏星标在指针设备上悬停行 / 当前行 / 键盘焦点才出现；笔记级「⋯」菜单（移动端顶栏 / 左右栏）可切换当前笔记收藏并与星标同步；收藏区实时增删、计数正确；取消收藏行立即消失且笔记不受影响。
3. 切库隔离：每个库各自收藏；无收藏的库不显示收藏区。
4. 收藏关系随删除 / 恢复 / 移动按 §54.3 表现（原型内演示）。
5. 深浅色 × 单 / 双 / 三屏布局不破；展开 / 收起状态与键盘操作正常；样式只用既有 token。
