# v1.37 需求文档 —— 设置页导出当前知识库

> 状态：🔵 原生已实现待设备验收（2026-11-06）；v2 原型已实现并经 headless Chrome 功能与截图核对；37.1–37.4 原生本地实现、自动测试与签名 HAP 构建完成，设备验收未做。
> 对应里程碑：独立优化。领取顺序以 [实施总清单](../实施总清单.md) 为准；依赖 [v1.25 25.18 库级分享](../v1.25/需求文档.md)。
> 需求来源：[需求池 C 节「设置页导出当前知识库」](../../requirements_backlog.md#c-同步与数据)（2026-11-04 原型走查，用户确认「按推荐的改」）。

## 1. 版本定位

设置 → 数据目前只有「重置所有数据」这一个危险操作，没有任何备份入口：用户想在重置、换机或升级前留一份笔记，只能想到去分享面板。本版在数据页提供「导出当前知识库（ZIP）」，**复用知识库分享（v0.8 ZIP + v1.25 25.18 入口）**，不新增打包格式；重置确认里提示先导出。

本版只做“导出备份”入口，不做 ZIP 导入 / 恢复（已分配 v1.36）。

## 2. 完成判定

数据页可一键打开当前知识库的 ZIP 分享；重置确认可直达同一入口；导出内容、文件名、排除项与 v0.8 知识库 ZIP 一致。原生与设备分别验收。

## 3. 需求清单

| # | 需求 | 验收点 |
| --- | --- | --- |
| 37.1 | **数据页备份分组。** 「设置 → 数据」在「本地数据」上方新增「备份」分组，一行操作「导出当前知识库（ZIP）」（`--blue` 标题，沿用 v1.13 操作行语义），说明行为「「库名」· N 篇笔记 · 打包为 ZIP，可保存到文件或发给自己」；分组下注明「不包含应用设置、草稿、回收站与访问令牌。其他知识库可在「管理库」中逐个分享。」 | 显示的库名与篇数为当前库；切换库后返回设置页即时更新 |
| 37.2 | **复用知识库分享。** 点按后打开当前库的「分享知识库」面板（与库管理页「分享」同一入口、同一 ZIP 规则与系统分享流程）；关闭面板后焦点回到该操作行。 | 打包内容、文件名、排除项与 v0.8 / v1.25 25.18 一致；不新增导出格式或保存路径 |
| 37.3 | **空库禁用。** 当前库没有笔记时操作行禁用，说明改为「当前知识库没有笔记，无需导出」。 | 空库不可点，读屏读出禁用 |
| 37.4 | **重置前建议导出。** 「重置所有数据」确认区首行提示「建议先导出当前知识库作为备份。」，其中「导出当前知识库」为行内链接：点按后收起确认区并打开 37.2 的分享面板。不强制导出，不改变重置的确认步骤。 | 未导出也能照常重置；导出后取消分享不触发重置 |

## 4. 明确不做

- **不做 ZIP 导入 / 恢复 / 换机迁移**，不做“全部知识库一次导出”、自动定时备份或云端备份（回需求池，Q2）。
- 不导出应用设置、草稿、回收站、最近打开、同步配置与访问令牌；令牌在任何情况下不进入导出包。
- 不改 ZIP 打包规则、文件命名与临时文件清理（v0.8），不改分享面板（v1.25）。
- 不改重置的影响范围与确认流程（v1.13）。

## 5. 技术约束与依赖

- 环境事实：HarmonyOS API 24 / ArkTS；包名 `com.jxg.huaweiobsidian`；目标设备 XT2。**禁止凭记忆编造 HarmonyOS API**（`AGENTS.md` 硬约束 18）。
- 只调用现有分享服务与 v1.25 25.18 的库级入口；不新增文件系统、压缩或分享接口。25.18 已有本地实现，本版仍需验证复用效果。
- 篇数取统一库访问层的计数，不在设置页另行遍历目录。
- 视觉 token 以 v2 原型 `:root` / `[data-theme="dark"]` 为准。
