## 1. 版本定位

简单模式的格式浮条原先**常驻**在每栏底部正中，读笔记时也盖在正文上，单屏还与缩放控件重叠。参考主流笔记 App（Apple 备忘录、Notion、Obsidian 移动端均为「编辑时出现、贴键盘或屏幕底边、位置不可拖动」），本版改为：**只在编辑时出现，停靠在栏底（单屏原生贴软键盘上沿），不再浮在正文上**。

## 2. 完成判定

简单模式下，阅读时不显示格式栏；光标进入某一栏正文后，该栏底部出现整行停靠的格式栏，同时隐藏该栏缩放控件；点「完成编辑」或焦点离开后格式栏收起、缩放控件恢复。单屏原生软键盘弹出时格式栏贴键盘上沿，随键盘升降。格式栏与缩放控件在任何形态下不再同时出现、不再重叠。原生与设备分别验收。

## 3. 需求清单

| # | 需求 | 验收点 |
| --- | --- | --- |
| 30.1 | **阅读时隐藏。** 简单模式下，只有该栏正文（可编辑块）或该栏格式栏 / Aa 面板持有焦点时才显示格式栏；焦点离开（点导航、另一栏、顶栏、空白处）即隐藏。 | 打开笔记仅阅读时看不到格式栏 |
| 30.2 | **停靠而非浮动。** 显示时格式栏为该栏底部整行：通栏宽、顶部细分隔线、`--paper` 底、无阴影与圆角；正文滚动区底部留出等高空白，最后一行不被遮住。宽屏按钮靠左、「完成编辑」靠右；单屏按钮居中、「完成编辑」在末尾；按钮超出时横向滑动。 | 正文末行可滚到格式栏之上 |
| 30.3 | **单屏贴软键盘（原生）。** 单屏软键盘弹出时，格式栏贴在键盘上沿并随键盘高度变化移动；键盘收起而焦点仍在正文（如外接键盘）时贴屏幕底边。原型无软键盘，以贴栏底示意。 | 键盘升降、输入法候选栏变化时格式栏不被遮挡、不悬空 |
| 30.4 | **完成编辑。** 格式栏末尾「完成编辑」（键盘收起图标，读屏「完成编辑」）：收起软键盘、结束编辑焦点、隐藏格式栏，焦点移到该栏笔记路径行。按下格式按钮不夺走正文焦点与选区。 | 点加粗后仍在编辑；点完成后格式栏消失 |
| 30.5 | **与缩放控件互斥。** 该栏处于编辑焦点时隐藏其缩放控件，结束编辑后恢复（与专业模式「源码编辑时隐藏缩放」一致）。 | 任一形态下两者不同时出现 |
| 30.6 | **按栏独立。** 双栏时只有获得编辑焦点的那一栏显示格式栏；另一栏保持阅读态与其缩放控件。 | 右栏编辑时左栏无格式栏 |
| 30.7 | **不改内容与功能。** 格式栏按钮集合、Aa 面板内容、块编辑浮条（v1.18）与保存链路不变；专业模式源码编辑工具栏不在本版调整。 | 既有格式操作结果不变 |
| 30.8 | **原型同步。** v2 原型以 `.text-focus` 状态、`simpleDone` / `simpleDoneRight` 与焦点跟踪实现 30.1、30.2、30.4–30.6。 | 原型不作为原生或设备验收 |

## 4. 明确不做

- **不做可拖动的格式栏**：拖到哪都会遮挡正文，并需按形态 / 横竖屏 / 双栏分别记位置，手势与选区、滚动冲突，读屏不可用；主流笔记 App 亦不提供。
- **不做格式栏按钮自定义**（增删、排序）与**选区旁快捷浮条**：已登记需求池，另行排期。
- 不改专业模式源码编辑的格式栏位置与样式。

## 5. 技术约束与依赖

- 环境事实：HarmonyOS API 24 / ArkTS；包名 `com.jxg.huaweiobsidian`；目标设备 XT2。**禁止凭记忆编造 HarmonyOS API**（`AGENTS.md` 硬约束 18）。
- 贴键盘：项目已记录键盘避让区接口（[api_notes](../../harmonyos/api_notes.md) 中 `AvoidAreaType.TYPE_KEYBOARD`、`Window.getWindowAvoidArea()`、`on/off('avoidAreaChange')` 及 ArkWeb `keyboardAvoidMode`）；实施前须按 API 24 SDK 复核起始版本与在 ArkWeb 简单模式编辑中的实际行为，未核实不落码。
- 编辑焦点判断需覆盖 ArkWeb 内可编辑块获得 / 失去焦点、Aa 面板打开、输入法组合中等状态；组合输入期间不得因焦点抖动收起格式栏。
- 视觉 token 以 v2 原型 `:root` / `[data-theme="dark"]` 为准。

### 6.2 原生（2026-11-05）

实现与验证记录（源码 / 自动测试 / 构建；模拟器与设备项见 6.3）：

- **改动文件**：`entry/src/main/ets/pages/Index.ets`（状态 + 停靠栏 + 共享格式行）、`entry/src/main/ets/components/PreviewWebView.ets`（焦点回调桥）、`entry/src/main/ets/common/Icons.ets`（`P_KEYBOARD_DONE`）、`web/mdpreview/src/index.ts`（焦点跟踪 + `finishSimpleEditing`）+ 重打包 rawfile（`entry/src/main/resources/rawfile/mdpreview/index.html`）。
- **30.1 阅读时隐藏**：web 侧 `activeElement.isContentEditable && contentElement.contains(...)` 判定（覆盖 plaintext-only 代码、表格单元、标注体），`focusin` 即时 / `focusout` 延迟刷新；native 侧 `simpleFormatBarVisible(pane)` = 正文聚焦 ‖ formatMenuOpen 且该栏 ‖ tableGridOpen 且该栏。失焦 250ms 去抖 + 组合输入（composing）期间自动重排程，输入法组合中不收起。
- **30.2 停靠**：原生 `SimpleFormatDock`（横向 Scroll + constraintSize minWidth '100%'）：通栏、`border-top` 细线、`bg_card` 底、无圆角阴影；内容区 `layoutWeight(1)` 自动收缩留出等高空间（末行不被遮）。宽屏按钮靠左 done 靠右；单屏 done 在滚动内容末尾。按钮间距 `Space.s1`，高 `Size.touch + 2*s1`，与原型 `.edit-tools` 一致。
- **30.3 单屏贴键盘**：dock 底部 `margin keyboardInsetVp()`（复用既有 `keyboardInsetPx`（`AvoidAreaType.TYPE_KEYBOARD`）→ `px2vp` 链路），随键盘升降；原型无软键盘，贴栏底示意。API 证据见 `api_notes.md`（`TYPE_KEYBOARD` / `getWindowAvoidArea` / `avoidAreaChange` 均 @since 9 ≤ 24 ✅）。
- **30.4 完成编辑**：`SimpleDoneAction`（`P_KEYBOARD_DONE` 图标、brand 色、读屏「完成编辑」）→ `finishSimpleEditingFor(pane)`：bridge `finishSimpleEditing()`（web blur + notify）+ 立即隐藏 + `requestFocus('pane-title-' + pane)`（PaneTitle 行已加 `.focusable(true).id(...)`）。格式按钮为原生 Button 不夺 ArkWeb 焦点。
- **30.5 缩放互斥**：两处 `zoomControlsVisible` 简单模式取 `!对应栏SimpleTextFocus`（右栏 `rightFilePath.length > 0 && (simple ? !rightSimpleTextFocus : !rightEditing)`；左栏 `currentFilePath.length > 0 && (simple ? !leftSimpleTextFocus : smMode === 'preview')`）。
- **30.6 按栏独立**：`leftSimpleTextFocus` / `rightSimpleTextFocus` 两态独立；dock 渲染点分别在 PreviewPane 与 RightWorkspacePane。
- **30.7 不改内容与功能**：格式按钮重构为共享 `FormatActionsRow(pane, gap)` —— 专业浮条 pill 样式与 gap=0 与 v1.7 完全一致（`test_simple_format_history_ui` 断言通过）；Aa 面板、块浮条、保存链路未动。
