# v1.78 需求文档 —— Git 同步页右栏铺满（代码查看器）

> 状态：已实现（2026-11-16）。设计真源：[Git 同步页设计](../../prototype/v2/Git同步页设计.md)（§2 结构图、§2A 逐行差异、§5 组件表）；原型入口 `?ui=2&view=sync`。需求来源：用户 2026-11-16 看到 v1.77 浅色截图后反馈「右边你为什么不占满呢？」——v1.77 虽有默认差异，但右栏 diff 仍是浮在灰底上的一张卡：四周留边、圆角 + 阴影、卡高只包内容、下方一大片空白，不像铺满的查看器。本版只改右栏的呈现容器，不改任何 Git 语义、diff 数据或左栏。

## 1. 版本定位

v1.77 让右栏「有内容」，但右栏本身还是「卡片 + 背景」两段式：卡片尺寸随内容收缩，留白和阴影让它看起来是一块贴上去的面板，而不是铺满的代码查看器。本版把右栏改成一个从标题行到底部操作栏、从左到右边缘连续铺满的查看器：去掉 diff 卡的边框 / 圆角 / 阴影 / 外边距，标题行带底部分隔线贴顶，行区占满剩余高度并独立滚动。左栏卡片分组、默认选中、必填提示、单屏堆叠、深浅色、全部 Git 流程沿用 v1.77 / v1.76 / v1.75，不改。

## 2. 完成判定

打开 Git 库同步页 → 右栏「逐行差异」标题行贴顶并有底部分隔线 → 其下的文件头 + 增删行从右栏左边缘一路铺到右边缘、从上到下占满剩余高度（无灰边、无浮卡圆角 / 阴影、无卡下方大块空白）→ 内容超出时行区内部滚动、标题行和文件头固定 → 左栏与底部操作栏观感不变，深色模式可读，单屏上下堆叠、返回 / 忙碌保护沿用。

## 4. 明确不做

- 不改 diff 数据口径（HEAD ↔ 工作区未提交改动）、native `getFileDiffs`、两份 `Index.d.ts`、`GitNativeService`。
- 不改左栏卡片分组 / 提交者必填 / 主按钮禁用原因 / 换行规则，不改底部操作栏。
- 不改 push-only、仅快进 pull、分支编辑、令牌重试流程与隐私边界（路径 / 正文不进日志）。
- 不改同步页之外的页面 / 弹窗视觉。

## 5. 技术约束与依赖

- 原型右栏从「卡片随内容收缩」改成「容器 flex 铺满」：`.sync-detail` 必须 `display:flex;flex-direction:column;overflow:hidden`，子级 `.sync-file-diff` 才有 `flex:1` 参照高度，`.sync-diff-lines` 才能内部滚动；`.hidden`（`display:none!important`）继续隐藏未选文件，铺满只作用于当前显示的那一张。
- ArkTS：`DiffPane()` 去掉 padding 后，标题行必须自带 `padding` + `border({ width: { bottom: 1 } })`，否则贴边；`@Builder` 调用不能链式加修饰符。`DiffPanel()` 去掉浮卡后用 `bg_page` 与外层同底，`layoutWeight(1)` 保留以占满剩余高度。
- 颜色 / 间距只引用 token（`app.color.*`、`Tokens`），不散写数值；原型改样式后同步截图。
- 真机验收（API24 / XT2）由用户执行后回填 §6.2。
