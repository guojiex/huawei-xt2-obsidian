> 配套设计规格：[关系图谱设计.md](../../prototype/v2/关系图谱设计.md)

## 1. 版本定位

交付关系图谱的**设计稿**：在 v2 原型上落地「全屏关系图谱视图」（全局图 + 当前笔记本地图），产出交互规格与数据口径；**原生实现留待后续版本**，本版只交设计稿、规格文档与防线测试。

设计理由：图谱是「看一眼就想装」的获客功能，但图渲染（力导向布局 + 手势交互）在 HarmonyOS 上尚无已验证路线，属待核实技术项；按 [v1.99](../历史版本归档.md#v199-需求文档) / [v2.1](../历史版本归档.md#v21-需求文档) / [v2.2](../历史版本归档.md#v22-需求文档) 先例，先出设计稿收口交互与口径，原生实现前完成渲染路线核实。

## 2. 完成判定

原型 `docs/prototype/v2/index.html` 具备可演示的关系图谱视图：全局图与本地图视角切换、节点与边渲染、点节点打开笔记、空态 / 无链接态、URL 状态往返；规格文档 [关系图谱设计.md](../../prototype/v2/关系图谱设计.md) 交付；防线测试 `tools/tests/test_prototype_graph.mjs` 通过；**不包含任何端侧 ArkTS 代码**（原生实现与渲染路线核实留待后续版本）。

## 4. 明确不做

- **不落任何端侧 ArkTS / Web 渲染代码**：原生实现、力导向布局引擎、手势（拖动 / 缩放 / 平移）与图渲染路线核实留待后续版本。
- **不绑定渲染技术**：Canvas（`CanvasRenderingContext2D`）还是 Web 渲染，原生实现前按 [硬约束 18](../../../AGENTS.md) 走 `docs/harmonyos/` 提问流程核实，本版不预设结论。
- **不做跨库图谱**：只当前激活库（沿用 [v1.35](../历史版本归档.md#v135-需求文档) 不跨库先例）。
- **不做**：图谱内编辑、节点搜索 / 过滤、按文件夹 / 标签着色分组、节点颜色自定义、时间线 / 历史回放、图谱导出图片、图谱统计（连边数等）、标签 / 文件夹作为节点、图谱动画时长设置。

## 5. 技术约束与依赖

- 双链数据层已存在：`WikiLinkService` 维护内存 `outgoing` / `incoming` 图（[源码](../../../entry/src/main/ets/model/WikiLinkService.ets)），实现版新增「导出完整边表」的只读方法即可，不重建索引；结论只准链接，不在此复制。
- 图渲染鸿蒙能力结论尚未沉淀到 `docs/harmonyos/api_notes.md`：原生实现前需核实「力导向布局 + 手势交互」的可行路线（Canvas 已有 v1.63 噪点先例，但布局 / 交互无先例），走提问流程。
- 设计 token 只引用既有 token，不新增色值（硬约束 17）；图谱的节点 / 边用 `--blue` / `--muted` / `--paper` 等既有语义色。
- 笔记名 / 路径 / 链接关系是笔记内容，禁止进埋点（硬约束 16）。
