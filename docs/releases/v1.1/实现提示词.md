> 将本文交给负责 v1.1 的 Agent。需求仅为当前库关键词搜索与可重建的增量索引。

## 项目和边界

你在“曜石笔记”仓库工作：华为 XT2 三折叠、ArkTS + Stage 模型、API ≤24。本版应在 v1.0 发布后实施。先读 `AGENTS.md`、`docs/releases/v1.1/需求文档.md`、`docs/releases/实施总清单.md`、`docs/requirements_backlog.md` B/E 节、`docs/mvp_design.md`、`docs/open_questions.md` 和 `docs/harmonyos/api_notes.md`。再看 `VaultRegistry`、`VaultPathResolver`、`FileTree`、`NoteService` 与 `Index` 的现有读写路径。

禁止凭记忆编 API；知识库或 API 24 SDK 无依据时报告待核实。Markdown 文件是真源，索引仅为可重建数据。索引和查询必须按当前库隔离；不实现双链、标签、跨库检索或高级搜索。
