# v1.65 需求文档 —— 常驻屏保 / 台历页（启动页复用）

> 状态：本地实现完成（2026-11-13 立项，11-14 收尾）；源码级回归与构建证据见 §7，API26 模拟器与 API24 / XT2 目视验收待用户。
> 真源：[需求池](../requirements_backlog.md) D 区「常驻屏保 / 台历页（复用启动页）」；视觉真源沿用 [启动页设计](../../prototype/v2/启动页设计.md) §4 与 `docs/prototype/v2/index.html` `.startup-*`（914–969）。
> 来源：2026-11-13 用户提出「右上角菜单常驻入口 → 启动页常驻为屏保/台历 → 可配置名言轮换间隔 → 点击屏幕关闭回笔记」。

## 1. 目标与边界

把只在冷启动出现约 3 秒的品牌遮罩，改造成**可随时从右上角更多菜单进入、常驻不自动消失**的全屏页面：复用同一套极光 / 颗粒 / 浮尘 / 衬线名言 / 中文日期视觉，按配置间隔轮换名言，点击任意处淡出并回到笔记工作区。

- 系统开屏（`module.json5`）保持简易启动页，零改动。
- 冷启动遮罩的入场编排、最短驻留、`ready` 淡出与原子首帧语义**不变**；屏保是同一组件的另一个模式，默认参数保持冷启动路径。
- 名言仍是本地 12 句、不联网、不轮播原型、不写入笔记内容、不进埋点。
- 屏保是应用内页面，不接管系统屏保 / 锁屏，不申请任何权限。

## 2. 长期规则

- **单一视觉真源**：冷启动与屏保共用 `StartupMask.ets` / `StartupAmbience.ets` / `Startup` token；不得复制一份品牌层代码另起组件。所有颜色 / 字号 / 间距 / 时长只引用 `$r('app.color.*')` 或 `Tokens.ets` 常量（硬约束 17）。
- **冷启动路径零回归**：`StartupMask` 的屏保参数一律带默认值（`screenSaver = false`），新增分支必须受 `screenSaver` 守卫；`onReadyChange` 在屏保模式直接返回，永不自动淡出。
- **动画起播时机**：遵守 [api_notes U4](../../harmonyos/api_notes.md#u4-显式动画起播时机abouttoappear-中动画不生效2026-11-13v164-修订)——`animateTo` / `keyframeAnimateTo` 不得在 `aboutToAppear()` / `aboutToDisappear()` 内直接调用；轮播动画由 `setTimeout` 异步触发或写在 `.onAppear()`。
- **定时器必须可清理**：轮播与逐字浮现的 `setTimeout` id 集中登记，`aboutToDisappear()` 与屏保退出时全部 `clearTimeout`；退出同时停止无限循环（`animateTo({duration:0})`）并销毁氛围层。
- **字体子集**：名言库改字仍需重跑 `tools/generators/gen_startup_serif.mjs`（[v1.64 §2](../v1.64/需求文档.md)），字符集不变时零改动。
- **偏好真源**：轮换档位与默认值只在 `Tokens.ets` 的 `ScreenSaver` 常量里定义；持久化走 `ScreenSaverPreferenceStore`（应用级 `preferences`，不按库隔离）；非法值回退默认档。
- 系统「减少动态效果」偏好按 [api_notes U1](../../harmonyos/api_notes.md#u-组减少动态效果偏好与arkui-动画) 保持未核实，只沿用组件 `reduceMotion` 开关；减动效时仍按间隔换句，但不播放淡入淡出与逐字动画。

## 3. 产品拍板（本版默认，改口径须先改本节）

| 决策 | 本版取值 | 理由 |
| --- | --- | --- |
| 进入方式 | 仅右上角更多菜单 → 应用组 →「屏保 / 台历」手动进入 | 用户只要求菜单入口；空闲自动进入需要全局触摸/前台计时，会侵入编辑链路 |
| 退出方式 | 点击页面任意处，240ms 淡出，回到 `topView = 'note'` 笔记工作区 | 对齐「点击屏幕自动关掉这个页面进去笔记」 |
| 名言轮换档位 | 不轮换 / 15 秒 / 30 秒（默认）/ 1 分钟 / 3 分钟 / 5 分钟 | 覆盖「多久换一下」，含短档便于屏保浏览；再次修订（2026-11-14 用户反馈 1 分钟太慢）：新增 15 秒 / 30 秒并将默认由 1 分钟下调为 30 秒；扩档只改 `ScreenSaver.intervalOptions` 与两标签数组 |
| 配置入口 | 设置与关于 → 常规 →「屏保 / 台历」分组，四个分段按钮 | 与「显示行号」等常规设置同层级，无新弹窗 / 新组件 API |
| 台历元素 | 屏保模式下中文数字日期放大至 `--large`，并显示「轻触任意处返回笔记」提示 | 启动页 1:1 视觉不变，屏保增加必要的退出可发现性 |
| 首次轮换时机 | 入场编排播完后（`minHold + enterDur`）再起算，不打断逐字浮现 | 与冷启动「编排播完再淡出」同口径 |

## 5. 实现口径

- 新增：`entry/src/main/ets/model/ScreenSaverPreferenceStore.ets`、`tools/tests/test_screensaver_design.mjs`。
- 修改：`common/Tokens.ets`（新增 `ScreenSaver` 常量类）、`common/Icons.ets`（新增 `screenSaver` 图标）、`components/StartupMask.ets`（屏保模式 / 轮换 / 点击退出）、`components/SettingsView.ets`（常规页分组与 `@Prop` 回调）、`pages/Index.ets`（状态、菜单项、覆盖层、偏好读写与设置接线）。
- 不新增 Service / Manager：轮换是组件内的局部定时流程，偏好读写沿用现有 `EditorPreferenceStore` 的 store 形态，无需新抽象。
- 屏保与冷启动共用 `startupSerifRegistered` 全局一次注册；`$rawfile` 路径保持编译期字面量。
- 轮换用 `setTimeout` 递归而非 `setInterval`：每轮逐字时长随句长变化，递归排程能让「换句完成」与「下次间隔起算」对齐，且退出时只清一个 id + 一组逐字 id。

## 6. 明确不做

- 空闲自动进入屏保 / 自动计时唤醒、系统屏保或锁屏接管、前后台生命周期联动。
- 联网名言、用户自定义名言库、名言收藏 / 分享、按月台历视图与日程。
- 原型页的名言 9s 轮播与「轻触进入」演示文案（仅原型演示，原生启动页不做）。
- 系统减少动态效果偏好自动接线、低端 / 省电自动降级、`blendMode` 离屏混合。
