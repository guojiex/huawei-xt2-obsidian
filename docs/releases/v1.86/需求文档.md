# v1.86 Web 组件过滚动反馈

> 来源：[需求池 AD 节](../../requirements_backlog.md)，2026-11-19 立项。
> 动机：v1.84 84.3 将「编辑器 / 预览（ArkWeb）内部 HTML 滚动无回弹」登记为设备观察项；用户 2026-11-19 在 XT2 真机实测确认正文划到底无回弹，并确认按 AGC《通用应用 UX 体验标准》2.1.5.3.3「滑动过界反馈动效一致性」（强烈推荐）应予补齐——标准看用户可见行为，不区分实现层。
> 与 [v1.84](../v1.84/需求文档.md)（ArkUI Scroll 的 edgeEffect）互补：v1.84 覆盖原生滚动容器，本版覆盖 Web 组件。

## 1. 根因与系统能力（本机 SDK 声明核对，api_notes AJ 组）

- `web.d.ts`（API 24 工具链）：`overScrollMode(mode: OverScrollMode): WebAttribute`，**@since 11**（≤ API24）。
- **默认值 `OverScrollMode.NEVER`**——Web 组件默认无过滚动反馈，这是正文无回弹的根因。
- 枚举：`NEVER = 0`（关闭）、`ALWAYS = 1`（开启，「适用于需要增强滚动反馈的场景」）。
- ⚠️ SDK 同时警告：Web 参与**嵌套滚动**（外层 ArkUI 滚动容器）时建议 `NEVER`，回弹会抢占滚动交接。本版涉及的 4 类 Web 均 100% 填充、自身滚动，不在 ArkUI Scroll 内，警告不适用。
- ⚠️ 未记载项：mdeditor 滚动发生在内层 `.cm-scroller`、mdpreview 在内层 `#content`（两包 body 均不滚动）；`overScrollMode(ALWAYS)` 对**内层滚动器**是否生效无文档记载，需真机验证（见 §4.2）。

## 2. 需求清单

| 编号 | 需求 | 验收点 |
| --- | --- | --- |
| 86.1 | 用户可见且自滚动的 Web 组件显式 `.overScrollMode(OverScrollMode.ALWAYS)`：EditorWebView（主编辑器）、PreviewWebView 三处（主预览 / 回收站预览 / 简单模式预览）、PrivacyPolicyView（隐私政策页）、SpikeEditorPage（M0.5 对照页）——共 6 处 | 源级防线测试：每个 `Web(` 组件声明必须显式 overScrollMode；GitBridgeView（1×1 隐形 git 引擎，无可见滚动）豁免并登记 |
| 86.2 | 其他行为零改动：`nestedScroll` / `keyboardAvoidMode` / `javaScriptAccess` / `renderMode` 等既有配置不动；`web/` 两包源码与 rawfile 产物不动；GitBridgeView 不加属性 | 既有回归零新增失败；Web 包零改动（86.3 备选除外） |
| 86.3 | **真机验证不生效时的升级路线（不在本版实现）**：若 `overScrollMode(ALWAYS)` 对内层滚动器不产生回弹，回到需求池评估 Web 侧方案（mdeditor / mdpreview 内实现过界动效，或改用文档级滚动），另立需求 | XT2 真机实测结论回填 §4.2 |

## 3. 明确不做

- 不改 `web/mdeditor` / `web/mdpreview` 源码与 rawfile 产物（86.3 是验证失败后的后续版本）。
- 不给 GitBridgeView 加 overScrollMode（隐形引擎，1×1，无用户可见滚动）。
- 不动嵌套滚动配置（SDK 警告场景本版不涉及）。
- 不新增 changelog 对外版本条目（`versionName` 不动；对外版本归 v1.85 抬升管理）。
