# v1.52 需求文档 —— 统计与成就面板（原生实现）

> 状态：本地实现完成（2026-11-10）。来源：[v1.51 §2 指标口径](../v1.51/需求文档.md)（承接需求池「统计 / 成就面板」条目的原生落码部分；用户授权「全都做，按顺序」）。

## 1. 背景

v1.51 交付了统计与成就面板的设计稿与指标口径；本版按该口径完成原生实现（ArkTS 统计服务 + 页面），不改动口径本身。口径真源是 [v1.51 §2](../v1.51/需求文档.md)，本文只定义原生落码的实现范围与验收，口径冲突时以 v1.51 为准。

## 2. 需求

### 52.1 统计服务（VaultStatsService）

- **输入**：当前库 `VaultAccess`（经 `VaultRegistry.accessFor(vaultId)`，沙箱 / 外部统一，不按 rootKind 分叉——硬约束 14）。
- **口径照抄 v1.51 §2**：
  - 笔记数 = 当前库未删除笔记数（`allNotes()`；回收站在库外 `filesDir/trash`，天然不计）；
  - 总字数 = 各笔记源码文本去掉空白字符后的字符数总和；
  - 连续写作天数 = 截至今天逐日往前数的连续活跃日；今天无修改从昨天起算；今天和昨天都无修改为 0；
  - 累计写作天数 = 有笔记 mtime 的日历日总数（去重，本地时区）；
  - 活跃日 = 当日至少一篇笔记 mtime 落在该日历日（`VaultFileStat.mtimeSec`，单位秒）；
  - 近 12 周热力图 84 格：行 = 周（最老在上）、列 = 星期一至日；当日修改笔记数分 4 档：0 / 1 / 2–3 / ≥4；最左月份刻度（同月不重复）；未来日期按 0 计并标注「未到」；
  - 徽章 8 枚里程碑（初稿 / 十篇 / 百篇 / 万字 / 十万字 / 七日连写 / 三十日连写 / 百日坚持），达成态（彩色 + 名称 + 已达成）与进度态（置灰 + `min(value,goal)/goal`）。
- **纯函数分层**：聚合逻辑（天数 / 热力图 / 徽章 / 字数）为不依赖 ArkUI 的纯函数，便于 Node 契约测试（沿用 FileTree 源码切片进 vm 的套路）；扫描与 UI 隔离。
- **不阻塞 UI（51.6）**：扫描按笔记分块读取（每块让出事件循环），页面先进骨架 / 缓存值再回填；不做 taskpool（库体量为个人笔记，分块读取足够）。
- **缓存与刷新时机（51.6 授权实现版定义）**：进页即重算（S 体量重算成本低于缓存一致性维护），不落盘缓存。

### 52.2 统计页面（VaultStatsView）

- 形态与库管理视图一致：整体替换内容区（Index `topView` 新增 `'stats'`），返回走顶栏 ‹ 与 `onBackPress`（2.7c 同级），内容页限宽居中（与 VaultManagerView 同 token）。
- 自上而下：范围行（当前库名 + 「统计只在本机计算与展示」）→ 四张数字卡（2×2）→ 近 12 周热力图（含档位说明）→ 成就徽章网格 → 口径说明（活跃日定义、mtime 口径限制——Git clone / 导入刷新 mtime 的「非写作修改」计入不补偿、全本地不上报）。
- 视觉全走 token（`app.color.*` / Tokens 常量），不散写数值；热度档用品牌色与卡片底的深浅表达，深浅色主题自适应。
- 扫描未完成时数字卡显示占位（`…`），完成后回填；扫描失败显示安全失败文案，不显示部分值。

### 52.3 入口

> 2026-11-13：原型入口与页面形态已按 [v1.58](../v1.58/需求文档.md) 重设计；本版原生仍为原形态，待 v1.58 实现。统计口径不变。

- 侧栏库切换下拉菜单 actions 区新增「统计与成就…」（「管理库…」之后、「导入库…」之前，与原型对称），点击关闭菜单并进入统计页；Agent 侧栏（`onManageVaults` 的 agent 分支同位置）同入口。

### 52.4 红线（继承 51.6，原生生效）

- 统计值、成就、热力图全部本地计算、本地展示；不进 `hiAppEvent` 埋点、不写 hilog、不随任何上报离开设备；测试锁住（stats 源文件不得 import PerformanceAnalysisKit / 出现 hiAppEvent）。
- 零新增权限、零改动 VaultAccess / 写路径——统计只读。

## 3. 明确不做（本版）

- 跨库汇总、年度报告、分享统计图（v1.51 §3 不变）。
- 历史峰值成就（只算当前值）。
- 统计结果持久化缓存与下拉刷新（进页重算已覆盖刷新语义）。

## 4. 验收标准

1. 库菜单出现「统计与成就…」入口，点击进入全屏统计页，顶栏返回 / 系统返回回到先前视图（note / agent），标题「统计与成就」。
2. 四张数字卡、84 格热力图（4 档 + 月份刻度 + 未到日）、8 枚徽章（达成 / 进度态）、口径说明齐备；数字卡在扫描完成后回填，空库显示 0 / 0 / 0 天 / 0 天。
3. 深浅色主题、单 / 双 / 三屏宽度下布局不破；token only。
4. 契约测试：活跃日 / 连写（今天有、今天无昨天有、断档）/ 累计 / 热力图分档与未来日 / 字数去空白 / 徽章达成与进度边界（value == goal）；源级断言：入口接线、topView 分支、无埋点。
5. `arkts_check` 零错误；签名 arm64-v8a HAP 构建成功。
