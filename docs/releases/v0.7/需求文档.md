## 1. 范围与完成判定

在 App 中提供库内 Agent 对话工作区，先使用明确标记的确定性 mock；工具是真实受控本地操作，mock 仅替代模型/平台回复。原型阶段仅操作浏览器内存样例，不冒称 App 文件写入。真实小艺接入由 v0.6 承担。

### 2.2 本版领取顺序

1. 共用导航与布局：7.10–7.14、7.20–7.23；先处理笔记/Agent 的共用控件，再接两页，避免等到 v1.0 才补底层依赖。
2. 对话生命周期与存储：7.1、7.8、7.17–7.18；重命名/归档/删除的模型、落盘、库隔离与恢复不能只做 UI。
3. 文件树/引用/运行集成与视觉：7.2–7.7、7.9、7.19；Agent 工程仍按 Agent v0.1 范围，不增加 Agent v0.2 的上下文深化。
4. 演示与验收：7.15–7.16 的生成检查，原型逻辑与 App 单测/HAP/正常模拟器交互分别记录；API24/XT2 保留待验。
