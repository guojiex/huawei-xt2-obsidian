# v2.0 需求文档 —— 应用图标长按静态快捷方式（新建笔记 / 搜索直达）

> 状态：开发中（2026-11-21 立项，当日落码）
> 来源：需求池 D 节「应用图标长按静态快捷方式」。机制核实见 [api_notes AO 组](../../harmonyos/api_notes.md)（本地官方文档库：创建应用静态快捷方式 / FAQ·X 键接入）。
> 版本号说明：v1.99 之后两位制 `+MINOR` 无法继续进位，按 R1 两位制顺延为 **v2.0**；仅内部迭代编号（R8），**非破坏性变更、非对外 2.0**（对外版本真源仍是 `changelog.json`）。

## 1. 版本定位

桌面长按应用图标弹出「新建笔记 / 搜索」两条静态快捷方式，点击直达对应功能；同一配置自动进入 XT2 X 键编辑界面，可添加至 X 键九宫格一键直达（[AO3](../../harmonyos/api_notes.md)）。零新增权限、零新增页面，纯声明式配置 + Want 参数路由，转发范式复用 v1.56 分享链路（AF 组）。

## 2. 完成判定

XT2 长按桌面图标弹出「新建笔记 / 搜索」两条快捷方式；点击后**冷启动与热启动**（App 已在后台）均直达新建笔记对话框 / 快切搜索面板；X 键编辑界面可见同两条快捷方式并可添加九宫格。

## 3. 需求清单

### 2.0.1 静态快捷方式声明

- `entry/src/main/resources/base/profile/shortcuts_config.json`：`shortcutId` `new_note` / `search`；label 走 `$string`（新建笔记 / 搜索）；icon 沿用现有 `$media` 资源；wants 指向 `EntryAbility` 并携带 `parameters['yaoshi_shortcut']`（官方配置法，[AO1](../../harmonyos/api_notes.md)）。
- `module.json5` 的 EntryAbility 挂 `metadata` `ohos.ability.shortcuts` → `$profile:shortcuts_config`。
- 桌面展示上限 4 条（[AO1](../../harmonyos/api_notes.md)），本版 2 条。

### 2.0.2 Want 参数路由（冷 / 热双路径）

- `EntryAbility` `onCreate` / `onNewWant` 读取 `want.parameters['yaoshi_shortcut']`，合法动作写 `AppStorage['launchShortcut']`（JSON + `receivedAt` 时间戳 nonce，复用 v1.56 `incomingShare` 转发范式）；普通启动零行为变化。
- 新增 `LaunchShortcutService` 纯逻辑层（无 SDK / UI 依赖，node 可单测，同 `ShareIngestService` 惯例）：动作常量、参数校验、载荷结构。
- `Index` `@StorageProp + @Watch` 消费：`@Watch` 兜晚到、`aboutToAppear` 兜早到，消费后清空键防重复（与 v1.56 完全同构）。
- 动作语义（两个动作都先回笔记主视图：关屏保、关抽屉、次级视图 / 弹层回落）：
  - `new_note`：打开新建笔记对话框（`openCreateNoteDialog()`，与侧栏「＋」同链）。
  - `search`：打开快切搜索（`openQuickSwitcher()`，与侧栏搜索同链）。

### 2.0.3 dev 双包同源

- dev 包 bundleName（`com.jxg.huaweiobsidian.dev`）与线上包不同，wants 里 `bundleName` 必须同源，否则快捷方式拉起线上包（[AO2](../../harmonyos/api_notes.md)）。
- `entry/src/devres` 按资源名覆盖机制（AM 组先列者优先）追加 dev 版 `shortcuts_config.json`（dev bundleName）；**profile JSON 是否同 string.json 一样被按名去重未实测**，构建 dev product 解包核实（[AO2](../../harmonyos/api_notes.md) ⚠️）。

### 2.0.4 防线测试

- `tools/tests/test_launch_shortcut.mjs`：`LaunchShortcutService` 纯逻辑单测（esbuild + vm，同 `test_share_ingest.mjs` 惯例）+ 源级断言：`module.json5` metadata、`shortcuts_config.json` 结构与参数键、devres dev 版 bundleName、`EntryAbility` 双路径接线、`Index` `@StorageProp` 消费与清空、label 字符串存在。

## 4. 明确不做（本版）

- **不做其他快捷项**：「同步 / 最近笔记 / 今日笔记」等不做——今日笔记原生未落地（v1.59 未实现）、同步入口需要 Git 库上下文；后续需要时从需求池重新分配。
- **不做独立快捷方式图标**：沿用现有 media 资源，不新增图标（不编造资源 id，硬约束 18）。
- **不做 AGC 应用内快捷方式**（pin 加桌，上限 2、需 AppGallery Kit）与**动态快捷方式 / shortcutManager 管理**（`setShortcutVisibleForSelf` 隐藏展示等）——本版只做静态声明。
- **不改 X 键接入**：系统侧行为，应用侧零代码（[AO3](../../harmonyos/api_notes.md)）；不做长按弹层样式定制。
- 冷启动备份恢复阻断页（`ApplicationBackupRecoveryPage`）替换 `loadContent` 时，快捷方式不达 Index——降级为正常启动，可接受，不专门处理。

## 5. 技术约束与依赖

- 鸿蒙行为结论一律链接 [api_notes AO 组](../../harmonyos/api_notes.md)，不复制结论。
- 转发范式复用 v1.56（AF 组 / `ShareIngestService`）：AppStorage + 时间戳 nonce + `@Watch` / 早到双兜，不另造机制。
- 零新增权限（硬约束 13：非 v1.5 功能不得新增权限）；不改 `requestPermissions` / `skills`。
- 无新增 UI 面（新建对话框与快切面板为既有组件），颜色 token 红线不涉及。
