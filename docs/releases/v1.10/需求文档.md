## 2. 需求与完成判定

| 项 | 范围与验收 |
| --- | --- |
| 读屏 | 主要入口和交互控件有可理解的名称、状态与操作顺序，覆盖知识库 / 文件导航、编辑与预览、常用对话框和设置。 |
| 系统字号 | 使用系统字号放大后，主要内容和操作可见可用，检查截断、遮挡及布局溢出。 |
| 对比度 | 浅色、深色下检查正文、图标与主要交互状态的可辨识度；实施前确定适用标准及测量方式。 |
| 形态矩阵 | 上述项目分别覆盖单屏、双屏、三屏，记录系统设置、设备与结果；API24 / XT2 验收由用户手动执行。 |

具体设备能力、读屏操作及测量标准需先核实；源码检查、自动测试、模拟器与真机证据分开记录，不预先标记通过。
