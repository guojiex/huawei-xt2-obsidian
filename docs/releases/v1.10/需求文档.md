## 4. 验收记录

### 4.1 对比度（2026-11-02）

- 测量口径：WCAG 2.1 AA —— 正文 4.5:1、UI 组件与图形 3:1；带 alpha 的 token 先按背景合成再算。工具 `tools/generators/check_contrast.mjs`（`--check` 可卡 CI），判定矩阵与豁免集中在文件内。
- 设计真源核对：浅色 token 与原型 v2 `:root` 完全一致（`--muted:#7c8390`、`--blue:#007dff`、`--danger:#cf4048`），因此浅色侧不达标属**设计层面**，不擅自改。
- 两处实现缺口已修（原型无依据或属遗漏，非设计意图）：
  - 深色 `danger`：原型 `[data-theme=dark]` 未定义 `--danger`（沿用浅色 `#cf4048`，深色底上 3.37:1）→ 改为 `#FF6B6B`，并**同步补进原型 dark 块**，避免设计与实现再漂；
  - `line_strong`（项目自定 token，无原型依据，用于输入控件描边）→ 浅色 `#D8DDE5`→`#8A909C`、深色 `#2EFFFFFF`→`#66FFFFFF`。
- 豁免（有设计依据，不达标也不改）：浅色 `text_tertiary` / `brand` / `danger` 与原型同值，属设计层面，记录为 WAIVED 并写明原因。
- 回归：`tools/tests/test_contrast_tokens.mjs` **7/7**（含合成计算、豁免有据、token 与原型比对）。

### 4.2 读屏名称（2026-11-02）

- API 核实（本机 SDK d.ts，非凭记忆）：`accessibilityText` / `accessibilityTextHint` / `accessibilityLevel` / `accessibilityGroup` 自 API 12，`accessibilityDescription` 自 API 10，均在 `compatibleSdkVersion 6.1.1(24)` 内。
- 补齐纯图标控件的可读名称：库切换卡片与其菜单项、搜索、新建、章节折叠、文件树「新建子目录 / 参考栏打开」、Git 同步（提示待推送数）、栏更多、工作区更多、格式按钮、插入图片（忙碌态）、归档对话；对话框内目录项与类型选择补「已选中 / 已展开」状态。名称尽量带作用对象（如「归档对话「标题」」）。
- 回归：`tools/tests/test_screen_reader_labels.mjs` 通过（按文件断言图标控件已带名称）。

### 4.3 系统字号（2026-11-07，模拟器实测）

- **配置落地（followSystem + 钳制）**
  - 新增 `AppScope/resources/base/profile/configuration.json`：`fontSizeScale: "followSystem"`、`fontSizeMaxScale: "1.75"`（适老化建议值；SDK schema 枚举 1/1.15/1.3/1.45/1.75/2/3.2，最大 3.2 对应系统「关怀模式」，钳 1.75 保护固定行高布局）。
  - `AppScope/app.json5` 加 `"configuration": "$profile:configuration"` 引用。
  - `EntryAbility.ets`：`ColorModeObserver` 接口加 `onFontSizeScaleUpdated` 回调打变化日志；`onWindowStageCreate` 打启动字号。数值日志用 `.toString()` + `%{public}s`（hilog 不支持 `%{public}f`）。
  - 回归：`tools/tests/test_font_scale_config.mjs` **4/4**（配置内容 / app.json5 引用 / SDK schema 枚举校验（非 Windows 跳过）/ EntryAbility 回调）。
- **官方问答**：`docs/harmonyos/qa/2026-11-07_系统字号缩放与模拟器形态切换_API26.md`，结论提炼进 `api_notes.md` AA 组（AA1–AA6）。要点：应用字体默认不跟随系统，必须 configuration.json `followSystem` + app.json5 引用；命令行改系统字号未记载。
- **实测**（Windows x86_64 模拟器，API 26，2048×2232；**证据不外推 API24 / XT2 真机**）：
  - 设置滑条 5 档：标准 = 第 2 档（1.0），特大 = 第 5 档（1.45，常规最大；更大字号页内提示走「关怀模式」）。
  - 回调链路：1 → 1.45 → 1 双向触发正常（`系统字号缩放变化 fontSizeScale=1.45` / `=1`）；同页文字高度比精确 1.45（如「通用」68/47 px、「显示主题」68/47 px），followSystem 缩放实证生效。
  - 1.45 倍下逐屏检查（截图 + 多模态分析）：主界面（侧栏 / 文件树 / 预览 / 底栏）、新建笔记对话框（含校验提示）、库管理页、设置与关于页 —— 无截断、无垂直切边、无重叠溢出。
  - 结论：此前盘点的 110 处 Text 固定高度**不盲改**——实测无截断，留待真机 / 关怀模式（3.2）暴露问题再定点修。
- **设置页操作注意（回归用）**：注入 `drag` 在恢复后的设置页可能失效；`click` 滑条轨道可直接跳档（tap-to-jump，跳到最近档位）。
- **已知模拟器问题（已恢复，非应用问题）**：显示尺寸切换（3184→2048）后 WM / RenderService 状态不一致，应用窗口渲染整屏均匀色（UI 树正常、桌面正常，SystemUI 窗口残留旧几何如 y=-11362048），重启模拟器恢复；**重启会把系统字号设置复位为标准**。
