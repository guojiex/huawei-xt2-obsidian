> 前置：[v1.7](../v1.7/需求文档.md) 简单模式、块源码映射与复杂块保护；[v1.10](../v1.10/需求文档.md) 读屏名称口径。

## 1. 版本定位

v1.7 17.4 把表格、代码、公式、图片、链接、HTML、frontmatter、callout 等整类划为简单模式只读。
2026-11-02 用户否决了「永久只读」这个定位，要求逐类排期；但每类各做一遍会各自造出一套
「识别块 → 解析 → 改结构 → 写回」的轮子。本版先把这套共用机制立起来，后续 v1.14 / v1.19 /
v1.20 / v1.21 各自只实现自己那类块的解析与操作。

本版不开放任何一类块的可编辑能力（表格除外也没有例外）：做完本版，简单模式的外观与今天一致。

## 2. 完成判定

光标或选区落在复杂块内时，简单模式能识别块的身份与源码区间、把块显示成选中态、提供该块的
两条操作路径：**上下文浮条**（高频操作，一击完成）与**块属性面板**（完整设置，本版只有通用的
「以源码编辑此块」），并通过块级源码抽屉安全回写；区间外源码逐字不变。识别失败或重叠时退回
只读并说明，不静默保护。Aa 浮层不改动，仍只管文本与段落。

## 3. 需求清单

| 编号 | 交付范围与验收要求 |
| --- | --- |
| 18.1 | **块注册表。** 把 `web/mdeditor/src/simpleMode.ts` 的 `collectSimpleModeRanges()` 升级为注册表：每类块一个匹配器，产出 `{ from, to, type, id }`；语法树能识别的走语法树，识别不了的走行模式（当前由 `blockRegistry.ts` 的 `customBlockRanges()` 识别，`simpleMode.ts` 的 `customProtectedRanges()` 负责投影到既有保护区间）。区间去重合并且互不重叠。语法树未就绪时维持现状：整篇只读并提示「正在安全解析，请稍后继续编辑」，不给结构操作。 |
| 18.2 | **块模型接口。** 定义 `parse(source, range) → Model \| null` 与 `stringify(model) → string` 的纯函数契约与类型；本版只落接口与一个空实现，**不实现任何具体块**。`parse` 返回 `null` 时该块降级只读。 |
| 18.3 | **块操作与回写。** `applyBlockEdit(state, range, op)` 只产出落在 `range` 内的 changes，底座统一校验越界即拒绝；回写后选择位置由 op 指定。撤销 / 重做、草稿、保存沿用 v1.7 的同一编辑状态，不新增状态机。 |
| 18.4 | **块选中态。** 光标或选区进入复杂块时，该块在正文里加描边（沿用 `brand` / `line_strong` token），离开时撤销；不改变块的渲染内容。**2026-11-03 修订（D-1 / D-4）**：简单模式下点链接、双链、图片先打开块属性面板，“打开链接 / 打开目标笔记 / 查看大图”为面板第一行；复选框仍直接切换。只含受支持行内项的段落整段可点，打开“这一段”面板逐项编辑，提示改为“含链接、代码或公式 · 点按逐项编辑”；真正未支持的格式仍用 v1.7 默认文案。 |
| 18.5 | **上下文浮条（C）。** 简单模式预览中的光标或选区进入已启用浮条的块时，块下沿浮出一条：最多 4 个图标按钮 + 「更多」（打开 18.6 的属性面板）；下方空间不足时向上翻转，块滚出可视区或光标离开即消失，Esc 收起并把焦点还给块。定位复用 v0.9 9.9 已落地的浮层测量能力（栏内宽度 / 可视高度约束、动态上下定位、内部滚动），限制在来源栏内不跨栏；与 Aa 浮层互斥。锚点由预览 Web 提供，具体见[统一设计 §4.3](../../engineering/简单模式复杂块编辑设计.md#43-c-上下文浮条规格)。按钮 `accessibilityText` 带对象与方向，口径同 v1.10。本版只落框架，**不启用任何块**；是否启用由各块版本写明操作项。 |
| 18.6 | **块属性面板（D）。** 半屏上滑面板，只作用于当前块：顶部拖拽条 → 标题行（块类型名 + 右上关闭图标）→ 设置行列表（标签 + 原生控件：开关 / 分段 / 步进 / 单行输入 / 选择器，可滚动）→ 底部「以源码编辑此块」；面板下方压遮罩，点遮罩即关闭。原生用 `bindSheet` 单档 `SheetSize.MEDIUM` + `dragBar: true` + `showClose: true` + `title`，`isShow` 必须 `$$` 双向绑定，不用多档 `detents`（依据 [api_notes X1](../../harmonyos/api_notes.md)）。本版只有通用行，不含任何具体块的设置项。键盘 / 读屏不依赖浮条：提供等价的「块操作」入口（菜单键 / Shift+F10 或栏内命令）直接打开本面板。**2026-11-03 修订（D-3 / D-5）**：单屏为本条原定的底部半模态；双屏 / 三屏为限制在来源栏内、避开来源块的跟手弹出。`preferType` 的 API 24 声明取值已按 [api_notes X1](../../harmonyos/api_notes.md) 核实；XT2 实际表现仍待设备验收。选择器、分段、开关与动作行即时生效且每次一个撤销步；文本框回车或失焦生效；公式与源码使用“应用 / 保存”。 |
| 18.7 | **块级源码抽屉。** 属性面板底部提供「以源码编辑此块」：只显示该块源码的编辑抽屉，保存时回写该区间；不切换模式、不暴露整篇源码。这是所有未排期语法与结构不规范块的兜底出口。**2026-11-03 修订**：保存前校验区间内容与打开时一致，否则拒绝并提示重新打开；支持 Ctrl / Cmd + Enter 保存。 |
| 18.8 | **安全不变式与单测。** 断言结构操作只改写目标区间（区间外子串相等）、解析失败即只读并说明、不清空也不用降级文本覆盖原文。沿用 `web/mdeditor/test/*.test.mjs` 的 esbuild harness 写法。 |

## 4. 明确不做

- 不开放任何具体块的编辑能力（表格归 v1.14，代码 v1.19，链接图片 v1.20，公式与扩展块 v1.21）。
- 不做整篇所见即所得，不引入富文本副本，不新增第二份 Markdown 解析。
- **Aa 浮层（`Index.ets` 的 `FormatMenu()`）不改动**：结构操作走 18.5 浮条与 18.6 属性面板，
  不往 Aa 里加区域（设计文档 §4.2 记录了 A 方向被否决的原因）。
- 不新增第二套避让规则：浮条复用 v0.9 9.9 的浮层测量与换向能力。
- 不做块级编辑态（底栏整条替换为专用工具条），见设计文档 §4.7。
- 不改专业模式行为，不申请新权限，不改包版本与发布状态。

## 5. 技术约束与依赖

- 块区间须兼容 BOM、CRLF 与转义，并与 v1.7 的块源码映射、滚动跟随共用同一套解析。
- 浮条与属性面板在 ArkWeb / ArkUI 中的定位、软键盘避让与焦点回归须在模拟器和 API24 / XT2 上验证，
  浏览器结果不能代替。
- 复杂块提示文案沿用 v1.7 的两个常量（`PROTECTED_HINT_TABLE` / `PROTECTED_HINT_DEFAULT`），
  实施到哪一类就撤掉那一类的只读提示。
