# v1.21 需求文档 —— 简单模式公式、提示块、属性与脚注

> 状态：🟡 开发中；21.1–21.5 本地实现与自动验证完成，21.6 未完成；设备验收未完成；未发布。
> 前置：[v1.18](../v1.18/需求文档.md) 块编辑底座；[v1.7](../v1.7/需求文档.md) 简单模式；[v1.4](../v1.4/需求文档.md) 提示块渲染。
> 统一设计：[简单模式复杂块编辑设计](../../engineering/简单模式复杂块编辑设计.md)。

## 1. 版本定位

公式、callout、frontmatter 属性、脚注与块 ID 属于 Obsidian 风格笔记的常见语法，出现频率低于
表格与代码，但一旦需要修改就必须面对源码。本版把它们收口：能结构化编辑的做结构编辑，
不能的（HTML 与未知语法）由 v1.18 的「以源码编辑此块」兜底。

## 2. 完成判定

在简单模式下，用户能编辑公式内容（含实时预览，前提是渲染能力已就绪）、切换提示块类型并改标题、
用属性面板编辑 frontmatter 键值、编辑脚注正文、复制块链接；改动只落在对应块区间，块外源码逐字不变。
未知与 HTML 语法保持只读并提供源码抽屉。

## 3. 需求清单

| 编号 | 交付范围与验收要求 |
| --- | --- |
| 21.1 | **公式。** 光标在块级或行内公式上时，块属性面板提供「编辑公式」：抽屉内输入 LaTeX 并实时预览，复用 v1.3 已落地的本地 KaTeX，不新增依赖。保存只改写该公式区间，保留原有定界符（`$$` / `$`）。 |
| 21.2 | **提示块（callout）。** 识别 `> [!type]` 块：块属性面板提供类型切换（note / tip / warning / danger 等常用类型 + 保留当前值）、编辑标题、可选折叠开关（`+\|-` 折叠标记）；正文仍按普通引用文本编辑。未知类型保留原值，只可改标题与正文。**2026-11-03 修订（D-8）**：阅读时点“展开 / 收起”只临时切换，不写入 `+` / `-`；写入只通过面板折叠选项。 |
| 21.3 | **属性 / frontmatter。** 文档头 frontmatter 提供属性面板：键值对编辑，支持文本、日期、标签、复选框四类；增删键值后按规范 YAML 回写，保留未知键与未知类型原值。非 YAML 或解析失败 → 只读 + 源码抽屉 + 说明。**2026-11-03 修订（D-7）**：属性面板只重写改动过的键，未触及的行（含嵌套结构、注释与原有排版）逐字保留；这是工程设计 §3.2 的属性例外。 |
| 21.4 | **脚注。** 光标在脚注引用上时提供「编辑脚注正文」（抽屉）与跳到定义处；定义在文末的脚注块同样可编辑正文。引用缺失定义时可编辑正文并说明。 |
| 21.5 | **块 ID。** 块 ID 不可编辑，提供「复制块链接」（`[[#^id]]`）；无块 ID 时提供「复制指向本段的链接」并说明需要先生成 ID（是否自动生成另议，不在本版）。 |
| 21.6 | **降级与不变式。** HTML 块、未知冒号块与混合复杂语法保持只读，提供源码抽屉与说明（用 v1.7 默认文案，不承诺后续版本）。所有编辑只改写目标块区间，块外逐字不变；解析失败保留原文，不清空或覆盖。**2026-11-03 修订（D-4）**：只含受支持行内项的段落采用 v1.20 20.4 的提示例外。 |

## 4. 明确不做

- 不做公式符号面板、可视化公式编辑器与 LaTeX 校验服务。
- 不做 frontmatter 的任意 YAML 结构编辑（嵌套、列表只保留不编辑）。
- 不在简单模式鼓励撰写 HTML；不为 HTML 提供结构化编辑。
- 不改专业模式行为，不引入新的前端渲染依赖（公式预览复用既有 KaTeX），不改包版本与发布状态。

## 5. 技术约束与依赖

- 各类块的区间识别与回写依赖 v1.18 底座；公式预览复用 v1.3 已实现的本地 KaTeX 渲染器。
- frontmatter 回写须兼容 BOM、CRLF 与文档头位置；不得移动或改写文档头之外的内容。
- 属性与脚注内容不得进入埋点或日志（沿用 v1.7 17.7 脱敏口径）。
