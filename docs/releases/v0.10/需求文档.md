# v0.10 需求文档 —— 文件导航推入与正文联动动画

> 状态：v2 原型真实浏览器单屏中间帧 / 快速反转与双 / 三屏终态已验；原生实现、自动回归与 unsigned HAP 构建完成，原生运行和设备验收待做（2026-10-31）。
> 来源：需求池 [N-01–N-03](../../requirements_backlog.md#n-文件导航推入与正文联动动画2026-10-28已分配-v010)。
> 对应里程碑：M4.11，完整归本版；执行顺序：先完成 v0.11 行号版本收口，再继续本版验收；无日历工期承诺。

## 1. 版本定位

让 v2 文件 / 章节侧栏与正文形成连续的推入、回位动画。点击汉堡打开导航时，看见列表从左边进入、原正文随之向右移动；关闭时两者同步返回。原型与原生都按这一交互验收。

v0.7 7.21 已描述过推入交互，且有部分原生实现 / 终态记录。本版是其在 v2 UI 下的完善和独立验收，不把它当作从未实现的新功能，也不抹去历史待验项。先检查并复用原生导航实现，不能另造一套状态和栏宽管理。

## 2. 完成判定

从动画开始、过渡中间到终态，导航和正文同步、无闪白、遮盖或内容重载；展开 / 关闭均可中途反向。单屏正文保持整屏宽度并向右平移，超出窗口的部分裁切；宽屏最终分栏和宽度记忆正确。文件 / 章节选择、返回、旋转和编辑状态都正常。原型视觉与原生设备验证分别留证，单纯 CSS / ArkTS 源码或终态截图不能证明动效通过。

## 3. 需求与验收点

| 10.5 | N-02 | 选笔记 / 章节后按单屏既定流程回正文并执行关闭动画；宽屏保留既定侧栏策略。保持两栏笔记、激活栏、编辑 / 预览状态、光标、滚动、未保存内容和栏宽，不重建编辑器，不新增保存逻辑 |

### 3.1 实施顺序

1. 复核 v0.7 7.21 的原生实现、v0.9 实际 UI 与 token，记录能复用和缺失的部分。
2. 在 v2 原型实现并核对单屏推入 / 回位与宽屏终态，确认按钮、状态和中间帧。
3. 原生复用现有组件与导航状态进行对齐，完成键盘、输入法、返回、快速点击和旋转处理。
4. 按 [验收场景](#6-验收记录与场景)记录自动检查、真实浏览器、模拟器和设备结果；未具备环境的项目保留待验。

### 3.2 与 v0.9 的边界

v0.9 完成既有 UI 迁移、功能保持及 v1 退出门禁；不撤销 v0.7 原有动画和已通过的行为，不引入回退。本版新增的 v2 联动动效完善与中间帧验收单独交付，不作为 v0.9 为本次增量追加的收口条件。原型和原生都以已经迁移的 v2 为起点，不再恢复、归档或改造旧稿。

## 4. 明确不做

- 当前先补原型演示；原生动效后续按本版实施，不随原型接线自动视为完成，不更新包版本或发布。
- 不重新设计文件树、双栏编辑、分享、设置、搜索或业务服务；不新增手势抽屉、第四栏或动画配置页面。
- 不恢复本地 Agent 工作区，不接入小艺或 Git 外部能力，不实施未排期的外部目录知识库。
- 不以动画触发保存、修改文件、清空草稿或重建 Web 编辑器；不通过模拟器强杀或中断写入测试动效。

## 5. 技术约束

遵循 [AGENTS.md](../../../AGENTS.md)、[已定决策](../../open_questions.md)、[v2 设计说明](../../prototype/v2/设计说明.md)、[v0.9](../v0.9/需求文档.md) 及 [v0.7](../v0.7/需求文档.md) 的现行范围。动画、可访问性与系统减少动态效果接口涉及鸿蒙行为时，先查 [API 真源](../../harmonyos/api_notes.md) 和本机 SDK，不编造 Hds / Symbol 或超 API24 接口。复用现有分栏比例与 token；原型预设不是设备物理折痕。

## 6. 验收记录与场景

- 2026-10-28：从需求池 N-01–N-03 分配，排在 v0.9 后，状态为规划中；本次没有新增动画实现或设备验收。

2026-10-28 用户要求在设计稿实际呈现动画，已补 v2 原型：导航与正文同步推入 / 回位、单屏正文保宽、宽屏分栏联动、CSS 中途反转、屏外区域 inert、减少动态效果。模拟 DOM 检查覆盖重复开关、文件选择、旋转与编辑现场保持；尚无真实浏览器中间帧 / 触控或原生 v0.10 验收证据，下方项目不据此勾选。

2026-10-31（v2 原型真实浏览器导航动画）：本地 HTTP 实页、浏览器视口 1280×720。单屏预设画布为 380×780，容器固定 380px 宽并裁切溢出；导航宽 300px、正文宽 378px。打开过渡在起始 / 约 80ms / 终态的导航 translateX 为 -297.4 / -54.5 / 0px，正文为 +2.6 / +245.5 / +300px；关闭分别为 -18.2 / -246.4 / -300px 与 +281.8 / +53.6 / 0px，正文宽度不变，导航仅在终态隐藏。关闭途中再次打开后转向最新目标并抵达展开终态，没有回到起点排队。双屏稳定终态画布 709px、导航 240px、导航展开时正文 467px；三屏稳定终态画布 1061px、导航 353px、正文 706px。双 / 三屏导航隐藏时正文回到 707 / 1059px，容器滚动宽度等于可用宽度。此处是浏览器原型几何 / 动画证据；不证明原生 ArkUI、触屏、编辑现场保持、旋转中途行为或 API24 / XT2，其他场景继续待验。

2026-10-31（原生导航实现与自动验证）：将动画接入当前使用的 `NoteWorkspaceShell`。单屏 / 单屏横向在裁切容器内用同一进度平移导航和完整宽度正文；双 / 三屏根据侧栏进度连续更新导航位置、正文可用宽度和分栏宽度，使用 `Motion.durNav` / `Motion.navCurve`。动画中不卸载导航或编辑器；MD 右栏宽度为零时禁用该栏交互。导航宽度受当前窗口限制。布局源方法回归 14/14、全仓 Node 回归 245/245；`assembleHap` 构建成功并产出 unsigned HAP，构建输出含仓库现有 ArkTS 警告。验证止于源码回归与构建，尚未在模拟器或 API24 / XT2 观察原生动画中间帧、快速反转、旋转、焦点或编辑现场；以下原生 / 设备验收项保持未勾选。

2026-10-31（10.7 减少动态效果接口核查）：v2 原型源码含 `prefers-reduced-motion: reduce` 媒体查询；原生导航目前无减动效分支，直接使用 `Motion.durNav`（240ms）。本机 SDK 声明了 `settings.display.ANIMATOR_DURATION_SCALE`（since 7、deprecated since 21）及 API 10 起的 `settings.getValue(context, name)`；但仓库 API 笔记和官方开发者文档未说明该旧缩放项是否仍可由 API 24 应用读取、是否代表无障碍减动效偏好，或是否会缩放 ArkUI 属性动画。它只是待核实候选，不据此新增设置项或接线；原生 10.7 继续待核实与验收。
