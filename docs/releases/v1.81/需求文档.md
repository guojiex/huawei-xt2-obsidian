## 2. 参考取舍

- 鸿蒙健康类界面：借鉴大数字、舒展留白、圆角分组和低对比表面；不宣称复刻官方组件或新增平台 API。
- Apple Fitness 成就陈列：借鉴奖章的层次与解锁状态；收敛为笔记应用适用的静态线稿，不加入动画、排名或社交。
- GitHub contributions：保留熟悉的周列热力图，强调长期积累。

### 年度口径与边界

- 用户于同轮追加年度统计；本版追加 81.5 / 81.6，不扩大到原生开发。
- 活跃天数：所选年内有笔记修改的去重日期数；最长连写：仅计算所选年内连续活跃日，跨年截断；活跃月份：至少有一个活跃日的月份数；月柱：活跃天数 / 该月日历天数。
- 当前稿的年度、连写、热力图均为演示数据，不是用户数据；年度演示为独立确定性夹具，不与近 12 周演示强行对账。年份下拉用当年及前两年演示，正式实现应按实际可用年份生成。
- 现有修改时间快照无法还原完整历史，不能据此声称年度新增笔记数 / 新增字数。若以后需要准确的历史写作量，应单独立项评估本地历史记录。
- 成就数量无技术上限；本版保持八枚及条件不变，收藏布局可随数据增加行数。新增徽章、年度限定徽章、分享长图均未纳入。
