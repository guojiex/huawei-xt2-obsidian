# v1.98 需求文档 —— 空笔记可编辑占位品牌蓝（输入栏打字起点提示）

> 状态：开发中（2026-11-21 立项落码）
> 来源：用户 2026-11-21 模拟器走查反馈（双栏开同一篇空笔记，「空笔记」占位视觉不一致引发讨论）。用户拍板：「输入栏才需要变蓝提示」——可编辑（输入）栏的空态占位改品牌蓝；只读预览栏维持 muted 灰（「你不编辑的变蓝有病吗」）。

## 1. 版本定位

简单模式里，空笔记的可编辑空态就是**打字起点**（光标落点，v1.83 统一文案、2026-11-09 修复贴顶对齐）。本版把这一占位从 muted 灰改为品牌蓝，与「焦点 / 活动态用品牌色」的既有语言对齐（编辑分段按钮选中态品牌蓝、树内当前笔记标题品牌色、简单模式活动块蓝色描边）；只读预览栏的空态占位维持「一行安静的提示」定位不动。

## 2. 需求清单

### 98.1 可编辑空态占位品牌蓝

- `web/mdpreview/build.mjs` 空态规则（276–279 行区域）：
  - `#content .empty[contenteditable="true"]:empty::before` 的 `color` 由 `var(--muted)` 改为 `var(--blue)`——只影响占位文字（`:empty::before`），**实际输入的文字仍为 `var(--ink)`**（第 277 行元素级 `color: var(--ink)` 不动，开始输入后 `:empty` 不再匹配、占位即消失）。
  - 深浅色随 `--blue` token 自动适配（token 来自 v2 原型 `:root` / `[data-theme=dark]`）。
- 只读空态（`#content .empty`，14px `--small`）**零改动**；两档字号（16px 可编辑 / 14px 只读）**零改动**（打字起点语义，见 build.mjs 2026-11-09 注释）。

### 98.2 产物同步

- `web/mdpreview` 重建 rawfile 产物（`node build.mjs`），`entry/src/main/resources/rawfile/mdpreview/index.html` 同步提交（硬约束：改 web 源必须重打包）。

## 3. 明确不做（本版）

- 只读 / 预览栏占位颜色、字号、对齐——不动。
- 专业模式（CodeMirror / mdeditor）空态——本就无「空笔记」占位，不新增。
- 空态字号统一（16px / 14px 两档保留，v1.83 + 2026-11-09 语义）。
- 原型 `docs/prototype/v2/index.html`——原型空态是另一套机制（空栏 eyebrow），本改动是端侧简单模式空态，原型无对应物，不同步。

## 4. 红线

- 零新增权限；颜色只引用 token（硬约束 17）；零埋点。
