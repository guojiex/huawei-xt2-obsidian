# v1.2 需求文档 —— 双链与反链

> **状态**：🟡 当前工作区已实现并通过本地单测、生成检查、HAP 构建及 API 26 TripleFold 核心交互；输入法自动补全目视验收、XT2/API 24 待验，未完成整版设备验收。
> **对应里程碑**：M7

## 1. 版本定位

让笔记之间可以互相链接，并在三屏展开态方便查看引用关系。

## 2. 完成判定

当前库内可插入并打开 `[[笔记]]` 链接；目标笔记可查看反链；重命名或移动目标笔记后，引用不会静默指向错误文件。

## 3. 需求清单

| # | 需求 | 来源 | 验收点 |
| --- | --- | --- | --- |
| 1 | 双链与自动补全 | 需求池 B「双链 `[[wikilink]]` 与自动补全」 | 输入链接时提示当前库笔记；选择后可跳转；同名文件的目标可区分 |
| 2 | 反链面板 | 需求池 B「反链面板」 | 显示当前笔记被哪些当前库文件引用，点击可打开来源笔记 |
| 3 | 未创建链接 | 需求池 B「未创建链接」 | 目标不存在时有明确状态，可从链接创建目标笔记 |
| 4 | 重命名更新引用 | 需求池 B「重命名自动更新引用链接」 | 重命名或移动目标时更新当前库内对应引用；每个文件原子写，失败时提示尚未更新的文件 |

## 4. 明确不做

- 跨库链接、全局图谱和插件接口：当前库语义先稳定。
- 修改旧版 Markdown 的普通链接语法：只处理本版定义的双链。

## 5. 技术约束与依赖

依赖 v1.1 索引；文件写入沿用 `AtomicFile` 约束，不能因批量改引用而绕过。鸿蒙行为结论见 [`api_notes.md`](../../harmonyos/api_notes.md)。

### 5.1 链接定位语义

- 仅解析 `[[目标]]` 与 `[[目标|显示文字]]`；显示文字只影响预览标签，不参与目标定位。
- 含 `/` 的目标按当前库根目录相对路径查找；`./` 表示显式从库根目录开始。路径只接受 `/` 分隔，不接受 `..`、反斜线或库外路径。可省略 `.md` / `.markdown` 后缀。
- 不含 `/` 的目标只在来源笔记所在目录查找同名 Markdown 文件，不跨目录猜测。自动补全选中候选时插入带库根相对路径的目标，重名笔记以完整路径区分。
- 名称与路径按大小写敏感、Unicode 原样精确匹配，不做大小写折叠或 Unicode 归一化；保留中文路径原文。
- 未命中路径链接时，创建位置按该库根相对路径确定；未命中无路径链接时，在来源笔记所在目录创建。标题锚点、笔记嵌入、普通 Markdown 链接不属于本版双链解析范围。
