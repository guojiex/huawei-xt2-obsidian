# v0.8 实现提示词：笔记、文件夹与知识库分享

## 项目与必读

你在“曜石笔记”仓库工作：华为 XT2 三折叠，ArkTS + Stage 模型，API ≤24，包名 `com.jxg.huaweiobsidian`。先读 `AGENTS.md`、`docs/releases/v0.8/需求文档.md`、`docs/releases/实施总清单.md`、`docs/requirements_backlog.md` D 节、`docs/mvp_design.md`、`docs/open_questions.md`、`docs/harmonyos/api_notes.md` 和 `docs/harmonyos/README.md`。本版在 v0.7 后、v1.0 前；只实现本版范围，保留其他未提交改动。

## 实施任务

- [x] 核实 API 24 系统分享、临时文件 URI 与接收端授权、压缩及图片输出接口。Share Kit / `fileUri` / `zlib` 的起始版本与 `dismiss`（API 11 起）、`shareCompleted`（API 18 起）事件声明已由本机 SDK 和官方示例核实；授权生命周期、`show()` 返回时机与 ArkWeb Markdown 完整分图链路仍未确认。事件只证明面板关闭或用户完成分享，不证明接收方已读 / 收到文件。详见 [`api_notes O 组`](../../harmonyos/api_notes.md#o-组本地文件分享与-zip-打包2026-10-26-官方文档--本机-sdk-声明核对)。
- [x] 补齐原型的文件夹/整库 ZIP 和 Git ZIP/链接选择，并接入原生入口。顶栏分享笔记、文件夹操作分享文件夹、库级分享知识库均显示明确范围。
- [x] 单篇按编辑内容快照生成图片并预览，按页分图并显示页数；只复用当前已支持的 Markdown 渲染。
- [x] 单篇无本地图片输出 MD，有图片输出 ZIP。文件夹递归收集笔记与引用图片；整库 ZIP 保留内容和附件结构。包内路径重写覆盖中文、空格、重复引用、同名资源和文件夹外库内图片逻辑。
- [x] 路径通过统一解析器；打包排除内部目录、草稿、缓存、凭据及应用状态；缺图或越界时阻止打包，网络图片保留原链接。路径与扫描逻辑已由 Hypium 覆盖。
- [x] Git 范围提供 ZIP 与链接选择：笔记网页、文件夹网页、仓库首页对应三个范围；固定样例测试 GitHub/Gitee URL 编码、分支路径、未推送提示及拒绝不支持/带凭据 URL。远端存在与权限仍待真实 Git 环境。
- [x] 系统分享面板接入；API26 模拟器有打开并取消的记录。目标列表依据系统可用项，不自动发送；面板事件不作为接收确认。
- [x] 处理取消、临时产物保留策略、打包/交接失败；源笔记不回写，内容不进入日志或埋点。`build-profile.json5` 的 `signingConfigs` 为空。
