# v1.64 需求文档 —— 启动页设计稿 1:1 还原

> 状态：本地实现完成（2026-11-13）；源码级回归与构建证据见 §6，API26 模拟器与 API24 / XT2 目视验收待用户。
> 真源：[启动页设计](../../prototype/v2/启动页设计.md) §4 与 `docs/prototype/v2/index.html` `.startup-*`（914–969）。只调启动页表现，不改原型、启动行为、会话恢复逻辑与原子首帧语义。
> 2026-11-13 修订：氛围层动效起播时机按 [api_notes U4](../../harmonyos/api_notes.md#u4-显式动画起播时机abouttoappear-中动画不生效2026-11-13v164-修订) 由 `aboutToAppear` 改为 `onAppear`，修复「背景浅蓝浮动动效不生效」的运行期缺陷。

## 1. 目标与边界

原生启动页与原型 CSS 逐项对齐：衬线字体、去模糊浮现、装饰引号、极光位置与整层模糊、名言自适应字号、字重、纸感颗粒密度。系统开屏仍维持简易启动页（`module.json5` 零改动）；名言仍为本地 12 句、冷启动随机一句、不轮播；装饰层不拦截命中、不参与读屏。

## 2. 长期规则

- **字体真源**：HarmonyOS 系统只预装 HarmonyOS Sans（[api_notes J-3](../../harmonyos/api_notes.md#j-3-要不要显式-fontfamily-harmonyos-sans--不需要)），通用 `serif` 族名会回退黑体。启动页衬线体必须由 `resources/rawfile/fonts/StartupSerif-{Regular,Semibold}.ttf` 用 `getFont().registerFont()` 注册；禁止改回 `fontFamily('serif')`，禁止引用系统宋体。
- **授权**：两档字体是 Noto Serif SC（**SIL OFL 1.1**，可商用 / 可嵌入 / 可修改再分发）的静态子集；`OFL.txt` 与字体同目录随 HAP 分发，字体内部 name 表保留 Adobe 版权与 OFL 声明、族名改写为自定义名。微软 `simsun.ttc` 等商业字体不得打包分发。
- **名言库增删或改字必须重跑** `tools/generators/gen_startup_serif.mjs`（子集只含当前 257 个字符），否则新字会回退系统黑体。
- **混合模式**：原型 `multiply / screen` 用 Canvas `ImageData` 逐块随机灰度低 alpha 近似，**不启用** `blendMode` 离屏合成；是否升级待 API24 / XT2 首帧性能证据。
- **动画起播时机**：`animateTo()` / `keyframeAnimateTo()` 一律不在 `aboutToAppear()` / `aboutToDisappear()` 里调用（[api_notes U4](../../harmonyos/api_notes.md#u4-显式动画起播时机abouttoappear-中动画不生效2026-11-13v164-修订)：build 未执行、动画属性无初值、动画不生效）。氛围层统一由根节点 `.onAppear()` 起播并用一次性守卫防重复；`aboutToAppear()` 只做数据准备与减动效静态终态。品牌层保持 `setTimeout` 异步调度。
- 系统「减少动态效果」偏好仍按 [api_notes U1](../../harmonyos/api_notes.md#u-组减少动态效果偏好与arkui-动画) 保持未核实，只保留组件 `reduceMotion` 开关。
- 颜色 / 尺寸 / 时长只引用 `$r('app.color.*')` 或 `Startup` 常量（硬约束 17）；`$rawfile` 路径是编译期字面量，必须写在组件内。

## 4. 实现口径

- 新增：`entry/src/main/resources/rawfile/fonts/{StartupSerif-Regular.ttf,StartupSerif-Semibold.ttf,OFL.txt}`、`tools/generators/gen_startup_serif.mjs`。
- 修改：`StartupMask.ets`（字体注册 / 去模糊 / 大引号 / 自适应字号 / 字重 / 出处字距）、`StartupAmbience.ets`（极光容器与归位 / `ImageData` 噪点 / **动效改由 `onAppear` 起播**）、`common/Tokens.ets`（`Startup` 常量）、`tools/tests/test_startup_mask_design.mjs`。
- 生成脚本前置 `npm install --no-save subset-font`；源字体默认本机 `NotoSerifSC-VF.ttf`，可用 `--src` 指向 [Google Fonts 官方同版](https://github.com/google/fonts/raw/main/ofl/notoserifsc/NotoSerifSC%5Bwght%5D.ttf)；`subset-font` 把 `wght` 轴钉死为静态实例后，脚本改写内部 name 表与 `OS/2.usWeightClass`、重算 sfnt 校验和，并校验 257 字符全覆盖。
- API 依据见 [api_notes U3](../../harmonyos/api_notes.md#u3-启动页自定义衬线字体与去模糊浮现api声明核对2026-11-13v164)；声明不等于 API 24 / XT2 运行证据。

## 5. 明确不做

- 增强启动页（`startWindow` profile / 品牌图）、名言轮播、系统减少动态效果偏好自动接线、低端 / 省电自动降级。
- `blendMode` 离屏混合、内置完整中文字库（包体与首帧预算）、启动页埋点或联网字体。
