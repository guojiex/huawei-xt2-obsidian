# v2.9 需求文档 —— 链接跳转返回导航（系统返回回上一笔记）

> 状态：已交付（2026-11-24 立项并当日交付；真机验收待用户反馈）
> 来源：需求池 B 节「链接跳转返回导航（系统返回回上一笔记）」。用户 2026-11-24 提出：预览里点击链接跳到新笔记后，按系统返回（返回键 / 侧滑手势 / 系统后退）不应直接退出应用，而应回到上一个打开的笔记。
> 追加（2026-11-24）：29.2 目录左滑「分享」按钮图标化，用户直提、当日交付（见 §3 / §7）。

## 1. 版本定位

现状：笔记视图是条件渲染（非路由），系统返回经 `Index.onBackPress()` 消费链（快切 / 抽屉 → 工作区导航 → 次级视图 → 图片查看器 → sm 预览态）逐档消费，链尾 `return false` 直接退出应用（[api_notes I3.1](../../harmonyos/api_notes.md)，返回键与侧滑均已真机核实）。点击 `[[双链]]` / 库内 Markdown 链接跳转（`handleWikiLinkClick` / `handleVaultLinkClick`）后没有任何「回上一笔记」通道，用户只能从文件树重新找回来。

本版在消费链末端补一条「链接跳转返回」：链接跳转时记录来源笔记进会话级历史栈，系统返回在本将退出应用时若历史非空则回上一笔记。

## 2. 完成判定

点双链 / 库内链接跳到新笔记后，按系统返回回到跳转前的笔记且应用不退出；连续跳转逐次回退；历史耗尽后返回行为与现状一致（退出应用）；切库后历史不跨库。`test_note_nav_history.mjs` 全过、受影响回归零新增失败；`arkts_check` 零错误 + 签名 HAP 构建通过。

## 3. 需求清单

来源：[需求池 B 节](../../requirements_backlog.md)

### 29.1 链接跳转历史栈与返回消费

- **记录**：`handleWikiLinkClick`（解析成功直接打开 / 创建后打开两条路径）与 `handleVaultLinkClick`（库内 Markdown 链接）在加载目标笔记前，把来源笔记（`pane` + `path`）压入 `noteNavStack`；左 / 右栏跳转各自记录来源栏。
- **返回**：`onBackPress()` 在既有消费链（菜单 / 抽屉 / 导航 / 次级视图 / 图片查看器 / sm 预览态）之后、`return false` 之前消费历史栈：弹出栈顶，目标仍存在则回该栏打开（左栏 `loadFile` / 右栏 `loadRightFile`），返回 `true` 拦截退出。
- **栈规则**：
  - 上限 50（`NOTE_NAV_LIMIT`），超出丢最旧；
  - 连续相同 `(pane, path)` 去重，不产生废条目；
  - 目标已被删除 / 改名（不在 `WikiLinkService.files`）则丢弃该条继续弹下一条，栈空才落回 `return false`；
  - 切库（`switchVault`）清空，不跨库回退；
  - 会话级内存态，不持久化、不进工作区会话恢复。

### 29.2 目录左滑「分享」按钮图标化（2026-11-24 追加，用户直提）

- **诉求**：用户 2026-11-24 提问「为什么左边文件列表，文件夹滑动之后出来的按钮是文字不是 icon」，并明确要求改为图标。原状是 `SwipeBar` 目录分支的「分享」为文字按钮（历史成因：1.6 左滑条按 v2 原型整体走文字按钮，v2.3 / v2.5 只把文件行 pin / star 图标化，目录行的分享不在图标化范围）。
- **改动**：`FileTreeView.ets` `SwipeBar` 目录分支，「分享」`Text` 换成 `Icon('share', ...)`（20vp、brand 色、`brand_bg` 底，与文件行 pin / star 同款形态）；补 `.id('share-swipe-' + relPath)` 与 `accessibilityText('分享：' + 名称)`（纯图标按钮必须自带读屏名称，v1.10 口径）。点击行为不变（`onSharePath(relPath, true)`）。
- **明确不做**：文件行「改名 / 移动 / 删除」与收藏区「改名 / 移出收藏」仍为文字（v2 原型口径，未在本次诉求内）；v2 原型 HTML 不改（原型侧文件夹左滑条本就是文字形态，原生侧为独立实现）。

## 4. 明确不做（本版）

- **不做前进栈**（forward）：只有返回，没有「再前进」。
- **文件树 / 搜索 / 快切 / 反链面板打开不入历史**：本版只承接「链接跳转」语义（用户诉求即链接）；其它打开路径仍按现状（返回不回退）。后续若要浏览器式全量导航历史，从需求池另行分配。
- **不跨库回退**：切库清空历史；跨库返回需要切库联动，成本与收益不匹配。
- **不持久化**：重启应用后历史为空（与 Obsidian 移动端「会话内返回」口径一致，避免冷启动多一层状态恢复链路）。
- **不恢复滚动位置**：回上一笔记只恢复到该笔记，编辑 / 预览滚动位置沿用各栏既有会话基线行为。
- **不加可见 UI**（返回按钮 / 面包屑）：入口只有系统返回（返回键 / 侧滑），与 `onBackPress` 既有口径一致。

## 5. 红线

- 不改既有消费链优先级：快切 / 抽屉 / 导航 / 次级视图 / 图片查看器 / sm 预览态的返回语义零变化，历史栈只在「本将退出应用」时接管。
- 历史栈不进任何持久化与埋点；笔记路径不进埋点（硬约束 16）。
- 打开笔记仍走 `loadFile` / `loadRightFile` 既有链路（保存冲刷 / 请求序号 / 失败回滚全部沿用），不新开旁路。

## 6. 技术约束与依赖

- 改动面：`entry/src/main/ets/pages/Index.ets`（`NoteNavEntry` 接口 + `NOTE_NAV_LIMIT` 常量 + `noteNavStack` 成员 + `pushNoteNav` / `goBackNoteNav` 两方法 + 三个链接跳转点接线 + `onBackPress` 一条分支 + `switchVault` 清栈）。
- 返回拦截依据 [api_notes I3.1](../../harmonyos/api_notes.md)：`onBackPress()` 返回 `true` 同时覆盖返回键与侧滑，条件渲染视图无需为侧滑另写兜底。
- 无新增权限、无数据结构持久化变化、无 web / native 产物改动。
- 新增 `tools/tests/test_note_nav_history.mjs`（行为级：压栈 / 去重 / 上限 / 失效跳过 / 左右栏分流 / `onBackPress` 集成；源级：接线点、清栈点、常量）。
