# v1.20 需求文档 —— 简单模式链接、双链与图片编辑

> 状态：⚪ 规划中；未实现、未验收、未发布。
> 前置：[v1.18](../v1.18/需求文档.md) 块编辑底座；[v1.7](../v1.7/需求文档.md) 简单模式；[v1.2](../v1.2/需求文档.md) 双链索引。
> 统一设计：[简单模式复杂块编辑设计](../../engineering/简单模式复杂块编辑设计.md)。

## 1. 版本定位

链接、双链与图片是正文里出现频率最高的行内复杂语法，v1.7 起在简单模式只读：改一个链接地址
要切专业模式面对 `[文字](地址)` 源码。本版让这三类可以在简单模式里改文字、改目标、换图和移除。

## 2. 完成判定

在简单模式下，光标落在链接 / 双链 / 图片上时，块显示选中态并可打开块属性面板，用户能改显示文字与目标、
跳转或打开、取消链接（保留文字）、重新选择双链目标、替换图片与改 Alt 文本；改动只落在对应语法区间，
块外源码逐字不变。结构不规范时只读并说明。

## 3. 需求清单

| 编号 | 交付范围与验收要求 |
| --- | --- |
| 20.1 | **链接。** 光标在链接内时块显示选中态，打开块属性面板（标题「链接」）：编辑显示文字、编辑地址、打开、取消链接（去掉语法、保留文字）。地址输入做基本校验（空地址拒绝并提示），不自动补全协议；取消链接后可撤销且源码完全恢复。**2026-11-03 修订（D-1）**：简单模式下点链接先开本面板，“打开链接”为第一行。 |
| 20.2 | **双链。** 属性面板提供「重新选择目标」（复用 v1.2 双链索引的笔记列表与别名）、跳转到目标、移除语法保留文字；目标不存在时仍可改显示文字，并在面板内说明目标尚未创建。**2026-11-03 修订（D-1）**：点双链先开本面板，“打开目标笔记”为第一行；标题锚点在面板内说明暂不支持跳转。 |
| 20.3 | **图片。** 图片提供替换图片（复用现有插入与附件落库链路）、编辑 Alt 文本、设置显示宽度、删除图片。外链图片只改地址，不下载、不自动转本地。本地图片替换后旧附件按既有规则处理，不静默删除用户文件。**2026-11-03 修订（D-1 / D-6）**：点图片先开本面板，“查看大图”在面板内；显示宽度采用 `![替代文字|宽度](路径)`，提供原始 / 小 240 / 中 360 / 大 480 四档。该写法不是标准 Markdown，其他编辑器可能把 `|宽度` 显示在替代文字中。 |
| 20.4 | **保护范围与降级。** 以下保持只读并在附近说明（用 v1.7 默认文案）：引用式链接定义与引用、嵌套链接、含标题属性的复杂链接、图片与链接嵌套、路径含未转义空格或括号的写法。解析失败保留原文。**2026-11-03 修订（D-4）**：只含受支持行内项的段落提示改为“含链接、代码或公式 · 点按逐项编辑”；本条真正未支持的写法仍用默认文案。 |
| 20.5 | **撤销与保存。** 每次编辑文字 / 地址 / 目标 / 替换图为一个撤销步；撤销后源码完全恢复。保存、草稿、失败保护沿用 v1.7 同一链路；图片附件沿用既有 VaultAccess 与 AtomicFile，外部库不分叉。 |

## 4. 明确不做

- 不做链接预览卡片、缩略图生成、图床上传、图片压缩与裁剪。
- 不做双链反链面板编辑、不为不存在的目标自动建笔记（需求池「未创建链接」另议）。
- 不改专业模式的链接与图片行为，不引入新的网络权限，不改包版本与发布状态。

## 5. 技术约束与依赖

- 行内语法区间依赖 v1.18 底座；链接与图片在语法树中已有节点，`parse` / `stringify` 须保留原有转义写法。
- 替换图片复用现有图片选择链路与权限，不新增权限申请（详见上架准备清单的权限口径）。
- 图片 Alt 文本为空时须给出可读的无障碍名称（v1.10 口径）。
