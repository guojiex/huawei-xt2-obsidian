# v1.63 需求文档 —— 启动页氛围动效与完整入场编排

> 状态：本地实现完成（2026-11-13）；表现细节的 1:1 还原以 [v1.64](../v1.64/需求文档.md) 为准，源码级回归与构建证据见 §6，API26 模拟器与 API24 / XT2 目视验收待用户。
> 来源：2026-11-13 用户反馈「只实现了文字浮现，背景动画都没有」，要求按 [启动页设计](../../prototype/v2/启动页设计.md) §4 补齐原生实现。
> 口径变更：[v1.41 §41.3](../v1.41/需求文档.md)「分组错峰、不逐字、不做持续氛围动画」由本版取代；原型视觉与节奏不变，系统开屏仍维持简易启动页。

## 1. 背景

v1.41 交付的品牌遮罩只包含分组 opacity / translate 入场（图标、品牌名、眉题、发丝线、名言、出处、页脚），把设计稿 §4 的氛围层与持续动效列为「本版不做」。原型 `.startup-*` 已完整实现极光、纸感颗粒、浮尘、图标轻浮、光晕呼吸、高光斜扫与逐字浮现，原生与原型视觉差距明显。本版只补启动页表现，不改启动行为、会话恢复逻辑、原子首帧语义与冷启动性能预算。

## 2. 完成判定

冷启动时遮罩呈现「底色 + 极光缓慢漂移 + 纸感颗粒 + 浮尘上浮 + 图标 / 光晕 / 高光循环动效 + 品牌名与名言逐字浮现」，就绪且本句名言的入场编排播完后一次淡出进入工作区；减少动态效果（`reduceMotion=true`）时直接呈现终态、退出直接切换；装饰层不拦截命中、不参与读屏；无新增权限、埋点、网络与日志。

## 4. 明确不做（本版）

- 增强启动页（`startWindow` profile / 品牌图）——系统开窗维持简易启动页，`module.json5` 零改动。
- 名言轮播（原型 9s 一轮仅用于评审）——原生冷启动仍只显示随机一句。
- 系统「减少动态效果」偏好自动接线——接口语义未核实（U1），只保留组件开关。
- 低端 / 省电模式自动降级、按库或按形态定制内容、加载进度、联网名言、启动页埋点。
- 浏览器 multiply / screen 混合模式——按 [v1.64 §2](../v1.64/需求文档.md) 用 Canvas `ImageData` 低 alpha 噪声近似，不启用 `BlendMode` 离屏合成。

## 5. 技术约束与依赖

- 真源：`docs/prototype/v2/启动页设计.md` §4 与 `docs/prototype/v2/index.html` 的 `.startup-*`；本版不改原型。
- 文件：`entry/src/main/ets/components/StartupAmbience.ets`（新增）、`StartupMask.ets`、`common/Tokens.ets`（`Startup` 常量扩充）、`resources/{base,dark}/element/color.json`（新增 `startup_aura_purple`，与原型 `--cb-purple` 同值；绿色复用 `success`）、`tools/tests/test_startup_mask_design.mjs`。
- API 依据（本机 API26 SDK 声明核对，API 24 兼容下限内）：`animateTo` 的 `iterations:-1` / 负 `delay`（`@since 7`）、`UIContext.keyframeAnimateTo` + `KeyframeState`（`@since 11`）、`blur`（`@since 7`）、`hitTestBehavior` / `HitTestMode.None`（`@since 9`）、`CanvasRenderingContext2D.createImageData` / `putImageData`（`@since 8`）。逐项见 [api_notes U2](../../harmonyos/api_notes.md#u2-启动页循环动效与氛围层api-声明核对2026-11-13)。声明不等于 API 24 / XT2 运行证据。
- 循环动效统一用 `keyframeAnimateTo` 的 0 → 峰值 → 0 两 / 四段帧，`iterations:-1`；不用 `PlayMode.Alternate`（SDK 注释要求有限轮次为奇数）。
- 逐字浮现用 `@State number[]` + 数组整体替换触发刷新，`animateTo` 插值 opacity / translate / blur；去模糊常量与字体注册见 [v1.64 §3](../v1.64/需求文档.md)。
- 性能：极光与浮尘为持续动画，`aboutToDisappear` / 退出完成后销毁氛围层；首帧恢复链路不新增等待、轮询或埋点。
