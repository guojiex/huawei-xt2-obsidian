# v1.11 需求文档 —— 关于页隐私政策入口

> 状态：⚪ 已排期；v2 设计稿已补入口，原生功能未实现、未验收、未发布。列入首发前上架收口，具体优先级见 [实施总清单](../实施总清单.md)。

## 1. 需求来源与范围

承接 [需求池隐私政策条目](../../requirements_backlog.md) 和 2026-11-02 用户提供的[隐私政策](https://agreement-drcn.hispace.dbankcloud.cn/index.html?lang=zh&agreementId=2064689818977197760)。在“设置与关于 → 关于”增加明确的“隐私政策”入口，供用户按需查看该政策；v2 设计见 [设计说明](../../prototype/v2/设计说明.md)。App 内查看的政策内容应与应用市场提交的版本一致。

## 2. 验收条件

- 关于页入口名称明确，单屏、双屏、三屏均可找到；不遮挡版本、反馈、许可和更新记录。
- 原生入口使用经 API24 核实的方式打开用户提供的政策；返回后仍能使用原工作区。网络不可用、打开失败时给出可理解提示与重试途径，不静默失败。
- 发布前在真实设备及不登录状态下核对链接可用、正文可读，核对应用内展示与应用市场提交的链接和内容一致；以实际发布包核对政策中的数据处理、权限、第三方服务和存储描述，并在控制台完成必要配置。
- 对照政策中“信息传至中国境内服务器”的主体与数据类别：核对是否涉及应用自建后端或华为等平台服务，避免将不同主体的数据处理混为一谈。现有 [上架事实](../上架准备清单.md#隐私问卷本地事实源码核对不是公开政策) 与源码显示本地笔记主要在设备处理、Git 按用户选择连接远端、分享由用户主动交给接收应用；本次没有完整证明所有构建产物和第三方服务均不存在其他上传路径，具体主体与范围待核对。
- 核对政策是否说明 Git 同步目标由用户自行选择、数据去向取决于所选服务；例如用户选择境外服务时可能发生跨境传输，不能仅凭应用在中国大陆上架或声明网络权限推断全部数据只在境内。
- 对照政策中“日志可能包含文件名 / 路径 / 字数”与 [v1.7 17.7 验收记录](../v1.7/验收记录.md#177-笔记数据日志脱敏补齐2026-11-01)：后者记录编辑相关链路移除了这些日志，范围限于该轮核对，不代表全 App 日志均已审计；按最终包逐项核对差异，不预判哪一处需要修改。
- 分开记录原型、自动检查、构建、模拟器、API24 / XT2 及商店审核结果；现阶段均未作为原生验收通过。

## 3. 明确不做

- 不凭空编写或擅自修改在线政策正文；发现差异先列明并由政策维护者确认后更新。
- 本版不自行增加其他权限、遥测、首次启动同意弹窗或采集功能；是否还需首次告知或同意，按实际数据处理和当期审核要求另行核对，不能以关于页入口代替。
