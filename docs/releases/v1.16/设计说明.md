# 小艺 Wiki 工具集设计（v1.16）

> 本地后端按 [需求文档](需求文档.md) 的 2026-11-06 授权继续实现，不改 UI；平台集成仍关闭。候选设计中涉及用户确认、平台能力、并发和设备结果的内容仍以需求文档与后续证据为准。用户已确认多篇批量写入前先审阅并确认具体计划。

## 1. 路径

用户对话 → 小艺平台选择经授权的端插件 → 用户指定的知识库访问层。查询可按目录、关键词、分段正文和双链逐步取数据；整理先生成包含库 / 文件 / 操作的计划，再由用户确认，执行器逐项校验、写入并记录结果，完成后汇报。实际可用交互、模型工具选择和工作流节点能力仍须核对；不能假设单 Agent 提示词可强制节点顺序。

可选工具契约候选：`SearchNotes`、`ListTree`、分段 `ReadNote`、`GetLinks`；保留现有 `QueryNotes` 和旧工具兼容，绑定与版本升级须另定。输出需要明确分页、截断、编码与读取边界，错误不能包装为成功。

## 2. 知识库约定

规则文件 `_wiki.md`、目录索引 `index.md`、操作记录 `log.md` 的模板已于 2026-11-05 删除，需要时查 Git 历史；本地执行器不自动创建这些文件。`_wiki.md` 的固定只读与受限 `readonly` 内联数组解析按需求文档实现；文件正文只作为可读资料，不能扩大执行器权限。只读工具使用 6000 UTF-16 码元的本地输出预算，该数值不是平台实测值。平台提示词、工作流、批量确认和批次撤销仍未实现。

## 3. 写入、并发与撤销

一次多文件整理的候选操作账包括目标稳定库标识、用户确认过的计划、逐项前像 / 版本和执行结果。写前比对、单文件原子保护、恢复账本与幂等重试是目标，不是已有批量事务。**检查哈希再写不是跨进程原子比较交换**；静态内存锁不能约束其他进程、其他应用或外部目录修改。执行前须确定共享协调或可证明的安全替代策略；在此之前拒绝批量写入。

即使预检全部成功，逐项写入或撤销仍可中途失败；记录哪些完成、哪些失败、是否可安全重试，并在不确定状态停止、保留前像供用户处理。不能承诺“整体原子回滚”或无条件撤销。

## 4. 交互、隐私与平台

原包建议在设置中配置允许访问的库、账本清理和调用日志导出，但这些仅是候选；用户确认的唯一新增交互是**批量写入前展示计划并确认**。本次不改变 v2 视觉基线，确认界面需要结合平台能力另行设计。

工具返回可能进入小艺模型上下文，依平台协议核对；仅返回任务需要的内容，日志不记录笔记正文、标题、路径、搜索词、令牌或前像。平台探针仅使用合成数据、隔离库与专用测试对象，不接触真实库，不自动发布。

## 5. 材料与现状

- [候选详细设计](候选详细设计.md)：保留已落码只读工具（`SearchNotes` / `ListTree` / `ReadNote`）的设计依据。平台配置、探针实验设计与 Wiki 模板随 2026-11-02 平台侧关闭不再维护，已于 2026-11-05 删除，需要时查 Git 历史。
- 当前源码的 `InsightIntentNoteService` 已有 `QueryNotes`、`ReadNote`、`CreateNote`、`AppendNote`、`EditNote`、`UndoLastEdit` 及 Wiki 只读导航路由，读写中有哈希、锚点和单项撤销逻辑；`AgentOperationStorage` 有私有持久化实现。此静态核对不证明平台真实调用、批量一致性或设备验收。
- 用户提供的[平台答复摘要](../../harmonyos/qa/2026-11-02_小艺多步工具调用限制_候选摘要_API24.md)不是官方原文，来源引用和断言待逐条核验；与 [现有 API 笔记](../../harmonyos/api_notes.md) 不一致时不覆盖已核实结论。
