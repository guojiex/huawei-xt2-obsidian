# 小艺 Wiki 平台能力探针（v1.16）

目标是在不碰用户笔记的前提下，验证候选设计依赖的能力；本文件不授权平台操作或真机操作，具体执行由用户手动完成并使用隔离测试对象。详细候选见 [探针原稿](候选探针设计.md)。

| 待验证项 | 最小证据与边界 |
| --- | --- |
| 输出与截断 | 合成 ASCII / 中文数据，分别记录字符数、字节数、端插件实际返回与平台接收；模型复述不一致不能单独证明截断。 |
| 超时与轮数 | 隔离请求逐档测量调用时限、对话步骤、错误与重试；结果带设备、平台版本、时间及样本次数，不能外推平台全局上限。 |
| 并行与生命周期 | 记录调用重叠和实例标识；计数器重置可能来自多实例 / 重启等，需其他证据才能判断回收；未复现并发不证明不会发生。 |
| 搜索冷启动 | 使用隔离合成库，测不同规模下索引构建、查询、内存与超时；主机基准不替代设备结果。 |
| 编排与确认 | 核实工作流是否支持所需顺序、循环、变量传递和可验证的用户确认；不能保证确认时只读。 |
| 写入与恢复 | 只有本地设计与安全边界完成、用户授权后，在隔离库验证冲突、部分失败、账本恢复与前台编辑竞争；不主动强杀进程或制造设备崩溃。 |

测试对象、设备系统 / 小艺版本、操作、预期与实际、时间、重复次数和失败样本分别记录。平台限制、取值与诊断日志不得由猜测填入“已验证”。
