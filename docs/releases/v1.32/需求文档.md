# v1.32 需求文档 —— 视觉一致性收口

> 状态：⚪ 规划中；v2 原型已按 32.1–32.7 顺序实现，headless Chrome 功能与截图核对通过；原生未实现、未验收。
> 对应里程碑：独立优化。领取顺序以 [实施总清单](../实施总清单.md) 为准；本版内按 32.1 → 32.7 顺序实施。
> 需求来源：[需求池 J 节「视觉一致性收口」](../../requirements_backlog.md#j-视觉与设计系统design-token)（2026-11-04 原型走查后用户确认合为一个版本按顺序修）。

## 1. 版本定位

v1.24 / v1.25 / v1.27 / v1.31 已重做导入库、分享、同步页与单屏更多菜单，但其余弹窗、专业模式格式栏、宽屏栏内菜单等仍是旧样式，放在一起割裂明显。本版只做视觉与交互一致性收口，不增删功能。

## 2. 完成判定

所有工具弹窗共用同一外壳（宽屏居中卡片、单屏底部半模态、圆形关闭、胶囊按钮且主操作突出）；简单 / 专业模式的格式栏都在编辑时停靠栏底；所有「…」菜单为图标行；新建弹窗、窄侧栏、Aa 面板、设置操作行的细节问题消除。原生与设备分别验收。

## 3. 需求清单（按实施顺序）

| # | 需求 | 验收点 |
| --- | --- | --- |
| 32.1 | **工具弹窗统一外壳。** 新建笔记 / 文件夹、重命名 / 移动、永久删除文件夹、快切与搜索、回收站、库新建 / 改名 / 删除，与导入库 / 分享 / 同步共用外壳：标题 `--large` / 600；关闭为 40vp 圆形 `--nav` 底；底部操作右对齐、胶囊高 `--touch`，取消 `--nav` 底，主操作 `--blue`，危险操作 `--danger` 底白字，禁用 45% 不透明度；单屏为底部半模态（拖拽条、顶部大圆角、按钮等宽），宽屏居中。 | 六个弹窗在单屏均贴底展开，宽屏均居中；Esc / 关闭 / 系统返回行为不变 |
| 32.2 | **专业模式格式栏停靠。** 专业模式源码编辑时，格式栏与 [v1.30](../v1.30/需求文档.md) 简单模式一致：停靠该栏底部整行、顶部细线、`--paper` 底、无阴影；宽屏靠左、单屏居中；源码编辑区底部留白，最后一行不被遮挡。仍只在编辑状态显示（沿用既有规则），预览时隐藏。 | 不再浮在源码上；Aa 跟手面板与插入图片照常可用 |
| 32.3 | **栏内「…」菜单图标行。** 宽屏左右栏的「…」菜单（在另一栏预览、查看 / 隐藏反链、跟随编辑）改为图标 + 文字行：行高 `--touch`、`--body` 字号、`--ink` 色、悬停 `--nav` 底，菜单圆角 `--r`；图标与 [v1.31](../v1.31/需求文档.md) 单屏菜单同一线稿。 | 与单屏更多菜单视觉一致 |

| 32.5 | **窄侧栏文字。** 文件页签下的计数只显示「N 篇笔记」（完整「文件目录 · N 篇笔记」在悬停提示）；底部操作提示缩短为「左滑操作 · 拖图标到任一栏」，单行、超出省略，完整说明在悬停提示。 | 双屏 240vp 侧栏不折行 |
| 32.6 | **撤销 / 重做独立成组。** 简单模式 Aa 面板中「撤销 / 重做」与段落格式（正文 / 大标题 / 小标题 / 引用）用细线分隔，作为底部一行两个带图标的按钮；面板高度随之增加，不被截断。 | 撤销重做不再混在段落格式列表中 |
| 32.7 | **设置操作行可辨识。** 「设置 → 通用 → 恢复默认栏宽」标题改为 `--blue`，表明为可点操作（沿用 v1.13 操作行语义）。 | 不再像一行普通说明 |

## 4. 明确不做

- 不增删任何功能或菜单项，不改弹窗内容与校验规则；不改设置页信息结构（v1.13）。
- 不调整图片查看器与 Aa 跟手面板（formatDialog）的外形。
- 不把快切改为全屏页面。

## 5. 技术约束与依赖

- 环境事实：HarmonyOS API 24 / ArkTS；包名 `com.jxg.huaweiobsidian`；目标设备 XT2。**禁止凭记忆编造 HarmonyOS API**（`AGENTS.md` 硬约束 18）。
- 单屏半模态沿用块属性面板 / 导入库的同一形态；原生弹窗组件与半模态接口以 API 24 SDK 核实为准。
- 视觉 token 以 v2 原型 `:root` / `[data-theme="dark"]` 为准；图标复用现有资源，缺失的按同一线稿规格补充。
