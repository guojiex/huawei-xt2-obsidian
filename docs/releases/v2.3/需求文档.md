# v2.3 需求文档 —— 置顶按钮图标化（左滑操作条 pin / pinOff 图标）

> 状态：已交付（2026-11-22 立项并当日交付；真机走查待用户反馈）
> 来源：需求池 Z 节「置顶操作图标化」。用户 2026-11-22 提出：「设计稿重新设计置顶按钮，能不能不显示文字，显示置顶和 unpin 图标」。范围经确认：左滑操作条两处（树内行「置顶 / 已置顶」+ 置顶区行「取消置顶」）都改；设计稿与 ArkTS 端侧同步落。

## 1. 版本定位

置顶入口从文字按钮改为图标按钮：未置顶 = 图钉（置顶动作），已置顶 = 图钉加斜杠（取消置顶动作）。与既有「图标即状态」语言（树行尾 12px pin 标记、收藏星标）一致；长按菜单「置顶 / 取消置顶」（图标 + 文字行）是菜单既定形态，不动。

## 2. 完成判定

原型（`?ui=2`）与端侧：树内文件行左滑操作条第一个按钮为图标（未置顶 pin / 已置顶 pinOff），无文字；置顶区行左滑操作条「取消置顶」为 pinOff 图标；读屏语义完整（aria-label / accessibilityText 携带动作与笔记名）；防线测试与既有原型测试零回归；端侧 `arkts_check` 与 HAP 构建通过。

## 3. 需求清单

### 2.3.1 树内左滑置顶切换（原型 + 端侧）

- 原型：`fileRowHtml` 操作条首按钮 `(pinned?'已置顶':'置顶')` 文字 → `svg(pinned?'pinOff':'pin')`；`aria-pressed` 保留，动作语义进 `aria-label`（置顶 / 取消置顶 + 标题）与 `title`。
- 端侧：`FileTreeView` `SwipeBar` 文字按钮 → `Icon` 图标（**字面量 if/else 分支**，规避全局 @Builder 按值实参首帧固化 [api_notes Z2/L-7]）；id `pin-swipe-<relPath>`、accessibilityText 动作 + 笔记名。
- `Icons.ets` 新增 pinOff：同款斜 45° 图钉 + 贯穿钉头的斜杠（纯直线命令，可整表缩放）；原型侧 icons 表加 lucide `pin-off`。

### 2.3.2 置顶区左滑取消置顶（原型 + 端侧）

- 原型：`renderPins` 操作条 fav-remove「取消置顶」文字 → `svg('pinOff')`，`aria-label` / `title` 保留语义。
- 端侧：`PinSwipeBar` 文字 → `Icon('pinOff')`，id `unpin-swipe-<relPath>`、accessibilityText「取消置顶：<标题>」。

### 2.3.3 布局与可访问性

- 原型新增 `.file-actions button svg{display:block;margin:auto}`（图标居中；尺寸 / 描边 / 颜色继承全局 svg 规则与按钮 color，token 零散写）。
- 键盘可达不变：pin 按钮仍是操作条首个 button（键盘聚焦链零改动）；delete-ready 隐藏规则复用现状。
- UI 用例适配：`UiNoteFlow` `clickPinButtonInBar` 改 `ON.id('pin-swipe-.*')`（图标无文字，`ON.text` 不可用），位置过滤保留；`unpinNoteByName` 改 `waitById('unpin-swipe-<relPath>')`。

## 4. 明确不做（本版）

- 长按菜单「置顶 / 取消置顶」项不动（图标 + 文字是菜单的既定形态）。
- 操作条其余文字按钮（改名 / 移动 / 删除 / 分享）不动——只按用户点名的置顶按钮重设计。
- 置顶区头「置顶」分区标签、树行尾 12px pin 标记不动。
- 不改置顶数据结构 / 持久化 / 手势提交逻辑（`bindFileSwipe`、滑到底松手取消置顶）。

## 5. 红线

- 颜色 / 尺寸只引用 token / `Space` / `Size` 常量（硬约束 17）。
- 读屏语义不降级：图标化后 accessibilityText / aria-label 必须携带动作与对象。
- 笔记内容不进 URL、不进埋点（硬约束 16）。
