# v1.74 需求文档 —— 回收站条目只读预览

> 状态：立项（2026-11-16）。来源：[需求池 B 节「回收站条目只读预览」](../../requirements_backlog.md)（2026-11-16 用户提出并选定「点条目弹只读预览」形态）。

## 1. 版本定位

回收站至今只有文件名 + 原位置两个信息（`TrashView.ets`），**没有查看内容入口**——用户无法判断一篇已删笔记到底该恢复还是永久删除，唯一的土办法是「先恢复 → 打开看 → 不行再删一次」（v1.47 / v1.55 补齐了删除侧出口，但决策依据一直缺位）。

本版补上决策依据：**点回收站条目弹出只读预览**，渲染 Markdown 内容（复用现有 mdpreview 预览链路），弹窗内就地提供「恢复」与「永久删除」入口，看完再决定；预览只读不可编辑，关闭后条目状态不变。

## 2. 完成判定

回收站展开后点条目主体（非操作按钮）→ 弹出预览：标题为笔记名，正文渲染该条目的 Markdown 内容（只读）；弹窗内可「恢复」（走既有恢复链）或「永久删除」（走 v1.47 确认弹窗链），也可直接关闭——关闭后回收站列表、计数、条目不变。读取失败时弹窗不打开并给出可读错误。原型与原生行为一致。

`arkts_check` 零新增错误；签名 HAP 构建通过；定向 Node 测试通过；API24 / XT2 真机验收待用户。

## 4. 明确不做

- 不做回收站内**编辑**或从预览直接保存——预览只读，改动必须先恢复回库。
- 不做批量预览 / 预览历史。
- 不加载图片附件：预览弹窗不注册 `readAsset` 代理（参照 `FormulaPreviewWeb` 的最小形态），图片引用在预览中不解析，正文文字完整可见；附件决策在恢复后打开时进行。
- 不改 v1.47 永久删除语义（确认弹窗仍为唯一保护）与 v1.55 清空回收站。

## 5. 技术约束与依赖

- 路径铁律（硬约束 14）：`readTrashText` 只经 `registry.absoluteInTrash()` 取绝对路径。
- 埋点红线（硬约束 16）：预览正文 / 文件名不进 hilog；Web `onConsole` 不转发（与 PreviewWebView 同款吞掉）。
- Web 尺寸约束（硬约束 12）：弹窗内 Web 宽高远小于 7680px，安全。
- 主题 token（硬约束 17）：弹窗颜色 / 间距 / 字号只引用 token。
- 图标实参约束（api_notes L-7 / Z2）：新增 `Icon(...)` 调用不得把含状态的实参写成三元。
