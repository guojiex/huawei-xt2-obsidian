## 交互修正：专注下汉堡只弹出文件列表，不再退出专注（2026-11-03）

- 用户在三屏（lg）专注模式点左上汉堡，预期只弹出文件列表并保持专注单栏；实际却退出专注并恢复双栏。根因：`onHamburger()` 专注分支调用 `toggleFocus()` + `setSidebarCollapsed(false)`，忠实复刻了 v2 原型 `$('menu').onclick` 的同款逻辑——交互本身是缺陷，原生与原型一并修正。
- 原生新增瞬态状态 `focusNavigationOpen`（不进会话快照）：专注下汉堡只切换它；`noteNavigationProgress()` / `noteContentWidth()` 据此推入 / 收回导航列；退出专注（`toggleFocus()`、`toggleReference()` 退出路径）一律重置；返回键先收专注内导航再走其余返回链；导航列与分隔条的 `.enabled`、设置页「当前栏宽」诊断同步该状态。
- v2 原型同步：新增 `focusNavigationOpen`，菜单专注分支只切换 `focus-nav` 类；CSS 改为 `.window.focus:not(.focus-nav)>.sidebar{display:none}` 并补 `focus-nav` 显示规则；`syncNavigation()` 的 inert / aria 与 `setFocused(false)` 清理同步。原型专注下分隔条仍隐藏（`.window.focus .split-control{display:none}` 未放开），与原生（专注内导航分隔条可见可拖）存在次要差异，暂记不扩散。
