# v1.44 需求文档 —— 工作区更多菜单统一

> 状态：规划中，2026-11-08 用户提出立项。来源：[需求池 P-04](../../requirements_backlog.md#工作区更多菜单统一2026-11-08)。原型已有初步调整，尚待验证；原生未实现。

## 1. 目标与范围

双栏中，各笔记栏的三点菜单与顶部三点菜单相邻，操作层级和作用对象不清晰；简单模式还曾出现左右栏入口不一致。本版以顶栏「更多」作为工作区唯一的三点菜单入口，集中已有笔记操作，并让用户在双栏中看清操作作用于哪一栏。

运行环境为 ArkTS、Stage 模型、API ≤ 24，包名 `com.jxg.huaweiobsidian`；设计真源为 [v2 原型](../../prototype/v2/index.html)。布局、激活栏及模式既有决定见 [设计主文档](../../mvp_design.md) 与 [决策总表](../../open_questions.md)。

## 2. 需求与完成判定

| 编号 | 需求 | 完成判定 |
| --- | --- | --- |
| 44.1 | 简单 / 专业模式下，单栏、双栏及目录加两栏布局均只在顶栏保留一个三点入口；每栏标题行保留笔记标题和关闭按钮，左右对齐，不出现多余空行。 | 浅色、深色及窄宽度下目视核对；标题截断、菜单和关闭按钮可点击且不重叠。 |
| 44.2 | 顶栏菜单区分当前笔记操作与应用操作；同时显示两篇笔记时，明确显示当前操作对象是左栏还是右栏；激活栏变化立即更新，菜单内操作始终作用于对应笔记。 | 分别激活左右栏打开菜单并检查反链、分享目标；空栏、关闭笔记、切库及布局变化后不得误操作另一篇笔记。 |
| 44.3 | 保留原栏内的「查看 / 隐藏反链」「在另一栏预览」「跟随编辑」等现有能力及适用条件；不适用时隐藏或禁用并保持既有行为。模式切换、设置等应用级操作保持可用。 | 两栏不同笔记、同篇联动、跟随开关、编辑 / 预览和无笔记状态逐项验证；菜单关闭和焦点返回正常。 |
| 44.4 | 原型与原生同步，沿用现有设计 token、激活栏状态与菜单交互；屏幕阅读器能识别菜单及当前操作对象，键盘可打开、选择和关闭菜单。 | 原型交互回归与浏览器目视；原生定向测试、构建，以及模拟器和 API24 / XT2 设备核验分开记录。 |

## 3. 明确不做

- 不更改分栏、笔记关闭、分享、反链索引或同篇联动的业务语义，不新增菜单功能。
- 不改变模式选择和设置入口的既定规则；不调整版本领取优先级。
- 不以原型、自动测试或构建结果代替设备验收；API24 / XT2 由用户操作。
