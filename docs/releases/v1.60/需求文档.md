## 1. 版本定位

有些库（工作、日记）不想被借手机的人随手翻到。本版为单个知识库设置访问密码：打开这个库时先输入密码。

**安全边界（请确认）**：这是**门禁锁**，只拦应用内的浏览入口——笔记文件仍是明文 Markdown，系统文件管理、Git 同步、ZIP 分享都不受影响。它防的是「随手翻看」，不防有意取文件。内容加密（档②，成本 L）不在本版。界面文案必须如实说明这一点，不能让用户误以为文件被加密。

## 2. 完成判定

可在库管理为某个库设置 / 修改 / 移除访问密码；切换到加锁的库时整窗显示锁定页，输对密码进入，输错有提示与次数限制；应用进入后台超过 5 分钟或冷启动后重新锁定；库选择器与库卡片显示锁图标。原型、原生与设备分别验收。

| 60.3 | **错误与限速。** 输错：密码框红框 + 轻微左右抖动（减少动态效果时不抖）+「密码不正确」；第 3、4 次附「还可尝试 N 次」；连续 5 次错误后 30 秒内不可再试，提示倒计时。输对清零。 | 第 5 次错误后 30 秒内输入正确也不能解锁 |

## 4. 明确不做

- 内容加密 / 加密落盘（档②）、加密 ZIP 分享。
- 生物识别解锁（需求池「应用锁（生物识别）」另行排期；本版锁定页预留位置但不放入口）。
- 整个应用的应用锁。
- 锁定 Git 同步或分享：加锁库在锁定状态下不出现在可操作入口中即可，不额外拦截已解锁时的同步与分享。
- 密码找回（无账号体系，不提供）。
- 密码与解锁行为不进埋点、不进 hilog（硬约束 16）。

## 5. 技术约束与依赖

- 环境事实：HarmonyOS API 24 / ArkTS；包名 `com.jxg.huaweiobsidian`；目标设备 XT2。**禁止凭记忆编造 HarmonyOS API**（`AGENTS.md` 硬约束 18）：哈希 / 随机数、系统锁屏验证、前后台切换时间点三项均须先按 `docs/harmonyos/` 提问流程核实，写入 `api_notes.md` 后再落码。
- 不新增权限（硬约束 13）；若系统锁屏验证需要权限，则 60.4 退回只做「删除后重新导入」。
- 库切换、会话恢复入口见 [v1.47 47.4](../v1.47/需求文档.md)；库管理页见 [v1.25 25.18](../v1.25/需求文档.md)。
- 视觉 token 以 v2 原型 `:root` / `[data-theme="dark"]` 为准。
