# v1.51 需求文档 —— 统计与成就面板（设计稿）

> 状态：设计稿交付（2026-11-10），原生实现留待后续版本。来源：[需求池 · 统计 / 成就面板](../../requirements_backlog.md)
> （用户授权「全都做，按顺序」，本版承接该条）。

## 1. 背景

需求池 2026-10-31 条目：笔记数、字数、写作连续天数等本地统计与成就展示。红线口径：本地展示不触碰 H 节「笔记内容禁止进埋点」红线（那是上报约束），但
**统计值与成就同样不得进埋点、不得上报**。

交付形态裁定：本版**只出设计稿**——原型 `docs/prototype/v2/index.html` 的入口与完整页面 + 本文档的指标口径定义。原生实现（ArkTS
统计服务 + 页面）留待后续版本，依据本口径落码。

## 2. 指标口径（原生实现按此执行）

### 51.1 统计范围

- **按当前知识库**统计（与回收站、搜索同库级口径）；跨库汇总不做。
- 只统计**未删除**笔记（回收站内容不计）。

### 51.2 四张数字卡

| 卡片     | 口径                                 |
|--------|------------------------------------|
| 笔记数    | 当前库未删除笔记文件数                        |
| 总字数    | 各笔记**源码文本去掉空白字符**后的字符数总和（不含图片等附件）  |
| 连续写作天数 | 截至今天、逐日往前数的**连续活跃日**天数；今天无修改则从昨天起算 |
| 累计写作天数 | 当前库有笔记修改记录的日历日总数（去重）               |

- 「活跃日」= 当日至少一篇笔记 mtime 落在该日历日。已知口径限制：Git clone / 导入会刷新 mtime，此类「非写作修改」计入不补偿，文档明示。
- 时间戳只用文件 mtime（沙箱 / 外部库 stat 均稳定提供，见 v1.49 结论）。

### 51.3 近 12 周热力图

- 84 格（12 周 × 7 天），按当日修改笔记数分 4 档：0（空）/ 1 篇 / 2–3 篇 / 4 篇及以上；悬停 / 长按显示日期与篇数。
- 行 = 周，列 = 星期；最左列显示月份刻度。

### 51.4 成就徽章（里程碑制）

- 两种类型：**达成态**（图标彩色 + 名称）与**未达成态**（图标置灰 + 名称 + 当前进度，如 6/10）。
- 首发徽章集：初稿（1 篇）、十篇（10 篇）、百篇（100 篇）、万字（10,000 字）、十万字（100,000 字）、七日连写（连续 7 天）、三十日连写（连续
  30 天）、百日坚持（累计活跃 100 天）。
- 里程碑数值只在达成瞬间变化，不回退展示（口径简单：按当前值实时计算是否达成，历史峰值不另存）。

### 51.5 入口与页面结构

> 2026-11-13：原型入口与页面形态已按 [v1.58](../v1.58/需求文档.md) 重设计；v1.52 原生仍为本节形态，待 v1.58 实现。统计口径不变。

- 入口：侧栏库菜单 actions 区新增「统计与成就…」按钮（与「管理库…」对称）。
- 页面：settings-page 风格全屏页（顶部返回 + 标题），自上而下：库范围说明行 → 四张数字卡（2×2 网格）→ 近 12 周热力图 →
  成就徽章网格 → 口径说明（活跃日定义、mtime 限制、统计全本地）。
- 关闭交互仿库管理页：返回按钮 + 焦点回到触发元素 + Esc / URL 状态同步按既有页面模式。

### 51.6 红线（原生实现时生效）

- 统计值、成就、热力图**全部本地计算、本地展示**；不进 `hiAppEvent` 埋点，不随任何上报离开设备（H 节红线延伸）。
- 统计计算不得阻塞 UI：按库扫描在后台任务执行，结果可缓存，页面展示缓存值 + 刷新时机（进页 / 下拉）由实现版定义。

## 3. 明确不做（本版）

- 跨库汇总统计、年度报告、分享统计图。
- 历史峰值成就（如「最长连写纪录」）—— 只算当前值。
- 原生 ArkTS 落码（本版仅设计稿 + 口径定义）。

## 4. 验收标准（设计稿）

1. 原型库菜单出现「统计与成就…」入口，点击进入全屏统计页，返回回到侧栏且焦点正确。
2. 页面含四张数字卡、12 周热力图、成就徽章网格、口径说明；深浅色主题与单 / 双 / 三屏宽度下布局不破。
3. 笔记数 / 总字数实时取自当前库样例数据（新建 / 删除笔记后数字变化）；连续天数与热力图使用确定性演示数据并带「演示数据」说明（样例笔记无时间戳，见
   §5）。
4. 设计稿样式只用既有 token 变量，不散写颜色 / 间距数值。
