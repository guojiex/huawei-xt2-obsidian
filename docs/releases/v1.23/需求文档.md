# v1.23 需求文档 —— 首发暂隐 Git 导入与同步入口

> 状态：开发中。来源：[需求池 C 节](../../requirements_backlog.md#c-同步与数据)；产品决定见[待决清单](../../open_questions.md)。本版本是首发范围收口，版本号不代表领取顺序。

## 1. 版本定位

首发界面暂不开放 Git 导入与同步入口；v0.3 Git 源码与已有验证记录保留，已有 Git 库仍保留远端链接分享。

## 2. 完成判定

v2 设计稿与原生 App 不展示 Git 导入、同步入口或待推送角标；已有 Git 库仍可使用远端链接分享，本地目录导入与本地文件分享仍可用。已有 Git 库仍可见、可打开本地内容，不删除库或凭据。

## 3. 需求清单

| # | 需求 | 验收点 |
| --- | --- | --- |
| 23.1 | 设计稿暂隐 Git 导入与同步入口 | 导入弹窗仅见本地目录；不显示同步入口与待推送角标；已有 Git 库仍可展示远端链接分享 |
| 23.2 | 原生 UI 暂隐 Git 导入与同步入口 | Git 导入不可选；笔记页同步按钮、更多菜单同步项和角标不可见；已有 Git 库仍可使用远端链接分享 |
| 23.3 | 保留已有数据 | 已登记 Git 库仍在库列表中，本地笔记和附件可访问，库管理不删除数据；不运行 Git 网络操作 |

## 4. 明确不做

- 不删除或重写 libgit2、SyncPage、Git 元数据与凭据，也不迁移或清理已有 Git 库。
- 不宣称 ZIP 分享已成为完整备份/恢复方案；发布前仍按 v0.8 验收实际导出可读性。
- 不在本版恢复 Git 导入 / 同步入口或补做 v0.3 的真机 / 服务商认证验收。

## 5. 技术约束与依赖

界面隐藏不等于底层能力删除；既有 Git 库的本地阅读与导出保持可达。设计真源为 [v2 原型](../../prototype/v2/index.html)。本版 UI 不触发真实远端；API24 / XT2 验收由用户手动执行。

## 6. 验收记录

- 源码：v2 隐藏 Git 导入切换及同步入口；旧 URL 的 Git 导入 / 同步状态不再恢复。原生导入弹窗仅显示本地目录；同步按钮 / 菜单 / 角标由入口开关隐藏。已有 Git 库列表、本地内容和远端链接分享保持可用。
- 自动检查：导入弹窗、库管理保留与 Git 角标定向测试 14/14；原型 Git 导入 / 同步入口暂隐定向 1/1；原型脚本语法检查通过。原型整套旧 fixture 因当前工作树中分栏设计的 `paintSplit` 调用 `handle.querySelector` 而在初始化阶段失败，未把它记为本版通过。
- 构建：本机 DevEco `assembleHap` 的 `CompileArkTS` 成功（含仓库既有警告）；`PackageHap` 因子进程调用 x86_64 `/Library/Java/JavaVirtualMachines/temurin-25.jdk` 报 `Bad CPU type in executable` 而失败，本轮没有完整 HAP 构建成功证据。
- 待完成：可用 Java/打包环境下重建 HAP；API26 界面目视；API24 / XT2 由用户手动验收。源码/自动检查不代替设备结果。

### 6.1 远端链接分享与入口开关隔离（2026-11-04）

- 原生实现将 Git 导入 / 同步入口开关限定在入口与待推送角标；已有 Git 库的远端链接分享不再受该开关控制。
- `node --test tools/tests/test_git_sync_badge.mjs`：5/5 通过，覆盖入口开关与链接分享条件相互独立。
- 全仓 `node --test tools/tests/*.mjs`：680 项中 675 项通过、5 项失败；4 项为原型图片 / 标签 / 源码区间 fixture 基线失败，1 项因测试硬编码的 Windows SDK 路径在 macOS 不存在；均不涉及本次改动。
- DevEco 自带 JBR 下执行 `hvigorw assembleHap --mode module -p product=default`：HAP 构建成功，33 项任务（19 执行、14 up-to-date）；存在仓库既有 ArkTS 警告。
- ⏭ 跳过：23.2 API26 模拟器目视验收 —— 当前 Mac 锁屏，无法可见操作模拟器；源码、自动测试和 HAP 构建不能证明界面实际显隐 —— 请用户解锁 Mac 后核对 Git 导入 / 同步入口与角标不可见、已有 Git 库远端链接分享可用，再回填实测结果。
- ⏭ 跳过：23.2 API24 / XT2 手动验收 —— 本轮不连接或操作真机，源码、自动测试和 HAP 构建不能证明目标设备表现 —— 请用户在 API24 / XT2 核对 Git 导入 / 同步入口与角标不可见、已有 Git 库远端链接分享可用，并提供实测结果。
