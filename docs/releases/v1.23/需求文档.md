# v1.23 需求文档 —— 首发暂隐 Git 入口

> 状态：开发中。来源：[需求池 C 节](../../requirements_backlog.md#c-同步与数据)；产品决定见[待决清单](../../open_questions.md)。本版本是首发范围收口，版本号不代表领取顺序。

## 1. 版本定位

首发界面只呈现可验收的本地笔记能力。v0.3 Git 源码与已有验证记录保留，Git 功能暂不对新用户开放。

## 2. 完成判定

v2 设计稿与原生 App 的导入、笔记顶栏/更多菜单、分享流程都不展示 Git 专属入口或待推送角标；本地目录导入与本地文件分享仍可用。已有 Git 库仍可见、可打开本地内容，不删除库或凭据。

## 3. 需求清单

| # | 需求 | 验收点 |
| --- | --- | --- |
| 23.1 | 设计稿隐藏 Git 专属入口 | 导入弹窗仅见本地目录；Git 分享示意开关不可见；普通分享不出现远端链接 |
| 23.2 | 原生 UI 隐藏 Git 专属入口 | Git 导入不可选；笔记页同步按钮、更多菜单同步项和角标不可见；分享不提供远端链接 |
| 23.3 | 保留已有数据 | 已登记 Git 库仍在库列表中，本地笔记和附件可访问，库管理不删除数据；不运行 Git 网络操作 |

## 4. 明确不做

- 不删除或重写 libgit2、SyncPage、Git 元数据与凭据，也不迁移或清理已有 Git 库。
- 不宣称 ZIP 分享已成为完整备份/恢复方案；发布前仍按 v0.8 验收实际导出可读性。
- 不在本版恢复 Git 入口或补做 v0.3 的真机/服务商认证验收。

## 5. 技术约束与依赖

界面隐藏不等于底层能力删除；既有 Git 库的本地阅读与导出保持可达。设计真源为 [v2 原型](../../prototype/v2/index.html)。本版 UI 不触发真实远端；API24 / XT2 验收由用户手动执行。

## 6. 验收记录

- 源码：v2 隐藏 Git 导入切换及分享示意开关；旧 URL 的 Git 分享状态不再恢复。原生导入弹窗仅显示本地目录；同步按钮/菜单/角标和远端链接分享由统一首发开关隐藏，已有 Git 库列表与本地内容未删除。
- 自动检查：导入弹窗、库管理保留与 Git 角标定向测试 14/14；原型 Git 暂隐定向 1/1；原型脚本语法检查通过。原型整套旧 fixture 因当前工作树中分栏设计的 `paintSplit` 调用 `handle.querySelector` 而在初始化阶段失败，未把它记为本版通过。
- 构建：本机 DevEco `assembleHap` 的 `CompileArkTS` 成功（含仓库既有警告）；`PackageHap` 因子进程调用 x86_64 `/Library/Java/JavaVirtualMachines/temurin-25.jdk` 报 `Bad CPU type in executable` 而失败，本轮没有完整 HAP 构建成功证据。
- 待完成：可用 Java/打包环境下重建 HAP；API26 界面目视；API24 / XT2 由用户手动验收。源码/自动检查不代替设备结果。
- 后续状态（2026-11-03）：用户决定恢复 Git 入口，现行 UI 由 [v1.26](../v1.26/需求文档.md) 承接；本节只记录 v1.23 暂隐阶段的实现和验收，不表示当前 UI 仍隐藏。
