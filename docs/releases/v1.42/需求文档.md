# v1.42 需求文档 —— 分享范围去重

> 状态：开发中，2026-11-08 立项。
> 需求来源：[需求池 D / 向外分享约定 · 范围去重](../../requirements_backlog.md#向外分享约定2026-10-25)。

## 1. 版本定位

未选目录（当前笔记位于库根目录）时打开分享面板，「文件夹」范围会退化为「知识库根目录」，与「知识库」范围的打包内容重复，用户看到两个几乎一样的选项。本版把退化为库根的「文件夹」范围从面板中去掉：原型隐藏对应分段按钮，原生不注入该范围；三个范围本身的规则不变。

## 3. 明确不做

- 不改「分享笔记 / 文件夹 / 知识库」三个范围的打包规则、Git 远端链接规则与 ZIP 排除项。
- 不新增「根目录」提示文案或引导跳转；隐藏 / 不注入即可，避免与知识库范围重复。
- 不改库管理页「分享知识库」入口（v1.25 25.18 / v1.37 37.2），该入口本就只含知识库范围。
