## 1. 版本定位

新建笔记永远从空白开始；写日记、会议记录这类固定结构的笔记，每次都要手敲同样的标题。本版提供两件事：

1. **新建笔记时可选模板**：内置「空白 / 日记 / 会议记录 / 读书笔记」，并读取库内 `模板/` 文件夹里的 `.md` 作为自定义模板（与 Obsidian 的核心插件「模板」目录约定兼容）。
2. **今日笔记**：文件栏头部一个日历按钮，一键打开今天的日记；不存在时用日记模板创建。

## 2. 完成判定

新建笔记对话框可选模板并预览前几行；创建后笔记内容为替换过变量的模板；点按今日笔记按钮，当天第一次创建 `日记/YYYY-MM-DD.md`，之后再点打开同一篇；库内 `模板/` 下的文件出现在模板列表中。原型、原生与设备分别验收。

## 3. 需求清单

| 编号 | 需求 | 验收点 |
| --- | --- | --- |
| 59.1 | **新建对话框模板选择。** 类型为「笔记」时，名称输入下方出现「模板」：芯片单选（`--pill`，选中 `--blue-soft` 底 + `--blue` 边与字），默认「空白」；下方浅底等宽字体预览框显示替换变量后的前 4 个非空行（空白模板显示「不使用模板，从空白开始」），名称输入变化时预览实时更新。类型为「文件夹」时整块隐藏。 | 切换芯片预览随之变化；输入名称后预览中的 `{{title}}` 同步；文件夹类型不显示 |
| 59.2 | **内置模板与变量。** 内置 4 个：空白、日记、会议记录、读书笔记（正文见原型 `NOTE_TEMPLATES`）。变量：`{{title}}` 笔记名、`{{date}}` `YYYY-MM-DD`、`{{time}}` `HH:mm`、`{{weekday}}` `星期X`；按创建时刻的本地时间替换。未知变量原样保留。模板中避免空列表项（空 `- ` 在简单模式会触发「请在专业模式编辑」提示），用占位文字代替。 | 创建后正文无残留的已知变量；未知变量原样 |
| 59.3 | **库内自定义模板。** 读取当前库 `模板/` 文件夹（仅一级）下的 `.md`，以文件名作为芯片名，排在内置模板之后；该文件夹不存在时不显示、不自动创建。自定义模板与内置重名时两者都显示，自定义的加「（库内）」后缀。模板文件本身仍是普通笔记，可在文件树中编辑。 | 在 `模板/` 新建一篇后，下次打开新建对话框可见 |
| 59.4 | **今日笔记按钮。** 文件栏头部（计数右侧）在「+」左边新增日历图标按钮（`--touch` 热区，与「+」「搜索」同列规则）；悬停提示「今日笔记 · YYYY-MM-DD」，读屏「打开今日笔记（日期），不存在时用日记模板创建」。点按：`日记/YYYY-MM-DD.md` 存在则在激活栏打开，提示「已打开今日笔记」；不存在则建文件夹（如需）并用日记模板创建，提示「已创建今日笔记：日记/日期（日记模板）」。 | 同一天连点两次只创建一篇；跨零点后再点创建新一天 |
| 59.5 | **默认位置与格式（首期固定）。** 日记文件夹 `日记`、文件名 `YYYY-MM-DD`、模板「日记」；若库内 `模板/日记.md` 存在则优先用它。本版不提供修改入口，设置项回需求池。 | 自定义 `模板/日记.md` 后今日笔记使用自定义内容 |

## 4. 明确不做

- 日历视图、按月浏览日记、周记 / 月记。
- 日记文件夹 / 日期格式 / 默认模板的设置项（回需求池）。
- 模板内脚本、条件、光标定位等高级语法（如 Templater）。
- 从现有笔记「另存为模板」入口。
- 模板与今日笔记不进埋点；模板内容不上报（硬约束 16）。

## 5. 技术约束与依赖

- 环境事实：HarmonyOS API 24 / ArkTS；包名 `com.jxg.huaweiobsidian`；目标设备 XT2。**禁止凭记忆编造 HarmonyOS API**（`AGENTS.md` 硬约束 18）；本版只用现有文件读写与日期能力。
- 新建笔记弹窗的外壳与焦点规则沿用 [v1.32 32.1](../v1.32/需求文档.md)。
- 视觉 token 以 v2 原型 `:root` / `[data-theme="dark"]` 为准。
