# v1.22 需求文档 —— 分栏调节条交互增强

> 状态：🟡 开发中；22.1 原生把手、轨线与扩展响应区域已实现；22.2 比例、宽度与边界反馈已实现，键盘调整留显待 22.4 接入；22.3–22.5 待实现。真实浏览器、模拟器及 API24 / XT2 验收未完成。
> 对应里程碑：独立优化。
> 需求来源：[需求池 Q-01](../../requirements_backlog.md)；设计基线：[分栏调节条设计](../../prototype/v2/分栏调节条设计.md)。

## 1. 版本定位

增强现有分栏调节条的可发现性、拖动反馈、恢复操作与无障碍状态，不改变既有分栏布局模型。

## 2. 完成判定

在支持的宽屏布局中，用户能通过触摸、鼠标或键盘发现并调整栏宽，明确获知当前比例与边界状态，可吸附或恢复默认、取消未完成拖动；读屏能获知当前值。原生能力与目标设备行为经独立验证。

## 3. 需求清单

| 编号 | 交付范围与验收要求 |
| --- | --- |
| 22.1 | **可见把手与轨线。** 静止时显示抓握把手和三个圆点提示；悬停 / 聚焦时显示全高轨线，拖动时把手放大并填充品牌色。粗指针热区不小于 36vp；把手与轨线不占布局、不改变栏宽计算。 |
| 22.2 | **数值与边界提示。** 拖动中显示两侧比例和宽度；键盘调整、恢复默认、取消后短暂保留。靠近默认比例吸附并说明“默认比例”；达到最小 / 最大宽度说明边界原因，颜色不是唯一信息。 |
| 22.3 | **拖动、恢复与触摸。** 沿用既有栏宽范围与保存键；距离默认比例约 10vp 内吸附，原型支持 Alt 暂停吸附；Esc 取消并恢复拖动前比例，双击恢复默认。触摸以两次轻触恢复默认，不依赖 `dblclick`；减少动态效果偏好下不播放吸附动画。 |
| 22.4 | **键盘与读屏。** 左 / 右方向键按 16vp 步进，Shift 扩大至 64vp，Home / End 到最小 / 最大，Enter 恢复默认。分隔条继续提供 `aria-valuemin` / `aria-valuemax` / `aria-valuenow`，并补充当前比例及状态文本。 |
| 22.5 | **原型与设计同步。** v2 原型覆盖目录栏和正文 / 参考栏两种调节条；保持现有 token、布局边界、栏宽状态键及单屏 / 专注模式隐藏规则。设计说明链接到独立规格。自动检查、真实浏览器、模拟器和 API24 / XT2 证据分开记录。 |

## 4. 明确不做

- 不改变默认栏宽、每栏最小宽度、栏数量、折痕规则或既有栏宽持久化键。
- 不增加栏宽设置项；默认恢复继续复用现有设置入口。
- 不做拖动惯性、多段吸附、拖动预览缩略图或振动依赖。
- 不将浏览器原型结果作为 ArkUI / ArkWeb 手势、触觉、读屏接口或 XT2 设备验收证据。

## 5. 技术约束与依赖

- 首次分栏实现归 [v0.7 §7.22–7.23](../v0.7/需求文档.md)；本版只增强调节条，不回填旧版需求或扩大布局范围。
- 现行设计 token 以 [v2 设计说明](../../prototype/v2/设计说明.md) 和原型 `:root` / `[data-theme="dark"]` 为准。
- HarmonyOS API、手势、读屏和触觉行为必须查证 [API 笔记](../../harmonyos/api_notes.md)，未核实的接口不写入实现承诺。
