# v1.22 需求文档 —— 分栏调节条交互增强

> 状态：⚪ 规划中；v2 原型与定向自动检查已完成，真实浏览器交互及原生实现 / 验收未完成。
> 对应里程碑：独立优化。
> 需求来源：[需求池 Q-01](../../requirements_backlog.md)；设计基线：[分栏调节条设计](../../prototype/v2/分栏调节条设计.md)。

## 1. 版本定位

增强现有分栏调节条的可发现性、拖动反馈、恢复操作与无障碍状态，不改变既有分栏布局模型。

## 2. 完成判定

在支持的宽屏布局中，用户能通过触摸、鼠标或键盘发现并调整栏宽，明确获知当前比例与边界状态，可吸附或恢复默认、取消未完成拖动；读屏能获知当前值。原生能力与目标设备行为经独立验证。

## 3. 需求清单

| 编号 | 交付范围与验收要求 |
| --- | --- |
| 22.1 | **可发现性与反馈。** 调节条静止时显示抓握把手；扩大触摸 / 指针热区；拖动与聚焦时显示全高边界轨线。拖动中展示两侧当前比例和宽度；吸附默认比例、到达最小 / 最大宽度时均提供文字状态反馈，颜色不能作为唯一信息。 |
| 22.2 | **拖动操作。** 沿用既有栏宽范围与保存键；距离默认比例 10px 内吸附，按住 Alt 暂停吸附；Esc 取消当前拖动并恢复拖动前比例；双击恢复默认。拖动释放后保存。 |
| 22.3 | **触摸操作。** 触摸拖动与指针拖动一致；以两次轻触恢复默认，不依赖触摸设备是否派发 `dblclick`。减少动态效果偏好下不播放吸附动画。 |
| 22.4 | **键盘与读屏。** 左 / 右方向键按既有 16px 步进调整，Shift 扩大步长；Home / End 分别到最小 / 最大，Enter 恢复默认。分隔条继续提供 `aria-valuemin` / `aria-valuemax` / `aria-valuenow`，并补充可读的当前比例及状态文本。 |
| 22.5 | **原型与设计同步。** v2 原型覆盖目录栏和正文 / 参考栏两种调节条；保持现有 token、布局边界、栏宽状态键及单屏 / 专注模式隐藏规则。设计说明链接到独立规格。原型自动检查通过；真实浏览器、模拟器和 API24 / XT2 证据分开记录。 |

## 4. 明确不做

- 不改变默认栏宽、每栏最小宽度、栏数量、折痕规则或既有栏宽持久化键。
- 不增加栏宽设置项；默认恢复继续复用现有设置入口。
- 不做拖动惯性、多段吸附、拖动预览缩略图或振动依赖。
- 不将浏览器原型结果作为 ArkUI / ArkWeb 手势、触觉、读屏接口或 XT2 设备验收证据。

## 5. 技术约束与依赖

- 首次分栏实现归 [v0.7 §7.22–7.23](../v0.7/需求文档.md)；本版只增强调节条，不回填旧版需求或扩大布局范围。
- 现行设计 token 以 [v2 设计说明](../../prototype/v2/设计说明.md) 和原型 `:root` / `[data-theme="dark"]` 为准。
- HarmonyOS API、手势、读屏和触觉行为必须查证 [API 笔记](../../harmonyos/api_notes.md)，未核实的接口不写入实现承诺。
