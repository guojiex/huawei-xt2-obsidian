> 状态：🟡 开发中；19.1–19.5 本地实现与自动测试已完成，交互与设备验收未完成；19.6 尚未完成；未发布。
> 前置：[v1.18](../v1.18/需求文档.md) 块编辑底座；[v1.7](../v1.7/需求文档.md) 简单模式与复杂块保护。
> 统一设计：[简单模式复杂块编辑设计](../../engineering/简单模式复杂块编辑设计.md)。

## 1. 版本定位

代码块是笔记里第二常见的复杂块（仅次于表格）。v1.7 起它在简单模式整体只读，改一行代码要切专业模式。
本版让围栏代码块可以在简单模式里直接改内容与语言，行内代码可以转回纯文本。

## 2. 完成判定

在简单模式下，用户点进围栏代码块就能改里面的代码、切换语言、复制内容，语言不在清单里时保留原语言；
改动只落在代码块区间，围栏、语言标记与块外源码逐字不变。行内代码可一键取消。

## 3. 需求清单

| 编号 | 交付范围与验收要求 |
| --- | --- |
| 19.1 | **块内改代码。** 点进围栏代码块进入块编辑态：块内为等宽纯文本编辑，回车、缩进、空行与普通文本一致；输入不触发任何 Markdown 格式映射（块内输入 `*` `#` 不变成格式）。围栏与语言标记保留；块外点击或 Esc 退出编辑态。改动只落到围栏内容区间，块外源码逐字不变。中文输入法组合期间不提交、不重建块。 |
| 19.2 | **语言选择。** 块属性面板（标题「代码块」）提供语言选择（常用语言清单 + 纯文本 + 保留当前值）；切换只改写语言标记，不动内容。语言不在清单内时保留原值，只提供「以源码编辑此块」。**2026-11-03 修订（D-2）**：代码块右上角常驻“语言 ▾”标签，点按打开本面板；围栏未闭合时显示“源码”。 |
| 19.3 | **复制与兜底。** 属性面板提供复制代码内容；任何降级场景都提供「以源码编辑此块」（v1.18 底座能力）。复制常驻在语言标签旁，作为块角标而非上下文浮条。 |
| 19.4 | **行内代码。** 光标在行内代码内时，属性面板（标题「行内代码」）提供「转为纯文本」（去掉反引号保留内容）。 |
| 19.5 | **保护范围与降级。** 以下保持只读并在附近说明（用 v1.7 的默认文案，不承诺后续版本）：含缩进围栏、未闭合围栏、嵌套围栏、围栏内出现无法安全回写的转义；Mermaid 等图型块按内容编辑处理，不校验图型语法、不渲染校验结果。解析失败保留原文，不清空或覆盖。 |
| 19.6 | **撤销与保存。** 一次块编辑态内的连续输入按既有输入合并策略成撤销步，语言切换与转纯文本各为一个撤销步；撤销后源码完全恢复。保存、草稿、失败保护沿用 v1.7 同一链路。 |

## 4. 明确不做

- 不做语法高亮编辑、代码补全、折叠、格式化、运行或终端能力。
- 不做 Mermaid / 图表可视化编辑，不引入渲染依赖。
- 不在简单模式新增「插入代码块」以外的新语法；插入围栏沿用现有格式面板「代码块」入口。
- 不改变专业模式的代码块行为，不改保存 / 附件 / Git / 外部授权服务，不改包版本与发布状态。

## 5. 技术约束与依赖

- 代码块区间识别依赖 v1.18 底座；围栏内容偏移须兼容 CRLF、BOM、缩进与波浪号围栏。
- 块编辑态与预览滚动、软键盘避让、选区恢复的关系须在模拟器验证；浏览器原型结果不能代替。
- 代码内容不得进入埋点或日志（沿用 v1.7 17.7 脱敏口径）。
