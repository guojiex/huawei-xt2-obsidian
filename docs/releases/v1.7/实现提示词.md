# v1.7 实现提示词 —— 默认简单模式与专业模式切换

在曜石笔记仓库实现 v1.7，优先级为当前新增功能首位。先检查 git status，保留已有未提交改动，不清理或覆盖。遵守 AGENTS.md；先读 docs/mvp_design.md、docs/open_questions.md、docs/harmonyos/api_notes.md、docs/harmonyos/README.md、docs/releases/README.md、docs/releases/实施总清单.md、本目录需求文档.md 和 docs/prototype/v2/设计说明.md。每完成并验收一条需求，同步记录后按当前用户指令 commit 并 push；不打 tag、不发布。

## 目标与范围

只实现本版 17.1–17.7，来源为需求池 A 的轻量编辑模式。默认简单模式，直接在排版正文内输入和设置基础格式；用户在「设置 → 通用 → 编辑模式」主动开启专业模式，保留原源码 / 预览与双栏。原型只作为入口、视觉和交互参考，不能把 contenteditable 示例当生产实现，也不能把浏览器测试记成原生完成。

## 执行顺序

1. 审查当前 Web 编辑 / 预览、Markdown 解析、ArkTS 桥接、自动保存 / 草稿、VaultAccess、模式偏好及会话恢复，记录可验证的方案和当前能力缺口。只使用 API ≤24 的已核实接口；禁止凭记忆编造 HarmonyOS API、Hds 名称或 sys.symbol 标识。
2. 先验证沙箱内最小闭环：空笔记和普通段落直接编辑、源码区间修改、中文组合、保存、重开、失败保留。扩展基础格式、图片插入与复杂块保护；不能用整篇 HTML 转 Markdown 覆盖文件，未编辑语法逐字保留。
3. 接入默认简单模式及应用级偏好；旧会话的源码标志不代表用户选择专业模式。设置两项单选和更多快捷项遵循 v2 token；单屏 / 双屏 / 三屏统一在工作区右上角更多菜单直接选择简单 / 专业模式，不进入子菜单或跳转设置，简单模式也保留入口；设置与关于统一收进该菜单，不保留独立顶栏设置图标，退出设置时焦点回到更多按钮；不把模式下拉放回正文工具栏。
4. 接通模式切换、当前笔记与选区 / 滚动保持、双栏恢复、切库 / 切笔记和过期回调保护；始终保留当前笔记，不因旧布局恢复跳回旧目标。
5. 运行相称的行为测试、现有必要回归及 unsigned arm64-v8a HAP 构建；有可用模拟器时验证正常编辑、保存、重开和布局切换。不制造设备崩溃、强杀或写入中断；失败注入在单测完成。API24 / XT2 真机由用户手动验收，不连接真机。
