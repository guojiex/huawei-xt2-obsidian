# v1.7 验收记录

> 更新：2026-11-01。当前仅记录 17.1 与 17.2 首轮实现证据，不代表 v1.7 整版完成。

## 17.1–17.2 原生首轮实现

### 实现

- 应用级编辑模式偏好默认简单模式；缺失、无效或读取失败回退简单模式。只有用户主动选择的有效模式会写入 Preferences，写入或 flush 失败返回失败并在 UI 明确反馈。
- 模式偏好独立于库和旧会话的编辑 / 预览标志；启动恢复不再从旧栏位状态推断用户选择了专业模式。
- 所有断点的工作区右上角更多菜单直接列出简单 / 专业模式；设置页通用分类提供带图标、说明和选中状态的两项模式选择。移除工作区独立设置按钮，简单模式仍保留更多菜单。
- 简单模式当前显示一个活动编辑区，使用 CodeMirror Markdown 源状态装饰标题、粗体、斜体、列表和待办；表格、代码、链接等复杂语法受保护并提示转专业模式。源码区间仍是唯一正文状态，不将预览 HTML 转成 Markdown。
- 设置返回时请求焦点回到更多按钮。模式变化通过既有编辑器桥同步，并先处理当前保存队列；组合输入中会拒绝切换并保留当前模式。
