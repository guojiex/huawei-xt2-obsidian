## 17.5 Markdown 复杂语法与源码完整性保护（2026-11-01）

### 实现

- CodeMirror Markdown 源仍是唯一正文真源；所有简单模式变更继续落到原始源码区间，不建立 HTML / 富文本副本，也不做整篇 HTML 反向转换。语法树未能在限定时间内覆盖全文时，现有逻辑会将整篇文档设为只读保护。
- 扩展只读区间，完整覆盖 Obsidian 双链 / 嵌入、引用式链接定义、行内 `$$...$$` 两侧定界符、`%%` 注释、`==` 高亮、`~~` 删除线、`~` 下标、`^` 上标 / 块 ID、脚注及冒号围栏块；未闭合的冒号块从起始行保护到文末。既有属性、表格、代码 / Mermaid 围栏、图片 / 链接、公式和 callout 保护保留。
- 跨越受保护区间的删除或粘贴被拒绝；保护区外的相邻普通段落仍允许编辑。扩展语法识别会忽略语法树已保护的代码、链接等内部标记，避免代码示例中的未闭合标记把后续普通段落一并锁住。没有改动保存、AtomicFile、图片导入、权限、日志或笔记迁移路径。
