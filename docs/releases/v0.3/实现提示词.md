# v0.3 实现提示词：Git 双向同步与形态收口

> **历史提示词**：2026-10-30 用户调整为 Native 优先，当前开发使用 [Native 优先实现提示词](实现提示词_Native优先.md)；本文件保留历史记录，不再作为当前任务范围。

> 排期规则：本轮包括“新 clone 隔离目录文件写入改造”和用户于 2026-10-27 单独授权的 Native libgit2 N-API 封装 PoC；后者只做独立模块，不接入 App。commit/push、既有库同步和其他 Git 功能仍在外部依赖队列后置。

> 本轮只完成新 clone 文件写入、隔离导入失败清理与相关验证；不要顺带实现 commit/push、重构存储系统或修改无关功能。

## 项目和边界

你在“曜石笔记”仓库工作：华为 XT2 三折叠、ArkTS + Stage 模型、API ≤24。先读 `AGENTS.md`、`docs/releases/v0.3/需求文档.md`、`docs/releases/实施总清单.md`、`docs/open_questions.md`、`docs/harmonyos/api_notes.md`、`docs/mvp_design.md` §4.4 和 v0.2 验收记录。v0.2 编辑/保存先完成可用模拟器验证；XT2 按既有安排延后统一验收，不因真机延期停止模拟器可验的开发，也不能把回写判为真机通过。

禁止凭记忆编 HarmonyOS API；先从当前安装 SDK 声明与知识库核对 API 起始版本。若没有 API24 SDK / 设备证据，明确标记为待验，不能把 API26 声明写成 API24 运行结果。遵守仓库已定的 HTTP 转发、常驻 Web 容器、统一路径解析器、`AssetStoreKit` 安全存储和 `AtomicFile` 约束。不得把令牌写入日志、文档或普通 preferences。新 clone 可在未登记的 `vaults/<id>__importing` 目录内使用经核实的普通二进制写入；这是仅限本次导入数据的受控例外，不可用于已有库。

> **2026-10-27 用户授权**：恢复新 clone 的文件写入改造。官方回复见 `api_notes.md` C1 和 2026-10-27 QA；不要再尝试更换 encoding。新 clone 失败仅清理本次导入目录，已有库文件保护要求不变；本轮不恢复其他 Git 同步功能。
