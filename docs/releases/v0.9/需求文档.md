# v0.9 需求文档 —— v2 UI 全面迁移与唯一入口

> 状态：实施中（2026-10-27 用户要求）；没有日历交付日期承诺。
> 来源：需求池 [L-01–L-10](../../requirements_backlog.md#l-v2-ui-迁移与-v1-退出2026-10-27已分配-v09)。
> 对应里程碑：新增 M4.10，完整归本版；既有 M0–M8 的功能承诺与验收记录不重新分配。

## 1. 版本定位

以 `docs/prototype/v2/index.html` 为唯一现行设计入口，完成现行能力迁移、原生 UI 对齐及 v1 退出。v2 是设计代次，App 交付版本是 v0.9。本版以 UI 迁移为主，9.12 会话恢复与 9.14 文本分享按明确需求扩展必要的本地状态与分享链路；其他业务服务与保存逻辑继续复用。

最新有效交互见 [v2 设计说明](../../prototype/v2/设计说明.md)；其中存在修订历史，应以后续明确替代的规则为准。本版实施时先整理成单一现行说明，旧修订留作记录，不靠堆叠覆盖条款解释当前行为。

## 2. 完成判定

[迁移验收清单](迁移验收清单.md)中每个当前有效功能均有 v2 入口、实际行为、回归结果与对应原生落点；单 / 双 / 三屏、90° 旋转、浅深色和窄栏无遗漏与溢出。v2 不依赖 v1 文件提供当前功能、token 或原型生成数据；原型专属入口 / 生成 / 测试以 v2 为准，共享生成器各自使用唯一真源，Markdown 测试验证组件行为。v1 文件及旧版原型测试保持删除。完成 v1 退出门禁及原生验收后，才能标记本版完成。

分阶段验收：原型行为与视觉、原生构建 / 单测、模拟器、API24 / XT2、分享接收端、发布分别记录。模拟 DOM 检查不能代替浏览器视觉，API26 记录不能代替 API24 / XT2，原型中的示意不能算原生实现。

### 3.1 执行顺序与门禁

1. **P1 盘点与补齐原型**：从 Git 历史只读对照 → v2 缺项补齐 → 现行设计说明收口。v1 继续从工作树删除，不恢复或归档。
2. **P2 v1 退出门禁**：确认 v2 是唯一现行设计入口；原型专属生成 / 测试与 token 规则以 v2 为准，共享生成器各自使用唯一真源，Markdown 测试验证组件行为；现行说明不依赖 v1。v1、归档副本、根路径兼容入口和旧版原型测试均不存在。保留 Git 历史与已有验收记录，不重建旧稿 / 旧测试。
3. **P3 原生 UI 对齐**：使用固定后的 v2 基线迁移原生 UI，回归现有服务与保存边界；不得把原型 P1/P2 完成当作 App 完成。
4. **P4 本版收口**：补齐 API24 / XT2 与必要目标应用验证，记录仍未通过的项目；正式发布按版本规则另行执行。

本版为接下来优先 UI 任务；既有本地版本的在途改动与验收证据保留，迁移复用它们，不要求为进入本版先完成所有旧版发布。缺少的真实服务按原属版本承诺补齐或记录依赖，不在本版编造成功状态。v0.3 / v0.6 仍在外部队列。

### 3.2 P2 v1 退出门禁

退出门禁须逐项满足：

- 当前有效功能均有 v2 入口；Git / 小艺外部待办保留状态与需求指向，不伪装可用；历史 Agent 能力不迁入当前 UI。
- 现行入口说明、token 规则和原型专属生成 / 测试均以 `docs/prototype/v2/index.html` 为准；共享样例 / 版本 / 反馈生成器分别以 `sample_vault/manifest.json`、`changelog.json` 与 `AppScope/app.json5`、`app_config.json` 为真源，Markdown 测试独立验证组件行为；没有新增手写第二真源。
- 工作树不存在 `docs/prototype/index.html`、`docs/prototype/archive/v1/` 或已删除的旧版原型测试；不创建兼容入口。历史稿只从 Git 历史只读读取。
- 自动检查与生成器检查通过；真实浏览器、模拟器、API24 / XT2、目标应用接收等证据分别记录，不相互替代。未完成的设备矩阵继续待验，不阻止把 v1 退出状态如实记为完成。

## 4. 明确不做

- 除 9.12 的会话持久化、9.14 的单篇文本分享及 9.15 的本地视口同步所需变更外，本版复用已有业务服务和数据格式；不修改包版本、tag 或发布状态，不得用原型内存行为替代真实原生能力。
- 不把当前 v2 概念稿直接视为全面迁移完成。
- 不恢复已撤下的本地 Agent View，不为 UI 迁移接入真实小艺或推进 Git clone / push；不扩展它们原版本的范围。
- 不新增云协作、第四栏、插件系统、ZIP 导入 / 备份恢复或未分配的 Markdown 能力。
- 不恢复或归档 v1 旧稿，不重建已删除的旧版测试，不创建根路径兼容入口；历史版本需求和验收证据保留原义，旧稿只从 Git 历史只读对照。
