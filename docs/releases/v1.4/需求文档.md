# v1.4 需求文档 —— 预览提示块（callout）渲染

> **状态**：🟡 本地功能与 API26 模拟器验收完成；API24 / XT2 与版本发布待验
> **对应里程碑**：新增 M8.1，完整归本版；M8（v1.3）范围不重新分配。本版收口 v0.5 样式基线（M4.6）遗留的 callout 渲染缺口。

## 1. 版本定位

补齐 Obsidian 风格提示块（callout）的预览渲染，从 Obsidian 迁来的笔记不再显示原始 `> [!note]` 语法。

## 2. 完成判定

共享样例 `20_样式/属性与提示块.md` 中的 note / warning / tip（含折叠写法）在预览中渲染为带类型标识的提示块；普通引用渲染不回归；渲染器单测覆盖语法分支。

## 3. 需求清单

| # | 需求 | 来源 | 验收点 |
| --- | --- | --- | --- |
| 1 | callout 块识别与渲染 | 需求池 A「提示块（callout）渲染」；v0.5 样式基线 L21 / L33 缺口 | 按 Obsidian 官方语法支持 `note`、`warning`、`tip`（ID 不区分大小写）；`> [!类型] 标题` 及后续 `>` 行渲染为带类型标识的提示块；未知类型保留普通引用显示 |
| 2 | 折叠 callout | 同上 | `> [!tip]-` 的折叠行为降级为展开显示；标题、正文和内容均保留 |
| 3 | 普通引用不回归 | 同上 | 不带 `[!]` 标记的 `>` 引用保持现有渲染 |
| 4 | 样例与测试同步 | v0.5 共享样例单一真源 | 样例正文「当前 App 不保证把这些扩展语法专门渲染」说明按实际支持更新；`web/mdpreview` 单测新增 callout 分支；改后重新打包 rawfile 并提交 |

## 4. 明确不做

- 高亮 `==mark==`、Obsidian 注释 `%%...%%`：仍在需求池未分配，本版不做。
- callout 嵌套、自定义类型注册、编辑器侧 callout 语法辅助（补全 / 格式按钮）：不做。
- 原型 v2 示意改写：原型保持现状，本版只改原生渲染器与共享样例。

## 5. 技术约束与依赖

- 渲染器在 `web/mdpreview`（marked 扩展路径，与 KaTeX / Mermaid 接入方式一致）；改后必须重新打包 rawfile 并连同产物提交（AGENTS.md 已知坑 3）。
- 颜色 / 圆角 / 间距 / 字号只引用 token，禁止散写数值（AGENTS.md 硬约束 17）。
- callout 类型与折叠语义以 Obsidian 官方文档为准，落码前核对；鸿蒙行为结论一律指向 [`api_notes.md`](../../harmonyos/api_notes.md)，不凭记忆编接口。
- 语法参考：[Obsidian Callouts](https://help.obsidian.md/Editing%20and%20formatting/Callouts)。本版实现 `note`、`warning`、`tip` 子集，ID 大小写不敏感；折叠标记按本版需求降级展开。
