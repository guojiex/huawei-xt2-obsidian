# 关系图谱设计（v2.4）

> 配套版本：[v2.4 需求文档](../../releases/v2.4/需求文档.md)。
> 本文档是**设计规格**：交互口径、数据口径与 token 清单。鸿蒙行为结论一律链接 [`docs/harmonyos/api_notes.md`](../../harmonyos/api_notes.md)，不在本文复制。

## 1. 思路收口

关系图谱是「一眼看懂笔记网络」的可视化。两条常见形态：

| 形态 | 说明 | 取舍 |
| --- | --- | --- |
| 全库图 | 整库所有笔记 + 全部双链 | 全貌；库大时信息密度高 |
| 本篇图 | 当前笔记 + 深度 2 邻域 | 聚焦当下写作；入口短、有上下文 |

本版**两种都做、同一视图内切换**：默认全库图，视角分段切「本篇」后以当前笔记为中心收窄（与 Obsidian 的 global / local graph 心智一致）。入口沿用 v1.81 统计页的 `topView` 全屏范式，不新增侧栏常驻入口，避免侧栏再挤一层。

> **命名（2026-11-22 更名）**：分段文案由「全局 / 本地」改为「**全库 / 本篇**」。「本地」在应用内已有「本地笔记（vs Git 远端库）」的既定语义，继续复用会让用户误以为切换的是存储位置。内部标识（`graphGlobalTab` / `graphLocalTab`）与 URL 参数（`graphFocus=global|local`）不变，只改显示文案。

## 2. 结构

```
图谱视图（.window.graph-open，隐藏侧栏 / 工作区）
├─ 顶栏：返回 ‹ · 标题「关系图谱」· 视角分段（全库 / 本篇）
├─ 图例（可选折叠）：节点大小 = 链接度数；当前笔记高亮
└─ 画布区：节点 + 边；空态 / 无链接态覆盖
```

- 视角分段：`全库`（`aria-pressed`）；`本篇`（当前笔记为空时禁用，提示「先打开一篇笔记」）。
- 返回：关闭图谱视图、焦点回来源入口（与统计页 `statsReturnFocus` 同款）。

## 2.1 布局口径（力导向）

- **力导向，不是圆环**：节点有位置 / 速度，边作弹簧（目标边长 90，刚度 0.08），全节点对斥力（`80000/d²`），弱向心力（0.01）+ 阻尼 0.85，迭代 400 次后取终态；初相位由节点 id 字符串哈希给出，**同一库同一数据必得同一布局**（可复现、可断言）。
- **拟合可视区**：算完布局后按包围盒做一次等比缩放 + 平移，把节点与标签收进带内边距（左右 64、上下 34）的可视区，**任何节点与文字都不被裁掉**；缩放上限 2.4 倍，避免节点少时被放得过大。
- **视口变换（2026-11-22 增补）**：拟合结果绘制在 `<g class="graph-view">` 视口组内，画布级平移 / 缩放只改视口组 `transform`
  ，不重排布局；节点拖拽改的是布局坐标并做微松弛（见 §3）。
- **碰撞分离（2026-11-22 增补）**：每轮力导向迭代后做一次成对位置校正，节点圆心距 ≥ r₁ + r₂ + 20（标签让位），拖拽微松弛同样执行；防止稠密图（36
  边样例库、K5 完全图）节点与标签互相压叠。半径统一由 `graphRadii` 计算，布局与渲染共用。
- **标签挖空描边（2026-11-22 增补）**：节点名文字带纸色描边（`paint-order:stroke`），连线从文字下方穿过时被描边遮住，不糊字形；深色模式自动跟随
  `--paper`。
- **本篇图**：只按「当前笔记 + 邻域」的包围盒拟合，非邻域节点随原坐标落到画布外或边缘（弱化 / 裁切），视觉上等于收窄范围。
- 节点半径 = 5 + 度数 × 1.5（clamp 5–13）；当前笔记实心品牌色，孤岛空心 `--muted`。

## 3. 交互口径

| 动作                   | 结果                                                           |
|----------------------|--------------------------------------------------------------|
| 点节点                  | 在当前激活栏打开该笔记（`selectNote`），退出图谱视图；与拖拽以位移阈值区分（移动 < 8 视图单位视为点按） |
| 悬停 / 键盘聚焦节点          | 高亮该节点的邻接边与邻居节点（`.near` / `.focus-dim`），其余淡出；移开或失焦恢复          |
| 拖拽节点（2026-11-22 增补）  | 节点跟随指针，其余节点按同一力导向常数微松弛（每帧 3 轮，被拖节点钉住）；松手即停，不做惯性              |
| 拖拽空白处（2026-11-22 增补） | 平移画布（视口组 `transform`，光标 `grab` / `grabbing`）                 |
| 滚轮（2026-11-22 增补）    | 以光标为中心缩放视口，范围 0.4–3 倍；触摸双指缩放不在本版（原型以指针事件为主）                  |
| 双击空白处（2026-11-22 增补） | 复位视口（平移 / 缩放归零，回到拟合后的初始视图）                                   |
| Enter / 空格（聚焦节点时）    | 与点节点等效：打开该笔记并退出图谱视图                                          |
| 切换「本篇」               | 以当前笔记为中心收窄到深度 2 邻域，其余节点淡出（仍绘制、弱化）                            |
| 无当前笔记时切「本篇」          | 分段禁用；全库图不受影响                                                 |
| 切换知识库                | 图谱按新库重算；本篇视角回落全库；视口与拖拽状态随重绘复位                                |
| 打开时                  | 力导向布局一次算到终态（无动画）；原生是否做成逐帧收敛动画待核实                             |

## 4. 数据口径

- **节点**：当前库所有非删除 Markdown（复用 `FileTree.allNotesOf`，与 [`WikiLinkService.files`](../../../entry/src/main/ets/model/WikiLinkService.ets) 同源）。
- **边**：每篇笔记经 `WikiLinkParser.parse` + `resolve` 得到的 resolved 目标路径（复用 v1.2 双链解析语义），去重、去自环；未解析（resolved 失败）的链接不成边。
- **度数**：出链 + 反链条数，决定节点半径；孤岛（度数为 0）节点最小半径、`--muted` 弱化。
- **不跨库**：只聚合当前激活库（沿用 [v1.35](../../releases/历史版本归档.md#v135-需求文档)）。
- **标签 / 文件夹不作节点**：只有笔记是节点（明确不做，见 §7）。

## 5. URL 与状态

| 参数 | 含义 | 恢复规则 |
| --- | --- | --- |
| `view` | `graph` 表示打开图谱视图（并入既有 `view` 枚举） | `restoreUrl` 打开图谱视图 |
| `graphFocus` | `local` / `global`（默认 `global`）；对应分段文案「本篇」/「全库」，参数值沿用英文枚举 | 校验枚举，无效丢弃回落 `global` |

返回后的激活栏 / 当前笔记沿用既有 `active` / `left` / `right` 参数，不改动其语义。

## 6. 可达性与红线

- 节点 / 图例均为可达元素：画布内节点用 `<g role="button" tabindex="0">`（SVG 内承载 button 语义的等效写法，
  `aria-label="打开笔记：{标题}"`），视角分段与返回为按钮。
- 读屏：视图 `aria-label="关系图谱"`；本篇图空态说明「当前笔记暂无链接」。
- 颜色 / 圆角 / 间距只引用 token（硬约束 17）；v2.4 CSS 块新增 token：无（复用 `--blue` / `--blue-soft` / `--muted` / `--paper` / `--ink` / `--s2` / `--s3` / `--caption` / `--touch`）。
- 笔记名 / 路径 / 链接关系是笔记内容，禁止进埋点（硬约束 16）；实现版沿用。

## 7. 明确不做（本版）

跨库图谱、图谱内编辑、节点搜索 / 过滤、按文件夹 / 标签着色分组、节点颜色自定义、时间线 / 历史回放、图谱导出图片、图谱统计、标签 / 文件夹作为节点、力导向动画时长设置、原生渲染路线——见 [需求文档 §4](../../releases/v2.4/需求文档.md)。
