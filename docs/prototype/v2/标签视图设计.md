# 标签视图设计（v2.1）

> 配套版本：[v2.1 需求文档](../../releases/v2.1/需求文档.md)。
> 本文档是**设计规格**：交互口径、数据口径与 token 清单。鸿蒙行为结论一律链接 [`docs/harmonyos/api_notes.md`](../../harmonyos/api_notes.md)，不在本文复制。
>
> **v2.11 修订一（2026-11-27）**：侧栏标签区形态从「药丸云」改为 **Obsidian / Bear 式纵向列表行**（一行一个标签：`#` 引导符 + 标签名 + 行尾计数，选中整行高亮）。理由：侧栏是导航区，主流笔记应用（Obsidian / Bear / Apple Notes）在侧栏一律用列表行，药丸是内容区的展示语言；列表行整行触达更大、长中文标签走省略号不挤乱布局、与置顶 / 收藏分区的行节奏一致。过滤条上的当前标签药丸、笔记预览内 chip **保持药丸不变**（那边才是药丸的语境）。
>
> **v2.11 修订二（2026-11-27，拍板）**：标签浏览入口从「文件页签内嵌分区」改为**独立「标签」页签**。侧栏页签变为 **文件 / 标签 / 章节**；标签是整栏高度的独立面板（Obsidian tag pane 模式）。理由：内嵌分区挤占文件树高度（XT2 三栏单栏仅 200-248px，单屏抽屉高度更紧）；标签与「文件」是平级的**浏览维度**，不是文件列表的子分区；页签天然承担收起，`tagsOpen` 折叠记忆偏好删除。点标签行 → 设置过滤并**自动切回「文件」页签**（过滤条与结果列表在那里）；过滤条、预览 chip、数据口径均不变。

## 1. 思路收口

按标签找笔记有几条常见路线：

| 路线 | 形态 | 取舍 |
| --- | --- | --- |
| A. 独立「标签」全屏页 / 弹窗 | 类似 Git 同步页 | 入口深一层；与侧栏浏览动线割裂 |
| B. 文件页签内嵌「标签」分区 + 树内过滤 | 复用置顶 / 收藏的分区语言 | 入口最浅；但挤占文件树高度，分区一多文件树被推到视口外 |
| **B'（v2.11 改稿二拍板）**. 侧栏独立「标签」页签 + 文件页签内过滤 | Obsidian tag pane 模式 | 入口仍浅（同一侧栏一击之遥）；标签升为与文件平级的浏览维度，整栏高度浏览；文件树零被挤 |

选 **B'**：用户的原始诉求是「按标签过滤笔记」，过滤的对象就是侧栏文件列表，标签入口留在侧栏动线最短；v2.1 初版选 B 的「入口浅」理由保留，但内嵌分区在真实三栏宽度下挤压了它要服务的文件树本身——标签作为浏览维度升为页签后，两侧诉求（入口浅 + 文件树不被挤）同时满足。

## 2. 结构与顺序

侧栏页签：**文件 | 标签 | 章节**。

filesPanel（文件页签）自上而下：

```
置顶区（v1.62）
收藏区（v1.54 / v1.97）
标签过滤条（过滤态才出现）
  └─ 「标签」+ 当前标签药丸 + 「清除筛选」
「全部笔记」分区标签（过滤态隐藏——显示的是子集，不再读作「全部」）
文件树 / 标签过滤列表（二选一）
左滑提示行（过滤态隐藏——过滤行无左滑 / 拖动）
回收站
```

tagsPanel（标签页签，独立面板）：

```
面板标题「标签 · N 个」（无标签时仅「标签」）
标签行列表（整栏高度、自身滚动）
  └─ 标签行：`#` 引导符 + 标签名 + 行尾计数（笔记数降序；同数按 localeCompare('zh') 名称序）
空态：「还没有带标签的笔记」（fav-empty）
```

- 过滤列表行形态复用收藏区：首字色块（`favTone` 按文件夹哈希）+ 标题 + 行尾所在文件夹；当前笔记高亮标题；**不带左滑操作与行尾按钮**（过滤列表是查找视图，改名 / 移动 / 收藏等操作回完整树做）。
- 过滤列表排序：文件夹路径 + 标题 `localeCompare('zh')`。
- 过滤态下文件页签内列表优先：置顶 / 收藏分区暂时收起（只影响显示，数据与展开状态不变），过滤条 + 结果列表占据腾出的空间，清除筛选后恢复。标签已独立成页签，不占文件页签高度，单屏不再需要连标签一起收起的特例（phone 专用规则已删）。

## 3. 交互口径

| 动作 | 结果 |
| --- | --- |
| 点标签行 | 进入该标签过滤并**自动切回「文件」页签**（过滤条 + 结果列表在那里）；行 `aria-pressed="true"` 整行高亮（切回标签页签仍可见当前过滤目标） |
| 再点同一标签行 | 清除过滤（留在标签页签），行高亮消失 |
| 点过滤条「清除筛选」/ 点过滤条药丸 | 清除过滤，回完整树 |
| 过滤列表行点击 | `selectNote` 在当前栏打开（与收藏 / 置顶一致） |
| 笔记预览内标签 chip（属性行 / 正文行内 `#tag`）点击 | 侧栏切到「文件」页签并进入该标签过滤（与点标签行同一状态）；单屏展开侧栏抽屉，双屏 / 宽屏确保目录栏可见，专注模式先退出专注；当前笔记不变 |
| 编辑器源码 textarea 内的 `#tag` | 只是普通文本，不可点击；不做输入期识别 |
| 切换知识库 | 清除过滤（标签集合按库不同） |
| 标签页签收起 | 页签切换天然承担，无折叠态、无 `tagsOpen` 记忆（改稿二删除） |
| 过滤态下标签被删光（删笔记等） | `renderTree` 校验失败自动退出过滤态，回完整树（防御路径） |

## 4. 数据口径

- **聚合范围**：frontmatter `tags:`（复用原型 `frontmatterTags`）+ 正文行内 `#tag`（排除 fenced code、行内代码、公式），合并后按小写去重、保留首个书写形式。
- `#父/子` 层级写法按**完整字符串**聚合（`validTag` 允许 `/`），不做层级展开（明确不做）。
- 不跨库：只聚合当前激活库（沿用 [v1.35](../../releases/历史版本归档.md#v135-需求文档) 不跨库先例）。
- 实现版数据源候选：复用 [v1.40](../../releases/历史版本归档.md#v140-需求文档) `search.db` 增量索引（推荐，免全量扫描）或实时扫描 + 缓存，排期时定；提取算法照本节口径。

## 5. URL 与状态

| 参数 | 含义 | 恢复规则 |
| --- | --- | --- |
| `tag` | 当前过滤标签（仅过滤态写入） | `restoreUrl` 校验 `tagIndex().has(tag)`，不存在则丢弃（不进过滤态） |
| `side` | 侧栏页签（`files` / `tags` / `chapters`） | `urlChoice` 直接恢复 |
| ~~`tagsOpen`~~ | ~~标签区展开（1/0）~~ | **改稿二删除**：页签方案下无折叠态 |

过滤状态不进「公开样例 URL」白名单约束：`restoreUrl` 的 `has()` 校验兜底，无效 `tag` 自然回落完整树。

## 6. 可达性与红线

- 侧栏页签按钮带 `aria-pressed` / `aria-controls`；标签行 / 清除按钮均为 `<button>`，键盘可达。
- 笔记内标签 chip 同样是 `<button data-note-tag contenteditable="false">`，读屏名 `按标签筛选：#x`，Enter / 空格触发；预览层在 `pointerdown` 阶段先于 contenteditable 的段落选中拦截，简单模式捕获层也放行 chip，避免被当作普通段落打开块编辑器。
- 读屏：标签面板标题「标签 · N 个」；标签行 `aria-label="按标签筛选：#x，N 篇笔记"` + `aria-pressed`；过滤条 `aria-label="已按标签筛选笔记列表"`；当前筛选药丸 `aria-label="当前筛选标签：#x"`。
- 颜色 / 圆角 / 间距 / 字号只引用 token（硬约束 17）；v2.11 改稿后标签行复用既有 token：`--blue-soft` / `--blue` / `--paper` / `--muted` / `--ink` / `--small-r` / `--touch` / `--s10` / `--s2` / `--caption` / `--small`；面板标题复用 `--caption` / `--muted` / 分区标签排版；过滤条药丸仍用 `--pill`。
- 标签值是笔记内容，禁止进埋点（硬约束 16）；实现版沿用。

## 7. 明确不做（本版）

- 多标签组合过滤（AND / OR）、标签层级展开、标签重命名 / 合并、标签管理页、输入 `#` 自动补全、跨库聚合、**编辑器源码 textarea 内的标签识别 / 点击**（仅预览 chip 可点）——见 [需求文档 §4](../../releases/v2.1/需求文档.md)。
