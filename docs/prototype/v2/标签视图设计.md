# 标签视图设计（v2.1）

> 配套版本：[v2.1 需求文档](../../releases/v2.1/需求文档.md)。
> 本文档是**设计规格**：交互口径、数据口径与 token 清单。鸿蒙行为结论一律链接 [`docs/harmonyos/api_notes.md`](../../harmonyos/api_notes.md)，不在本文复制。

## 1. 思路收口

按标签找笔记有两条常见路线：

| 路线 | 形态 | 取舍 |
| --- | --- | --- |
| A. 独立「标签」视图页 / 弹窗 | 类似 Git 同步页的全屏页 | 入口深一层；与侧栏浏览动线割裂 |
| B. 侧栏「标签」分区 + 树内过滤 | 复用置顶 / 收藏的分区语言 | 入口浅；与文件树同一视线内切换 |

选 **B**：用户的原始诉求是「按标签过滤笔记」，过滤的对象就是侧栏文件列表，把标签入口放进侧栏动线最短；且 v1.54 / v1.62 / v1.97 已把「分区标签 + 折叠区 + 行组件」打磨成侧栏统一语言，标签分区是同一语言的第三次复用（承诺出处：[v1.62 §62.1](../../releases/历史版本归档.md#v162-需求文档)「收藏落地时共用分区标签与行组件」）。

## 2. 结构与顺序

侧栏 filesPanel 自上而下：

```
置顶区（v1.62）
收藏区（v1.54 / v1.97）
标签区（v2.1，无标签时整区隐藏）
  └─ 区头「标签」+ 标签总数 + 折叠箭头
  └─ 药丸流：#标签 N（笔记数降序；同数按 localeCompare('zh') 名称序）
标签过滤条（过滤态才出现）
  └─ 「标签」+ 当前标签药丸 + 「清除筛选」
「全部笔记」分区标签（过滤态隐藏——显示的是子集，不再读作「全部」）
文件树 / 标签过滤列表（二选一）
左滑提示行（过滤态隐藏——过滤行无左滑 / 拖动）
回收站
```

- 过滤列表行形态复用收藏区：首字色块（`favTone` 按文件夹哈希）+ 标题 + 行尾所在文件夹；当前笔记高亮标题；**不带左滑操作与行尾按钮**（过滤列表是查找视图，改名 / 移动 / 收藏等操作回完整树做）。
- 过滤列表排序：文件夹路径 + 标题 `localeCompare('zh')`。
- 过滤态下列表优先：置顶 / 收藏分区暂时收起（只影响显示，数据与展开状态不变），双屏 / 宽屏保留标签分区用于直接切换过滤目标；单屏抽屉高度有限，过滤态连标签分区一起收起，优先露出结果列表。过滤条 + 结果列表占据腾出的空间，清除筛选后恢复。这样点笔记内 chip 后结果不会被较高的置顶 / 收藏分区挤到视口外。

## 3. 交互口径

| 动作 | 结果 |
| --- | --- |
| 点标签药丸 | 进入该标签过滤；药丸 `aria-pressed="true"` |
| 再点同一药丸 / 点过滤条「清除筛选」/ 点过滤条药丸 | 清除过滤，回完整树 |
| 点其它药丸 | 直接切换过滤目标 |
| 过滤列表行点击 | `selectNote` 在当前栏打开（与收藏 / 置顶一致） |
| 笔记预览内标签 chip（属性行 / 正文行内 `#tag`）点击 | 侧栏切到「文件」并进入该标签过滤（与点药丸同一状态）；单屏展开侧栏抽屉，双屏 / 宽屏确保目录栏可见，专注模式先退出专注；当前笔记不变 |
| 编辑器源码 textarea 内的 `#tag` | 只是普通文本，不可点击；不做输入期识别 |
| 切换知识库 | 清除过滤（标签集合按库不同） |
| 标签区折叠 | 点区头任意处展开 / 收起；键盘 ←/→ 收起 / 展开；按库记忆 |
| 过滤态下标签被删光（删笔记等） | `renderTree` 校验失败自动退出过滤态，回完整树（防御路径） |

## 4. 数据口径

- **聚合范围**：frontmatter `tags:`（复用原型 `frontmatterTags`）+ 正文行内 `#tag`（排除 fenced code、行内代码、公式），合并后按小写去重、保留首个书写形式。
- `#父/子` 层级写法按**完整字符串**聚合（`validTag` 允许 `/`），不做层级展开（明确不做）。
- 不跨库：只聚合当前激活库（沿用 [v1.35](../../releases/历史版本归档.md#v135-需求文档) 不跨库先例）。
- 实现版数据源候选：复用 [v1.40](../../releases/历史版本归档.md#v140-需求文档) `search.db` 增量索引（推荐，免全量扫描）或实时扫描 + 缓存，排期时定；提取算法照本节口径。

## 5. URL 与状态

| 参数 | 含义 | 恢复规则 |
| --- | --- | --- |
| `tag` | 当前过滤标签（仅过滤态写入） | `restoreUrl` 校验 `tagIndex().has(tag)`，不存在则丢弃（不进过滤态） |
| `tagsOpen` | 标签区展开（1/0） | 直接恢复，默认展开 |

过滤状态不进「公开样例 URL」白名单约束：`restoreUrl` 的 `has()` 校验兜底，无效 `tag` 自然回落完整树。

## 6. 可达性与红线

- 药丸 / 清除按钮均为 `<button>`，键盘可达；区头键盘行为与置顶 / 收藏一致。
- 笔记内标签 chip 同样是 `<button data-note-tag contenteditable="false">`，读屏名 `按标签筛选：#x`，Enter / 空格触发；预览层在 `pointerdown` 阶段先于 contenteditable 的段落选中拦截，简单模式捕获层也放行 chip，避免被当作普通段落打开块编辑器。
- 读屏：区头 `aria-label="标签，N 个标签"`；药丸 `aria-label="按标签筛选：#x，N 篇笔记"` + `aria-pressed`；过滤条 `aria-label="已按标签筛选笔记列表"`；当前筛选药丸 `aria-label="当前筛选标签：#x"`。
- 颜色 / 圆角 / 间距 / 字号只引用 token（硬约束 17）；v2.1 CSS 块新增 token：无（全部复用既有 token：`--blue-soft` / `--blue` / `--paper` / `--muted` / `--pill` / `--touch` / `--s1` / `--s2` / `--s3` / `--caption` / `--small`）。
- 标签值是笔记内容，禁止进埋点（硬约束 16）；实现版沿用。

## 7. 明确不做（本版）

- 多标签组合过滤（AND / OR）、标签层级展开、标签重命名 / 合并、标签管理页、输入 `#` 自动补全、跨库聚合、**编辑器源码 textarea 内的标签识别 / 点击**（仅预览 chip 可点）——见 [需求文档 §4](../../releases/v2.1/需求文档.md)。
