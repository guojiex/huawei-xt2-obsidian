## 1. 目标

让用户能看见分隔条、容易抓取、理解栏宽变化，并可通过触摸、鼠标或键盘完成调整与恢复。现有栏宽计算、默认比例、边界、持久化键和布局显隐规则保持不变。

## 2. 控件构成

调节条不占布局宽度；热区、轨线、把手与提示均为边界上的交互或装饰层。

| 部分 | 设计 |
| --- | --- |
| 热区 | 常规指针至少 24px；粗指针扩大至 36px，全高并承接拖动。 |
| 轨线 | 全高；静止透明，悬停弱化显示，键盘聚焦与拖动时清晰显示。 |
| 抓握把手 | 静止时可见的垂直胶囊与三个抓握点；悬停、聚焦、拖动均有明确状态。粗指针下增大把手。 |
| 数值提示 | ~~调整时显示两侧比例及像素宽度；到默认比例或边界时补充文字状态。~~（2026-11-07 用户决定撤销：拖动 / 键盘调整不弹视觉读数浮层；比例、栏宽与边界状态仅保留在读屏文本。） |

颜色、圆角、间距、字号和控件尺寸沿用 v2 token；深色与强制颜色模式保持可辨认。吸附 / 边界不能只靠颜色表达。减少动态效果时取消过渡与吸附动画。

## 3. 交互

### 3.1 鼠标与触控笔

- 按住热区拖动；指针离开热区后仍继续跟随，拖动中禁止选中文本。
- 接近默认比例 10px 内吸附：目录栏为窗口宽度的 1/3，正文 / 参考栏为目录右侧可用区域的 1/2（目录收起时即整个窗口）。按住 Alt 临时关闭吸附；键盘调整不吸附。
- 到达既有最小 / 最大宽度时停止越界，并通过读屏文本说明边界。
- 释放后按既有栏宽存储键保存；双击恢复默认。
- Esc 取消当前拖动并恢复开始拖动前的比例。

### 3.2 触摸

- 使用与指针相同的拖动和边界规则；热区在粗指针环境增大。
- 两次轻触恢复默认，以短时间间隔和极小位移识别；不依赖触摸设备触发 `dblclick`。
- 不依赖振动反馈。浏览器振动接口不构成原生能力或权限依据。

### 3.3 键盘与读屏

调节条使用垂直 `role="separator"` 并可聚焦：

| 按键 | 行为 |
| --- | --- |
| ← / → | 以现有 16px 步长减少 / 增加宽度 |
| Shift + ← / → | 以 64px 步长减少 / 增加宽度 |
| Home / End | 调整到最小 / 最大宽度 |
| Enter | 恢复默认比例 |
| Esc | 拖动期间取消并恢复起始比例 |

`aria-valuemin`、`aria-valuemax` 与 `aria-valuenow` 持续反映当前范围；`aria-valuetext` 说明栏名、百分比、另一侧比例和默认 / 边界状态。键盘操作后的可见提示短暂保留。

## 4. 显示范围与比例

- 目录调节条只在目录可见的宽屏工作区显示。
- 正文 / 参考调节条在正文与参考双栏均可见时显示，**不论目录是否展开**：
  - 双栏（目录收起）：调节条一处，位于正文与参考之间。
  - 三栏（目录 + 正文 + 参考）：调节条两处——目录 | 正文、正文 | 参考，均显示抓握把手、均可拖动，样式与状态一致。
- 三栏时两处调节条的联动：
  - 正文 / 参考比例以「目录右侧可用区域」为基准保存，与目录收起时共用同一个比例值和存储键，展开 / 收起目录后比例保持。
  - 拖动目录调节条时，右侧两栏按当前比例同步缩放，正文 / 参考比例不变。
  - 目录最大宽度按当前正文 / 参考比例限制，保证右侧每栏均不少于内容栏下限（v1.39 前统一 240vp，现按 §4 末条随角色与字号计算）；正文 / 参考调节条的范围为 [内容栏下限, 可用区域 − 内容栏下限]。
  - 同一时刻只响应一处拖动；拖动中另一处轨线弱化显示（沿用 `splitting` 状态）。
  - 恢复默认（双击 / Enter / 两次轻触 / 设置「恢复默认栏宽」）同时恢复目录 1/3 与正文 / 参考 1/2。
- 双屏预设下目录展开时参考栏不显示，此时不出现正文 / 参考调节条（沿用现有布局显隐规则）。
- 单屏、专注模式与设置页面不显示调节条。
- 默认目录比例为 1/3，正文与参考栏均分。折痕只标注，不参与栏宽计算。
- 最小宽度（2026-11-07 设计变更，实现归 [v1.39](../../releases/v1.39/需求文档.md)；**原型与原生已落地（2026-11-08）**）：
  - 按栏角色取基准：目录 200vp，正文 240vp，参考 240vp（设计起点，非平台规定）。
  - 跟随系统字号：实际下限 = 基准 × clamp(fontSizeScale, 1, 1.45)，向上取整；字号变化实时重新布局，不改写已保存比例。
  - 不按机型、不按窗口宽度比例取值；1.45 倍上限保证 lg 三栏（986 ≤ 1107vp）与 md 双栏（696 ≤ 709vp）仍放得下。
- 恢复默认同时清除已保存比例，与设置中的“恢复默认栏宽”一致。

比例和像素只用于当前原型提示；实际平台的单位映射须在原生实现中核实。

## 5. 原生实现边界

- ArkUI 手势、读屏、触觉反馈及 ArkWeb 栏宽变化时的重绘成本，须对照当前 SDK 与官方资料核实；未核实前不写具体组件或接口名。
- 不凭原型推断触控目标规范或系统无障碍行为。HarmonyOS 结论记录到 `docs/harmonyos/`。
- 原生实现应复用既有栏宽规则和状态，不新增设置项、不依赖振动权限。

## 7. 明确不做

- 不改变栏数量、默认比例、最小栏宽、折痕规则或已有持久化方式（三栏可调正文 / 参考沿用同一比例键，不新增存储项）。
- 不做拖动惯性、多段吸附、预览缩略图、新设置项或振动依赖。
- 不把原型和浏览器模拟作为原生或真实设备验收。

## 8. 已知风险

- 浮层提示可能遮挡窄栏内容；浏览器验证时需重点检查，可调整提示位置而不改变布局模型。
- 粗指针媒体查询和触摸双击模拟不等同于 XT2 手指操作体验。
- 颜色语义由提示文案补足；仍需检查强制颜色模式与读屏反馈。
