# 启动页设计

> 状态：v2 原型已实现（2026-11-07）；同日改版为「品牌入场动效 + 名言轮播」文艺版（见第 4、5 节）。原生实现与验收以 [v1.63 需求文档](../../releases/v1.63/需求文档.md) 为准。
> 设计范围：冷启动链路「系统开屏窗 → App 品牌遮罩 → 工作区」的三段视觉衔接。不改变启动行为、会话恢复逻辑与冷启动性能预算。

## 1. 现有启动链路

- 系统开屏窗（简易启动页）：`module.json5` abilities 的 `startWindowIcon`（`$media:startIcon`，152×152）+ `startWindowBackground`（浅 `#E9EDF2` / 深 `#10151D`）。图标按实际大小居中显示、不随窗口缩放；背景为不透明纯色。
- App 内冷启动遮罩：工作区会话恢复完成前（`workspaceInitialRenderReady=false`），Index 用一层纯 `bg_page` 色遮罩盖住默认工作区；会话与当前可见内容就绪后一帧展示真实工作区（原子首帧，首屏恢复不能因某个可见 Web 面板异常而永久停在遮罩下）。
- 现状问题：三段底色已经一致（`start_window_background` = `bg_page` = 原型 `--outer`），但 App 遮罩没有任何品牌元素，启动过程缺少「这是曜石笔记」的识别度。

## 2. 目标体验

系统开屏（图标 + 底色）→ App 品牌遮罩（图标入场 + 「曜石笔记」+ 一句名言）→ 淡出进入工作区。

- 三段共用同一底色（`--outer` / `start_window_background` / `bg_page`），全程无闪白、无跳变；氛围层（极光、颗粒、浮尘）均为半透明叠加，不改变底色真源。
- 气质：安静、留白、书卷气。动效只做「浮现」，不做弹跳、旋转、进度条。
- 就绪后仍等**最短驻留 3000ms**（入场编排播完：末组 2200ms + 800ms）才淡出——冷启动快于编排时长时，为看完完整段入场多等一会儿；名言逐字较长时按本句末字与出处完成时刻继续顺延，编排不被打断。

## 3. 系统开屏窗

- 本设计稿按**维持简易启动页**绘制：`startWindowIcon` 与 `startWindowBackground` 不变。启动页图片分辨率建议不超过 256×256（Code Linter 性能规则 `@performance/start-window-icon-check`；现 152×152 达标），背景不建议透明色。
- 可选升级（原生落地时二选一，须在版本需求文档里拍板）：**增强启动页**（`startWindow` 字段 → `resources/base/profile/start_window.json`，API 19 起，本工程 API 24 可用）。可用能力：`startWindowAppIcon`（上部图标，系统侧缩放，展示区 128/192/256vp）、`startWindowBrandingImage`（底部品牌图，窗口高不足 300vp 时隐藏）、`startWindowBackgroundColor`（必配，不配则整体回退简易）、`startWindowColorModeType: FOLLOW_SYSTEM`（API 20 起，深浅色跟随）。字段与版本依据见 [api_notes AB 组](../../harmonyos/api_notes.md#ab-组应用启动页startwindow-简易--增强2026-11-07-官方文档核对)；均未真机验证（⚠️），落地前按硬约束 18 逐项核实。
- 增强启动页只改变系统侧开屏的呈现，不影响第 4 节 App 内遮罩的设计；两者共用同一图标真源与底色。

## 4. App 内品牌遮罩

- 位置：现有 `workspaceInitialRenderReady` 遮罩**升级为品牌层**。原子首帧语义、Web 面板异常兜底、点击拦截全部保留，只更换遮罩内容；遮罩不等待网络、不产生额外等待时间。
- 视觉（全部引用 token，组件不散写数值，硬约束 17）：
  - 底色：`bg_page`（浅 `#E9EDF2` / 深 `#10151D`），铺满全屏并延伸到安全区。
  - 氛围层（自下而上）：① 极光——三团大半径径向渐变（`blue` 26% / `cb-purple` 16% / `green` 12%，blur 48），22–31s 缓慢漂移；② 纸感颗粒——噪点纹理，浅色 multiply 7%、深色 screen 5%；③ 浮尘——16 粒 1.5–4px `blue` 光点，16–30s 自下而上缓升并轻微摆动。三层均为装饰、不拦截命中。
  - 应用图标：真源 `docs/assets/app_icon_1024.png`（不得回退旧紫色图标），96vp，圆角 24（`--r` + `--s2`），浮层阴影 `float_shadow`；背后一圈 `blue` 光晕（外扩 `--s10`）。
  - 品牌名：「曜石笔记」，衬线体（宋体系），字号 `--large` × 1.4，字重 600，颜色 `ink`，字距 0.32em；其下英文眉题 `OBSIDIAN NOTES`（`--caption`，字距 0.42em，`muted`）。
  - 分隔：`--s16` 宽发丝线（`muted` 两端渐隐）。
  - 名言：衬线体 17–23px 自适应，行高 1.9，字距 0.1em，`ink`；按分句断行、标点留行尾；左上饰一枚 `blue` 14% 的大号引号。出处以「—— 作者《篇名》」置于下方，`--small`、`muted`。
  - 页脚：距底 `--s10`（+ 安全区），中文数字日期「二〇二六年十一月七日 · 星期六」+「轻触任意处进入」提示（仅原型演示用，见下）。
  - 深浅色共用同一套 token；整体在可用区域内居中。
- 名言库（首批 12 句，均为公版古籍或广为流传的译句，出处已核对）：苏轼《稼说送张琥》、陆游《冬夜读书示子聿》、朱熹《观书有感》、苏轼《和子由渑池怀旧》、《诗经·小雅·鹤鸣》、王维《终南别业》、荀子《劝学》、陆游《文章》、《论语·为政》、曹雪芹《红楼梦》、笛卡尔《谈谈方法》、苏格拉底（柏拉图《申辩篇》）。主题围绕「读书 · 积累 · 思考 · 记录」，与笔记产品气质一致。每次冷启动随机取一句；本地静态资源，不联网、不统计。
- 动效编排（入场，总长约 2.6s，均为 opacity / transform / blur，曲线 `cubic-bezier(.2,0,0,1)`）：

  | 时刻 | 元素 | 效果 |
  | --- | --- | --- |
  | 0–1.6s | 极光 | 淡入，之后持续漂移 |
  | 0.1–1.0s | 图标 | 上浮 14px + 0.9→1 缩放 + 去模糊；之后 6s 周期轻浮 ±5px |
  | 0.3–1.3s | 光晕 | 淡入，之后 5s 周期呼吸 |
  | 1.0s 起 | 图标 | 一道高光斜扫，6s 周期 |
  | 0.45s 起 | 品牌名 | 逐字去模糊浮现，字间隔 120ms |
  | 1.0s / 1.1s | 眉题 / 发丝线 | 淡入 / 自中向两侧展开 |
  | 1.4s 起 | 名言 | 逐字浮现，字间隔 45ms；末字后 0.35s 出处淡入 |
  | 2.2s | 页脚 | 淡入，提示语 3.2s 周期呼吸 |

- 退出：恢复就绪（`workspaceInitialRenderReady=true`）且最短驻留到期（`Startup.minHold`，两者取较晚）后一次 240ms 透明度淡出（`--nav-duration` + `--nav-curve`），内容同时轻微放大至 1.03，完成后隐藏；淡出前入场编排不被打断。
- 系统「减少动态效果」：不播放任何入场 / 循环动效、不显示浮尘，直接呈现终态；退出直接切换、不做过渡。原生按 [api_notes U1](../../harmonyos/api_notes.md#u-组减少动态效果偏好与arkui-动画) 保持系统偏好接口未核实，组件以 `reduceMotion` 入参提供等效终态（宿主默认关闭）。
- 交互与读屏：遮罩期间拦截触摸（沿用现状）；遮罩为装饰层，不参与读屏焦点与播报（名言不朗读）。
- 明确不做：加载进度指示、联网获取名言、按库或按形态定制内容；不在启动页做任何埋点或内容采集（硬约束 16）。

## 5. 原型对应

- `.startup-mask`（`position:absolute` 限定在 `.window` 窗口框架内并整体居中，底色 `--outer`）内含：`.startup-aura`（极光）、`.startup-dust`（浮尘，JS 生成）、`.startup-stage`（`.startup-tile` 图标 + `.startup-halo` 光晕、`.startup-name`、`.startup-eyebrow`、`.startup-rule`、`.startup-quote`）、`.startup-foot`（日期 + 提示）。深浅主题共用 token。
- 入场动效只在 `.is-playing` 下生效：每次打开开关都会重放；系统减少动态效果时不加该类，直接呈现终态。
- 原型中名言每 9s 轮播一次（模糊淡出 → 下一句逐字浮现），便于评审浏览名言库；**原生冷启动只显示随机一句、不轮播**。
- 展示方式：设计控制区「启动页预览」演示开关（与其他 demo 开关同款）——**开 = 窗口框架内播放品牌入场 + 名言（不自动消失），关 = 原设计稿**；默认关闭，页面加载不受影响；点按遮罩等同关闭，并演示 240ms 退出淡出。开关状态不随 URL 持久化；`?startup=1` 供截图复现，可加 `&quote=N`（0–11）固定名言。
- 截图：`截图/启动页设计/04–07` 为本版（入场中、浅色、深色、单屏）；`02–03` 为改版前的纯品牌遮罩，留作对照。
- 原型只表达视觉与动效节奏，不构成启动性能、系统开窗行为或真机验收证据。

## 6. 原生落地注意（版本立项后）

- 资源：图标真源 `docs/assets/app_icon_1024.png`；若升级增强启动页，品牌图为新增资源，生成与分发脚本进 `tools/generators`，与现有 `gen_app_icon.py` 的分发规则保持一致。
- 原生落码见 [v1.63](../../releases/v1.63/需求文档.md) 与 [v1.64](../../releases/v1.64/需求文档.md)：`StartupAmbience.ets` 承载极光（容器 `inset:-20%`、整层 blur 一次、紫团右下）/ `ImageData` 颗粒 / 浮尘（循环动效用 `keyframeAnimateTo({iterations:-1})`）；`StartupMask.ets` 承载 OFL 衬线子集注册、图标与逐字去模糊、装饰大引号、名言 `clamp` 自适应字号、发丝线展开与三段循环动效；就绪且本句名言编排播完（动态 `holdMs`）后 240ms 淡出，退出时停止循环并销毁氛围层；`Index.ets` 只常驻挂载。
- 名言库：静态资源，随机下标在本地计算；衬线体用 Noto Serif SC（OFL 1.1）静态子集两档注册（[v1.64 §2](../../releases/v1.64/需求文档.md)），系统 `serif` 族名会回退黑体故不可用；名言库改字必须重跑生成脚本补齐字符集。
- 起播时机：原生所有动画 API 统一在 `.onAppear()`（布局渲染完成后）调用，禁止在 `aboutToAppear()` 里调用（[api_notes U4](../../harmonyos/api_notes.md#u4-显式动画起播时机abouttoappear-中动画不生效2026-11-13v164-修订)：build 未执行、动画属性无初值、动画不生效）；无限循环须用一次性守卫防重复起播。
- 性能：极光与浮尘为持续动画、逐字 blur 与全屏 `ImageData` 噪点均有合成开销，须验证不抢占首帧恢复的主线程；循环动效在退出时停止并销毁氛围层；低端或省电模式的**自动**降级未接线（只保留组件 `reduceMotion` 开关），待 API24 / XT2 性能证据再定。
- 验收：冷启动目视三段衔接（系统开屏 → 品牌遮罩 → 工作区）无闪白 / 跳变；浅色、深色各验一次；XT2 真机为准，模拟器证据不外推（硬约束与既有验收惯例）。
- 屏保口径（[v1.65](../../releases/v1.65/需求文档.md)）：同一 `StartupMask` 组件新增 `screenSaver` 模式——右上角菜单进入、全屏常驻不自动淡出，名言按档位轮换，点击任意处 240ms 淡出回笔记工作区；轮换档位 / 首次起算 / 台历字号等拍板以该版 §3 为准。本设计的冷启动口径（随机一句、编排播完淡出、不轮播）与原型 `.startup-*` 均不变。
