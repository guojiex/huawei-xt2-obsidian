# v2 设计说明：阅读与写作工作台

> **现行设计基线（2026-10-28）**：本文件是 `docs/prototype/v2/index.html` 的唯一现行交互说明，服务于 App v0.9 UI 迁移。v2 是设计代次，不是 App v2.0。早期修订按发生顺序保存在 Git 历史 `79db8b4582f1:docs/prototype/v2/修订记录_2026_10_27.md`，不作为当前规则。
> v1 原型已从工作树删除，且不恢复、不归档、不创建根路径兼容入口；历史稿只允许从 Git 历史只读查看。
> 本版只迁移原型、原生 UI 与文档；原生界面复用现有模型、文件、保存、搜索、Markdown、分享与设置服务，不新增或重构业务层。
> 本文件描述应达到的设计行为；当前原型与原生的逐项实现状态、复现步骤和证据以 [v0.9 迁移验收清单](../../releases/v0.9/迁移验收清单.md) 为准，目标说明不代表功能已落地。

## 1. 范围与约束

- 对照原设计稿及 v0.1–v1.3 当前有效需求，所有仍在用的操作都要在 v2 有可发现的入口；界面行为不得让现有原生功能不可达或改变其结果。
- 原生侧只调整布局、组件外观、导航和现有服务的界面接线。不得修改模型、存储、分享服务算法、数据格式或协议。发现现有服务能力不足时，登记为后续业务需求，不在本版扩展。
- 原型只使用共享样例和页面内状态，刷新恢复样例。原型交互不证明真实落盘、系统分享、邮件发送、Git 或平台能力；相关入口明确标示为演示、暂缓或真实原生功能。
- 不在当前笔记 UI 恢复已撤下的本地 Agent View。小艺入口采用系统 FunctionComponent；原型用不可交互的胶囊展示配色和布局意图，示意图标不是系统组件截图，也不模拟平台对话。Git 同步继续保留外部依赖状态。外部目录知识库已分配 v1.5；2026-10-31 按用户要求补齐“导入库”设计示意，原生交付仍归 v1.5，不并入 v0.9。
- 遵守 API 24、统一路径解析、已有笔记原子更新、令牌安全、隐私和常驻 Web 容器约束；具体 API 以 `docs/harmonyos/api_notes.md` 为准。

## 2. 视觉与响应式布局

- 以本目录 `index.html` 当前效果为视觉基准：浅灰外围、浅灰导航、白色编辑面、克制蓝色强调、细分隔线、轻量浮层和圆角卡片。颜色、字号、圆角、间距只使用 CSS token；明暗主题共用组件结构。
- 预览预设为单屏 380×780、双屏 709×860、三屏 1061×830 逻辑像素示意。旋转交换宽高，再按 600 / 840 断点计算当前栏数；高度小于 480 时收紧非正文留白。预设不是设备测量值。
- 三屏显示文件 / 章节导航、左正文栏和右正文栏；双屏显示正文两栏，目录可以推入或收起。单屏一次显示一个正文栏，汉堡展开文件 / 章节列表，选择项目后回到激活栏。
- 单屏顶栏始终一行，放目录按钮、必要时显示的知识库名、系统 FunctionComponent 入口和更多按钮。单屏不提供双栏与专注操作；分享、设置和文档切换都收进更多菜单。不同笔记分别位于左右栏时，菜单提供带目标笔记名的切换项；同篇或缺少任一笔记时不显示。双屏 / 三屏使用相应布局操作，不以换行塞入按钮。
- 旋转、窗口变化、主题切换与栏目切换保留编辑内容、光标、滚动、激活栏和栏宽状态，不通过重载内容重建编辑器。
- 分栏仅在实际可见的宽屏栏目中可拖动；默认目录占 1/3、正文两栏均分，每栏至少 240px。单屏和专注模式不显示拖动条。双击或键盘 Enter 恢复默认，方向键微调；比例按 v2 独立键保存。
- 按旋转后的实际宽度选择布局。双栏开启时进入双栏宽度会自动收起导航，以保留两篇正文；用户可重新展开导航，此时第二正文栏让位，收起导航后恢复。复现 URL 显式指定 `nav=1` 时保留展开导航。
- 双屏宽度下若右栏处于专注状态，点击汉堡退出专注并展开导航时，工作目标切回占用可见正文区的左栏，使文件 / 章节操作与当前可见栏一致。

## 3. 知识库与文件导航

- **导入库（2026-10-31）**：知识库选择器和库管理页提供统一入口“导入库”，弹窗以分段按钮切换“本地目录 / Git 仓库”，默认本地目录。布局、颜色与明暗主题共用现有 token，小屏允许弹窗内部滚动。
- 本地目录展示目录选择卡片，选择后显示目录名并启用“关联此目录”。遵循 [v1.5 15.1 / 15.2 / 15.5](../../releases/v1.5/需求文档.md)：授权关联、不复制、直接读写原目录；移除只解除关联，不删除原文件。目录选择与授权依据见 [api_notes T1 / T2](../../harmonyos/api_notes.md#t-组外部目录选择与持久授权2026-10-31v15-前置核实)。原型只选用示例目录，不调用系统选择器。
- Git 仓库展示 HTTPS 地址、分支与“导入 Git 仓库”按钮，沿用 [v0.3](../../releases/v0.3/需求文档.md) 的克隆到应用内语义，私有仓库在原生应用内安全验证。原型只验证地址格式，不访问远端、不接收令牌。两种来源均可添加空白演示库，刷新恢复公开样例；外部库改名只改显示名，移除使用“解除关联”，Git 使用“移除副本”。

- 导航固定提供统一知识库选择器、文件 / 章节页签和列表；回收站作为文件视图底部的折叠目录，使用垃圾桶图标，仅在当前库有已删除笔记时显示数量并按库隔离，删除不自动展开，恢复最后一篇后隐藏。回收站行显示文件名与原位置，恢复使用带目标位置说明的图标；同名冲突保留回收站条目且不覆盖。章节视图不重复显示回收站。库名、笔记数、目录结构及笔记内容由 `sample_vault/manifest.json` 与其文件生成；样例不得在 HTML 中再造第二份。
- 文件树按库内相对路径任意深度显示；文件夹可折叠。文件 / 章节切换保留树的折叠与滚动状态。章节由当前激活栏笔记的 H1–H6 建立层级；同名标题按源码顺序区分，代码围栏和 frontmatter 内的标题不列入章节。无章节时给出说明空态。
- 新建笔记和文件夹可选库根或当前文件夹。现有文件 / 文件夹的重命名、移动、删除、同目录重名、空库和空目录状态都有入口。笔记删除沿用现有回收站与撤销 / 恢复行为；文件夹删除须确认并永久删除整棵子树。
- 文件行左滑显示改名、移动、删除；滑动达到删除阈值后松手移入回收站。文件夹行左滑显示分享、改名、移动、删除；目录滑到底只展开操作条，不触发删除。文件夹移动候选排除自身及子孙，重名按现有后缀规则处理。两类操作条都可用 Shift+F10 / 菜单键打开、Escape 收起并将焦点还给原行；纵向手势留给列表滚动。整行背景只表示激活栏当前笔记，右栏已打开状态只由行尾图标表示。文件名点击在激活栏打开；宽屏行尾按钮用于在另一栏打开，拖动图标只作用于目标栏。单屏隐藏跨栏图标、不接受跨栏拖放。
- 文件列表标题行提供放大镜入口，打开快切面板；默认显示当前库最近打开项，可按文件名 / 路径或正文搜索。改名、移动、删除和切库后的结果遵循现有原生服务，不在 UI 层另存第二份业务索引。原型仅在当前页面演示搜索，刷新即恢复共享样例；原生继续调用现有快切与全文搜索服务。
- 库管理提供现有的本地库新建、切换、改名和删除操作；Git 库继续显示已有能力与未完成状态，不增加 clone / push 行为。原型只在当前页面内存演示本地库操作，刷新恢复公开样例；原生必须调用现有库管理服务，不得用演示代替真实文件操作。

## 4. 双栏与正文操作

- 双栏只控制第二栏显隐。两栏各自有笔记、编辑 / 预览状态、栏内更多菜单、图片入口、格式栏和滚动位置；当前激活栏用细蓝线标识。栏头只有编辑 / 预览和栏内更多操作，不显示“选择笔记”按钮；从文件列表打开笔记时跟随激活栏。编辑 / 预览使用轻描边分段样式；原型中的样式选择器仅供对比，不进入 App 设置或功能承诺。
- 小艺入口在单 / 双 / 三屏笔记工作区顶栏直接放置系统 `FunctionComponent`，由用户点击组件进入平台托管面板；不叠加自绘按钮，不将入口藏入更多菜单。设计使用品牌浅蓝胶囊、品牌蓝文字与系统图标，标题为“Agent 对话”；HTML 的图标和胶囊是不可交互的样式示意。浅深色分别复用 `--blue-soft` / `--blue`，原生使用对应的 `brand_bg` / `brand`；实际图标、尺寸和设备行为以 XT2 实测为准。接口依据见 [F1](../../harmonyos/api_notes.md#f1-应用内对话入口functioncomponent--官方入口明确--目标设备与资格待验)。
- 同篇笔记只有激活栏可编辑，另一栏同步显示预览或只读镜像；任一时刻只有一个有效编辑光标，并只走一个内容与保存来源，不得复制出独立草稿。不同笔记仍各自编辑。中文输入组合期间，不向正在组合的编辑器推送另一栏刷新。
- 保存成功反馈位于工作区左下角，初始隐藏；仅在一次真实本地写入成功后显示“更改已保存在本地”，约 3.5 秒后自动淡出。输入、自动保存防抖等待、未变更跳过、保存失败或笔记已切换时均不显示成功文案；失败仍走明确错误提示。原型用 800ms 的页面内存成功回调展示时序，页面顶部 / 底部的“演示、未写入设备”说明仍有效，不把它当作设备落盘证据。
- 文件点击、章节跳转、格式、摘录与分享均作用于激活栏。宽屏栏内“在另一栏预览”位于栏内更多菜单，目标栏打开同篇预览，不占用顶栏的双栏开关。单屏隐藏栏内更多菜单；需要切换不同笔记时使用应用顶栏更多菜单，并保留两栏各自编辑 / 预览状态。
- 同篇编辑 / 预览并排时，可从预览栏的更多菜单开启单向滚动跟随；默认开启并保存偏好，状态也写入复现 URL。按源码位置映射到预览块，不按全文滚动百分比推算。手动滚动预览会暂停，下一次主动滚动编辑栏恢复；重渲染和栏宽变化重新测量映射。不同笔记、单屏、专注模式和不可见栏目不互相滚动。此项仅为原型交互，原生 UI 与设备行为另行验收。
- 格式栏位于编辑栏底部，固定入口为 Aa、加粗、斜体、待办、插入图片图标；图片入口不放在栏头。栏宽不足 280px 时收起斜体快捷按钮，斜体仍可从 Aa 面板选择，以保持工具条单行与触控空间。Aa 面板提供正文、H1–H6、粗体、斜体、行内代码、代码块、链接、无序 / 有序 / 任务列表和引用。面板在来源正文栏内贴近 Aa 展开、空间不足换向并可内部滚动；关闭 / Escape 恢复原选区，应用格式只修改来源笔记。预览状态隐藏格式栏。代码块按来源光标 / 选区识别同一围栏块；重复点击可取消整块围栏及语言标记，保留代码、空行和邻接段落；支持反引号 / 波浪线围栏、CRLF 与未闭合围栏，普通文本应用后可反向取消、不累积围栏。细项验收见 [v0.9 §6.1–§6.2](../../releases/v0.9/需求文档.md#61-aa-跟手面板独立验收99)。
- 图片沿用原生选择、附件保存和查看服务。预览中的 Markdown 图片按该栏笔记所在文件夹解析相对路径；左右栏、同篇同步和分享预览使用一致的解析规则。越出库根、未知协议或缺失资源显示缺图提示，不访问任意本地文件。预览图片可点击或聚焦后按 Enter / 空格打开完整图片查看器；查看器内滚动，关闭或系统返回后焦点回到原图。原型图片仅用于展示，不写设备文件。
- 双链沿用 v1.2 已定子集：只解析 `[[目标]]` 与 `[[目标|显示文字]]`；带目录目标从库根解析，不带目录目标只在来源笔记所在目录查找；代码行内与围栏中的写法不解析。目标笔记在另一栏打开；缺失目标按路径预填新建笔记，取消不改原文；反链从栏内更多菜单打开，来源在当前激活栏跳转。标题锚点与 `![[嵌入]]` 不属于已支持双链语法，原型保留原写法并显示“暂不支持”，不得生成伪造的笔记创建入口。公式、Mermaid 和其余 Markdown 渲染继续遵循原生既有实现与各自版本规格；原型示意不替代原生渲染器。
- 同篇笔记显示在两栏时，隐藏冗余的“在另一栏预览”入口；不同笔记仍可通过栏内更多菜单在另一栏打开。文件列表行尾图标标识另一栏已打开状态，整行选中只跟随激活栏。
- 左右栏预览及分享排版预览隐藏笔记开头完整 YAML frontmatter；编辑器与原始 Markdown 文件预览保留全部源码。章节列表不收录属性区内容，但源码定位保留原始偏移，兼容 BOM 与 CRLF；正文中的 `---` 仍按分隔线显示，未闭合属性区不吞掉后续正文。`tags` 属性与正文标签按当前原型规则呈现为标签块，预览顶部不额外显示“标签”前缀；不提供完整 YAML 属性编辑器或标签筛选。
- 预览正文底部右侧提供紧凑缩放选择器，左右栏比例独立，支持 50%–200% 预设、双指捏合和 Ctrl+滚轮连续缩放；仅正文缩放，编辑器、导航、栏头和操作控件保持原尺寸。切换编辑 / 预览保留比例，编辑时隐藏控件，100% 时不显示重置按钮。原型保留该交互；原生缩放尚未分配到本版。

## 5. 设置、分享与次级页面

- 单屏、双屏、三屏均常显工作区右上角「…」菜单；菜单内直接选择「简单模式 / 专业模式」，并提供「设置与关于」入口，不跳设置页切模式，也不保留独立顶栏设置图标。选择模式后关闭菜单，焦点回到更多按钮；进入设置后工作区和编辑器保持在原树中，不重置笔记内容或栏目状态，退出设置后焦点同样回到更多按钮。双 / 三屏设置为左分类、右详情；单屏和矮横屏先选分类，再进入详情。单屏仅在顶栏提供一个返回按钮，依次返回关于、设置分类和笔记；返回键与 Escape 同样按层级返回。原生界面待同步。
- 当前笔记 UI 的分类为通用、数据、问题与建议、关于。通用含外观、布局、栏宽恢复和诊断；数据含重置确认与影响范围；反馈显示配置邮箱、手动发送说明和隐私边界；关于显示应用名称 / 图标、包版本 / 构建号、许可、项目链接、最近更新和可返回的完整版本记录。历史 Agent 设置不加入当前笔记设置。
- 版本从 `changelog.json` 与 `AppScope/app.json5` 生成，反馈邮箱从 `app_config.json` 生成。`docs/prototype/v2/sync_settings_data.py` 是原型设置快照的唯一入口；不得在 HTML 手填第二份数据。
- 分享保留笔记、文件夹及子目录、整个知识库三个范围；本地库的笔记提供排版图片、Markdown / ZIP 和文本；文本预览标题与纯正文，可编辑本次分享内容，说明 YAML、图片及复杂格式的降级，取消不改笔记。文件夹与知识库提供 ZIP。Git 库沿用 v0.8：本地内容可选 ZIP，笔记文本仍基于当前编辑快照，另可按范围选远端笔记、文件夹或仓库链接；私有库说明接收权限，远端链接不包含未推送的本地修改。原型顶部 `#designControls` 的“Git 分享示意”只用于展示这些格式和说明，不代表当前样例库已连接远端；不显示虚构 URL、不访问网络、不生成或发送内容。原生继续调用现有分享服务，并保留取消、无附件、生成失败和目标应用不可用状态。
- 库管理、回收站、搜索和分享均由当前页面入口打开并可返回；系统返回与显式返回保持一致。同步和小艺只显示既有实际状态。

## 6. 空态、错误态与键盘

- 空库、空目录、无匹配、无最近记录、无章节、无回收站项目、未选择笔记、保存中 / 已保存 / 保存失败、加载失败、重名冲突、移动失败、图片缺失、分享取消 / 失败都有明确文本和下一步入口。
- 菜单、弹层和次级页面支持关闭按钮、Escape 和明确焦点回归。文件树目录用左右方向键展开 / 收起；章节和设置分类支持方向键及 Home / End。不可见栏不接收焦点。
- 240px 窄栏、长文件名、长标题、中文输入、软键盘、无结果与空态不得造成顶栏换行、水平溢出或操作不可达。触屏操作与键盘操作均需有等价入口。

## 7. 数据生成、验收与迁移

- 样例唯一来源：`sample_vault/` 与 `manifest.json`，由 `tools/generators/build_sample_vault.py` 生成原型和原生样例数据。
- 版本唯一来源：`changelog.json` 与 `AppScope/app.json5`；反馈唯一来源：`app_config.json`。原型设置快照由 `sync_settings_data.py` 更新并以 `--check` 验证。
- v2 `:root` / `[data-theme="dark"]` 是唯一现行视觉 token 真源。编辑器、预览构建脚本从该处读取，原生资源按明确映射同步；未映射的原生语义色保留。原型专属测试与设置快照生成以 v2 为目标；样例、版本、反馈生成器使用各自数据源，Markdown 测试独立验证编辑器 / 预览组件。规则见 [仓库手册 §17](../../../AGENTS.md)，逐项差异和验证证据见 [迁移验收清单](../../releases/v0.9/迁移验收清单.md)。现行流程不依赖或写入 v1。
- 逐项验收按 [v0.9 迁移验收清单](../../releases/v0.9/迁移验收清单.md)。自动检查、真实浏览器、模拟器、API24 / XT2、目标应用接收和发布分别记录；一个层级的证据不能代替另一层级。

## 8. URL 复现状态

原型将界面状态写入地址栏查询参数，点击、选择和导航后同步；刷新或打开链接恢复状态，浏览器前进 / 后退恢复对应页面。滚动和栏宽调整更新当前历史项，避免连续操作产生大量记录。URL 使用 `ui=2` 标识格式，参数只接受已知值；失效笔记、跨库笔记和无效数值回退为可用状态。

| 参数 | 内容 |
| --- | --- |
| preset / rotate / theme | 设备展开预设、90° 旋转、浅深色 |
| modeStyle | 原型比较编辑 / 预览控件样式，不改变栏状态 |
| lz / rz | 左右预览正文缩放比例 |
| vault / left / right / active | 演示知识库、左右笔记 ID、激活栏 |
| lm / rm / dual / follow / focus | 两栏编辑或预览、双栏开关、滚动跟随偏好、专注 |
| side / nav / nw / cw | 文件或章节、导航显隐、两种栏宽比例；显式 `nav=1` 恢复展开导航 |
| view / settings / detail / history | 笔记或设置页面、设置分类、分类详情、完整版本记录 |
| panel / scope / stage / formatPane / shareFolder / gitShareDemo | 分享目标范围与阶段；从文件夹操作条发起时保留样例文件夹目标；Git 分享示意开关仅为评审辅助；搜索词不进入链接 |
| trashOpen / trashDemo | 回收站目录展开状态、仅原型使用的回收站内容演示开关 |
| action / file | 改名 / 移动对话框及目标样例笔记，仅打开，不执行文件修改 |
| collapsed / chapter / scroll_* | 目录折叠、选中章节、列表和正文 / 编辑器滚动位置 |

链接仅携带公开样例 ID 和界面配置，不包含正文、搜索词、插入图片、反馈草稿、令牌或临时编辑；恢复快切面板时搜索词为空。别人打开链接看到的是其本地同版本样例；临时编辑、新建或删除产生的数据不会通过 URL 传播，失效 ID 使用回退。不同浏览器窗口的可用宽度仍影响实际布局。更新正文不会作为历史记录写入 URL；回退页面也不回滚本页未保存内容。恢复链接不会自动重置、删除、发送反馈或发送分享。

## 简单模式与专业模式（2026-11-01）

> 原型探索归 v0.9 9.16；原生产品实现已分配 [v1.7](../../releases/v1.7/需求文档.md)，排在当前新增功能队列首位，尚未开始。下文的可编辑范围描述当前原型，App 交付以 v1.7 的 17.1–17.7 为准。

- 应用级「设置 → 通用 → 编辑模式」提供带图标、说明与选中圆点的两项单选列表，单屏同样可用。正文栏不放常驻下拉框。单屏、双屏、三屏统一使用工作区右上角「…」菜单，在菜单内直接列出「简单模式 / 专业模式」，选中项高亮并打勾；选择立即生效，不跳转设置或进入子菜单。栏内更多只保留笔记级操作。默认使用简单模式，专业模式由用户在快捷菜单或设置中主动开启；无模式参数或参数无效时回到简单模式，原型 URL `ui=2&experience=professional` 可显式复现专业模式。模式偏好不推定为 App 已实现。
- 简单模式仅显示一篇排版正文和导航，直接点击文字输入；底部浮条提供 Aa、加粗、斜体、列表、待办。Aa 展开段落格式选择。隐藏源码 / 预览切换、双栏和“在另一栏预览”；三种宽度均使用同一正文编辑方式；移除无内容的模式工具行，笔记标题下直接进入正文。
- 专业模式保留现有源码编辑、预览和双栏能力。切入简单模式时以激活栏笔记为目标；返回专业模式恢复原先的栏位、编辑 / 预览及双栏状态，期间修改保留在同一篇 Markdown。切换本身不改正文，不另建富文本副本。
- **原型可交互范围**：普通段落、标题、基础无序列表、待办与引用，可输入、选中文字加粗 / 斜体及改变段落类型；空笔记可输入。Enter 新增同块换行。粘贴仅接收纯文本。撤销 / 重做保留当前笔记的原型编辑历史。
- **复杂内容保护**：表格、代码、图片、链接、双链、公式、属性、callout 及复杂混合语法只展示并保留原始 Markdown；原型不支持编辑这些块，局部标注“此内容请在专业模式编辑”。基础块修改只替换对应源码区间，不对整篇 HTML 反向转换，未触及源码逐字保留。完整富文本能力与中文输入法、跨块选择、长文性能等由未来原生版本专项验证。
- 当前原型依据 v0.9 9.16；内容与编辑历史保存在当前页面，刷新恢复样例，不代表设备保存或 v1.7 原生编辑器完成。


### 编辑模式入口修订与参考（2026-11-01）

用户指出原型把应用级模式下拉框放在正文工具栏中间，造成与编辑 / 预览分段按钮并列、层级混淆。本轮移走常驻下拉框，保留专业模式的文档视图工具；简单模式收起整行视图工具。模式管理使用既有设置导航，快捷入口复用已有更多菜单，不新增顶栏图标、悬浮按钮或独立设置分类。

参考与本项目判断分开记录：

- [Obsidian 编辑器设置](https://obsidian.md/help/settings)：将默认编辑方式作为编辑器偏好；本项目据此把跨工作区的模式选择归入设置，而非每篇笔记的视图分段控件。
- [Obsidian 更多菜单](https://obsidian.md/help/more-options-menu)：包含阅读 / 源码等视图操作。本项目只借鉴“次级入口收纳在更多菜单”，全屏幕形态的工作区更多菜单直接选择全局编辑模式，不冒充笔记级模式。
- [Apple 备忘录格式操作](https://support.apple.com/en-mt/guide/iphone/iph1ac0b3a2/27/ios/27)：正文输入配合格式、清单等工具。本项目保留正文附近的格式浮条，使低频模式偏好与高频写作操作各归其位。
- [HarmonyOS 菜单说明](https://developer.huawei.com/consumer/cn/doc/doccenter-capabilities/ui-js-components-menu)：菜单是展示可执行操作的临时弹窗；仅参考入口收纳方式，不采用该页面的旧 HML / JS 组件实现，也不据此断言原生 HDS 外观已验证。当前为 HTML 设计稿，颜色、间距、圆角及触控尺寸沿用 v2 token。

单选行整行可点击，支持键盘方向键，选中项用圆点与蓝色边框双重表达。明暗主题保持相同结构；窄屏说明文字换行，设置详情可滚动。切换后仍留在当前设置详情，返回笔记时呈现新模式。设置偏好持久化与原生实现已排入 v1.7，尚未开始，不以本次浏览器交互补造原生证据。

2026-11-01 快捷入口一致性修订：三个断点均常显工作区右上角更多入口，直接在同一菜单内选模式；设置页保留完整说明。简单模式也保留此入口，不依赖已隐藏的栏内工具行。切换后关闭菜单、焦点返回触发按钮，设置单选与快捷菜单选中态同步。
