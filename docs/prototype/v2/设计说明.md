# v2 设计说明：阅读与写作工作台

> **现行设计基线（2026-10-28）**：本文件是 `docs/prototype/v2/index.html` 的唯一现行交互说明，服务于 App v0.9 UI 迁移。v2 是设计代次，不是 App v2.0。早期修订按发生顺序保存在[修订记录](修订记录_2026_10_27.md)，不作为当前规则。
> 本版只迁移原型、原生 UI 与文档；原生界面复用现有模型、文件、保存、搜索、Markdown、分享与设置服务，不新增或重构业务层。

## 1. 范围与约束

- 对照原设计稿及 v0.1–v1.3 当前有效需求，所有仍在用的操作都要在 v2 有可发现的入口；界面行为不得让现有原生功能不可达或改变其结果。
- 原生侧只调整布局、组件外观、导航和现有服务的界面接线。不得修改模型、存储、分享服务算法、数据格式或协议。发现现有服务能力不足时，登记为后续业务需求，不在本版扩展。
- 原型只使用共享样例和页面内状态，刷新恢复样例。原型交互不证明真实落盘、系统分享、邮件发送、Git 或平台能力；相关入口明确标示为演示、暂缓或真实原生功能。
- 不在当前笔记 UI 恢复已撤下的本地 Agent View。Git 同步与小艺保留外部依赖状态，不伪装可用。外部目录知识库 M-01 未分配版本，本版不做。
- 遵守 API 24、统一路径解析、已有笔记原子更新、令牌安全、隐私和常驻 Web 容器约束；具体 API 以 `docs/harmonyos/api_notes.md` 为准。

## 2. 视觉与响应式布局

- 以本目录 `index.html` 当前效果为视觉基准：浅灰外围、浅灰导航、白色编辑面、克制蓝色强调、细分隔线、轻量浮层和圆角卡片。颜色、字号、圆角、间距只使用 CSS token；明暗主题共用组件结构。
- 预览预设为单屏 380×780、双屏 709×860、三屏 1061×830 逻辑像素示意。旋转交换宽高，再按 600 / 840 断点计算当前栏数；高度小于 480 时收紧非正文留白。预设不是设备测量值。
- 三屏显示文件 / 章节导航、左正文栏和右正文栏；双屏显示正文两栏，目录可以推入或收起。单屏一次显示一个正文栏，汉堡展开文件 / 章节列表，选择项目后回到激活栏。
- 单屏顶栏始终一行，只放目录按钮、必要时显示的知识库名和更多按钮。单屏不提供双栏与专注操作；分享、设置和文档切换都收进更多菜单。不同笔记分别位于左右栏时，菜单提供带目标笔记名的切换项；同篇或缺少任一笔记时不显示。双屏 / 三屏使用相应布局操作，不以换行塞入按钮。
- 旋转、窗口变化、主题切换与栏目切换保留编辑内容、光标、滚动、激活栏和栏宽状态，不通过重载内容重建编辑器。
- 分栏仅在实际可见的宽屏栏目中可拖动；默认目录占 1/3、正文两栏均分，每栏至少 240px。单屏和专注模式不显示拖动条。双击或键盘 Enter 恢复默认，方向键微调；比例按 v2 独立键保存。

## 3. 知识库与文件导航

- 导航固定提供统一知识库选择器、文件 / 章节页签、列表和回收站入口。库名、笔记数、目录结构及笔记内容由 `sample_vault/manifest.json` 与其文件生成；样例不得在 HTML 中再造第二份。
- 文件树按库内相对路径任意深度显示；文件夹可折叠。文件 / 章节切换保留树的折叠与滚动状态。章节由当前激活栏笔记的 H1–H6 建立层级；同名标题按源码顺序区分，代码围栏和 frontmatter 内的标题不列入章节。无章节时给出说明空态。
- 新建笔记和文件夹可选库根或当前文件夹。现有文件 / 文件夹的重命名、移动、删除、同目录重名、空库和空目录状态都有入口。笔记删除沿用现有回收站与撤销 / 恢复行为；文件夹删除沿用原生既定确认语义。
- 文件行左滑显示改名、移动、删除；滑动达到删除阈值后松手移入回收站。整行背景只表示激活栏当前笔记，右栏已打开状态只由行尾图标表示。文件名点击在激活栏打开；宽屏行尾按钮用于在另一栏打开，拖动图标只作用于目标栏。单屏隐藏跨栏图标、不接受跨栏拖放。触摸与键盘提供等效入口，纵向手势留给列表滚动。
- 文件列表标题行提供放大镜入口，打开快切面板；默认显示当前库最近打开项，可按文件名 / 路径或正文搜索。改名、移动、删除和切库后的结果遵循现有原生服务，不在 UI 层另存第二份业务索引。原型仅在当前页面演示搜索，刷新即恢复共享样例；原生继续调用现有快切与全文搜索服务。
- 库管理提供现有的本地库新建、切换、改名和删除操作；Git 库继续显示已有能力与未完成状态，不增加 clone / push 行为。

## 4. 双栏与正文操作

- 双栏只控制第二栏显隐。两栏各自有笔记、编辑 / 预览状态、栏内更多菜单、图片入口、格式栏和滚动位置；当前激活栏用细蓝线标识。
- 同篇笔记只有激活栏可编辑，另一栏同步显示预览或只读镜像；任一时刻只有一个有效编辑光标，并只走一个内容与保存来源，不得复制出独立草稿。不同笔记仍各自编辑。中文输入组合期间，不向正在组合的编辑器推送另一栏刷新。
- 文件点击、章节跳转、格式、摘录与分享均作用于激活栏。宽屏栏内“在另一栏预览”位于栏内更多菜单，目标栏打开同篇预览，不占用顶栏的双栏开关。单屏隐藏栏内更多菜单；需要切换不同笔记时使用应用顶栏更多菜单，并保留两栏各自编辑 / 预览状态。
- 同篇编辑 / 预览并排时可开启单向滚动跟随；手动滚动预览暂停跟随，下一次主动滚动编辑栏恢复。不同笔记和不可见栏目不互相滚动。
- 格式栏位于编辑栏底部，固定入口为 Aa、加粗、斜体、待办、插入图片图标；图片入口不放在栏头。栏宽不足 280px 时收起斜体快捷按钮，斜体仍可从 Aa 面板选择，以保持工具条单行与触控空间。Aa 面板提供正文、H1–H6、粗体、斜体、行内代码、代码块、链接、无序 / 有序 / 任务列表和引用。对选区应用格式保留选区和焦点；无选区插入可编辑占位文字。预览状态隐藏格式栏。
- 图片沿用原生选择、附件保存和查看服务。预览中的 Markdown 图片按该栏笔记所在文件夹解析相对路径；左右栏、同篇同步和分享预览使用一致的解析规则。越出库根、未知协议或缺失资源显示缺图提示，不访问任意本地文件。原型图片仅用于展示，不写设备文件。
- Markdown 渲染、双链跳转、缺失链接创建规则、反链、公式和 Mermaid 继续使用现有原生实现及各自版本的已定能力。原型示意排版不替代原生渲染器。
- 左右栏预览及分享排版预览隐藏笔记开头完整 YAML frontmatter；编辑器与原始 Markdown 文件预览保留全部源码。章节列表不收录属性区内容，但源码定位保留原始偏移，兼容 BOM 与 CRLF；正文中的 `---` 仍按分隔线显示，未闭合属性区不吞掉后续正文。`tags` 属性与正文标签按当前原型规则呈现为标签块，预览顶部不额外显示“标签”前缀；不提供完整 YAML 属性编辑器或标签筛选。

## 5. 设置、分享与次级页面

- 设置是独立页面，笔记工作区和编辑器保持在原树中，不重置笔记内容或栏目状态。双 / 三屏为左分类、右详情；单屏和矮横屏先选分类，再进入详情；返回键与 Escape 按层级返回。
- 当前笔记 UI 的分类为通用、数据、问题与建议、关于。通用含外观、布局、栏宽恢复和诊断；数据含重置确认与影响范围；反馈显示配置邮箱、手动发送说明和隐私边界；关于显示应用名称 / 图标、包版本 / 构建号、许可、项目链接、最近更新和可返回的完整版本记录。历史 Agent 设置不加入当前笔记设置。
- 版本从 `changelog.json` 与 `AppScope/app.json5` 生成，反馈邮箱从 `app_config.json` 生成。`docs/prototype/v2/sync_settings_data.py` 是原型设置快照的唯一入口；不得在 HTML 手填第二份数据。
- 分享保留笔记、文件夹及子目录、整个知识库三个范围；笔记提供排版图片和 Markdown / ZIP 预览，文件夹与知识库提供 ZIP 清单预览。格式、范围和激活栏上下文一致。原型明确说明不生成文件、不发送；原生继续调用现有分享服务，并保留取消、无附件、生成失败和目标应用不可用状态。
- 库管理、回收站、搜索和分享均由当前页面入口打开并可返回；系统返回与显式返回保持一致。同步和小艺只显示既有实际状态。

## 6. 空态、错误态与键盘

- 空库、空目录、无匹配、无最近记录、无章节、无回收站项目、未选择笔记、保存中 / 已保存 / 保存失败、加载失败、重名冲突、移动失败、图片缺失、分享取消 / 失败都有明确文本和下一步入口。
- 菜单、弹层和次级页面支持关闭按钮、Escape 和明确焦点回归。文件树目录用左右方向键展开 / 收起；章节和设置分类支持方向键及 Home / End。不可见栏不接收焦点。
- 240px 窄栏、长文件名、长标题、中文输入、软键盘、无结果与空态不得造成顶栏换行、水平溢出或操作不可达。触屏操作与键盘操作均需有等价入口。

## 7. 数据生成、验收与迁移

- 样例唯一来源：`sample_vault/` 与 `manifest.json`，由 `tools/build_sample_vault.py` 生成原型和原生样例数据。
- 版本唯一来源：`changelog.json` 与 `AppScope/app.json5`；反馈唯一来源：`app_config.json`。原型设置快照由 `sync_settings_data.py` 更新并以 `--check` 验证。
- v2 `:root` / `[data-theme="dark"]` 为迁移后的视觉 token 来源；在旧稿归档门禁通过并完成原生资源同步后，更新 `AGENTS.md` 和相关生成器 / 样式引用。归档副本不得再被当前生成器写入。
- 逐项验收按 [v0.9 迁移验收清单](../../releases/v0.9/迁移验收清单.md)。自动检查、真实浏览器、模拟器、API24 / XT2、目标应用接收和发布分别记录；一个层级的证据不能代替另一层级。

## 8. URL 复现状态

原型将界面状态写入地址栏查询参数，点击、选择和导航后同步；刷新或打开链接恢复状态，浏览器前进 / 后退恢复对应页面。滚动和栏宽调整更新当前历史项，避免连续操作产生大量记录。URL 使用 `ui=2` 标识格式，参数只接受已知值；失效笔记、跨库笔记和无效数值回退为可用状态。

| 参数 | 内容 |
| --- | --- |
| preset / rotate / theme | 设备展开预设、90° 旋转、浅深色 |
| vault / left / right / active | 演示知识库、左右笔记 ID、激活栏 |
| lm / rm / dual / focus | 两栏编辑或预览、双栏开关、专注 |
| side / nav / nw / cw | 文件或章节、导航显隐、两种栏宽比例 |
| view / settings / detail / history | 笔记或设置页面、设置分类、分类详情、完整版本记录 |
| panel / scope / stage / formatPane | 分享、回收站、格式和快切面板及对应步骤；搜索词不进入链接 |
| action / file | 改名 / 移动对话框及目标样例笔记，仅打开，不执行文件修改 |
| collapsed / chapter / scroll_* | 目录折叠、选中章节、列表和正文 / 编辑器滚动位置 |

链接仅携带公开样例 ID 和界面配置，不包含正文、搜索词、插入图片、反馈草稿、令牌或临时编辑；恢复快切面板时搜索词为空。别人打开链接看到的是其本地同版本样例；临时编辑、新建或删除产生的数据不会通过 URL 传播，失效 ID 使用回退。不同浏览器窗口的可用宽度仍影响实际布局。更新正文不会作为历史记录写入 URL；回退页面也不回滚本页未保存内容。恢复链接不会自动重置、删除、发送反馈或发送分享。

## 9. 版本边界

v2 原型包含文件导航推入动效；该动效的原型 / 原生一致性、中间帧、快速反向和设备验收单独归 [v0.10](../../releases/v0.10/需求文档.md)，不作为 v0.9 的新增收口条件。v0.9 仍需按既有导航布局、入口和状态保持要求验收。

自动检查：`node --test tools/test_prototype_v2_url.mjs tools/test_prototype_shared_edit.mjs`。2026-10-28 在真实应用内浏览器通过本地 HTTP 页面检查了快切入口、文件名与正文搜索、激活栏打开和刷新恢复；`file://` 地址、完整形态 / 主题 / 旋转回归仍待验证。

### 回收站入口视觉收敛（2026-10-28）

侧栏底部回收站改成低强调的文字入口，去掉垃圾桶图标、顶部边框和按钮底色。名称后紧邻灰色数量，不使用右侧徽标或独立图标；空回收站不显示数量。悬停以文字颜色和下划线反馈，保留完整触控高度和键盘焦点。位置与回收站行为不变，文件 / 章节视图均可访问。

### 回收站作为沉底折叠目录（2026-10-28）

回收站放入文件视图底部，采用与普通目录一致的展开箭头、文件夹图标和文字，默认折叠，不再作为独立文字按钮。展开后直接列出当前库已删除的笔记及恢复操作，空时显示空态；数量随删除 / 恢复更新，删除不会自动展开目录。列表内容较多时在目录内滚动；键盘左右键可展开 / 收起。显式展开状态按库保留并可由 URL 的 trashOpen 复现；章节视图不重复显示该目录。之前回收站独立按钮及纯文字入口方案由本节替代。

### 回收站图标与空态显示规则（2026-10-28）

回收站沿用沉底、默认折叠的目录交互，图标改为垃圾桶并保留展开箭头。仅在当前知识库存在已删除笔记时显示整个入口及数量；为空时不占列表位置。恢复最后一篇后自动隐藏并清除展开状态，之后再次出现仍默认折叠；各库独立判断。本节替代此前普通文件夹图标及空回收站仍显示入口的规则。

### 预览正文缩放（2026-10-28）

预览正文底部右侧提供紧凑比例列表，比例选择和按需出现的重置按钮均采用 32px 控件尺寸，区别于编辑格式栏的 48px 操作按钮；常用比例为 50%、75%、100%、125%、150%、175%、200%。仅缩放正文（含标题、图片、表格和代码块），导航、栏头、编辑器和操作控件保持原尺寸；放大后正文按可用栏宽重新排版。左右栏独立维护比例，切换编辑 / 预览保留比例；编辑时隐藏整个缩放控件。100% 时隐藏重置按钮，其他比例显示回转箭头，点击恢复 100%。

预览区支持双指捏合连续缩放，限制在 50%–200%；触控板通过 Ctrl+wheel 事件缩放。普通单指滚动和滚轮仍用于阅读；手势结束 / 取消即停止缩放。连续缩放产生的非预设百分比临时出现在列表中，列表与手势始终使用同一比例。URL 的 lz / rz 分别保存左右栏百分比，旧链接缺省为 100%；缩放更新当前历史项。

本次仅交付浏览器原型与设计规则；原生缩放列入需求池待分配，不自动纳入 v0.9 / v0.10。自动检查共 28 项通过（含原有回归），覆盖比例列表、重置可见性、编辑隔离、双栏独立、URL 与非法比例、捏合取消及触控板事件；真实浏览器排版、触屏手势冲突与 XT2 手感尚待验收。

### 回收站样式演示开关（2026-10-28）

设计稿顶部（屏幕形态与主题控件旁）增加“回收站有内容”开关。开启时展示一条临时已删除笔记样例和默认折叠的回收站目录；关闭时模拟空回收站并隐藏目录。该控件仅用于设计对比，不属于 App 设置，不删除、恢复或改写实际样例笔记。开启后可展开查看内部列表；点击演示行恢复会切换为空态。trashDemo 参数保存该演示状态；再次执行真实删除操作时退出模拟并展示实际回收站。单屏需通过汉堡展开文件列表查看。

回收站列表的逐条恢复操作采用回转箭头图标按钮，省去可见“恢复”文字，保留完整触控热区、悬停“恢复笔记”提示与包含笔记名称的无障碍标签；操作行为不变。

回收站每条笔记采用两行信息：第一行文件名，第二行以弱化字号显示“原位置：知识库 / 文件夹”（无文件夹显示“根目录”）；长路径省略并提供完整悬停提示。恢复仍使用图标按钮，提示明确显示“恢复到原位置：…”；实际恢复成功后提示目标位置，同名冲突保留已删除条目并禁止覆盖。该规则替代上一条笼统的“恢复笔记”悬停文案。

### 同篇双栏的冗余入口收敛（2026-10-28）

### Aa 格式面板跟手展示（2026-10-28，v0.9 9.9）

点击 Aa 后，格式面板优先贴近该按钮上方展开，不再以居中遮罩弹窗展示；上方空间不足时选用下方，宽高限制在来源正文栏、原型窗口与浏览器可视区交集之内。狭窄 / 矮屏中面板内部滚动，格式项采用三列布局。左右栏独立定位，不跨到另一栏；导航推入、分栏拖动和旋转期间逐帧更新坐标，浏览器可视区变化时重新计算。此处采用鸿蒙“基于触发组件就近展示”的设计方向；[官方参考](https://developer.huawei.com/consumer/cn/doc/doccenter-references/api/ohos-arkui-advanced-dialogv2) 仅作交互参考，不据此宣称当前原生组件或 API24 已完成接入。

### 代码块格式识别与取消（2026-10-28，v0.9 9.10）

Aa 打开时，根据来源栏的光标 / 选区识别所属围栏代码块。只选代码内容、部分内容、连同围栏选中，或把光标放在块内，“代码块”按钮均呈蓝色选中态（aria-pressed=true），提示为“取消代码块”；打开 / 关闭面板本身不扩展源码选区、不修改正文。跨越多块和普通正文的混合选区不显示单块选中态。

点击已选中的“代码块”会去掉所属整块的起止围栏及起始语言标记，保留内部代码、空行与相邻段落；取消后选中保留下来的内容，便于继续编辑。普通文本点击“代码块”按整行包裹并选中内容，再点可取消，不能逐次嵌套围栏。识别反引号、波浪线、不同长度围栏以及 CRLF；普通文本含反引号时采用更长围栏。未闭合代码块延续到文末，取消时仅移除已有起始标记。预览及章节扫描使用相同围栏匹配规则，避免长围栏内的短围栏或标题被提前解析。左右栏格式只修改来源笔记，保留滚动与焦点。

已登记需求池 L-08、[v0.9 9.10 / §6.2](../../releases/v0.9/需求文档.md)。42 项模拟 DOM 检查通过，包括代码块识别、重复应用 / 取消、围栏匹配、CRLF、空块、未闭合块、跨块选区与来源栏隔离；共享样例生成一致性检查通过。原生代码未改，真实浏览器视觉与触屏、API24 / XT2 验收待做。

汉堡对齐修正：顶部与下方编辑 / 预览控件继续共用水平留白；另补偿汉堡 SVG 在触控区内的居中留白和 viewBox 左侧空白，使可见横线左端对齐下方分段控件的可见左边缘。只移动按钮内部图形，保留完整触控区及单屏展开导航后的可点击性。

### 格式面板跟手演示开关（2026-10-28）

设计稿顶部“格式面板跟手”开关直接将当前可见激活栏切到编辑并展开 Aa，无需先手动进入编辑。开启后拖动分隔条、切换屏幕预设、旋转或主题时保留面板，便于观察就近定位；演示控件区域不触发面板的外部点击关闭。单屏先收起文件导航再展开面板。关闭开关收起面板；手动点 Aa、完成或关闭面板时同步开关状态。沿用 URL 的 panel=format / formatPane 恢复，无需新增持久化开关；开关仅是设计稿入口，不是 App 的“是否跟手”设置，不改变正文。44 项模拟 DOM 检查通过，实际视觉跟随仍待浏览器验收。

### 编辑 / 预览切换样式对比（2026-10-28）

设计稿顶部新增“切换样式”选择器，同步更换左右栏编辑 / 预览控件外观：胶囊（原方案）、轻描边分段、下划线页签。三者均保留明确的“编辑”“预览”文字和相同的触控区域；仅替换视觉，不改变栏位、当前笔记、编辑状态和格式栏行为。轻描边为选定的默认样式；设计稿 URL 的 modeStyle 参数可复现其他样式，未知值回退轻描边。此选择器只用于设计比较，不进入 App 设置或版本功能承诺。
