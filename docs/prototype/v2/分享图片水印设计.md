# 分享图片水印设计

> 适用版本：[v1.25 单篇分享图片水印](../../releases/v1.25/需求文档.md)。
> 设计范围：仅单篇 Markdown 笔记的「长图」导出；图片宽度与明暗选择见[分享面板设计](分享面板设计.md)。

## 1. 长图末尾

- 水印位于分享纸面内，紧接完整笔记正文之后；它是文档内容的一部分，不是悬浮层，也不占用或覆盖正文、图片、代码。
- 正文结束后留出独立空白，以细分隔线区分，再右对齐显示纯文字「曜石笔记」。
- 使用现有 v2 token：上边距 `--s8`、分隔线间距 `--s3`、线宽 `--stroke`、线色 `--line`、文字色 `--muted`、字号 `--caption`、行高 `--leading`。
- 水印跟随分享面板所选浅色 / 深色外观；不额外跟随应用主题，也不引入单独颜色。
- 不加图标、标题、日期、说明语或其他品牌元素；无论内部捕获多少视口，整张图片只出现一次。

## 2. 生成行为

- 只在「当前笔记 → 长图」的一次性分享渲染文档中追加水印。Markdown、普通预览及 Markdown / ZIP / 文本、文件夹 / 知识库导出均不变。
- 等待 Mermaid 与库内图片完成渲染后，将水印追加到正文末尾；用于分页、尺寸和长图合成的测量必须包含水印。
- 水印与正文进入同一组视口捕获、同一张 PixelMap / JPEG。长图预算触发整体缩放时，两者同比例缩放；预览和 Share Kit 继续复用同一临时 JPEG。
- 默认始终显示，不提供关闭开关、自定义文案、位置或透明度设置。生成失败或取消沿用现有临时文件清理流程。

## 3. 原型对应

v2 原型的单篇图片预览在 `.share-paper` 内按「文章 → 水印 footer」顺序展示；footer 使用上文 token。宽度和主题控件行为以[分享面板设计 §3](分享面板设计.md#3-长图设置)为准。

原型只表达视觉与交互，不生成 JPEG、不调用 Share Kit，也不构成原生、模拟器、API24 / XT2 或接收端验收证据。
