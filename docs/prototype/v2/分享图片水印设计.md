# 分享图片水印设计

> 适用版本：[v1.25 单篇分享图片水印](../../releases/v1.25/需求文档.md)。
> 设计范围：仅单篇 Markdown 笔记的「图片」导出；不改变其他分享入口、格式或范围。

## 1. 视觉与位置

- 连续长图在完整笔记内容之后增加专用留白区，不把水印压在正文、图片或代码上。
- 留白区以细分隔线与正文区分，右对齐显示纯文字「曜石笔记」。
- 使用小字号和弱化文本色；间距、字号、颜色与分隔线只引用 v2 设计 token。浅 / 深色样式沿用分享渲染页当前主题。
- 不加图标、标题、日期、说明语或其他水印；不按视口分段重复。

## 2. 行为

- 水印只加入一次性分享渲染文档，并在捕获尺寸测量前加入，确保正文、水印进入同一张 PixelMap / JPEG。
- 长图预览和 Share Kit 复用同一临时 JPEG；确认前可完整预览，取消不分享。
- 水印默认始终开启，不增加设置或关闭入口。后续若需要可选水印，另从需求池分配版本。
- 不修改 Markdown 内容、普通预览或其他分享产物。

## 3. 原型边界

v2 分享预览以正文后的末尾品牌区示意位置、分隔和色彩。原型不生成 JPEG、不调用 Share Kit，也不构成原生或设备验收证据。
