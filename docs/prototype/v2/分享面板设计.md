# 分享面板设计（v1.25）

> 现行设计规格，服务 [v1.25 需求](../../releases/v1.25/需求文档.md)。原型入口：[v2 原型](index.html) → 笔记顶栏分享（单屏：更多菜单 → 分享）或文件夹操作条 → 分享。
> 分享范围与格式规则见 [v0.8](../../releases/v0.8/需求文档.md)，单张长图规则见 [v1.9](../../releases/v1.9/需求文档.md)，面板外壳与 [导入库弹窗设计](导入库弹窗设计.md) 共用。

## 1. 为什么要选宽度

v1.9 长图按当前栏的预览视口截取，**排版宽度 = 当前栏宽**：

| 场景 | 当前栏宽（示意） | 结果 |
| --- | --- | --- |
| 单屏 | ≈ 380vp | 窄图，字大，表格易换行 |
| 双屏 / 三屏 · 双栏 | ≈ 350vp | 比单屏还窄 |
| 双屏 / 三屏 · 单栏 | ≈ 470–750vp | 宽图，字相对小 |
| 拖动分栏后 | 任意 | 每次都不同 |

同一篇笔记发出去的样子取决于“分享时手机怎么摆”，用户无法预期。本版改为按**固定排版宽度**渲染，与形态解耦；「跟随当前栏」保留旧行为，作为所见即所得选项。

## 2. 面板流程

```
格式列表（范围分段 + 格式行） ──选格式──▶ 格式详情（设置 / 预览 / 清单） ──分享──▶ 系统分享面板
          ▲                                       │
          └──────────────── 返回 ─────────────────┘
```

| 阶段 | 标题 | 主体 | 底部 |
| --- | --- | --- | --- |
| 格式列表 | 分享笔记 / 分享文件夹 / 分享知识库 | 范围分段「笔记 / 文件夹 / 知识库」；格式行 | 仅演示脚注（原型） |
| 长图详情 | 长图分享 | 图片宽度分段 + 外观分段；等比预览；输出信息 | 返回 · **分享图片** |
| 文件详情 | ZIP 分享 / Markdown 分享 | 文件名 + 带图标清单；数量信息 | 返回 · **分享文件** |
| 文本详情 | 文本分享 | 可编辑文本框 + 降级说明 | 返回 · **分享文本** |
| 系统面板 | 不变 | 原型为示意卡片 | 返回 |

**位置与动效（2026-11-03）**：宽屏面板顶部锚定（距顶 `min(10vh, 96px)`），不垂直居中，切换时标题不动。范围切换不改变面板高度（格式区按笔记范围行数预留），只有格式行淡入并上移 `--s2`，200ms；进入 / 返回详情时面板高度 220ms 平滑过渡、详情内容淡入。单屏半模态贴底，范围切换不变高，进入详情时向上平滑展开。减少动态效果时全部即时切换。

摘要行（标题下）：`名称 · N 篇笔记 · M 张本地配图`，无配图省略后段。

## 3. 长图设置

### 3.1 图片宽度

| 预设 | 排版宽度 | 输出宽度 | 说明文案 |
| --- | --- | --- | --- |
| 手机（默认） | 360vp | 1080 px（3×） | 适合在聊天中查看 |
| 宽版 | 720vp | 1440 px（2×） | 表格与代码不易换行，适合电脑查看 |
| 跟随当前栏 | 当前激活栏预览宽度（原型限 320–960） | 栏宽 × 设备像素比 | 与当前栏看到的一致，单屏与双屏结果不同 |

- 说明文案与输出宽度显示在「图片宽度」标签右侧，如「适合在聊天中查看 · 1,080 px 宽」。
- 手机 360vp 取主流手机竖屏逻辑宽度，接收方在聊天里打开时字号接近原生阅读；宽版 720vp 接近本应用正文版心（`--reading-width` 660 + 边距）。

### 3.2 外观

浅色（默认）/ 深色，只作用于本次图片，与应用主题无关。原型把 `:root` 规则中的 token 读出后写到预览纸面，深色直接使用 `[data-theme="dark"]`，不另抄颜色值。

### 3.3 预览与输出信息

- 预览区为 `--nav` 底的“台面”，中间放白（或深）色“纸面”：纸面按排版宽度渲染，再按台面宽度整体缩小（只缩不放），纵向滚动浏览全文。宽版在单屏中缩小显示，**换行位置与最终图片一致**。
- 纸面内边距：手机 `--s8 / --s6 / --s10`，宽版 `--s10 / --s10 / --s12`；正文统一 `--body`、`--ink`（修正旧版预览正文被弹窗段落规则染成 `--muted` 的问题）。
- 输出信息：`1 张长图 · 1,080 × 约 3,534 px · 浅色`；原型高度按纸面高度 × 倍率估算，原生显示最终 JPEG 实际像素；发生预算缩小时追加「已整体缩小至 W px 宽」。
- 原生切换宽度 / 外观后重新排版，期间显示「正在排版…」并禁用「分享图片」。

## 4. 组件规格

| 元素 | 规格 |
| --- | --- |
| 外壳 | 同导入库：宽屏居中，宽 `--share-width`（520）；单屏底部半模态；头部图标块随阶段变化：格式列表为顶栏「分享」同款箭头，详情页为所选格式图标（图片 / 文件 / 文本 / 链接），与格式行一致；不使用通用「上传 / 导出」箭头 |
| 范围分段 | `.seg` 胶囊；三等分，高 `--s10`；选中为 `--paper` 底 + `--float-shadow` + `--blue` 字；`role=radiogroup`，方向键切换 |
| 格式行 | 最小高 `--s16 + --s2`；`--line` 描边、`--r` 圆角、`--paper` 底；图标块 `--s10`、`--blue-soft` 底；名称 `--body` / 600，说明 `--caption`；右侧箭头 `--muted`；悬停浅品牌底 |
| 设置分段 | 同范围分段；标签 `--small` / 600，说明 `--caption` `--muted` 右对齐 |
| 预览台面 | 内边距 `--s4`、`--r` 圆角、`--nav` 底，最高约窗口最小高度 62% |
| 文件清单 | `--line` 描边卡片，行高 `--s10`，文件 / 图片图标；附件未载入行尾 `--caption` 标注 |
| 底部操作 | 同导入库：返回 `--nav` 底胶囊，主操作 `--blue` 胶囊；单屏等宽 |

## 5. 无障碍与键盘

- 打开后焦点进入面板首个可聚焦元素；关闭后回到触发入口。范围与设置分段均为 `radiogroup` / `radio`，`aria-checked` 表达选中，左右 / 上下方向键移动并选中。
- 「图片宽度」分段以说明文案为 `aria-describedby`；输出信息为 `aria-live=polite`，切换后可被读屏感知。
- 颜色不是唯一信息：选中态同时有底色、阴影与文字色变化。

## 6. URL 复现（原型）

| 参数 | 取值 | 写入时机 |
| --- | --- | --- |
| `shareWidth` | `phone` / `wide` / `pane` | `panel=share&stage=image` 时 |
| `shareTheme` | `light` / `dark` | 同上 |

无效值回退为当前页面状态（默认手机 + 浅色）。其他分享参数沿用 [v2 设计说明 §8](设计说明.md#8-url-复现状态)。

## 7. 原型实现备注

- 样式段 `/* Share panel (v1.25) … */`；脚本 `shareWidthPresets`、`sharePaneWidth`、`shareLayoutWidth`、`shareThemeVars`、`syncShareChoices`、`layoutSharePaper`、`setShareImageOption`。
- `#shareScope` 保留为隐藏的状态源：分段按钮写入它并触发原有 `onchange`，URL 恢复与文件夹入口逻辑不变。
- 预览用 CSS `zoom` 缩放纸面；半模态重新定位（窗口尺寸变化、`#window` 过渡结束）后会重新计算缩放。
