# 导入库弹窗设计（v1.24 / v1.26）

> 本地目录视觉规格服务 [v1.24](../../releases/v1.24/需求文档.md)；Git 来源切换恢复归 [v1.26](../../releases/v1.26/需求文档.md)。原型入口：[v2 原型](index.html) → 知识库选择器或库管理页 →「＋ 导入库」。
> 本地目录导入语义（授权关联、不复制、解除关联）见 [v1.5](../../releases/v1.5/需求文档.md)；Git 导入与认证沿用 [v0.3](../../releases/v0.3/需求文档.md)。本文定义两种来源共用的弹窗结构与本地目录视觉。

## 1. 改版原因

| 旧版问题 | 新版处理 |
| --- | --- |
| 「导入库 / 把已有的笔记，带进你的工作台 / 使用手机里的笔记目录 / 选择已有 Markdown 目录…」四层文字，层级平、信息重复 | 图标标题 + 一行副标题；小节标题只给读屏 |
| 目录卡片虚线框里文字和 ↗ 箭头挤在左半边，右侧大片空白，看不出可点 | 整行卡片：图标块 / 文案 / 状态胶囊三段铺满，胶囊直接写出动作 |
| 灰底说明框长得像禁用输入框 | 改为两条带图标要点，无底色 |
| 「原型演示…」说明与正文同级，干扰阅读 | 降为底部脚注，带「演示」标签；原生不显示 |
| 「取消」是无底色文字按钮独占一行，主按钮通栏，操作区松散 | 两键并排：宽屏右对齐，单屏等宽 |
| 单屏也是居中浮窗，与块属性面板形态不一致 | 单屏改底部半模态 |
| 打开时焦点落在已隐藏的「本地目录」分段按钮上，焦点丢失 | 焦点落在目录卡片 |
| 失败 / 重试没有视觉状态 | 新增授权失败态与「重试」 |

改版前后对照见交付包 `截图/改版前` 与 `截图/改版后`。

## 2. 结构

```
┌──────────────────────────────────────────┐
│ [▣] 导入库                          (×) │  标题区 import-head
│     关联已有的 Markdown 笔记目录         │
├──────────────────────────────────────────┤
│ [ 本地目录 ] [ Git 仓库 ]                │  来源切换 import-tabs
├──────────────────────────────────────────┤
│ ┌──────────────────────────────────────┐ │  目录卡片 directory-choice
│ │ [📁]  选择笔记目录            (选择) │ │
│ │       在系统选择器中选一个文件夹     │ │
│ └──────────────────────────────────────┘ │
│  🔗 直接使用原目录                       │  关联说明 import-facts
│     不复制文件，笔记改动直接写回该目录   │
│  🛡 移除只解除关联                       │
│     原目录和其中的文件都会保留           │
├──────────────────────────────────────────┤
│ [演示] 点击目录卡片选用示例目录…（仅原型）│  脚注 import-demo
│                      ( 取消 ) (关联此目录)│  操作 import-actions
└──────────────────────────────────────────┘
```

- 标题区与底部操作固定，中间 `import-body` 内部滚动（矮窗口、单屏半模态时生效）。
- 默认选中“本地目录”，显示本地目录卡片和关联说明；切到“Git 仓库”后，显示 Git 表单：仓库地址、分支及 HTTPS / 私有仓库提示，底部主按钮变为“导入 Git 仓库”。
- 来源分段始终位于当前来源内容上方。两种来源共用标题区、滚动区和底部操作区；本地目录视觉与授权状态遵循 v1.24，Git 输入与认证语义遵循 v0.3。

## 3. 尺寸与 token

| 元素 | 规格 |
| --- | --- |
| 宽屏弹窗 | 宽 `--import-width`（480）且不超过窗口宽减 `--s8`；圆角 `--r`；阴影 `--shadow`；最高 `--panel-height` |
| 单屏半模态 | 贴应用窗口底边、与窗口等宽；顶部圆角 `--r × 2`；拖拽条 `--s10 × --s1`；最高约窗口高度 86% |
| 标题区 | 内边距 `--s5 --s4 --s4 --s5`；图标块 `--s10` 方、`--small-r`、`--blue-soft` 底 `--blue` 图标；标题 `--large` / 600；副标题 `--small` `--muted` |
| 关闭按钮 | `--s10` 圆形，`--nav` 底、`--muted` 图标；悬停 `--line` 底 |
| 目录卡片 | 最小高 `--s16 + --s6`；内边距 `--s4`；圆角 `--r`；图标块 `--s12`；名称 `--body` / 600、最多两行；说明 `--caption`；状态胶囊 `--caption` / 600 |
| 关联说明 | 图标 `--s5`、`--blue`；标题 `--small` / 600；说明 `--caption` `--muted`；条目间距 `--s3` |
| 底部操作 | 按钮高 `--touch`，胶囊圆角，最小宽 `--s16 + --s8`；取消 `--nav` 底，主按钮 `--blue` 底 |

## 4. 目录卡片状态

| 状态 | 描边 / 底色 | 图标块 | 名称 / 说明 | 胶囊 | 主按钮 |
| --- | --- | --- | --- | --- | --- |
| 未选择 | 虚线（`--blue` 40% 混 `--line`）/ `--nav`，悬停 `--blue-soft` | `--paper` 底、`--blue` 文件夹 | 选择笔记目录 / 在系统选择器中选一个文件夹 | 选择 | 禁用 |
| 已选择 | 实线 `--blue` / `--blue-soft` | 实心 `--blue`、文件夹带勾 | 目录名 / 目录位置 | 更换 | 可用 |
| 授权失败 | 实线 `--danger` / `--danger` 8% 混 `--paper` | `--danger` 文件夹带叹号 | 未获得目录授权 / 没有登记知识库，可重新选择目录（`--danger`） | 重试 | 禁用 |

过程状态（仅原生，原型不模拟）：

- **选择器打开中**：卡片保持当前状态；系统选择器返回前不重复响应点按。
- **已取消选择**：卡片回到打开选择器前的状态，状态行提示「已取消选择」。
- **关联中**：主按钮显示「正在关联…」并禁用，卡片与取消保持可见。
- **关联失败**：保留弹窗与已选目录，状态行说明原因，不登记知识库；成功则关闭弹窗、切到新库并提示。

## 5. 交互与无障碍

- 打开：焦点到目录卡片。关闭：关闭按钮、取消、Esc / 系统返回、点遮罩；焦点回到触发入口（库管理页的「＋ 导入库」或知识库选择器）。
- Tab 顺序：关闭 → 来源分段 → 当前来源的控件（原型：本地目录还包含“查看授权失败”）→ 取消 → 当前来源的主按钮。
- 卡片是一个按钮：可访问名称 = 名称文本，描述 = 说明文本（`aria-describedby`），胶囊 `aria-hidden`。状态变化经状态行播报（原型 `role=status`）。
- 颜色不是唯一状态信息：三态同时更换文案、图标与胶囊文字。
- 减少动态效果偏好下，卡片与图标块不做过渡。

## 6. 原型实现备注

- 代码位置：`index.html` 中 `/* Import entry (v1.24) … */` 样式段、`#importVaultDialog` 结构，以及脚本 `importDirectoryCopy` / `setImportDirectoryState` / `positionImportSheet`。
- 单屏半模态用 `.as-sheet`：打开时、浏览器尺寸变化及 `#window` 宽度过渡结束后，按 `#window` 位置计算 `left / width / bottom / max-height`，与 `positionBlockSheet` 同一思路。
- `importLocalTab` / `importGitTab` 控制来源；`importGitPanel` 仅在默认本地来源下隐藏，切换后可见。所有既有元素 ID 保留，确认逻辑只修改页面内演示数据，不调用系统选择器、不读取设备文件或访问远端。
