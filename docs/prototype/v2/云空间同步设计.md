# 云空间同步设计（v1.99）

> 现行设计规格，服务 [v1.99 设计稿](../../releases/v1.99/需求文档.md)。原型入口：[v2 原型](index.html) → 库管理页 →「华为云空间」入口卡，或用 `?ui=2&view=cloud` 直达；页脚「状态演示」五个按钮切换四态。
> 技术结论真源：[`docs/harmonyos/api_notes.md`](../../harmonyos/api_notes.md) **AN1–AN5 组**（Core File Kit 端云文件协同、`cloudFileDir`、`@ohos.file.cloudSync`、错误码语义）。本文只讲 UI 设计，不复制技术结论。

## 1. 思路

华为云空间同步是**库的存储位置**，不是另一个同步引擎：云空间库的根目录在系统云空间目录下，登录同一华为账号的设备自动出现并双向同步（系统行为，应用不实现传输）。因此 UI 只回答三件事：

1. **现在通没通**——状态页四态：未开启（引导）/ 已连接 / 同步中 / 同步失败；
2. **哪些库在云上**——云空间库列表，新建时选存储位置；
3. **怎么用不出事**——多端勿同时编辑、云空间库不参与 Git 同步等注意事项。

与 [Git 同步页](Git同步页设计.md) 的分工：Git 是「把改动安全推上去 / 拉下来」的**传输工具**，有 diff、提交者、分支；云空间是**存储位置**，没有传输操作界面，只有状态与开关引导。两者永不混用：一个库要么是云空间库，要么是 Git / 本地库（99.2 创建时二选一）。

## 2. 结构

全屏页占满应用内容区（`window` 加 `cloud-open` 隐藏侧栏 / 工作区 / 分栏控件，与 `sync-open` / `stats-open` 同范式）；顶部返回栏，主体**单列滚动流**（无 diff 双栏，宽窄屏同构），底部演示脚注。内容按卡片分组：

```
┌───────────────────────────────────────────────┐
│ ‹  华为云空间同步            返回栏 settings-header │
│    同账号设备自动保持一致                        │
├───────────────────────────────────────────────┤
│ ┌ 状态卡 ────────────────────────────────────┐ │
│ │ (◌)  已连接华为云空间            [立即同步] │ │  cloud-card
│ │      上次同步 10:32 · 2 个云空间库          │ │  四态见 §3
│ └────────────────────────────────────────────┘ │  ↑
│ ┌ 云空间库 · 2 个 ───────────────────────────┐ │  │
│ │ 工作笔记        cloud/work · 12 篇 · 已同步 │ │  │
│ │ 生活记录        cloud/life  · 5 篇 · 已同步  │ │  单列滚动流
│ │                    [＋ 新建云空间库]        │ │  cloud-body
│ └────────────────────────────────────────────┘ │
│ ┌ 使用注意 ──────────────────────────────────┐ │
│ │ ▸ 避免在多台设备上同时编辑同一篇笔记…       │ │
│ │ ▸ 云空间库不参与 Git 同步…                  │ │
│ │ ▸ 省电、无网络或云端繁忙时，系统可能延迟同步 │ │
│ │ ▸ 在另一台设备新建的笔记，首次打开需联网取回 │ │
│ └────────────────────────────────────────────┘ │  ↓
├───────────────────────────────────────────────┤
│ 演示｜不连接华为云空间… 状态演示：未开启·已连接… │  sync-page-foot
└───────────────────────────────────────────────┘
```

- **入口**：库管理页顶部「华为云空间」入口卡（在「＋ 新建笔记库」操作区之前）——云空间是库的事，入口放库管理而不是顶栏 / 设置。入口卡与状态页共享同一份演示状态，四态摘要：`未开启`（灰 pill）/ `已连接`（蓝 pill）/ `同步中`（蓝 pill·同步中）/ `同步失败`（红 pill）+ 一行摘要（上次同步时间 · 云空间库数量）。
- **返回**：返回栏箭头回到库管理页所在上下文（原型实现为关闭全屏页；`Escape` 同效）。

## 3. 状态四态

状态卡是唯一随状态变化形状的区块；库列表卡、注意卡恒定。

| 状态 | 标题 | 正文 | 主按钮 |
| --- | --- | --- | --- |
| 未开启 | 未开启华为云空间同步 | 三步引导（见下） | 我已开启，重新检测 |
| 已连接 | 已连接华为云空间 | 上次同步 `HH:MM` · N 个云空间库 | 立即同步 |
| 同步中 | 正在同步… | 正在与华为云空间交换变更，请保持网络畅通 | （禁用占位） |
| 失败·网络 | 上次同步失败：网络不可用 | 系统会在网络恢复后自动重试；也可以稍后手动同步 | 重试 |
| 失败·云端 | 上次同步失败：云端暂未就绪 | 请确认已登录华为账号，并在系统设置的云空间中打开「曜石笔记」的同步开关 | 重试 |

- **未开启引导（三步）**：① 在这台设备上登录华为账号；② 打开系统设置 → 华为账号 → 云空间，找到「曜石笔记」并开启同步；③ 回到这里新建云空间库。步骤序号用品牌蓝圆形数字（`cloud-step-num`），与正文的 muted 灰区分。
- **「我已开启，重新检测」**：演示语义为把状态从「未开启」切到「已连接 · 刚刚同步」；真实语义见 AN 组（应用侧无主动探测接口，只能靠同步动作的结果判断，❓）。开启失败不在此卡展开——「失败·云端」态已覆盖「开关没真开 / 未登录」的用户可见结果。
- **「立即同步 / 重试」**：点击后进入「同步中」，演示 1.2s 后回到「已连接 · 刚刚」。真实语义见 AN 组 `FileSync.start`（错误码 22400001 云端未就绪 / 22400002 网络不可用 / 22400003 低电量）。
- **云空间库列表**：行 = 库名 + `cloud/<id> · N 篇笔记 · 已同步`。空态一句话「还没有云空间库」+ 主按钮「新建云空间库」（关闭状态页 → 打开库管理 → 新建对话框并预选「华为云空间」存储位置）。

## 4. 新建库存储位置（新建库对话框）

新建模式在「库名称」下方加「存储位置」段选（`seg`，与导入来源 tab 同控件语言）：

- **本机**（默认）：标题「新建本地笔记库」，说明「在 vaults/ 下新建一个空目录，不参与同步，与现有库互不影响。」，目录提示 `目录：vaults/<id>`。
- **华为云空间**：标题「新建云空间笔记库」，说明「存入华为云空间，登录同一华为账号的设备会自动出现这个库并保持同步。」，目录提示 `目录：cloud/<id>`。
- **未开启时禁用**：云空间处于「未开启」态时「华为云空间」选项禁用（`title` 提示「需先在系统设置中开启华为云空间同步」）；已开启时恢复可用。
- 改名 / 删除模式隐藏该段选；存储位置一经创建不可改（真实语义：库根目录不同，属于搬移库，不在本版）。
- 创建结果：库对象 `type: 'cloud'`，库管理卡片类型标签显示「华为云空间」，其余行为（设为当前、分享、加锁、改名、删除）与本地库一致——**上层不按存储位置分叉业务操作**（对应硬约束 14 的「上层不得按 rootKind 分叉」）。

## 5. 交互与数据边界（原型）

- **演示状态**：`cloudSyncDemo={enabled, status, errorKind, lastSync}`（第二个 script 块，与 Git 同步代码同区）；刷新即重置，不进 localStorage、不进 URL。页脚「状态演示」五按钮：未开启 / 已连接 / 同步中 / 失败：网络 / 失败：云端未就绪。
- **入口卡联动**：状态页内的一切状态切换同时刷新库管理页的入口卡（`renderCloudEntry`），两处永远同源。
- **URL 直达**：`?ui=2&view=cloud`。沿用 Git 同步页的跨 `<script>` 模式：第一个 script 块的 URL 捕获区记 `window.__initialViewCloud`，第二个 script 块在 `openCloudSync` 定义后据此打开；`urlChoices.view` 加入 `cloud` 防止参数被洗掉；`restoreUrl` 复位 `cloudSyncPage` 的 `hidden` 与 `cloud-open` class。状态不进 URL（与 Git 同步页一致：全屏页是一次性视图，不用 back 恢复）。
- **不做的事**：不连接华为云空间、不读写任何文件、不弹真实系统设置；演示脚注明示「本页不连接华为云空间，不读写任何文件」。
- **实机差异提示**：原型把「检测 / 同步」简化成立即切换；实机的状态回调、进度与错误枚举见 AN 组（⚠️/❓ 未实机验证项），实现版以 SDK 实测为准。

## 6. 视觉 token

- 画布 `--nav`，卡片 `--paper` + `--line` 描边 + `--r` 圆角（与 Git 同步页卡片语言一致）。
- 状态 pill：已连接 / 同步中 `--blue-soft` 底 + `--blue` 字；未开启 `--nav` 底 + `--muted` 字；同步失败 `--diff-del-bg` 底 + `--danger` 字。
- 引导步骤数字 `--blue-soft` 底 + `--blue` 字；注意卡列表 muted 正文。
- 全部间距 / 字号 / 圆角引用 `--s*` / `--caption`/`--small`/`--body` / `--r` token，组件内不散写数值。
