| v1.13 设置页分组列表（本项目已定） | 面板里的设置行沿用同一套分组卡片、行高与字号，块面板与设置页观感一致 |

### 1.2 笔记软件的常见做法（公开产品行为，未逐一核对当前版本）

| 做法 | 参考产品 | 本稿取舍 |
| --- | --- | --- |
| 代码块角上常驻语言标签，点按切换语言；旁边有复制 | Notion、Bear、Typora | **采用**：代码块右上角“语言 ▾ + 复制”，点语言直接打开代码块面板（§4.1） |
| 编辑态点链接先出浮层，“打开”放在浮层里，避免误跳转 | Notion、Bear、Apple 备忘录 | **采用**：简单模式下点链接、双链、图片先开面板，第一行是“打开 / 跳转 / 查看大图”（§7 D-1，需拍板） |
| 文档属性在文首单独一行显示，不在正文里露出 YAML | Obsidian 属性视图 | **采用**：文首“属性 · N 项”入口，点按打开属性面板 |
| 光标进入复杂语法时只展开这一块的源码 | Obsidian 实时预览 | **改为抽屉**：不在正文里展开源码（会让简单模式看见 Markdown），改为“以源码编辑此块”抽屉，只显示这一块 |
| 表格行列边缘的“+”手柄 | Notion、Apple 备忘录 | 工程设计已定为**后置加速项**（B），本稿不做 |
| 块左侧拖拽把手、斜杠菜单 | Notion | 不做：拖拽把手可发现性依赖悬停，斜杠菜单属于插入型能力，归 Aa |

## 2. 交互总览

```
点按 / 键盘进入块
 ├─ 表格 ──────────── 上下文浮条（下加行 · 右加列 · 删除 · 更多）→ 更多 = 表格面板        【工程设计 C，原型沿用】
 ├─ 代码块 ────────── 直接在块内改代码；右上角“语言 ▾”→ 代码块面板；“复制”一键复制
 ├─ 提示块标题 ────── 提示块面板（类型 / 标题 / 折叠）；正文行照常直接编辑
 ├─ 公式（块 / 行内）─ 公式面板（LaTeX + 预览 + 应用）
 ├─ 属性入口 ──────── 属性面板（键值 + 类型）
 ├─ 链接 / 双链 / 图片 / 行内代码 ─ 各自面板（第一行是打开 / 跳转 / 查看大图）
 └─ 含复杂内容的段落 ─ “这一段”面板：逐项列出可编辑内容 + 以源码编辑这一段
所有面板底部：以源码编辑此块（只显示这一块 / 这一项的 Markdown）
```

- **Aa 浮层保持纯净**（工程设计 §4.5）：本稿没有往 Aa 里加任何结构操作。
- **浮条只服务表格**（工程设计 §4.3）：其他块点按即开面板，不再各浮一条。
- 键盘 / 读屏：块与行内项均可聚焦；**Enter / 空格**或 **Shift+F10 / 菜单键**打开面板；**Esc** 关闭并把焦点还给原来的块；代码块内 Shift+F10 打开代码块面板，Tab 插入两个空格。

## 3. 面板形态

| 形态 | 何时 | 外观 | 关闭 |
| --- | --- | --- | --- |
| 底部半模态 | 单屏（< 600vp） | 宽度铺满窗口，顶部拖拽条，顶部大圆角，背后深色遮罩 | 关闭按钮 / 点遮罩 / Esc / 系统返回；原生另有下拉 |
| 跟手弹出 | 双屏、三屏 | 宽 380（源码抽屉 480），限制在来源栏内，**放在块的上方或下方中空间更大的一侧，高度以该侧为上限，内容可滚动，永不盖住来源块**；无拖拽条；背后透明遮罩仅用于“点外面关闭” | 关闭按钮 / 点外面 / Esc |

共同结构：标题（块类型）+ 副标题（如“python · 2 行”“10_写作/基础排版”）→ 分组设置行 → 说明文字 → “以源码编辑此块”。需要确认的操作按钮（公式“应用”、源码“保存”）固定在面板底部，不会被滚走。

**生效方式**（§7 D-5）：选择器、分段、开关、动作行**即时生效**，每次一个撤销步；文本框在回车或失焦时生效；公式和源码文字较长、需要先看预览，用“应用 / 保存”按钮。每次写入后面板原位刷新，可以连续改。

## 4. 各类块规格（对齐 v1.14 / v1.19 / v1.20 / v1.21）

图例：写回范围指只替换的源码区间；所有写入前校验该区间内容与打开时一致，不一致则拒绝并提示“这一块已经变化，请关闭后重新打开再改”。

### 4.1 代码块（v1.19）

| 项 | 规格 |
| --- | --- |
| 入口 | 直接点代码进入块内编辑（等宽、纯文本、`*` `#` 不变格式）；右上角“语言 ▾”打开面板；“复制”一键复制内容 |
| 面板 | 语言（常用 18 种 + 纯文本；不在清单内显示“保留：xxx”）· 复制代码 · Mermaid / 插件查询的说明 · 以源码编辑此块 |
| 写回 | 改语言只改开围栏行；改内容只改两条围栏之间；输入法组合期间不提交 |
| 降级 | 围栏未闭合：不进入块内编辑，标签显示“源码”，面板只给源码抽屉；输入一整行与围栏相同的内容会被拒绝并撤回这次输入 |

### 4.2 行内代码（v1.19）

面板：转为纯文本（去反引号保留文字）· 以源码编辑。

### 4.3 链接（v1.20）

面板：打开链接（显示地址）· 显示文字 · 地址（空地址拒绝，不补协议）· 取消链接（保留文字）· 以源码编辑。写回只替换 `[文字](地址)` 这一段。

### 4.4 双链（v1.20）

面板：打开目标笔记（在另一栏，目标存在时）· 目标笔记（当前库笔记列表；目标不存在 / 无法解析时列表顶部保留原值并说明）· 显示文字（留空即去掉别名）· 移除双链（保留显示文字）· 以源码编辑。标题锚点 `[[笔记#标题]]`：给出“暂不支持跳转”的说明，仍可改文字与目标。

### 4.5 图片（v1.20）

面板：替代文字 · 显示宽度（原始 / 小 240 / 中 360 / 大 480，§7 D-6）· 查看大图 · 替换图片（复用插入图片链路；原型只提示）· 删除图片（只删引用，附件按既有规则保留）· 以源码编辑。外链图片只改地址。

### 4.6 公式（v1.21）

块级与行内共用一个面板：LaTeX 文本框 · 实时预览（原生由本地公式库排版，原型只显示文本）· 应用 · 以源码编辑。写回保留原定界符（`$$` 多行 / 单行、`$`）；空公式拒绝（删除走源码）；行内公式不允许出现 `$`。

### 4.7 提示块（v1.21）

正文行与普通引用一样直接编辑；点标题打开面板：类型（13 类，未知类型显示“保留：xxx”）· 标题 · 折叠（不折叠 / 默认展开 / 默认收起，对应 `+` / `-`）· 以源码编辑。写回只改标题行。阅读时可点“展开 / 收起”临时切换，不写入。

### 4.8 属性 / frontmatter（v1.21）

文首“属性 · N 项”入口。面板逐行列出属性，按值的形态给控件：文本框、日期选择、开关（true / false）、列表（用顿号或逗号分隔，tags 显示为“标签”）；嵌套 / 多行结构显示“保留原值，请用源码编辑”。每行可移除；底部“添加属性”（名称 + 值，值写成“a、b”即保存为列表）。**只重写改动过的键，其他行（含嵌套结构与注释）逐字保留**（§7 D-7）。非标准 YAML：只给源码抽屉。

### 4.9 含复杂内容的段落

段落含链接、代码、公式等行内内容时，正文暂不能直接打字（沿用 v1.7 的块级保护）。整段可点，打开“这一段”面板：逐项列出可编辑内容（点按进入该项面板）+ 以源码编辑这一段。段落下的提示改为“含链接、代码或公式 · 点按逐项编辑”；只有含高亮、注释、嵌入等真正未支持的格式时，才保留 v1.7 的“此内容请在专业模式编辑”（§7 D-4）。

### 4.10 表格（v1.14，沿用原型既有示意）

沿用工程设计 §4.3 的浮条与表格面板；本稿只做两处改动：宽屏下表格面板改为跟手弹出；“以源码编辑此块”从提示改为真正打开源码抽屉。表格行列的结构写回仍是界面示意（v1.14 另行实现）。

### 4.11 块级源码抽屉（v1.18 18.7）

标题“以源码编辑”，副标题为块类型；说明“只显示这一块的 Markdown，保存后只替换这一块”；等宽文本框（Ctrl / ⌘ + Enter 保存）；取消 / 保存。保存前校验区间未变；不切换模式、不显示整篇源码。

## 5. 安全不变式（设计要求）

1. 每次写入只替换目标块 / 目标行内片段的区间；测试逐项断言区间外子串完全相同。
2. 写入前校验区间内容与打开面板时一致，否则拒绝（已用“打开后在别处改动再保存”验证）。
3. 每次写入一个撤销步；各类操作撤销后与原文逐字相同。
4. 解析失败（未闭合围栏、非标准 YAML、非常规链接写法）→ 只给源码抽屉并说明，不静默转换。
5. 模式切换、保存、草稿沿用 v1.7 同一编辑状态；专业模式下不显示任何简单模式入口。
