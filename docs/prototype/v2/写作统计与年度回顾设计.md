# 写作统计与年度回顾设计

对应 [v1.81 需求](../../releases/v1.81/需求文档.md)，仅设计稿。入口沿用右上「⋯ → 应用 → 写作统计」，各形态均为独立页面：单屏占满应用，双 / 三屏占满工作区。顶部返回笔记，无遮罩、关闭叉号或拖拽条；返回与 Esc 恢复入口焦点。

## 视觉方向

借鉴鸿蒙健康类页面的大数字、轻底色圆角分组与舒展留白，Apple Fitness 的成就收藏层次，以及 GitHub 周列热力图。不复刻官方组件；不引入新平台接口。色彩沿用品牌蓝、暖色 `--cb-warn` 及浅深色语义 token，尺寸新增为 `:root` 的 `--stats-*` token。

- 三个同级视角：「概览 / 年度回顾 / 成就」，互斥展示，切换后回到内容顶部。
- 写作概览：左侧暖色「每一天，都算数」主卡，用大数字突出连写，星期点与下一步提示伴随展示；三项库快照为辅助数字行。宽屏右侧为近 12 周热力图，单屏纵向堆叠。
- 成就收藏：宽屏四列、单屏两列；暖色轻浮雕奖章表示已获得，品牌蓝圆环表示唯一的下一枚，其余为灰色内圈线稿。每枚都有状态、名称与条件 / 进度，不仅靠颜色区分。数量由数据决定，可增加行数；本次仍为已有八枚。
- 年度回顾：可选当年及前两年演示；年度标题、三个指标和十二个月柱图。宽屏指标与月图并排、单屏纵向堆叠。当前月份品牌蓝强调，未来月份虚线留空，月柱按活跃天数占当月日历天数绘制。成就独立于年度视角，沿用累计口径。

## 数据与边界

年度口径、跨年截断、mtime 局限与演示年份规则统一见 [v1.81 年度口径与边界](../../releases/v1.81/需求文档.md#年度口径与边界)。当前库笔记 / 字数是快照，不冒充年度新增；年度、热力图与连写均为演示夹具，页面明确标注。本版不新增徽章条件、分享长图、目标、提醒、排行榜或原生实现。

## 预览与证据

在原型 URL 加 `?ui=2&view=stats` 打开；附加 `preset=phone` / `preset=double` 验证形态，`theme=dark` 验证深色。点击「年度回顾」和年份下拉切换。

当前截图见 [独立统计页面](截图/独立统计页面/)；原浮窗截图保留为历史证据。浏览器截图是设计稿证据，不是原生、API24 或 XT2 验收。

## 形态取舍（2026-11-17 用户确认）

[鸿蒙半模态指南](https://developer.huawei.com/consumer/cn/doc/doccenter-ux-design/bindsheet-0000001956852753)建议面板内操作尽量简化、避免复杂交互；展开态居中规则针对已选择半模态的场景，并非统计页必须浮窗。[Apple Fitness](https://support.apple.com/en-gw/guide/iphone/iph4c34a8a95/ios)采用 Summary 概览并进入趋势 / 奖章详情，[Strava Progress](https://support.strava.com/en-us/articles/15401618-progress-summary-chart)在个人进度中提供时间范围与详细图表。本项目加入年份、趋势和成就收藏后，按用户确认改为独立页，避免在小浮窗内长距离滚动；不据此推导新的 HarmonyOS API 或真机结论。
