## 编辑、库导航与双屏补齐

- 笔记栏头常驻“编辑 / 预览”，编辑是可直接输入的 Markdown 源码；移除底部重复编辑入口。输入即时更新本页笔记对象，切笔记、切库不丢本页修改，刷新恢复样例。
- 三个原创演示库可切换；每库显示文件夹与笔记，文件夹可折叠，记住各库当前笔记和参考。引用选择仅限当前库。
- 单屏：列表与正文切换，正文与参考切换。双屏：默认目录＋正文，点击“参考”或收起目录后切为正文＋参考；再次打开目录恢复目录＋正文。三屏：目录、正文、参考并排。
- 复用现有多库/文件树需求，仅补齐 v2 原型，不新增原生实现承诺。预设宽度用于概念比较，不作为 XT2 物理屏宽实测值。

## 多级文件树修订

此前按单个文件夹字段分组的列表替换为按库内路径逐层建立的文件树，不限制为一层。样例包含“阅读 / 读书笔记 / 阅读方法”等三级目录；沿用原稿的箭头、文件夹/文件图标、24px 层级缩进与辅助线。目录采用单行名称，去除逐篇重复副标题，完整路径通过行标题查看；当前文件保持浅蓝选中。每库/每路径独立折叠，切换笔记和库不覆盖折叠状态；键盘 Tab 可达，左右方向键展开/收起目录。深层目录允许横向滚动，避免无限挤压文件名。仅修改 v2，原稿与原生 App 不变。

入口去重：移除侧栏底部“工作方式”的对照阅读/专注写作按钮，顶部不再提供“对照 / 阅读 / 专注”模式组；编辑 / 预览只在正文栏头保留，参考笔记和专注各保留一个独立入口；侧栏只承担知识库与文件目录导航。

## 分栏宽度交互

补回原稿的分栏控制：目录展开时拖动目录边界，三屏正文/参考均分剩余空间；收起目录后可拖动正文与参考边界。双屏也可调整目录＋正文比例，收起后可调整正文＋参考；单屏与专注模式不显示拖动条。每个可见栏最小 240px（原型逻辑尺寸），窗口变化或恢复旧值时重新约束。目录默认 1/3，正文/参考默认各半；按 v2 独立 localStorage 键记住两种比例，不改原稿状态。双击任一可见把手或聚焦后 Enter 恢复默认，左右键微调；切模式与窗口变化不重建编辑器，笔记和选区保持。浏览器持久化失败时提示，不影响当前拖动。

## 编辑状态与布局解耦

“预览”即阅读，不另设阅读模式。参考笔记独立开关不改变编辑状态；双屏打开参考时收起目录，单屏进入参考页。专注仅暂时隐藏目录及参考，退出恢复此前布局与编辑 / 预览状态；专注期间参考开关不可用，避免隐藏状态下改变布局。删除底部重复编辑、专注及摘录入口，摘录只保留在参考栏。分栏拖动与比例记忆继续保留。

## 知识库切换样式

将浏览器默认 select 替换为轻量下拉入口：浅蓝知识库图标、库名、灰色本地与笔记数说明、统一线性箭头，默认融入侧栏背景。展开为白色圆角浮层，当前库使用浅蓝选中和勾选标记。沿用现有三库切换及本页编辑保留逻辑；支持键盘 Tab、Enter / Space 展开、Escape 关闭和点击外部收起，深色模式沿用已有 token。

## 编辑工具栏与图片

编辑状态下，在正文栏头下方显示格式工具栏：二级标题、加粗、斜体、列表、待办、引用、代码块、链接和图片。按钮对当前选区或光标位置插入 Markdown，窄栏自动换行，预览状态隐藏工具栏。图片通过本地文件选择器插入，使用本页临时资源进行预览，不上传、不写入真实附件目录；刷新后图片与编辑内容恢复样例。该原型演示 PNG / JPEG / GIF / WebP，尚不代表 HarmonyOS 系统选图和附件落盘实现。

## 设置与分享入口

- 工作区顶部补齐“分享”和“设置与关于”图标入口，与参考、专注各自独立；窄屏允许工具栏换行。弹窗支持关闭按钮、Escape、点击遮罩关闭，关闭后焦点回到入口。

## 左栏文件 / 章节切换

知识库入口下增加“文件 / 章节”切换，替代正文顶部章节弹层。文件视图沿用原多级树；切换侧栏视图不重建文件树，保留展开状态与滚动位置。章节视图顶部显示当前笔记名和标题数量，按 H1–H6 建立层级，父章节箭头独立控制展开 / 折叠，点击标题负责定位。跳级标题挂到最近的较低级标题下，同名标题按出现位置区分；与当前简化渲染器一致，忽略反引号围栏代码块中的标题。

编辑状态下定位标题源码行并保持编辑；预览状态下定位对应标题并保持预览。单屏点击章节后收起侧栏、回到正文；专注时点击目录按钮退出专注并打开侧栏。编辑内容、切换笔记或知识库时更新章节；没有标题时显示引导空态。原型当前只解析 ATX（`#`）标题，不声称完整 CommonMark 支持。验证为脚本与模拟 DOM 逻辑检查；实际文本换行后的源码滚动位置、触控及视觉效果待浏览器验收。

## 参考笔记流程修订

选中参考文字后才启用摘录，不再自动插入示例。摘录插入当前笔记上次编辑的光标位置；存在选区时插入选区末端，保留原文字；尚未编辑时追加文末。每篇笔记分别记住编辑选区。摘录后可撤销，若之后有新编辑则保留新内容。

来源写为完整库内路径并显示笔记名，避免同名歧义。在预览中点击来源，会打开只读参考栏，保留正在写的笔记与内容；单屏进入参考页，双屏收起目录展开参考。源码状态仍显示 Markdown，切到预览后点击来源。普通标题双链只有在当前库唯一匹配时才可打开，缺失或歧义链接不自动创建笔记，代码内的双链保持原文。

本节更新前述对照表：来源双链已可打开参考，编辑选区已按笔记记录；反链列表、缺失链接创建、按笔记恢复滚动位置仍未迁移。模拟 DOM 检查已覆盖光标插入、无选区不写入、撤销冲突保护及跨形态来源导航；真实选区、触控与滚动效果仍待浏览器验收。

## 从文件树选取参考笔记

移除参考栏的下拉笔记选择框，改为显示已固定笔记名称、完整路径和“从文件列表选择”入口。文件树每篇笔记行右侧提供“设为参考”图标按钮，支持点击与键盘；原来的文件名点击仍打开主笔记，两者操作独立。当前主笔记不能设为自身参考。

鼠标可从文件树拖动笔记到参考栏；参考栏隐藏时可拖到顶部“参考笔记”按钮，落点高亮，松手后展开对应笔记。仅接受本页当前知识库内的笔记拖动，不移动文件，不接受外部文件导入。触屏通过行尾按钮完成同一操作，不依赖浏览器原生拖动支持。

双屏“从文件列表选择”会显示目录，选定后恢复正文＋参考；单屏会打开文件列表，选定后进入参考页，可返回当前笔记。整个过程保留主笔记及编辑内容，参考切换清空旧的摘录选区。验证包含模拟拖放、按钮、单 / 双屏跳转及主笔记保持；实际鼠标拖放、触屏和视觉仍待浏览器验证。

## 双栏工作区与回收站视觉修订

本节取代前文“右栏固定只读参考”的规则。顶部更名为双栏；左右两栏均有独立的编辑 / 预览、标题、格式工具与图片入口。两栏可以打开不同笔记并分别编辑，也能打开同一篇笔记；同篇内容在输入时同步到另一栏，支持一侧编辑、一侧实时预览或两侧编辑。每栏提供“同篇预览”，在另一栏打开当前笔记的预览；单屏会切到生成的预览栏。章节列表与分享使用当前激活栏的笔记。

点击或聚焦正文栏使其激活，以栏头蓝色细线提示。点击文件名在激活栏打开；行尾图标点击在另一栏打开，拖到哪一栏就在该栏打开，拖到顶部“双栏”则在右栏打开。当前笔记也允许在另一栏打开。单屏提供“切到左栏 / 右栏”，双屏并排两栏，三屏保留文件 / 章节侧栏。摘录改为右栏选中文字后出现的辅助操作，不再常驻；同篇时不显示自我摘录。

回收站移到侧栏底部，使用灰色线性图标、文字和数量，与列表以细线分隔，不再使用居中的大按钮；文件和章节视图均可访问。

对照表状态更新：同篇编辑加实时预览已补齐，滚动跟随仍未迁移。模拟交互验证覆盖双篇独立编辑、同篇实时预览及双编辑同步、右栏格式操作、激活栏文件导航 / 章节 / 分享、单屏切栏、切库保留双栏笔记、删除及回收站数量。实际布局、触控及双编辑中文输入兼容性仍待浏览器验收。本轮只修改设计稿与说明，未修改原生代码。

## 10. 导航推入动画（v0.10 原型实施）

点击汉堡后列表从左向右进入，单屏正文保留整屏宽度同步右移，超出画布部分裁切；收起时连续回位。导航宽度最多 300px，并保留返回入口所需空间。宽屏使用负边距与正文可用宽度联动，双屏第二栏随终态切换；栏宽仍来自既有比例，不通过 display:none 重建列表或正文。位移 / 宽度使用同一组 240ms 缓动 token，反向操作从当前进度转向新目标。初次打开或恢复 URL 不播放入场动画，减少动态效果时取消过渡。

导航关闭即设置 inert，单屏被推出的正文暂不可交互；打开 / 关闭保持编辑器节点、笔记内容、光标和滚动。原型已接线并有模拟交互检查；真实浏览器中间帧、触控与原生实现仍按 [v0.10](../../releases/v0.10/需求文档.md) 独立验收。

预览区支持双指捏合连续缩放，限制在 50%–200%；触控板通过 Ctrl+wheel 事件缩放。普通单指滚动和滚轮仍用于阅读；手势结束 / 取消即停止缩放。连续缩放产生的非预设百分比临时出现在列表中，列表与手势始终使用同一比例。URL 的 lz / rz 分别保存左右栏百分比，旧链接缺省为 100%；缩放更新当前历史项。

本次仅交付浏览器原型与设计规则；原生缩放列入需求池待分配，不自动纳入 v0.9 / v0.10。自动检查共 28 项通过（含原有回归），覆盖比例列表、重置可见性、编辑隔离、双栏独立、URL 与非法比例、捏合取消及触控板事件；真实浏览器排版、触屏手势冲突与 XT2 手感尚待验收。

### 回收站样式演示开关（2026-10-28）

### 代码块格式识别与取消（2026-10-28，v0.9 9.10）

Aa 打开时，根据来源栏的光标 / 选区识别所属围栏代码块。只选代码内容、部分内容、连同围栏选中，或把光标放在块内，“代码块”按钮均呈蓝色选中态（aria-pressed=true），提示为“取消代码块”；打开 / 关闭面板本身不扩展源码选区、不修改正文。跨越多块和普通正文的混合选区不显示单块选中态。

点击已选中的“代码块”会去掉所属整块的起止围栏及起始语言标记，保留内部代码、空行与相邻段落；取消后选中保留下来的内容，便于继续编辑。普通文本点击“代码块”按整行包裹并选中内容，再点可取消，不能逐次嵌套围栏。识别反引号、波浪线、不同长度围栏以及 CRLF；普通文本含反引号时采用更长围栏。未闭合代码块延续到文末，取消时仅移除已有起始标记。预览及章节扫描使用相同围栏匹配规则，避免长围栏内的短围栏或标题被提前解析。左右栏格式只修改来源笔记，保留滚动与焦点。

已登记需求池 L-08、[v0.9 9.10 / §6.2](../../releases/v0.9/需求文档.md)。42 项模拟 DOM 检查通过，包括代码块识别、重复应用 / 取消、围栏匹配、CRLF、空块、未闭合块、跨块选区与来源栏隔离；共享样例生成一致性检查通过。原生代码未改，真实浏览器视觉与触屏、API24 / XT2 验收待做。

汉堡对齐修正：顶部与下方编辑 / 预览控件继续共用水平留白；另补偿汉堡 SVG 在触控区内的居中留白和 viewBox 左侧空白，使可见横线左端对齐下方分段控件的可见左边缘。只移动按钮内部图形，保留完整触控区及单屏展开导航后的可点击性。
