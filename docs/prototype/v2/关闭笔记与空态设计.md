# 关闭笔记与空态设计（v1.28）

> 现行设计规格，服务 [v1.28 需求](../../releases/v1.28/需求文档.md)。原型入口：[v2 原型](index.html) → 任一正文栏路径行右端「×」。

## 1. 规则

- **在哪一栏关闭，就只清空哪一栏。** 不收起右栏、不切换双栏 / 专注、不改栏宽、不动另一栏。
- 关闭前先保存；保存失败不关闭。
- 单屏关闭后停在空态页。

## 2. 关闭入口

```
┌─────────────────────────────────────┐
│ 00_开始 / 快速上手.md            (×) │  ← .pane-title-row，× 40vp 圆形
├─────────────────────────────────────┤
│ 正文 …                              │
```

- 放在笔记路径行而不是栏头：简单模式隐藏了栏头，路径行在所有模式与形态下都可见。
- × 使用 `--muted`，悬停 `--nav`（右栏为 `--paper`）底；读屏「关闭笔记：<标题>」。

## 3. 空态

```
            ( ◎ )              ← 浅蓝圆形图标 --s16+--s4
          未打开笔记            ← --large / 600
  从文件列表选一篇，或拖到这一栏打开。  ← --small --muted
     ( ↶ 重新打开「快速上手」 )   ← 仅刚关闭时
   [ 新建笔记 ]  ( 搜索笔记 )    ← 单屏另有 ( 文件列表 )
  最近打开
   📄 基础排版        10_写作
   📄 公式与流程图    20_样式 · 另一栏已打开
```

| 元素 | 规格 |
| --- | --- |
| 容器 | 顶部留白 `min(14vh, 96px)`，内容最大宽 `--s16 × 5.5`，左右栏同一套组件与对齐 |
| 图标 | `--s16 + --s4` 圆形，`--blue-soft` 底、`--blue` 线稿笔记图标 |
| 重新打开 | 胶囊，`--line` 描边、`--paper` 底，左侧 `--blue` 回退箭头，标题过长省略 |
| 操作 | 胶囊高 `--touch`；主「新建笔记」`--blue`，次按钮 `--nav`（右栏 `--paper`） |
| 最近打开 | 最多 4 行，行高 `--s12 + --s1`；标题 `--small`，文件夹 `--caption --muted`；排除刚关闭的那篇 |
| 空库 | 标题「这个库还没有笔记」，说明「新建第一篇笔记，开始写作。」，仅「新建笔记」 |

- 空栏隐藏「编辑 / 预览」栏头，避免出现一排不可点的控件，也让左右空态顶部对齐。
- 新建、搜索、最近打开、重新打开都作用于这一空栏。

## 4. 焦点与键盘

- 关闭后焦点到「重新打开」，没有时到「新建笔记」。
- 空态各按钮均可 Tab 到达；从空态打开笔记后焦点回到该栏正文。

## 5. 复现链接

`left=` / `right=` 为空值表示该栏为空，刷新与分享链接不回退为默认笔记（见 [设计说明 §8](设计说明.md#8-url-复现状态)）。
