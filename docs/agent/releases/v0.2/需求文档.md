# Agent v0.2 —— 上下文预算与运行恢复完善

> 状态：⚪ 规划，未实施/未发布。来源：需求清单 AG-09–AG-11。前置 Agent v0.1 基础验收；App 集成版本尚未分配，不阻塞 App v0.7 的已定范围。

| 需求 | 验收出口 |
| --- | --- |
| AG-09 | 在明确的测试窗口/预算下，去重、分块、裁剪与摘要保留当前任务、最新操作与有序引用，不产生孤立工具结果；缺真实模型时只验确定性结构，不宣称摘要语义正确 |
| AG-10 | 系统覆盖取消/超时/重复投递/结果未知/写后未登记的对账；预算可停止，恢复不重复副作用；故障矩阵用 mock/单测，不制造模拟器崩溃 |
| AG-11 | 固定版本的原创案例、自动断言与语义人审记录，修改模板/Runner/工具后可比较；不上传用户笔记到第三方观测平台 |

本版只深化已有运行设计，不增加跨库对话、外部插件或后台常驻承诺。实际原生工程与模型语义评估分别验收，平台不可用不阻塞可独立的本地工作。当前无验收完成证据。
