## 2. 验证与边界

确定性单测覆盖禁用工具、错误参数、库隔离、A/B/A 引用、版本冲突、幂等/撤销、配置与存储失败。原生工具及 App 集成完成后才可认为交付；App HAP、sm/md/lg 与设备结果由 App v0.7 回填。平台/模型未接入，不声称验证了真实语义质量。

本版不承诺真实小艺、长期后台、系统通知、多库 RAG 或完整长上下文摘要机制。数据保护、基本恢复不重放属于本版，不能以留到 v0.2 为由跳过。失败恢复用单测，不做模拟器崩溃/强杀/写入中断实验，不实际重置用户数据。
