# Agent 功能与工程需求清单

> 本表是 Agent 能力的唯一需求入口。来源：App 需求池 G 节、App v0.7 §7.3–7.8 以及用户关于 loop、上下文、配置与独立版本的要求。App UI 继续由 App 版本跟踪，状态见 [版本索引](README.md)。
> 2026-10-26 用户决定本地 Agent View 不需要做，App v0.7 集成暂缓。下方 AG 项目继续作为 Agent 工程需求保留；“App 侧对应项”是旧映射，不属于当前 App 交付，待重新分配。
> “原型已有”只指浏览器 JS/内存样本，不表示 App/平台验收完成。

| 编号 | 需求 | 可验证出口 | 分配 | 当前状态 |
| --- | --- | --- | --- | --- |
| AG-01 | 确定性 MockProvider | 固定问法对应固定回复/工具步骤，未知输入回退，无真实网络调用 | Agent v0.1 | 原生场景表与执行器已有初稿；Hypium 与 API 26 lg 已验证未知问法回退且不调用工具，完整场景待验 |
| AG-02 | 有界执行 loop | 顺序执行、配置快照、工具预算、最终成功/失败如实返回，执行状态可查询 | Agent v0.1 | 原生有界执行与配置快照初稿；Hypium 局部覆盖，跨形态/完整用例待验 |
| AG-03 | 有序消息与来源快照 | text / note_ref 顺序、A/B/A 重复位置保留；来源去重但不重排句子；库范围与失效校验 | Agent v0.1 | 原生 parts/快照及隔离校验初稿；Hypium A/B/A 与 API 26 点击引用/读取已验，拖入与失效 UI 待验 |
| AG-04 | Tools 执行与权限 | 查询/读取/创建/追加/唯一锚点修改/撤销，白名单与开关/Skill 限制生效 | Agent v0.1 | 原生六工具和权限交集初稿；Hypium 覆盖六工具分别及同时被用户开关与 Skill allowlist 拒绝，API 26 查询/读取/创建撤销已验，追加/修改页面路径待验 |
| AG-05 | 写入、幂等与撤销基础 | 明确指令直接执行，最新版本/未保存编辑保护，operationId 防重复，撤销不覆盖后续编辑 | Agent v0.1 | 原生进程内操作账初稿；Hypium 同 run 重放/新 run 再执行及冲突保护、API 26 创建撤销已验；跨进程持久化待 AG-08 |
| AG-06 | 系统提示词管理 | 内置/自定义、保存与恢复、版本记录、下一轮生效，不能改掉执行器权限 | Agent v0.1 | 原生设置与内存配置初稿；Hypium 保存/恢复和快照局部覆盖，API 26 lg 已验页面保存/恢复；跨进程持久化待 AG-08 |
| AG-07 | 内置 Skills | 读书追问/讨论沉淀、选择与模板覆盖、恢复默认、允许工具取交集，不运行任意代码 | Agent v0.1 | 原生内置 Skill/权限交集和设置初稿；Hypium 局部覆盖，API 26 lg 已验读书追问编辑/恢复；其他 Skill、全路径和跨进程持久化待验 |
| AG-08 | 对话与运行持久化基础 | 对话/草稿/配置/真实工具结果可重开，库间隔离；恢复不自动重放副作用 | Agent v0.1 | 2026-10-26 [存储方案已确认](../engineering/应用内部存储架构_审查稿.md#9-用户确认记录2026-10-26)；含稳定库身份、配置持久化、手动保留及删库清理；会话、配置和操作账仍为进程内状态，待实现/验收 |
| AG-09 | 上下文预算与长会话压缩 | 按实际能力预算，来源去重、分块、完整往返裁剪与摘要，可解释哪些材料未进入上下文 | Agent v0.2 | 设计待实施，不能宣称 mock 已验证真实模型效果 |
| AG-10 | 取消、超时与恢复对账完善 | 参数错误/取消/网络未知/写后未登记等状态的系统故障矩阵；无重复追加或假成功 | Agent v0.2 | 设计待实施；v0.1 仍须保证基本不重放与数据保护 |
| AG-11 | 固定版本回归与质量评估 | 固定 Provider/mock、模板/Skill/工具版本与原创案例，确定性测试和语义人审分开 | Agent v0.2 | 原型有局部测试；完整评估待建立 |
| AG-12 | 小艺托管 Agent 本地工具桥接 | 端插件映射已有工具，校验发起范围、编辑保护并返回真实结果；聊天和模型调度归平台，见 App v0.6 新设计 | Agent v0.3 | 2026-10-26 用户调整设计；外部暂缓，不领取 |
| AG-13 | 后台持续执行 | phone 资格与权限成立，脱离 UI 的运行、撤销授权/回前台恢复可验收 | 未分配 | 外部核实，末尾暂缓 |
| AG-14 | 系统通知 | 系统授权、完成/失败/需处理去重、点击回对话、无内容泄漏 | 未分配 | 仅偏好原型；系统未接入，与 AG-13 条件分开核实 |
