欢迎使用曜石笔记。请在使用前阅读本协议；你按照应用提供的明确步骤接受本协议后，本协议适用于你对应用的使用。如你不同意，请停止使用。协议中的重要权利义务及责任限制应在正式发布时以清晰、易理解的方式呈现。

## 一、协议主体与适用范围

本协议由你与曜石笔记的提供者郭捷昕（个人开发者，发布前须核对其与 AppGallery Connect 实名主体一致）订立。本协议适用于你下载、安装或使用曜石笔记及其实际提供的相关功能。

## 二、服务内容

曜石笔记是一款面向个人知识管理的 Markdown 笔记应用。应用提供的核心能力为创建和管理本地知识库、浏览与整理笔记、编辑 Markdown 内容及查看排版预览。搜索、链接、图片附件、导入、导出和分享等功能，以你所使用版本中实际开放的功能为准。

部分版本可能提供 Git 仓库导入或同步、外部目录关联等可选功能。只有在相应版本实际提供并由你主动使用时，本协议中与该功能相关的条款才适用；本协议不代表这些功能已在所有版本开放或已通过特定设备、服务商的兼容性验收。

## 三、你的内容与数据

1. 你保留自己创建或依法有权使用的笔记、附件及其他内容的权利。除为你主动使用的功能所必需外，本协议不向提供者转让这些内容的所有权。
2. 沙箱知识库内容保存在设备应用数据中。设备故障、系统清理、卸载应用或重置数据等情况可能导致内容无法恢复。请对重要内容自行备份；此提示不免除提供者依法应承担的责任。
3. 如你主动使用 Git 功能，应用会按照你选择的仓库、分支和操作与相应远端服务交互。你应确认自己有权访问该仓库，并了解远端服务提供者可能按其条款处理你推送或分享的内容。具体同步范围以应用界面实际提示和操作结果为准。
4. 如你使用的版本支持外部目录关联，应用仅在你通过系统选择并授权后访问所选目录。该功能对目录内容的读取、编辑、移动或删除，可能直接作用于原目录；解除应用内关联不等于删除原目录。
5. 如你使用系统分享或反馈邮件功能，接收应用或邮件客户端由你选择。反馈邮件由应用交给邮件客户端形成草稿，是否发送由你在邮件客户端确认。请先检查内容和收件人，再决定是否发送。
6. 个人信息的处理目的、方式、种类、保存期限及你的权利，以单独公布的《曜石笔记隐私政策》为准。本协议不替代隐私政策。

## 四、使用规范

你应遵守适用法律法规及本协议，不得利用应用从事违法活动，不得侵害他人知识产权、隐私权或其他合法权益，不得试图破坏应用、设备或相关服务的安全与正常运行。你应对自己创建、导入、同步和分享的内容及操作负责。
