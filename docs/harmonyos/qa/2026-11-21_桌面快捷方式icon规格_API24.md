# 桌面静态快捷方式 icon 规格（API 24，2026-11-21）

> 背景：[v2.0](../../releases/v2.0/需求文档.md)（应用图标长按静态快捷方式）落地时长按弹层里快捷方式图标直接复用了应用启动图标，显示成「应用图标」而不是系统应用（如备忘录「新建便签」）那种功能入口小图标。为确定 icon 的官方规格与正确资源形态，向官方 Agent 提问（用户转交答复）。答复来源：《module.json5 配置文件》shortcuts 标签说明 + 设计侧《桌面快捷方式》《HarmonyOS Symbol 系统图标》《应用图标》规范。关键点已用本机文档库（`devecocli docs`《创建应用静态快捷方式》《shortcutManager》）复核互证。

## 问了什么（可复现粒度）

环境：DevEco Studio 26.0.0.851，`compatibleSdkVersion 6.1.1(24)`（API 24），`targetSdkVersion 26.0.0`；华为 Mate XT2 三折叠真机（系统 API 26）。场景限定：Stage 模型静态快捷方式，`resources/base/profile/shortcuts_config.json` 中 `shortcuts[].icon` 字段；现象 = icon 填了完整应用启动图标（`$media` 分层/完整图标），桌面长按弹层显示为应用图标，与系统应用功能入口小图标风格不一致。

提问（4 问）：

1. `shortcuts[].icon` 的官方规格：取值类型（`$media`？`$symbol`？）、尺寸/格式要求（SVG / PNG / 分层图标）、是否需按屏幕密度出多套资源、是否支持 `$symbol` 系统符号图标？
2. 桌面长按弹层（快捷菜单）与 X 键九宫格面板对 icon 的自动处理：是否做圆角/圆形裁剪、加浅色底容器、统一缩放？两处显示规格是否一致？
3. 系统应用（备忘录「新建便签」等）长按弹层中快捷方式图标用的什么资源/风格？与系统风格对齐可参考哪些官方设计规范文档？
4. icon 是否可省略？省略后长按弹层与九宫格分别显示什么？

末尾防编造约束：每问若无明确记载直接答「未记载」，不猜接口名、资源名或尺寸。

## 官方逐条答复（要点）

### 1. icon 字段官方规格

- 取值类型：资源文件的索引（如 `$media:xxx`）。
- 图标分单层/分层；官方推荐分层图标：前景 = 显示大小 450*450px、资源大小 1024*1024px 的透明图层；背景 = 1024*1024px。
- 设计规范支持两种资源格式：
  - SVG：建议优先提供，须透明背景、图标资源大小 24*24vp；
  - PNG：1024*1024px 正方形，无需圆角，添加到桌面由系统处理为最大圆角生成遮罩裁切。
- 是否按密度出多套资源：**未记载**。
- 是否支持 `$symbol` 系统符号图标：**未记载**（官方示例均使用 `$media` 索引）。

### 2. 长按弹层与九宫格的自动处理

- 官方明确记载的自动处理仅一条：PNG 正方形资源「添加到桌面由系统处理为最大圆角生成遮罩裁切」（圆角遮罩系统做，开发者无需自行裁圆角）。
- 长按弹层对 icon 是否做圆角/圆形裁剪、加浅色底容器、统一缩放：**未记载**。
- 长按弹层与九宫格面板显示规格是否一致：**未记载**。

### 3. 系统应用快捷方式图标的资源/风格

- 备忘录「新建便签」等系统应用快捷方式图标的具体资源：**未记载**。
- 可参考的官方设计规范：
  - 桌面快捷方式图标规范（SVG 24*24vp 透明背景 / PNG 1024*1024px）：<https://developer.huawei.com/consumer/cn/doc/design-guides/shortcat-0000002550987962>
  - HarmonyOS Symbol 系统图标规范（标准图标 24*24vp、主题物保留 22*22vp 区间、描边 1.5vp、圆头终点）：<https://developer.huawei.com/consumer/cn/doc/design-guides/system-icons-0000001929854962>
  - 应用图标规范（分层资源、1024*1024px、PNG、系统自动生成遮罩裁切）：<https://developer.huawei.com/consumer/cn/doc/design-guides/application-icon-0000001953444009>
- 结合现象的定性：复用完整应用启动图标（带背景层的完整图标）→ 显示为「应用图标」而非功能入口小图标。要与系统应用功能入口风格对齐，应提供**透明背景、24*24vp 的 SVG 单色功能图标**（或 1024*1024px 透明前景 PNG），而不是完整应用图标；系统应用弹层小图标视觉上对应 Symbol 类 24*24vp 线性图标风格。

### 4. icon 可否省略

- 可以省略：官方标签说明 icon「该标签可缺省，缺省值为空」。
- 省略后长按弹层与九宫格分别显示什么：**未记载**（建议真机验证）。

### 补充说明（答复附带）

- 桌面展示快捷方式数量上限 4 个。
- API version 20 起 shortcuts 支持 `visible` 子标签控制快捷方式是否显示。
- 运行时隐藏/展示：`shortcutManager.setShortcutVisibleForSelf`；查询配置文件定义的快捷方式：`getAllShortcutInfoForSelf`（API 20 起支持）。

## 本机文档库复核（devecocli docs）

- 《创建应用静态快捷方式》原文核实：「桌面展示快捷方式的数量有上限要求，最多展示4个」；示例 `icon` 均为 `$media:xxx`；「可以通过setShortcutVisibleForSelf接口隐藏或展示快捷方式」——与答复一致。
- 《ShortcutInfo》/《@ohos.bundle.shortcutManager》：「本模块首批接口从API version 20开始支持」——与答复 API 20 口径一致。
- 《module.json5 配置文件》shortcuts 标签子表（icon 可缺省/缺省值为空）在本机文档库读取被截断未能逐字复核，以答复转述为准。
