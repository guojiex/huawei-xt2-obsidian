# 小艺自绘按钮拉起答复与官方 API 对照（API 24）

日期：2026-10-26。来源：开发者社区帖子及华为官方 Function 组件指南/API 参考。社区答复不等于 SDK 契约；API 24 / XT2 真机运行未验证。

## 问题

能否保留普通 ArkUI 自绘按钮，并在点击时程序化拉起指定小艺智能体托管对话面板；FunctionComponent 的最低版本与自定义图标能力是什么。

## 社区帖子答复

帖子：[HarmonyOS 6/API24 能否从自绘按钮程序化拉起指定小艺智能体？](https://developer.huawei.com/consumer/cn/forum/topic/0201228430173796122?fid=0109140870620153026)。刷新后页面显示“已解决”，有两条答复：

1. **采纳答复**：称没有普通 Button 程序化拉起 API；只能由用户点击 FunctionComponent。FunctionController 仅查询/监听，没有 open/launch 方法；无自定义图标资源参数。并称组件起始于 HarmonyOS 6.0.0(API 20)，API 24 满足版本下限。
2. **AI 助手答复**：核心结论相同；额外建议在 Stack 中叠放自绘图形与 FunctionComponent，并补充 Agent 发布/测试白名单、小艺版本、地区与模拟器等运行条件。

## 官方文档核对

- [通过 Function 组件拉起智能体](https://developer.huawei.com/consumer/cn/doc/doccenter-capabilities/hmaf-function)：示例通过组件 UI 入口打开对话框；要求开发智能体、关联应用，并确保设备登录华为账号、联网。
- [FunctionComponent（功能组件）API](https://developer.huawei.com/consumer/cn/doc/doccenter-references/api/hmaf-function-component)：Phone / Tablet、Stage 模型自 6.0.0(API 20) 起支持；FunctionController 当前仅继承 AgentController 方法，无额外实现。API 列出的控制器能力是 isAgentSupport 查询及 opened/closed 事件，未提供程序化打开方法。
- 同一 API 中 FunctionOptions / BaseOptions 有 buttonType、title、iconSize、iconColors、backgroundColor、titleColors、isShowShadow、queryText 等参数，没有自定义图片资源字段。API 24 高于起始版本，但这不能替代 XT2 真机验证。

## 结论与边界

- 两条答复在核心 API 结论上并不矛盾；差异是第二条加入了 Stack 叠放建议和额外运行条件。
- Stack 叠放不是官方指南/API 的方案，未证明普通 Button 可触发 FunctionComponent，也未验证触摸命中与最终视觉效果。若尝试，只能作为独立 UI spike，不能视为已确认的启动接口。
- 本次核对的官方页面支持“创建 Agent、关联应用、登录华为账号、联网”这些前置条件；AI 答复中的小艺精确版本、地区、测试白名单与不支持模拟器等具体条件，尚未从这些官方页面证实。
- 原设计要求保留自绘按钮，因此当前不接入未经证实的调用；设计调整前维持外部依赖队列。API 主结论见 [api_notes F1](../api_notes.md)。
