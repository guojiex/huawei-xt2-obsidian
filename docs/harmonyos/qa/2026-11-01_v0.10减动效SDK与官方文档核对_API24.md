# v0.10 减少动态效果：本机 SDK 与官方公开资料核对

> 日期：2026-11-01。此文件是本机声明与公开官方资料的核对记录，不是华为官方 Agent 答复，也不是 API 24 / XT2 运行实测。

## 核对环境与问题

- 工程兼容 API：6.1.1 (24)；当前机器只安装 DevEco Studio 26.0.0.851 内的 HarmonyOS SDK 26.0.0.105。
- 对照 v0.10 10.7：是否能用 API 24 应用安全识别系统“减少动态效果”偏好，并据此缩短或取消 ArkUI 导航动画。
- 检查本机 `ets/api/@ohos.settings.d.ts`、本仓 `docs/harmonyos/api_notes.md` 与官方公开文档；本 SDK 源码全文检索 `reduce motion`、`ANIMATOR_DURATION_SCALE` 等词。

## 声明 / 文档证据

1. 本机 `@ohos.settings.d.ts` 声明 `settings.display.ANIMATOR_DURATION_SCALE: string`，注释表示它是“动画时长缩放因子”，`@since 7`，`@deprecated since 21`。它没有说明该项等同于无障碍“减少动态效果”偏好。
2. 同一声明文件的 Stage `settings.getValue(context, name): Promise<string>` 标注 `@since 10`。这证明本机 SDK 声明的接口起始版本低于 API 24；不证明 API 24 / XT2 运行时可读取该设置项或读取结果含义。
3. SDK 全文检索只找到 `ANIMATOR_DURATION_SCALE` 和 `TRANSITION_ANIMATION_SCALE` 常量，没有发现 Reduce Motion API 或 ArkUI 与该缩放项联动的声明。
4. 官方 [ArkUI 动画样式文档](https://developer.huawei.com/consumer/cn/doc/doccenter-references/api/js-components-common-animation)描述动画属性和时长配置；官方 [Accessibility Kit 概览](https://developer.huawei.com/consumer/en/doc/harmonyos-guides-V5/accessibilitykit-overview-V5)描述无障碍状态、触摸探索状态与无障碍事件。核对到的页面没有说明上述缩放项代表减少动态效果偏好，亦没有说明系统缩放会作用于本应用 ArkUI 属性动画。该页面核对不是对全部官方文档的穷尽证明。

## 结论

- **接口声明：✅** `getValue` 的 Stage 重载在本机 SDK 标注 since 10；只说明声明版本。
- **偏好语义与 ArkUI 联动：❓** 公开证据不足，旧缩放项仍标记弃用；不将其接入 v0.10 原生动画关键路径，不将值 `0` 推定为系统无障碍偏好。
- **API 24 / XT2 运行行为：未验证。** 本轮未调用接口、未改变系统设置，也未在设备观察动画。
- 后续若仍需履行 10.7 的系统偏好响应，需有官方明确说明或可复核的 API 24 / XT2 验证；不得把应用自有开关当成系统偏好，除非产品范围另有决定。
