# 应用反馈能力核实（API24）

用户转交的 AI 答复先声称存在 Feedback Kit，随后明确撤回：该名称来自第三方华为云社区博客，并非已检索到的官方独立 Kit 文档。原答复的 rsub 引用不是可访问的证据链接；智能分类/闭环追踪、附件期限与运营后台适用范围不能据此作为本应用能力承诺。

本机 DevEco SDK 26.0.0.105 核对：

- `hms/ets/api/@hms.core.appgalleryservice.commentManager.d.ts` 声明 `showCommentDialog(context): Promise<void>`，起始 6.0.0(20)，用于应用评分评论；有未登录、评论频率限制等错误，不能替代问题反馈。
- `hms/ets/api/@hms.core.atomicserviceComponent.atomicserviceUi.d.ets` 的 `FunctionalButtonController.onFeedback` 起始 6.0.0(20)，注释明确仅元服务可用；不能直接用于当前普通应用。
- `@hms.hiviewdfx.feedbackService.d.ts` 只有导出占位，没有可调用签名；`@kit.ServiceSupportKit` 仅公开 deviceDetection，不能据文件名推断通用反馈 SDK。

官方参考：[应用评论指南](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/appgallery-comment)、[评论 API](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/appgallery-commentmanager)、[FunctionalButton](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/scenario-fusion-functionalbutton)。本轮在线抓取官方指南返回动态空壳/API 页面超时，因此上面签名结论基于 SDK 声明，不代表 API24/XT2 实测。

用户最终选择反馈邮箱，收件地址配置在 `app_config.json`，不采用未经证实的 SDK。自建表单不会自动把数据接入华为运营后台；目前没有这条链路的证据。本次不新增评分功能或原生邮件接口。
