## 结论与边界

- API 26 SDK 声明的 API 起始版本低于工程 `compatibleSdkVersion 24`；这是类型声明证据，不证明 API 24 设备运行时行为。
- SDK 描述了 ArkUI PinchGesture 的识别参数与回调，但没有说明它和 ArkWeb 内部滚动、页面默认缩放或 DOM 触摸事件的仲裁顺序。
- v1.12 当前保留固定比例控件，不在不确定的事件竞争关系上接入双指或 Ctrl+滚轮。是否支持触控缩放需经正常交互验证及后续需求评估；不得把原型行为或 API 注解写成设备验收通过。
