# 待问：API24 系统减少动态效果偏好与 ArkUI / ArkWeb 动画响应

项目：曜石笔记，ArkTS Stage，`compatibleSdkVersion 6.1.1(24)`，目标设备含 XT2（系统设备类型 phone）。当前 v0.10 导航动画使用 ArkUI `.animation({ duration: Motion.durNav, curve: Motion.navCurve })`；v2 浏览器原型有 CSS `prefers-reduced-motion: reduce` 媒体查询。实现要求：系统减少动态效果时缩短或取消过渡，但保持相同开关语义、终态和焦点规则。

本机 DevEco Studio 26.0.0.851 随附 API26 SDK 的 `@ohos.settings.d.ts` 声明 `settings.display.ANIMATOR_DURATION_SCALE` 为 since 7、deprecated since 21；同一 SDK 随附 API 参考明确说该常量“不支持使用”。`ACCESSIBILITY_STATUS` 仅表示是否启用任一无障碍功能，不能代替减少动态效果偏好。对本机 API26 ArkTS 声明的检索未找到 `reduceMotion` / `reducedMotion` API。以上均是 SDK / 本机参考核对，不是 API24 或 XT2 运行实测。

请逐项回答并提供可访问的 HarmonyOS 官方文档链接、章节、API 起始版本、Kit、SystemCapability、权限与应用模型限制：

1. API24 普通 Stage 应用读取系统“减少动态效果 / 减弱动画”偏好的受支持接口是什么？如果没有公开接口，请明确说明“不支持”或“官方资料未记载”，不要猜接口名。
2. 如果没有可读取的偏好接口，ArkUI `.animation`、`animateTo` 或组件转场是否会自动遵循系统减动效设置？各自有哪些明确文档或 API24 / XT2 实测证据？
3. ArkWeb 中 CSS `prefers-reduced-motion` 是否会在 XT2 / API24 反映系统设置？若会，提供受支持版本与官方说明；若资料未记载，请明确标未知。
4. 现有 `ANIMATOR_DURATION_SCALE` 被 SDK 随附参考标注“不支持使用”且 deprecated since 21。是否存在受支持的替代 API？请勿建议继续读取旧常量、写系统设置或用整体 `ACCESSIBILITY_STATUS` 推断减动效偏好。
5. 若 API24 没有公开读取途径且动画不会自动遵循，官方对普通应用的建议是什么？若无官方建议，请明确说明缺失，区分可由应用自行提供的设置与跟随系统偏好。
