## 复制区开始（完整版）

我是 HarmonyOS 应用开发者，正在为**华为三折叠设备（Mate XT / XT2）**开发一款本地 Markdown 笔记应用，需要你帮我核实一批技术细节。

请先记住我的环境，后续所有回答都必须基于这个版本：

- DevEco Studio 26.0.0.851
- `compatibleSdkVersion: 6.1.1(24)` —— 也就是 **API 24**
- `targetSdkVersion: 26.0.0`，`runtimeOS: HarmonyOS`
- Stage 模型 + ArkTS，`deviceTypes` 目前是 `["phone", "tablet", "2in1"]`
- 已申请权限：`ohos.permission.INTERNET`

我的应用有几个特殊之处，会影响你的判断：

1. **它是三折叠**，所以有单屏态 / 双屏态 / 三屏展开态三种形态，断点不是常见的两档而是三档。
2. **我在 Web 组件里运行 isomorphic-git**（纯 JS 的 git 实现），通过自定义 fs 与 http 客户端把 IO 转发到 ArkTS 侧：文件读写走 `@ohos.file.fs`，网络请求走 `@ohos.net.http`。所以我对 Web 组件的行为细节有特殊要求。
3. 笔记库存放在应用沙箱 `filesDir/vaults/<库名>/` 下，纯文件树，可能有上千个 `.md` 文件。

请按下面五组逐条回答，每条给出：**结论 → 准确的接口名/属性名（API 24）→ 最小可用代码片段或调用顺序 → 官方文档链接**。

### A 组：三折叠形态与折痕（最高优先级，直接决定我的布局方案）

A1. 在 **API 24** 下，获取当前折叠形态（展开/折叠/半折）的**准确接口名**是什么？是 `display` 模块下的折叠状态接口，还是 `screen` 模块？请给出完整导入路径与方法签名。

A2. 获取**折痕区域**（crease / fold region）的接口在 API 24 下叫什么？返回值是什么结构（Rect 数组？单个 Rect？）？**对于三折叠设备，它会返回几段折痕？** 我需要把 UI 分栏的边界压在折痕上，所以必须拿到真实折痕位置，不能按等分假设。

A3. 我的三档断点是靠 `window.on('windowSizeChange')` 拿 `size.width` 再用 `px2vp()` 换算成 vp 判断的。请确认：在 API 24 下这是**推荐做法**吗？还是有更准确的获取窗口 vp 宽度的方式（比如从窗口属性或 display 对象直接取）？

A4. 折叠态切换（比如双屏展开成三屏）时，**UIAbility 会不会重建**？会不会触发 `onDestroy` + 重新 `onCreate`？如果会，我需要在 `module.json5` 里配置什么来避免（比如把窗口尺寸变化排除在配置变更之外）？我需要保证切换时用户正在编辑的笔记不丢。

A5. 三折叠设备全展开态（约 10 英寸）在系统看来是 tablet 还是 2in1？我的 `deviceTypes` 填 `["phone", "tablet", "2in1"]` 是否合适，还是需要调整？

### B 组：Web 组件（决定我的编辑器方案是否成立）

B1. `runJavaScript()` 单次调用的**脚本字符串长度有没有上限**？我需要把大文本（100KB 级别的 Markdown 源码，以及 git packfile 的 base64 结果）通过它传入传出。如果有上限，具体是多少，官方推荐的替代方案是什么（分片？还是改用别的通道）？

B2. 一个 **1×1 像素**或 `visibility(Hidden)` / `opacity(0)` 的 Web 组件，其内部的 JavaScript **是否会正常执行**？我需要一个"只做计算、不显示"的 WebView 来跑 git 逻辑，请确认这种做法可行，以及有没有更合适的隐藏方式。

B3. Web 组件加载的页面里**能否使用 Worker**？如果在 Worker 里，我通过 `javaScriptProxy` 注入的原生对象**还能访问吗**（Worker 内没有 window）？如果不能，跨线程调用原生能力应该走什么通道？

B4. 通过 `$rawfile()` / `resources/rawfile` 加载的本地 HTML 页面，它的 **origin 是什么**？页面内发起的网络请求（fetch / XHR）是否受同源策略限制？（背景：我实测发现 github.com 的 git 端点不返回 CORS 头，WebView 内 fetch 被拦，所以我已经改成把请求转发到原生 `@ohos.net.http`。请确认这个规避思路是官方推荐的做法，还是有更好的方案。）

B5. 折叠形态切换导致 Web 组件尺寸变化时，页面**会不会重新加载**（`onPageEnd` 是否重新触发）？我需要保住页面内的滚动位置和编辑内容，官方有没有推荐的 resize 处理方式或应避免的坑？

B6. 在 Web 组件内的 `contenteditable` 或 `textarea` 里，**中文输入法的候选词跟随、光标定位**是否完整支持？有没有已知的输入法兼容性问题或在 Web 侧必须做的配置？

### C 组：文件系统与存储

C1. `@ohos.file.fs` 的 `renameSync(src, dest)` 在 **dest 已存在**时的行为是什么？会覆盖吗？覆盖是**原子**的吗？（我在用它实现笔记的原子写：先写 `xxx.md.tmp` 再 rename 覆盖目标，防止写一半崩溃损坏笔记。）非原子的话，官方推荐的原子写方式是什么？

C2. 遍历含上千个文件的目录时，`listFileSync` 有无分页或性能上限？在 **TaskPool 子线程**里能否正常调用 `@ohos.file.fs` 的全部接口？有没有必须在主线程调用的接口？

C3. **关键资产存储服务（Asset Store Kit）**在 API 24 下的**准确模块名与接口**是什么？我要存用户的 GitHub / Gitee 访问令牌。需要申请额外权限吗？请给出写入与读取的最小调用示例。

C4. 工程自动生成的 `EntryBackupAbility`（backup extension）配合 `backup_config.json`，能否备份整个 `filesDir/vaults/` 目录（含子目录与上千文件）？有没有备份体积上限或目录限制？

### D 组：HAR 打包与 ohpm 发布（我打算把这个 git 桥接层开源发布）

D1. 如果我建一个 **Static Library（HAR）模块**，把 HTML/JS 放在它的 `src/main/resources/rawfile/` 下，那么**依赖这个 HAR 的主模块**能否直接用 `$rawfile('xxx/index.html')` 加载它？资源在编译期是否会合并进主 HAP？如果不行，正确的加载方式是什么（比如用 `resourceManager` 读出内容后写入临时目录再加载）？

D2. 请给出在 **ohpm.openharmony.cn** 发布三方库的当前完整流程与硬性要求：需要哪些必备文件、HAR 必须用 release 模式构建吗、审核周期大概多久、库名被占用后的规则是什么。

### E 组：其他

E1. 在应用**沙箱目录**（`filesDir`）内读写自己创建的文件，是否需要申请任何权限？我目前只申请了 `INTERNET`，是否有遗漏？

E2. `@ohos.net.http` 以 `HttpDataType.ARRAY_BUFFER` 接收响应时，**单次响应体大小有无限制**？对大响应（几十 MB 的 git packfile）有无官方建议（流式读取？分片？）？

E3. 我的应用需要长时间持有网络请求（git clone 可能持续数十秒），是否需要申请后台网络或长时任务相关的权限/能力？

### 回答约束（重要，请务必遵守）

1. **每条答案请标注你所依据的 API 版本**。如果我问的接口在 API 24 已改名或废弃，请明确指出"旧名是 X，API 24 应为 Y"。
2. **不确定就直接说"不确定"**，不要猜测接口名。编造的接口名对我有害——我会直接写进代码并在真机上浪费大量时间调试。
3. 涉及行为结论（比如"会不会重建""是否原子"）时，请说明这是**文档明确记载**还是**你的推断**。
4. 如果某个需求在 HarmonyOS 上有**官方推荐的标准做法**且与我的方案不同，请直接指出并说明原因——我更想用官方方案，而不是自己造轮子。
5. 请优先给**准确接口名 + 文档链接**，代码示例可以简短。
