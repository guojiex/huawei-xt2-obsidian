## 1. 针对三折叠设备的应用和服务设计（与 XT2 直接相关）

### 1.1 三折叠响应式布局（三种布局手法）

| 布局 | 定义 | 适用场景 |
| --- | --- | --- |
| **重复布局** | 宽屏下重复同一内容单元，避免结构单调、信息量过少，改善浏览舒适度和使用效率 | 列表、卡片流 |
| **延伸布局** | 宽屏设备上内容横向延伸，结合物理尺寸适当**形变、自适应裁剪**，确保显示效果 | 图片、单栏内容 |
| **挪移布局** | 利用屏幕宽度优势，把**上下结构变为左右结构**，避免内容仅横向延伸过于单调 | 详情页、图文混排 |

### 1.2 三折叠价值场景

共四类：**影音娱乐类、新闻阅读类、图文笔记、自由多窗**等。

| 场景 | 官方建议 |
| --- | --- |
| 影音娱乐（短视频） | 单屏态：评论区从屏幕底部弹出；**双屏态 / 三屏态：评论区从右侧展开**，边看边评 |
| 新闻阅读 | 详情默认全屏沉浸式；**允许用户手动切换布局**，将评论区挪移到右侧，边看边评 |
| **图文笔记**（即我们这类应用） | 笔记详情随屏幕变宽，**双屏态和三屏态建议采用挪移布局**：文字挪移至图片右侧，左图右文对照。**双屏态图文区域宽度比建议 6:4，三屏态建议 1:1** |

> 注意：6:4 / 1:1 是「单篇图 + 文详情页」的**内容区内部比例**建议，不是分栏比例。

## 2. 针对阔折叠设备的应用和服务设计（**不适用于 XT2，仅存档**）

> XT2 是三折叠，不是阔折叠（外屏/内屏双形态）设备。本节仅留档备查，**设计稿不引用本节结论**。

### 2.1 通用基础体验

- **布局完整**：折叠、展开、横竖屏切换时，图片/视频等元素避免错位、截断、变形模糊；外屏文字、图标大小与内屏一致。
- **导航条适配**：外屏不显示导航条，也不显示其占用的纵向空间。
- **状态栏适配**：外屏隐藏状态栏，释放纵向空间。
- 另有：多窗适配、画中画适配。

### 2.2 组件适配

- **标题栏**：外屏大标题切为小标题，减少留白。
- **搜索框**：外屏切换为搜索图标，与标题栏同行。
- **索引条**：分段式索引条，长按指定分段可滑动选取具体字母。
- 另有：弹出框、半模态。

### 2.3 典型场景

- **图文详情页（单图）**：上图下文，图片等比缩放，**高度 ≤ 窗口高度 60%**，确保图文都在窗口内。
- **图文详情页（多图）**：等比缩放后，原滑动显示的图片改**延展布局**显示。
- **长视频**：画面区域完整显示，顶部固定冻结区域；上滑可等比缩放至屏幕高度 40%，下滑恢复；全屏播放**窗口不旋转**。
- **短视频**：画面完整不截断；横比例（16:9、21:9、4:3）宽度占满、自适应缩高；纵比例（9:16）高度占满纵向内容区、自适应缩宽。
- **直播弹幕**：底部弹幕最大高度 ≤ 窗口高度 50%。

## 3. 对照我们的设计稿（结论）

> 对照对象：`docs/mvp_design.md` §2（形态与断点）、§2.3（折痕避让）、§8（DoD）。

### 3.1 被官方背书、无需改的

| 官方指南 | 我们已有的对应设计 |
| --- | --- |
| 挪移布局：上下结构变宽后变左右结构 | sm 底部分段切换 → md/lg 多栏（`mvp_design.md` §2），方向被官方背书 |
| 官方把**图文笔记**点名为三折叠价值场景 | 我们这类应用正是官方认定的三折叠核心场景 |
| 布局完整：切换不错位、截断、变形 | DoD「无控件溢出」+ Web 组件 ≤ 7680px 物理像素约束（硬约束 12） |
| 重复/延伸布局：宽屏下内容不能只横向拉伸 | 「侧栏比实际需要宽 → 每条笔记多显示一行修改时间与字数」（`mvp_design.md` §2.3） |

### 3.2 要警惕、别照抄的

| 官方建议 | 为什么不能直接套 |
| --- | --- |
| 图文 6:4 / 1:1 宽度比 | 那是「单篇图 + 文详情页」的建议。我们的分栏宽度由**折痕避让**决定（`mvp_design.md` §2.3：一栏占一整块物理屏），套官方比例会导致栏边界跨折痕 |
| 阔折叠全部规则（状态栏隐藏、导航条适配、索引条、视频冻结区、弹幕 50%） | 那是另一类设备（外/内双屏），XT2 不适用 |

### 3.3 可吸收进后续需求的

> 两条可落地项已于 2026-10-25 登记进 `requirements_backlog.md`（预览图片高度上限 → A 节；sm 态顶栏组件适配 → D 节），版本归属以版本目录为准。

| 官方规则 | 落点 | 版本 |
| --- | --- | --- |
| sm 态组件适配：**大标题切小标题、搜索框收成搜索图标与标题栏同行** | sm 顶栏设计：M4.5 快速切换（文件名搜索）与 v1.1 全文搜索做 sm 态时直接套 | v0.4 / v1.1 |
| 图片等比缩放 + **高度上限**（详情页 ≤ 60% 窗高） | 预览区 Markdown 图片加 max-height，避免单张图撑爆预览栏 | v0.2 预览（M3） |
| 重复布局 | 未来搜索结果列表、最近打开等卡片流在宽态改多列 | v1.1+ |
| 新闻场景「允许用户**手动切换布局**」的思路 | 可作为形态适配的补充：布局档位自动切换之外，允许用户锁定/覆盖（仅记录，未立项） | 需求池 |

### 3.4 验收措辞可借用

官方「布局完整」的定义（**不错位、不截断、不变形模糊**）比我们 DoD 现有的「无控件溢出」覆盖面更全，后续版本验收条目可借用这组措辞补强形态切换项。
