| 项 | 原因 |

| 真实 Git 远端 clone / push / HTTPS 认证 | 不操作真实远端；只用本地 commit 与隔离 fixture |
| Share Kit 真实接收端交接 | 接收端可用性为真机验收项（面板层见 EM-J2） |
| 系统手势 / 指关节截图 / 折痕形态值 | v1.33 需真机；模拟器形态值正常，不复现 XT2 折痕缺陷 |
