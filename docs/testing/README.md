# 模拟器回归测试

> 本目录维护**模拟器回归测试用例**：在 API26 模拟器上对曜石笔记做版本回归时「测什么、怎么测、什么不算数」。
> 用例见 [模拟器回归用例.md](模拟器回归用例.md)。本 README 只定环境、边界与记录规则，不复制用例。
> 自动化子集见 [UI自动化测试.md](UI自动化测试.md)（hypium 套件 + `tools/uitest.ps1`，只覆盖 x86 可达冒烟，不替代本目录人工回归）。
> 执行入口 Skill：[.agents/skills/xt2-emulator-regression/SKILL.md](../../.agents/skills/xt2-emulator-regression/SKILL.md)（不支持自动发现的模型按该文件执行）。

## 定位与边界

- 用例汇总各版本需求文档中「API26 模拟器」类验收项与跨版本回归点；**不替代** API24 / XT2 真机验收（真机由用户手动执行）。
- 模拟器结果**不外推**到 API24 / XT2；模拟器通过只证明「当前模拟器上该交互正常」，真机结论单独记录。
- 测试边界照 `AGENTS.md` 与 [实施总清单](../releases/实施总清单.md)：**不主动制造崩溃、强杀进程或写入中断**；恢复与失败注入只做单测。
- 不在模拟器验证的项（更新链路成功态、真实 Git 远端、系统手势 / 指关节截图、IME × Web 等）见用例文件「不在模拟器执行」一节，依据是 [api_notes](../harmonyos/api_notes.md) **L-8 模拟器环境限制清单**。

## 环境与前提

| 项 | 要求 |
| --- | --- |
| 目标 | API26 模拟器在线（`hdc list targets` 出现 `127.0.0.1:5555`，`const.ohos.apiversion` 为 26），且应用有**可见可操作窗口**；若 `aa dump -a` 显示 `window attached #0`（无附着窗口 / 宿主桌面锁定），先恢复窗口再执行，相关用例记「环境阻塞」，不记失败 |
| ABI | Windows 本机为 x86 镜像：先 `.\tools\abi.ps1 -Status`，必要时 `-Dual` 或 `-Set x86_64`（前提是 arm64 / x86_64 两种 libgit2 都已编，见 `AGENTS.md` Native 构建一节）；Mac arm64 镜像用默认 arm64。换架构后必须先跑对应 `native/git2_napi/build.sh` |
| 构建 | `.\tools\build.ps1`（签名构建）；安装并拉起用 `.\tools\install.ps1 -Run`。覆盖安装失败（签名不一致 / 版本降级）时按 `AGENTS.md` 已知坑处理，不盲试 |
| 夹具 | 全新安装自带首装教程库；需要多库 / 中文长文样例时以 `sample_vault/` 为真源运行 `python3 tools/generators/build_sample_vault.py` 生成；**不把个人笔记、令牌或运行时状态放入模拟器夹具** |
| 探针 | 每轮先执行 EM-C0（IME 可用性探针）：不可输入时，C 组依赖文本输入的用例一律记「环境阻塞」，不记失败 |

## 执行与记录

1. 按版本需求挑选组；发布前回归建议全量，日常小改动至少跑用例文件标注的**冒烟子集**。
2. 视觉 / 交互结论必须有截图或 HDC 控件树佐证；警惕「截图纯白但视觉模型看出文本」的幻觉（L-8），关键结论需像素检测或日志佐证。截图可暂存 `.local/shots/`（gitignore），验收记录写结论与关键观察，不依赖本地路径长期有效。
3. 执行结果一律记入**对应版本需求文档 §6 验收记录**，模拟器、Node、构建、真机四类证据分开写；本目录只维护用例，不记录执行进度与通过计数。
4. 用例与实际实现脱节时，以版本需求文档为准，先修订用例再执行；被否决或移出的功能，用例标注废弃原因后保留，不删除。
