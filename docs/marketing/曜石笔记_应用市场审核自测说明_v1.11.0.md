## 2. 权限用途说明

应用仅申请两个权限，均为实现下述功能所必需，无后台行为、无超范围采集：

| 权限 | 授权方式 | 用途 | 申请时机 |
| --- | --- | --- | --- |
| ohos.permission.INTERNET | system_grant | 用户主动配置 Git 远端仓库时的 clone / pull / push 同步；应用内检查更新 | 安装即授予，仅在使用同步 / 检查更新功能时发起网络请求 |
| ohos.permission.FILE_ACCESS_PERSIST | user_grant | 记住你授权的笔记目录，重启应用或设备后仍能直接读写该目录，无需重新选择（外部笔记库功能，v1.5 起） | 仅当用户主动选择「从外部目录打开笔记库」并经系统选择器授权时申请；不选择则永不申请 |

不申请定位、通讯录、短信、通话记录、相机、麦克风、剪贴板常驻监听等任何其他权限；笔记内容不进埋点（埋点仅用系统 hiAppEvent 采集功能使用计数，不含标题 / 文件名 / 路径 / 正文 / 标签）。

## 3. 本版本主要更新（1.10.0 → 1.11.0）

本版本为 1.10.0 提审被拒后的整改重提，核心整改与新增功能：

1. **直板手机布局走查整改**（对应审核引用的 2.1.2.1 布局基础要求）：按《通用应用 UX 体验标准》逐面走查直板单栏形态，修复错位 / 截断类显示缺陷；滚动边界反馈统一补齐（全部滚动容器开启边界回弹动效）。
2. Git 同步页重构：同步浮窗升级为全屏页面，推送前按文件卡片分组展示逐行差异；宽屏右栏铺满为代码查看器。
3. 写作统计重设计：统计迁移为独立工作区页面，成就面板重做，新增年度回顾（年份切换、活跃天数与逐月柱状）。
4. 应用级备份与恢复：全部笔记数据可导出为备份包并从备份恢复。
5. 回收站支持一键清空（逐条永久删除，失败条目保留可重试）。
6. 系统打开 Markdown：注册为系统可打开 .md 文件的应用，无需笔记库即可只读预览单个 Markdown 文件，不入库、不写回源文件。
7. PDF 导出升级为矢量输出：文字可选中可搜索，分页遵循印刷级规则，预览即产物。
8. 收藏笔记：侧栏新增「收藏」分区，文件树行尾星标与笔记菜单均可收藏 / 取消。
9. 桌面图标长按快捷方式：直达「新建笔记」与「搜索」。
10. 空笔记品牌蓝占位提示打字起点；左滑置顶按钮图标化；文件树深层级缩进封顶。
11. 分享长图入口按内容预估隐藏：超长笔记不展示「长图」选项并提示 PDF 替代方式。

另含若干缺陷修复（ZIP 导入误判、多页 PDF 只出第一页、空栏点击无响应等），完整列表见应用内「设置 → 版本记录」。

## 4. 功能操作指南（供审核验证）

全部功能无需注册登录、无需网络即可使用（Git 同步与检查更新除外）。

### 4.1 基础流程

1. **首启**：全新安装不预置示例内容，首次启动创建空白「我的笔记」知识库，可直接新建笔记（此前版本的内置教程样例库已于 1.10.0 移除，如旧审核材料提及请以本版为准）。
2. **新建 / 编辑**：侧栏「+ 新建笔记」或在文件树新建；编辑器实时保存，无需手动保存。
3. **多栏布局**：XT2 展开态三栏（导航 / 正文 / 参考），双栏、直板单栏按窗口宽度自适应；正文 / 参考分栏宽度可拖动调节。
4. **删除与恢复**：左滑笔记行呼出操作条删除（进回收站，可恢复 / 永久删除 / 清空）；左滑到底直接删除并弹 5 秒撤销条。

### 4.2 新增功能验证路径（1.9.0 之后）

| 功能 | 操作路径 |
| --- | --- |
| 收藏 | 文件树笔记行尾星标点击，或笔记「⋯」菜单 → 收藏；侧栏「收藏」分区查看 |
| 备份恢复 | 设置 → 备份与恢复 → 导出备份 / 从备份恢复 |
| 回收站清空 | 侧栏回收站展开 → 底部「清空回收站」→ 确认弹窗 |
| Git 同步差异页 | 库管理 → Git 同步 → 有待推送改动时全屏差异页逐文件查看、推送 |
| 统计与年度回顾 | 侧栏统计入口 → 独立统计页 → 年度回顾切换年份 |
| PDF 矢量导出 | 笔记 → 分享 → PDF → 预览弹窗逐页查看 → 导出 |
| 桌面快捷方式 | 系统桌面长按应用图标 → 新建笔记 / 搜索 |
| 系统打开 .md | 系统文件管理器打开任意 .md 文件 → 选择曜石笔记 → 只读预览 |
| 空笔记占位 | 新建空白笔记，可编辑栏显示品牌蓝打字起点提示 |
| 缩进封顶 | 文件树建 4 级以上深层文件夹，行缩进第 4 级封顶，笔记名不被挤没 |
| 置顶图标化 | 左滑笔记行 → 置顶按钮显示图钉图标（已置顶显示取消置顶） |

### 4.3 审核重点自查项

- 空态 / 错误态均有可理解的文案与引导，无空白死页。
- 弹窗默认焦点在「取消」等安全侧，危险操作（永久删除、清空回收站、重置数据）均有确认。
- 深色模式跟随系统，全量颜色引用设计 token，无黑白反色硬编码。
- 单直板形态下导航可用返回键 / 手势逐级退出，无死角层级。
