曜石笔记

## 应用介绍（当前稿）

折叠时，随手记下想法；展开后，让资料、写作与预览各有空间。

曜石笔记是一款面向华为 Mate XTs / XT / XT2 三折叠屏设计的本地 Markdown 笔记应用。从单屏记录到展开整理，让阅读、写作和查阅资料在同一个工作区里完成。

【随屏展开的工作区】
单屏时专注当前笔记，需要时展开文件列表；大屏下同时查看目录与笔记，按需开启双栏、调整分栏宽度，为长文阅读和资料整理留出合适的空间。

【双栏对照，边读边写】
同时打开两篇笔记，一边查阅资料，一边整理思路；也可以在两栏中打开同一篇笔记，一边编辑 Markdown，一边预览排版。两栏均可切换编辑与预览，适应不同的写作习惯。

【用 Markdown 组织内容】
不熟悉语法也能上手：简单模式下直接在排版后的正文里书写，表格、公式、代码、链接、图片与待办通过底部格式栏点按插入；想掌控细节时切换专业模式，用标题、列表和引用梳理想法，用代码块、数学公式与 Mermaid 图表表达细节。

【把笔记整理成知识库】
用多个知识库区分不同主题，再通过多级文件夹整理内容，支持从 ZIP 压缩包导入已有笔记。跨库搜索按库分组呈现结果，也可在当前库内按文件名或正文查找；通过章节导航定位长文，用双向链接连接相关内容，让零散记录逐步形成自己的知识脉络。列表支持排序与置顶，误删的笔记可在回收站找回；统计面板按库汇总笔记数、总字数与写作热力图，帮助回顾自己的积累。

【方便阅读，也方便分享】
预览正文支持缩放，配合浅色与深色主题，按自己的习惯阅读。需要分享时，可将笔记导出为 PDF、生成单篇长图，或通过 Markdown 文件、ZIP 打包分享单篇、文件夹与整个知识库，便于交流与留存。

请妥善保存重要内容：保存在应用内的笔记和知识库，可能因卸载应用或重置数据而丢失。建议定期导出需要保留的内容。

## 推荐视频_纯录屏方案

采用约 **30 秒的应用录屏 + 字幕**，无需外拍、露脸或配音，轻音乐可选。XT2 保持全展开，重点展示「切换笔记」和「编辑后预览」，先录清楚操作，再处理剪辑、字幕和音乐。

### 录制前准备

- 使用专门的演示笔记库，准备两篇内容充实、排版清楚的笔记，以及一篇可实际编辑的笔记。
- 开启免打扰，检查账号、令牌、私人路径与通知等信息没有出现在画面里。
- 字号适当调大，先试录几秒并回看，确认缩小后正文仍能看清。
- 提前走一遍下面的操作，只展示当前录制版本中已确认可用的功能。

### 30 秒成片脚本

| 成片时间 | 屏幕操作 | 后期字幕 |
| --- | --- | --- |
| 0～5 秒 | 停在内容充实、排版清楚的笔记页面，展示完整工作区 | 曜石笔记，为三折叠展开 |
| 5～12 秒 | 点开文件夹，切换两篇笔记，展示目录与正文的关系 | 三栏浏览，查找更顺手 |
| 12～22 秒 | 打开提前准备好的笔记，输入一句话，再展示预览；可提前准备同篇笔记的编辑与预览双栏 | 用 Markdown，记下你的想法 |
| 22～30 秒 | 回到最好看的完整工作区，停留几秒 | 曜石笔记 · 本地 Markdown 笔记 |

### 实际录制与剪辑

1. 真机录制使用系统录屏；模拟器可运行[HDC 截图录制脚本](../../tools/record_emulator.py)。脚本默认连接 `127.0.0.1:5555`，在模拟器端连续截图后批量拉回，并按实测采集速度合成 30fps MP4。运行示例：

   ```bash
   python3 tools/record_emulator.py \
     --duration 30 \
     --output "docs/marketing/素材/_中间素材/应用推荐视频_模拟器样片.mp4"
   ```

   需要 `ffmpeg` 在 PATH 中；Mac 默认尝试 DevEco Studio 自带的 HDC。模拟器采集是抽帧，动作更新速度受设备截图速度限制，不能等同于系统连续录屏。
2. 保持全展开状态，按脚本顺序操作；无需为了表现折叠形态而中途折叠设备。
3. 每做一个动作停约两秒，让观众看清变化。输入一句短文字即可，避免长时间等待打字。
4. 一次录制一两分钟的原始素材。点错或等待时继续录，剪辑时删除多余片段，不必每次从头重录。
5. 挑出最清楚的约 30 秒，按表格加字幕；先保证操作可读，再按需添加轻音乐。
6. 脚本默认导出 1920×1080 / 16:9 横版。10:7 模拟器画面会等比缩小后居中，左右补白，不裁掉目录或编辑、预览栏。竖版渠道需另行制作 1080×1920 版本，并保持原画面比例。

### 当前模拟器样片

[教程库模拟器样片](素材/_中间素材/应用推荐视频_模拟器样片.mp4)：30.7 秒、1920×1080 / 16:9、H.264 / 30fps、无音轨。由[录屏脚本](../../tools/record_emulator.py)在 DevEco Huawei_TripleFold API 26 模拟器上批量采集 153 张 1920×1344 截图，实测约 4.98 张/秒，再合成为 30fps 视频；原画面等比缩小至约 1542×1080 并居中，左右白边补足画布，不裁切内容。成片按输出帧率重复显示截图以保持时长，因此笔记切换可见，但动作更新约每秒 5 次，流畅度仍低于系统连续录屏。样片展示教程库中的多篇笔记切换和双栏工作区，不代表 XT2 / API 24 真机验收；尚未加字幕或音乐，尚未重新上传。
