## 应用介绍（当前稿）

折叠时，随手记下想法；展开后，让资料、写作与预览各有空间。

曜石笔记是一款面向华为 Mate XTs / XT / XT2 三折叠屏设计的本地 Markdown 笔记应用。从单屏记录到展开整理，让阅读、写作和查阅资料在同一个工作区里完成。

【随屏展开的工作区】
单屏时专注当前笔记，需要时展开文件列表；大屏下同时查看目录与笔记，按需开启双栏、调整分栏宽度，为长文阅读和资料整理留出合适的空间。

【双栏对照，边读边写】
同时打开两篇笔记，一边查阅资料，一边整理思路；也可以在两栏中打开同一篇笔记，一边编辑 Markdown，一边预览排版。两栏均可切换编辑与预览，适应不同的写作习惯。

【用 Markdown 组织内容】
用标题、列表、待办和引用梳理想法，用代码块、表格、数学公式与 Mermaid 图表表达细节。支持插入图片，让文字与配图放在同一篇笔记里。

【把笔记整理成知识库】
用多个知识库区分不同主题，再通过多级文件夹整理内容。按文件名或正文搜索笔记，通过章节导航定位长文，用双向链接连接相关内容，让零散记录逐步形成自己的知识脉络。

【方便阅读，也方便分享】
预览正文支持缩放，配合浅色与深色主题，按自己的习惯阅读。需要分享时，可将笔记生成图片，或通过 Markdown 文件、ZIP 打包分享，便于交流与留存。

请妥善保存重要内容：保存在应用内的笔记和知识库，可能因卸载应用或重置数据而丢失。建议定期导出需要保留的内容。
