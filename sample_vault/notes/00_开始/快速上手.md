# 快速上手

欢迎使用曜石笔记。这是随应用附带的公开样例库，所有文字都可编辑或删除，重启不会恢复成模板。

## 写下第一篇笔记

点击目录头部的 **＋** 在根目录创建笔记，也可以点击目录行尾的 **＋** 在指定目录里创建。

编辑后会自动保存。切换笔记前，应用会先保存当前内容。

## 三种形态

| 形态 | 主要布局 |
| --- | --- |
| 单屏 | 文件树抽屉，编辑与预览切换 |
| 双屏 | 文件树与编辑区 |
| 三屏 | 文件树、编辑区、预览区 |

用顶栏放大镜按文件名快速打开笔记；空输入显示最近打开。
