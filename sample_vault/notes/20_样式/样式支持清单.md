# 样式支持清单

## 基础 Markdown

标题、段落、列表、表格、引用、代码块、任务列表和标准图片已有 App 渲染路径，仍需用本样例在实际设备回归。代码块展示不等于语法着色。

## 后续扩展目标

| 样式 | 目标 |
| --- | --- |
| YAML frontmatter | 与正文分开显示属性 |
| 双链与标题链接 | 正确解析路径、别名和跳转 |
| callout | 支持 note、warning、tip 类型；折叠标记展开显示 |
| 公式 | 行内与块级公式渲染 |
| Mermaid | 本地渲染流程图，错误不影响正文 |
| 嵌入 | 本地图片与笔记引用按库解析 |
| 高亮、标签、注释 | 按 Obsidian 语义展示 |

这些是样式目标，不是当前已全部支持的承诺。当前能力以版本验收记录为准。
